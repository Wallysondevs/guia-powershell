Format-List

A tabela é ótima para comparar muitos objetos lado a lado, mas fica apertada quando o objeto tem muitos campos ou valores compridos. O Format-List (apelido fl) mostra cada objeto como uma ficha, com um campo por linha.

Você vai aprender
  • A mostrar objetos em lista com Format-List.
  • A escolher os campos da lista.
  • A ver todos os campos com Format-List *.
  • Quando o PowerShell escolhe lista ou tabela sozinho.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a ficha do paciente

A recepção do consultório tem uma tabela com os pacientes do dia: nome e horário. Mas quando o médico atende, ele quer a ficha de um paciente, com tudo, um dado embaixo do outro. A tabela é o Format-Table; a ficha é o Format-List.

1. A mesma coisa, em lista

PS> $cliente = [pscustomobject]@{ Nome = "Ana Souza"; Email = "ana@exemplo.com"; Cidade = "Recife"; Pontos = 1250 }
PS> $cliente | Format-List

Nome   : Ana Souza
Email  : ana@exemplo.com
Cidade : Recife
Pontos : 1250
Nome : Ana Souza
Cada linha é um campo: o nome do campo, os dois-pontos e o valor.

2. Escolhendo os campos

PS> $cliente | Format-List Nome, Pontos

Nome   : Ana Souza
Pontos : 1250

3. Quando o PowerShell escolhe sozinho

Se um objeto tem até 4 campos, o PowerShell mostra em tabela. Com 5 ou mais, ele passa para lista:

PS> [pscustomobject]@{ A = 1; B = 2; C = 3; D = 4 }

A B C D
- - - -
1 2 3 4
PS> [pscustomobject]@{ A = 1; B = 2; C = 3; D = 4; E = 5 }

A : 1
B : 2
C : 3
D : 4
E : 5

O Format-Table e o Format-List servem para você mandar no formato, em vez de deixar o PowerShell decidir.

4. Todos os campos: Format-List *

Muitos objetos do .NET têm campos que não aparecem na exibição padrão. O * mostra todos. Veja uma data:

PS> $d = Get-Date -Year 2026 -Month 3 -Day 15 -Hour 9 -Minute 30 -Second 0 -Millisecond 0
PS> $d | Format-List Day, Month, Year, DayOfWeek, DayOfYear, Hour, Minute

Day       : 15
Month     : 3
Year      : 2026
DayOfWeek : Sunday
DayOfYear : 74
Hour      : 9
Minute    : 30

Experimente: mostre o cliente em formato de lista, com Format-List.

$cliente = [pscustomobject]@{ Nome = "Ana"; Cidade = "Recife"; Pontos = 1250 }
$cliente

$cliente = [pscustomobject]@{ Nome = "Ana"; Cidade = "Recife"; Pontos = 1250 }
$cliente | Format-List

Quando dá errado

Formatar e depois querer o campo 
PS> $ficha = $cliente | Format-List
PS> $ficha.Nome

Igual ao Format-Table: o que sai do Format-List é desenho para a tela, não o objeto. $ficha.Nome não devolve nada. Guarde o objeto e formate só para mostrar.

Formas diferentes: lista ou tabela?

SituaçãoUse
Muitos objetos, poucos camposFormat-Table
Um objeto, muitos camposFormat-List
Valores compridos que cortam na tabelaFormat-List
Quer ver tudo o que o objeto temFormat-List *

Resumo

  • Format-List (apelido fl) mostra um campo por linha.
  • Format-List A, B escolhe os campos; Format-List * mostra todos.
  • Até 4 campos o padrão é tabela; com 5 ou mais, lista.
  • Como o Format-Table, é para a tela: use no fim.
