Parâmetros de Script e $args

Um script fica muito mais útil quando você pode mudar o que ele faz sem editar o arquivo. É só colocar um bloco param() na primeira linha: o script passa a aceitar parâmetros, igualzinho a uma função.

Você vai aprender
  • A colocar param() no topo de um arquivo .ps1.
  • A chamar o script com -Nome valor e por posição.
  • A dar tipos, valores padrão e switches aos parâmetros do script.
  • A ler argumentos soltos com $args.
  • Onde o param() precisa ficar para funcionar.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a receita com espaços em branco

Uma receita que diz "bata __ ovos com __ xícaras de açúcar" serve para um bolo pequeno ou grande. Os espaços em branco são os parâmetros: o script é o mesmo, você só preenche os valores na hora de usar.

1. Um script com param()

Vamos criar o arquivo saudar.ps1 na pasta atual. O Set-Content grava o texto entre @' e '@ (uma here-string):

PS> Set-Content saudar.ps1 @'
>> param(
>>     [string]$Nome = "visitante",
>>     [int]$Vezes = 1
>> )
>> 1..$Vezes | ForEach-Object { "Olá, $Nome!" }
>> '@

Agora rode o script de três jeitos:

PS> .\saudar.ps1
Olá, visitante!
PS> .\saudar.ps1 -Nome Ana -Vezes 2
Olá, Ana!
Olá, Ana!
PS> .\saudar.ps1 Beto 3
Olá, Beto!
Olá, Beto!
Olá, Beto!
.\saudar.ps1
Roda o script que está na pasta atual. O .\ é obrigatório: o PowerShell não roda scripts da pasta atual só pelo nome.
-Nome Ana
Preenche o parâmetro $Nome.
Beto 3
Sem nomes, os valores entram na ordem em que os parâmetros foram declarados.

Se o Windows recusar o script com uma mensagem sobre execution policy, veja a aula Política de Execução.

Experimente: o script já foi criado. Chame .\saudar.ps1 com -Nome Duda e -Vezes 2.

Set-Content saudar.ps1 'param([string]$Nome = "visitante", [int]$Vezes = 1)
1..$Vezes | ForEach-Object { "Olá, $Nome!" }'
.\saudar.ps1

Set-Content saudar.ps1 'param([string]$Nome = "visitante", [int]$Vezes = 1)
1..$Vezes | ForEach-Object { "Olá, $Nome!" }'
.\saudar.ps1 -Nome Duda -Vezes 2

2. Switch e Mandatory

Tudo o que você aprendeu em param e validação vale aqui: [switch], [Parameter(Mandatory)], [ValidateSet()]...

PS> Set-Content conta.ps1 @'
>> param(
>>     [Parameter(Mandatory)][double]$Valor,
>>     [ValidateSet("BRL", "USD")][string]$Moeda = "BRL",
>>     [switch]$Gorjeta
>> )
>> if ($Gorjeta) { $Valor = $Valor * 1.1 }
>> "{0} {1:N2}" -f $Moeda, $Valor
>> '@
PS> .\conta.ps1 -Valor 80
BRL 80,00
PS> .\conta.ps1 -Valor 80 -Gorjeta
BRL 88,00
PS> .\conta.ps1 -Valor 15.5 -Moeda USD
USD 15,50

O {1:N2} formata com duas casas e a vírgula do português (veja o operador -f). Se você esquecer o -Valor, que é Mandatory, o PowerShell pergunta o valor antes de rodar.

3. $args: o que sobrou

Um script sem param() recebe tudo em $args, uma lista com os argumentos na ordem:

PS> Set-Content lista.ps1 @'
>> "Recebi $($args.Count) argumento(s)."
>> foreach ($a in $args) { "- $a" }
>> '@
PS> .\lista.ps1 maçã uva "pão de queijo"
Recebi 3 argumento(s).
- maçã
- uva
- pão de queijo

Use $args só em scripts bem pequenos. Com param() você ganha nomes, tipos, valores padrão e ajuda automática.

Quando dá errado

param() fora da primeira linha

O bloco param() precisa ser a primeira instrução do arquivo. Comentários e linhas em branco antes dele podem; um comando antes dele, não. Com um comando antes, o PowerShell trata param como um comando desconhecido e os parâmetros não funcionam.

Esquecer o .\

Digitar só saudar.ps1 não funciona, mesmo estando na pasta certa: o PowerShell só procura comandos nas pastas do sistema. Escreva .\saudar.ps1 (ou o caminho completo).

Missão final: grave em contar.ps1 um script que mostra Total: + a quantidade de argumentos + itens (use $args.Count). Depois rode com .\contar.ps1 a b c.

Set-Content contar.ps1 '"Total: ? itens"'

Resumo

  • param() na primeira linha transforma o script num comando com parâmetros.
  • Chame com .\script.ps1 -Param valor ou por posição.
  • Tipos, padrões, [switch] e Mandatory funcionam como nas funções.
  • $args guarda os argumentos quando não há param().
