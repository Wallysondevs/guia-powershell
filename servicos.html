Serviços (Get-Service)

Alguns programas do Windows não são uma janela que você abre e fecha. Eles ficam nos bastidores, ligados ou desligados, e o sistema chama isso de serviço. O spooler de impressão, por exemplo, é o que segura a fila de páginas que vão para a impressora. Nesta aula você vai consultar um serviço pelo nome. Não vamos ligar, desligar nem reiniciar nada: esses comandos mudam o computador e, se forem usados no serviço errado, podem parar uma função que o Windows precisa.

Você vai aprender
  • O que é um serviço e como consultá-lo pelo nome com Get-Service só Windows.
  • A ler a tabelinha padrão: Status, Name e DisplayName.
  • A pedir também o StartType com Select-Object.
  • A ver de quais outros serviços o Spooler depende, com -RequiredServices.
  • Que o resultado é um objeto, com propriedades que o Get-Member lista.
  • O erro real em português de um nome de serviço que não existe.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta pessoal da usuária fictícia ana. O editor do guia é um PowerShell 7 de Linux: não conte com o serviço Spooler lá. As missões pedem que você escreva o comando certo, sem tentá-lo no editor.

Nunca use Get-Service sem um nome nos exemplos desta aula. Sem -Name, o comando lista todos os serviços do computador — uma lista longa, que inclui o que está instalado aí. Sempre consulte pelo nome, como Get-Service -Name Spooler. Ligar, parar ou reiniciar um serviço (Start-Service, Stop-Service, Restart-Service) muda o sistema e em geral pede administrador: nesta aula eles aparecem só como explicação, sem saída colhida. Se um dia precisar realmente usá-los, ensaie antes com -WhatIf.

A ideia: a equipe dos bastidores

Pense num prédio. Além das pessoas que você vê, existe uma equipe nos bastidores: o elevador, a calefação, a gráfica que imprime os avisos. Você pode perguntar "a gráfica está funcionando?" e receber um sim ou um não. Você não pede a lista de todos os funcionários do prédio, e nesta aula você também não manda ninguém ir embora nem começar o expediente.

No Windows, cada um desses "funcionários invisíveis" é um serviço. O da gráfica, nesta aula, se chama Spooler — o Spooler de Impressão.

De quem a gráfica depende para trabalhar-RequiredServices

1. Consultar pelo nome: o Spooler

O Get-Service -Name devolve um serviço. No laboratório, o da impressão:

PS C:\Users\ana> Get-Service -Name Spooler

Status   Name               DisplayName
------   ----               -----------
Running  Spooler            Spooler de Impressão
Get-Service
"Obter serviço." só Windows Consulta o estado de um serviço. Com -Name, só aquele.
Status Running
Está em execução agora. Outros valores comuns são Stopped (parado) e Paused (pausado). No seu computador, o Spooler pode estar parado — a consulta continua válida.
Name Spooler
O nome curto, o que você usa no comando.
DisplayName Spooler de Impressão
O nome em português que o Windows mostra nas telas. É o mesmo serviço, com um nome mais legível.

Experimente: o editor do guia não tem o Spooler do Windows, então não rode o cmdlet. Escreva, numa string, o comando que consulta o serviço Spooler pelo nome, e deixe o Write-Output mostrar a string.

# Escreva o comando numa string. Não chame o cmdlet.
$comando = ''
Write-Output $comando

# Escreva o comando numa string. Não chame o cmdlet.
$comando = 'Get-Service -Name Spooler'
Write-Output $comando

2. Mais um campo: StartType

A tabelinha padrão não mostra como o serviço nasce com o Windows. Para ver isso, peça o campo StartType com Select-Object:

PS C:\Users\ana> Get-Service -Name Spooler | Select-Object Name, DisplayName, Status, StartType

Name    DisplayName           Status StartType
----    -----------           ------ ---------
Spooler Spooler de Impressão Running Automatic
StartType Automatic
O serviço começa sozinho quando o Windows inicia. Outros valores comuns são Manual (só quando alguém pede) e Disabled (não deve iniciar).

A linha de dados veio com um espaço entre cada coluna, não alinhada como o cabeçalho: é a saída real do laboratório, copiada assim.

3. De quem o Spooler depende

Alguns serviços só funcionam se outros já estiverem no ar — como a gráfica, que precisa da energia e do corredor. O parâmetro -RequiredServices lista essas dependências do Spooler, ainda pelo nome:

PS C:\Users\ana> Get-Service -Name Spooler -RequiredServices

Status   Name               DisplayName
------   ----               -----------
Running  RPCSS              RPC (Chamada de Procedimento Remoto)
Running  http               Serviço HTTP

No laboratório, o Spooler precisava de dois serviços, os dois em execução: RPCSS (chamada de procedimento remoto) e http (o serviço HTTP). São nomes padrão do Windows, não uma lista de tudo o que está instalado. Se um deles estiver parado, o Spooler pode não iniciar — mais um motivo para, nesta aula, só consultar.

4. O serviço é um objeto

O Get-Service não devolve um texto solto: devolve um objeto, com propriedades. O Get-Member lista essas propriedades. Pedimos só as oito primeiras, do tipo Property:

PS C:\Users\ana> Get-Service -Name Spooler | Get-Member -MemberType Property | Select-Object -First 8

   TypeName: System.Service.ServiceController#StartupType

Name                MemberType Definition
----                ---------- ----------
CanPauseAndContinue Property   bool CanPauseAndContinue {get;}
CanShutdown         Property   bool CanShutdown {get;}
CanStop             Property   bool CanStop {get;}
Container           Property   System.ComponentModel.IContainer Container {get;}
DependentServices   Property   System.ServiceProcess.ServiceController[] DependentServices {get;}
DisplayName         Property   string DisplayName {get;set;}
MachineName         Property   string MachineName {get;set;}
ServiceHandle       Property   System.Runtime.InteropServices.SafeHandle ServiceHandle {get;}

A lista continua depois dessas oito: Status e StartType, que já usamos, também são propriedades do mesmo objeto. Três avisos práticos:

  • CanStop diz se aquele serviço aceita ser parado — é uma consulta, não um pedido para parar.
  • DependentServices são os serviços que dependem deste (o inverso de -RequiredServices). Não peça o valor sem necessidade: a lista pode ser grande.
  • MachineName é o nome do computador. Não leia esse valor na prática do guia: fique com a ficha das propriedades, sem exibir o nome da máquina.

5. Ligar, parar e reiniciar: só a ideia

Existem cmdlets que mudam o estado de um serviço:

CmdletO que faria
Start-ServiceLigar (iniciar) o serviço.
Stop-ServiceParar o serviço.
Restart-ServiceParar e ligar de novo.
Esta aula não roda esses três comandos, nem mostra saída deles. Parar o Spooler, por exemplo, interrompe a impressão. Parar o serviço errado pode derrubar rede, áudio ou atualização. Em geral eles pedem administrador. Se um dia você realmente precisar usá-los, comece com -WhatIf: o parâmetro conta o que o comando faria e não faz. É o mesmo hábito seguro da aula de criar arquivos e da aula do Registro. Não invente o texto do ensaio: rode o -WhatIf no seu Windows, só no serviço que você realmente pretende tratar, e leia a frase "What If" antes de tirar o parâmetro.

Quando dá errado

O nome do serviço não existe

Pedimos um nome que não é serviço nenhum neste Windows:

PS C:\Users\ana> Get-Service -Name 'NaoExisteGuia'
Get-Service: Não é possível localizar nenhum serviço com o nome de serviço 'NaoExisteGuia'.
Get-Service:
Qual comando reclamou.
Não é possível localizar nenhum serviço com o nome de serviço 'NaoExisteGuia'.
A mensagem veio em português. Não existe serviço com esse nome. Nada foi ligado nem parado.

Como resolver: confira a grafia. O nome curto do spooler é Spooler, não "Spooler de Impressão" (esse é o DisplayName). Não saia listando todos os serviços para "descobrir" o nome: se você não tem certeza, use a interface do Windows (Serviços) ou peça um nome que você já conheça.

Resumo

  • Um serviço é um programa dos bastidores do Windows. Get-Service -Name Spooler consulta só esse, só Windows.
  • Sem -Name, o Get-Service lista todos os serviços. Esta aula nunca faz isso.
  • A tabelinha padrão traz Status, Name e DisplayName. Com Select-Object você pede também o StartType.
  • -RequiredServices mostra de quem o Spooler depende. O resultado do Get-Service é um objeto: o Get-Member lista as propriedades.
  • Start-Service, Stop-Service e Restart-Service mudam o sistema e ficam fora dos exemplos. Se um dia for usar, comece com -WhatIf.
  • O erro de um nome inexistente saiu em português: Não é possível localizar nenhum serviço com o nome de serviço 'NaoExisteGuia'.
