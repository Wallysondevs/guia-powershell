Get-Command: Achando Comandos

Você já rodou uns comandos, mas o PowerShell tem centenas deles. Ninguém decora a lista toda. Nesta aula você vai aprender a procurar um comando pelo nome, pelo verbo ou pelo substantivo, a reconhecer se o que apareceu é um cmdlet, um apelido ou um programa, e a ler o erro de quando o nome não existe.

Você vai aprender
  • O Get-Command, que lista os comandos que o PowerShell conhece.
  • A procurar com um padrão, usando o asterisco * ("qualquer coisa").
  • Os parâmetros -Noun ("substantivo") e -Verb ("verbo").
  • A diferença entre Cmdlet, Alias (apelido) e Application (um programa .exe).
  • A contar quantos comandos existem, com Measure-Object.
  • A ler o erro real de um nome que o PowerShell não reconhece.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta pessoal da usuária fictícia ana. No Windows PowerShell 5.1 os comandos são os mesmos; quando a resposta muda, a aula avisa.

A ideia: o catálogo da biblioteca

Pense no catálogo de uma biblioteca. Você não precisa decorar todos os livros. Você pergunta: "tem algum livro com 'data' no título?", ou "me mostra os de cozinha", e o catálogo lista o que existe.

O Get-Command é esse catálogo: ele não executa o comando que você está procurando. Ele só responde "existe, e é este aqui".

1. Procurando por um pedaço do nome

O asterisco * quer dizer "qualquer coisa". *-Date é: "qualquer verbo, desde que o substantivo seja Date". Digite e aperte Enter:

PS C:\Users\ana> Get-Command *-Date

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Cmdlet          Get-Date                                           7.0.0.0    Microsoft.PowerShell.Utility
Cmdlet          Set-Date                                           7.0.0.0    Microsoft.PowerShell.Utility
Get-Command
O catálogo: "me mostre os comandos".
*-Date
O padrão de nome. O * substitui qualquer texto no começo; o -Date tem de aparecer no fim.
CommandType
O tipo: aqui, Cmdlet (comando nativo do PowerShell, no formato Verbo-Substantivo — aula Cmdlets).
Name
O nome oficial do comando.
Version e Source
A versão e o módulo de onde ele vem (uma caixa de comandos relacionados). Por enquanto, basta saber que existem.

Apareceram dois: Get-Date, que você já usou, e Set-Date, que muda a data do computador. Não rode o Set-Date nesta aula: ele altera o relógio do Windows e pede permissão de administrador.

Experimente: troque o padrão para *-Date e clique em Rodar. Você deve ver o Get-Date na lista.

Get-Command *-Time

Get-Command *-Date

2. Procurando pelo substantivo: -Noun

Se você lembra do "assunto" do comando, mas não do verbo, use -Noun:

PS C:\Users\ana> Get-Command -Noun Service

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Cmdlet          Get-Service                                        7.0.0.0    Microsoft.PowerShell.Management
Cmdlet          New-Service                                        7.0.0.0    Microsoft.PowerShell.Management
Cmdlet          Remove-Service                                     7.0.0.0    Microsoft.PowerShell.Management
Cmdlet          Restart-Service                                    7.0.0.0    Microsoft.PowerShell.Management
Cmdlet          Resume-Service                                     7.0.0.0    Microsoft.PowerShell.Management
Cmdlet          Set-Service                                        7.0.0.0    Microsoft.PowerShell.Management
Cmdlet          Start-Service                                      7.0.0.0    Microsoft.PowerShell.Management
Cmdlet          Stop-Service                                       7.0.0.0    Microsoft.PowerShell.Management
Cmdlet          Suspend-Service                                    7.0.0.0    Microsoft.PowerShell.Management
-Noun
O parâmetro: "quero só comandos cujo substantivo é este".
Service
O valor: "serviço" (os programas que o Windows deixa rodando em segundo plano). A aula deles é bem mais à frente; aqui eles só servem de exemplo de busca.

A lista começa com Get-Service, New-Service, Remove-Service… todos falam do mesmo assunto, cada um com um verbo diferente. É a regra Verbo-Substantivo funcionando na prática.

3. Procurando pelo verbo: -Verb

O contrário também vale: "me mostra os que apagam", ou seja, o verbo Remove. Como a lista é grande, pedimos só os oito primeiros com Select-Object -First 8 (você vai estudar o Select-Object no Nível 2; por enquanto, leia como "me dê só os 8 primeiros"):

PS C:\Users\ana> Get-Command -Verb Remove | Select-Object -First 8

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           Remove-AppPackage ->                               2.0.1.0    Appx
Alias           Remove-AppPackageVolume ->                         2.0.1.0    Appx
Alias           Remove-AppProvisionedPackage ->                    3.0        Dism
Alias           Remove-EtwTraceSession ->                          1.0.0.0    EventTracingManagement
Alias           Remove-ProvisionedAppPackage ->                    3.0        Dism
Alias           Remove-ProvisionedAppxPackage ->                   3.0        Dism
Alias           Remove-ProvisioningPackage ->                      3.0        Provisioning
Alias           Remove-TrustedProvisioningCertificate ->           3.0        Provisioning

Repare: os oito primeiros são Alias, não Cmdlet. O PowerShell lista em ordem alfabética, e vários apelidos de outros módulos (Appx, Dism…) vêm antes do Remove-Item, que é o comando de apagar arquivo. O catálogo mostra o que existe; não é uma recomendação de uso. Apelidos têm uma aula só para eles: Apelidos.

4. Também acha programas e apelidos

Get-Command não olha só os cmdlets. Ele também encontra programas do Windows e apelidos:

PS C:\Users\ana> Get-Command ping, notepad

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Application     PING.EXE                                           10.0.1904… C:\Windows\system32\PING.EXE
Application     notepad.exe                                        10.0.1904… C:\Windows\system32\notepad.exe
Application
Um programa (.exe), não um cmdlet. O ping e o Bloco de Notas já vinham no Windows muito antes do PowerShell.
PING.EXE / notepad.exe
O nome do arquivo. O PowerShell não liga para maiúsculas: ping e PING.EXE são o mesmo programa.
C:\Windows\system32\…
O caminho de onde o programa está. A versão aparece truncada com reticências quando não cabe na coluna.
PS C:\Users\ana> Get-Command ls, dir, cd

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           ls -> Get-ChildItem                                           
Alias           dir -> Get-ChildItem                                          
Alias           cd -> Set-Location

Aqui o tipo é Alias: ls e dir são apelidos do Get-ChildItem, e cd é apelido do Set-Location. Quando alguém escreve ls, o PowerShell na verdade roda Get-ChildItem.

Missão: descubra qual comando está por trás do apelido ls.

Get-Command pwd

Get-Command ls

5. Quantos comandos existem?

Para contar, em vez de rolar uma lista enorme, você encosta o Measure-Object ("medir o objeto") no final, com o cano |. O cano é o pipeline, a esteira que leva a saída de um comando para o próximo — assunto do Nível 2. Aqui ele só serve para contar:

PS C:\Users\ana> Get-Command -CommandType Cmdlet | Measure-Object

Count             : 610
Average           : 
Sum               : 
Maximum           : 
Minimum           : 
StandardDeviation : 
Property          :

Neste computador, no PowerShell 7.7, são 610 cmdlets. O número muda de um PC para outro, conforme os módulos instalados: o valor da sua máquina pode ser outro, e isso é normal. As outras linhas (média, soma…) vêm vazias porque estamos só contando, não medindo números.

PS C:\Users\ana> Get-Command -Module Microsoft.PowerShell.Management | Measure-Object

Count             : 61
Average           : 
Sum               : 
Maximum           : 
Minimum           : 
StandardDeviation : 
Property          :

Só no módulo Microsoft.PowerShell.Management (pastas, processos, serviços, computador) são 61 comandos. É por isso que o catálogo existe: ninguém decora 61 nomes, quanto mais 610.

No Windows PowerShell 5.1 a contagem é outra: neste mesmo computador havia 659 cmdlets no total e 89 no módulo Management. São listas diferentes, não um "erro de conta".

Formas diferentes de procurar

FormaQuando usar
Get-Command *-DateQuando você lembra de um pedaço do nome. O * preenche o resto.
Get-Command -Noun ServiceQuando você lembra do assunto (o substantivo) e quer todos os verbos dele.
Get-Command -Verb RemoveQuando você lembra do verbo e quer ver o que dá para apagar, criar, obter…
Get-Command lsQuando você tem um nome exato e quer saber se é cmdlet, apelido ou programa.

Quando já sabe o nome e quer a explicação de como usar, o comando certo é o Get-Help (aula Get-Help: a Ajuda).

Quando dá errado

O nome não existe

Pedimos um comando inventado, NaoExiste:

PS C:\Users\ana> Get-Command NaoExiste
Get-Command: O termo "NaoExiste" não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.
Verifique a ortografia do nome ou, se um caminho foi incluído, verifique se o caminho está correto e tente novamente.

A mensagem aparece em vermelho. Linha por linha:

Get-Command:
Quem está reclamando: o próprio Get-Command.
O termo "NaoExiste" não é reconhecido…
Ele procurou um cmdlet, uma função, um script e um programa com esse nome, e não achou nenhum.
Verifique a ortografia do nome…
A dica: confira se você escreveu certo, ou se o caminho está correto.

Como resolver: confira a grafia. Se o nome for um padrão (*-Date), use o asterisco. Se você não lembra do nome, procure pelo verbo ou pelo substantivo. O erro não estraga nada.

No Windows PowerShell 5.1 a mesma mensagem é mais comprida: ela traz também o No linha, os tils sublinhando o pedaço e o CommandNotFoundException, no mesmo estilo da aula Seu Primeiro Comando.

Resumo

  • Get-Command é o catálogo: ele mostra o que existe, sem executar.
  • Get-Command *-Date procura por um pedaço do nome; o * vale "qualquer coisa".
  • -Noun filtra pelo substantivo e -Verb pelo verbo.
  • O tipo pode ser Cmdlet, Alias (apelido) ou Application (programa .exe).
  • Measure-Object no fim da esteira conta quantos comandos vieram; o número muda de um computador para outro.
  • Se o nome não existe, a mensagem é "não é reconhecido": confira a grafia e tente de novo.
