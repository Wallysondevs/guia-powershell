ForEach-Object

O ForEach-Object (apelidos foreach e % no pipeline) é a máquina que "faz algo com cada um": recebe os objetos da esteira, um de cada vez, e roda o mesmo bloco para cada um.

Você vai aprender
  • A transformar cada item com ForEach-Object { ... $_ ... }.
  • A preparar antes e fechar depois com -Begin e -End.
  • A forma curta: ForEach-Object Nome ou ForEach-Object ToUpper.
  • A diferença para o laço foreach da aula foreach.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional. Os quadros marcados Saída no Windows (PowerShell 7.7) foram colhidos num Windows 10 em português, com o nome do computador e o da usuária trocados por exemplos (NOTEBOOK e ana).

A ideia: o carimbo

Na fila de documentos, cada papel passa pelo carimbo. O carimbo é o mesmo, o papel é que muda. No ForEach-Object, o bloco entre chaves é o carimbo, e o $_ é o papel da vez.

1. Transformando cada item

PS> 1..5 | ForEach-Object { $_ * $_ }
1
4
9
16
25
PS> "ana", "beto" | ForEach-Object { $_.ToUpper() }
ANA
BETO
ForEach-Object { ... }
Roda o bloco uma vez para cada item que chega.
$_ * $_
O item da vez vezes ele mesmo: o quadrado.
$_.ToUpper()
Chama um método no item da vez.

2. Montando um texto para cada objeto

PS> $produtos = @(
>>   [pscustomobject]@{ Nome = "Arroz"; Preco = 25.9 }
>>   [pscustomobject]@{ Nome = "Café"; Preco = 18.5 }
>> )
PS> $produtos | ForEach-Object { "{0}: R$ {1:N2}" -f $_.Nome, $_.Preco }
Arroz: R$ 25,90
Café: R$ 18,50

O -f (aula Formatando Textos) com {1:N2} mostra duas casas decimais, com vírgula, como no Brasil.

Experimente: use o ForEach-Object para dizer Olá, Ana! e Olá, Beto!.

"Ana", "Beto"

"Ana", "Beto" | ForEach-Object { "Olá, $_!" }

3. Antes, durante e depois: -Begin, -Process, -End

O bloco -Begin roda uma vez, antes do primeiro item. O -Process roda para cada item. O -End roda uma vez, no fim. Ótimo para somar:

PS> 10, 20, 30 | ForEach-Object -Begin { $soma = 0 } -Process { $soma += $_ } -End { "Total: $soma" }
Total: 60
-Begin { $soma = 0 }
Prepara o cofrinho, antes de tudo.
-Process { $soma += $_ }
Para cada número, soma.
-End { "Total: $soma" }
No fim, mostra o resultado.

4. A forma curta

Se tudo o que você quer é um campo ou um método de cada item, escreva só o nome:

PS> $produtos | ForEach-Object Nome
Arroz
Café
PS> "ana", "beto" | ForEach-Object ToUpper
ANA
BETO

Formas diferentes: ForEach-Object × foreach × .ForEach()

FormaComo escreveQuando usar
ForEach-Object$lista | ForEach-Object { $_ }No meio do pipeline, um item de cada vez.
foreach (palavra-chave)foreach ($x in $lista) { $x }Nos scripts, com a lista já numa variável.
.ForEach()$lista.ForEach({ $_ * 2 })Atalho rápido sobre uma lista em variável.
PS> (1..3).ForEach({ $_ * 2 })
2
4
6

Quando dá errado

Chaves no lugar errado 
PS> 1..3 | ForEach-Object $_ * 2
ForEach-Object: Não é possível associar o parâmetro 'RemainingScripts'. Cannot convert the "*" value of type "System.String" to type "System.Management.Automation.ScriptBlock".

Sem as chaves, o PowerShell não sabe que $_ * 2 é um bloco para rodar: ele tenta encaixar o * e o 2 como parâmetros e o comando falha com um erro de parâmetro. Coloque tudo entre { }.

$_ dentro do -Begin 
PS> 1..3 | ForEach-Object -Begin { "começo: [$_]" } -Process { $_ }
começo: []
1
2
3

No -Begin ainda não chegou nenhum item, então o $_ está vazio. Use o $_ só no -Process.

Referência rápida

Você digitaO que faz
| ForEach-Object { $_ }Faz algo com cada item.
| % { $_ }O mesmo, com o apelido %.
-Begin { } -Process { } -End { }Antes, para cada um, depois.
| ForEach-Object NomePega o campo Nome de cada um.
$lista.ForEach({ })Método da lista.

Resumo

  • ForEach-Object { } roda o bloco para cada item do pipeline; o item é $_.
  • -Begin roda antes, -Process para cada um, -End no fim.
  • Forma curta: ForEach-Object Nome ou ForEach-Object ToUpper.
  • Apelido %. Nos scripts, o laço foreach costuma ser mais claro.
