PowerShell Variáveis Automáticas ($_, $HOME…)

Algumas variáveis você nunca cria: o PowerShell já traz prontas, com a sua pasta, a versão instalada, o resultado do último comando. Conhecer essas variáveis evita trabalho e deixa os scripts mais espertos.

Você vai aprender
  • O que são variáveis automáticas: as que o PowerShell cria e preenche sozinho.
  • $HOME e $PWD: a sua pasta e a pasta atual.
  • $PSVersionTable, $PSEdition e $IsWindows: qual PowerShell e qual sistema.
  • $?: o último comando deu certo?
  • $_: o item da vez na esteira.
  • O que muda no Windows PowerShell 5.1.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: o painel do carro

Você não precisa medir a gasolina nem a velocidade: o painel do carro já mostra. As variáveis automáticas são o painel do PowerShell: ele mesmo cria e atualiza, e você só lê. Não guarde nada nelas: são de leitura.

1. Sua pasta e a pasta atual

PS C:\Users\ana> $HOME
C:\Users\ana
PS C:\Users\ana> $PWD

Path
----
C:\Users\ana

$HOME ("casa") é a sua pasta de usuária. $PWD (print working directory) é a pasta onde você está agora, a mesma do Get-Location (aula Get-Location).

2. Qual PowerShell é este?

PS C:\Users\ana> $PSVersionTable

Name                           Value
----                           -----
PSVersion                      7.7.0
PSEdition                      Core
GitCommitId                    7.7.0
OS                             Microsoft Windows 10.0.19045
Platform                       Win32NT
PSCompatibleVersions           {1.0, 2.0, 3.0, 4.0…}
PSRemotingProtocolVersion      2.4
SerializationVersion           1.1.0.1
WSManStackVersion              3.0

PS C:\Users\ana> $PSEdition
Core
PS C:\Users\ana> $PSVersionTable.PSVersion

Major  Minor  Patch  PreReleaseLabel BuildLabel
-----  -----  -----  --------------- ----------
7      7      0

$PSVersionTable é a "ficha técnica": a linha que importa é PSVersion. Core é a edição do PowerShell 7 (a que roda em Windows, Linux e macOS).

3. Windows, Linux ou macOS 7

PS C:\Users\ana> $IsWindows
True
PS C:\Users\ana> $IsLinux
False
PS C:\Users\ana> $IsMacOS
False

Úteis para um script que precisa agir diferente em cada sistema. No editor do guia, que é um PowerShell de Linux, $IsLinux dá True.

Experimente: troque o texto fixo pela variável $PSEdition.

"Edição: ???"

"Edição: $PSEdition"

4. Deu certo? ($?)

$? responde True se o último comando deu certo e False se deu erro:

PS C:\Users\ana> Get-Date | Out-Null
PS C:\Users\ana> $?
True
PS C:\Users\ana> Get-Variavel
Get-Variavel: O termo "Get-Variavel" não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.
Verifique a ortografia do nome ou, se um caminho foi incluído, verifique se o caminho está correto e tente novamente.
PS C:\Users\ana> $?
False

O Get-Date | Out-Null funcionou (o Out-Null só esconde a data), então $? deu True. O Get-Variavel não existe, então deu False. Repare: $? muda depois de cada comando; leia logo em seguida.

5. O $_ da esteira

PS C:\Users\ana> 1, 2, 3 | ForEach-Object { $_ * 10 }
10
20
30

Na esteira (pipeline), $_ é "o item da vez": primeiro 1, depois 2, depois 3. Você vai usar muito em ForEach-Object e Where-Object.

6. Outras úteis

PS C:\Users\ana> $Host.Name
ConsoleHost

$Host.Name diz onde o PowerShell está rodando (ConsoleHost = a janela de terminal). E $PID mostra o número do processo do PowerShell aberto agora; ele muda a cada vez que você abre uma janela nova.

Windows PowerShell 5.1: a edição é Desktop, e $IsWindows, $IsLinux e $IsMacOS não existem (o Get-Variable não achou nenhuma e não mostrou nada):

Formas diferentes de saber a versão

FormaQuando usar
$PSVersionTable.PSVersionSó a versão, em colunas.
$PSVersionTableA ficha técnica inteira.
$PSEditionSó a edição: Core (7) ou Desktop (5.1).
$Host.VersionA versão do programa que hospeda o PowerShell; no console costuma bater com a do PowerShell, mas em outros programas pode ser outra. Prefira $PSVersionTable.

Quando dá errado

Leu o $? tarde demais

Qualquer comando no meio (até um $x para ver um valor) atualiza o $?. Se ele deu True depois de um erro, confira se não rodou outro comando antes. Guarde logo: $deuCerto = $?.

Comando inexistente 
PS C:\Users\ana> Get-Variavel
Get-Variavel: O termo "Get-Variavel" não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.
Verifique a ortografia do nome ou, se um caminho foi incluído, verifique se o caminho está correto e tente novamente.

"O termo Get-Variavel não é reconhecido como cmdlet, função…" O certo é Get-Variable. Use Tab para completar nomes e evitar erros de digitação.

Resumo

  • Variáveis automáticas são criadas pelo PowerShell; você só lê.
  • $HOME, $PWD, $PSVersionTable, $PSEdition.
  • $? diz se o último comando deu certo.
  • $_ é o item da vez na esteira.
  • No 5.1: edição Desktop e sem $IsWindows.
