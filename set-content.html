Set-Content: Escrevendo em Arquivos

A Ana quer anotar coisas sem abrir o Bloco de Notas: uma lembrança, uma lista de compras, a data de hoje. Nesta aula você vai gravar texto num arquivo com Set-Content, acrescentar linhas com Add-Content, conhecer os atalhos > e >>, e entender por que os acentos às vezes viram símbolos estranhos.

Você vai aprender
  • A gravar texto num arquivo com Set-Content (e que ele substitui o que havia).
  • A acrescentar linhas no fim com Add-Content.
  • A gravar várias linhas de uma vez pelo pipeline.
  • Os atalhos > (substituir) e >> (acrescentar).
  • A gravar a saída de um comando com Out-File.
  • Por que os acentos podem quebrar no Windows PowerShell 5.1.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, dentro de uma pasta de treino guia-ps-teste. Na parte dos acentos aparece também o Windows PowerShell 5.1, para comparar.

A ideia: o quadro branco e o caderno

O Set-Content é um quadro branco: para escrever algo novo, você apaga tudo o que estava lá. O Add-Content é um caderno: cada anotação nova vai para a linha de baixo e as antigas ficam.

1. Gravando: Set-Content

PS C:\Users\ana\guia-ps-teste> Set-Content nota.txt "Primeira linha"
PS C:\Users\ana\guia-ps-teste> Get-Content nota.txt
Primeira linha
Set-Content
"Definir conteúdo". Set é "definir", e Content é "conteúdo".
nota.txt
O arquivo (parâmetro -Path). Se não existe, é criado.
"Primeira linha"
O texto a gravar (parâmetro -Value).

Nenhuma mensagem: deu certo. O Get-Content (aula Lendo Arquivos) confirma o que foi gravado. Agora grave outra coisa no mesmo arquivo:

PS C:\Users\ana\guia-ps-teste> Set-Content nota.txt "Trocou tudo"
PS C:\Users\ana\guia-ps-teste> Get-Content nota.txt
Trocou tudo
O "Primeira linha" sumiu, sem aviso. O Set-Content substitui o conteúdo inteiro do arquivo. Antes de gravar num arquivo que já existe, pense se não queria acrescentar.

2. Acrescentando: Add-Content

PS C:\Users\ana\guia-ps-teste> Add-Content nota.txt "Mais uma linha"
PS C:\Users\ana\guia-ps-teste> Get-Content nota.txt
Trocou tudo
Mais uma linha

O Add-Content ("adicionar conteúdo") põe o texto numa linha nova no fim e mantém o que já havia.

Experimente: o script cria a lista de compras com "Arroz". Acrescente "Feijão" sem apagar o arroz, usando Add-Content.

Set-Content compras.txt "Arroz"

Get-Content compras.txt

Set-Content compras.txt "Arroz"
Add-Content compras.txt "Feijão"
Get-Content compras.txt

3. Várias linhas de uma vez

Mande uma lista pelo pipeline (o |, aula Pipeline): cada item vira uma linha.

PS C:\Users\ana\guia-ps-teste> "a", "b", "c" | Set-Content lista.txt
PS C:\Users\ana\guia-ps-teste> Get-Content lista.txt
a
b
c

4. Os atalhos > e >>

Quem vem do cmd ou do Linux conhece o redirecionamento: > manda o resultado para um arquivo, substituindo, e >> acrescenta no fim.

PS C:\Users\ana\guia-ps-teste> "via redirecionamento" > redir.txt
PS C:\Users\ana\guia-ps-teste> "acrescenta" >> redir.txt
PS C:\Users\ana\guia-ps-teste> Get-Content redir.txt
via redirecionamento
acrescenta

Gravando a saída de um comando: Out-File

O Out-File grava exatamente o que apareceria na tela. Por isso aparecem as linhas em branco antes e depois da data:

PS C:\Users\ana\guia-ps-teste> Get-Date | Out-File data.txt
PS C:\Users\ana\guia-ps-teste> Get-Content data.txt

sexta-feira, 20 de novembro de 2026 17:13:10
O > é um atalho do Out-File. A diferença prática: Set-Content grava o valor, e Out-File/> grava o texto formatado da tela. Para texto simples o resultado é o mesmo; para tabelas de objetos, o Out-File grava a tabela como você a vê.

5. Acentos e codificação

Um arquivo guarda bytes, não letras. A codificação é a tabela que diz qual byte é qual letra. Veja o que o PowerShell 7 grava para a palavra "ação", com o Format-Hex, que mostra os bytes:

PS C:\Users\ana\guia-ps-teste> Set-Content acento.txt "ação"
PS C:\Users\ana\guia-ps-teste> Format-Hex acento.txt

   Label: C:\Users\ana\guia-ps-teste\acento.txt

          Offset Bytes                                           Ascii
                 00 01 02 03 04 05 06 07 08 09 0A 0B 0C 0D 0E 0F
          ------ ----------------------------------------------- -----
0000000000000000 61 C3 A7 C3 A3 6F 0D 0A                         aÃ§Ã£o��

O PowerShell 7 usa UTF-8: o "ç" vira dois bytes (C3 A7) e o "ã" também (C3 A3). O 0D 0A no fim é a quebra de linha do Windows. A coluna "Ascii" mostra aÃ§Ã£o porque ela tenta ler byte por byte, sem entender UTF-8. O arquivo está certo.

No Windows PowerShell 5.1, o mesmo comando grava outra coisa, e o > grava uma terceira:

PS C:\Users\ana\guia-ps-teste> Set-Content acento51.txt "ação"
PS C:\Users\ana\guia-ps-teste> Format-Hex acento51.txt


           Caminho: C:\Users\ana\guia-ps-teste\acento51.txt

           00 01 02 03 04 05 06 07 08 09 0A 0B 0C 0D 0E 0F

00000000   61 E7 E3 6F 0D 0A                                ação..          


PS C:\Users\ana\guia-ps-teste> "ação" > acento51-redir.txt
PS C:\Users\ana\guia-ps-teste> Format-Hex acento51-redir.txt


           Caminho: C:\Users\ana\guia-ps-teste\acento51-redir.txt

           00 01 02 03 04 05 06 07 08 09 0A 0B 0C 0D 0E 0F

00000000   FF FE 61 00 E7 00 E3 00 6F 00 0D 00 0A 00        .þa.ç.ã.o.....
Quem gravaCodificação"ação" em bytes
PowerShell 7, qualquer formaUTF-8 (sem marca no começo)61 C3 A7 C3 A3 6F
5.1 Set-ContentANSI (a tabela antiga do Windows)61 E7 E3 6F: um byte por letra
5.1 > e Out-FileUTF-16 (dois bytes por letra, começa com FF FE)61 00 E7 00 E3 00 6F 00

Na prática: se um arquivo gravado no 5.1 for aberto por um programa que espera UTF-8, o "ação" aparece como a��o. No 5.1, para evitar isso, diga a codificação: Set-Content a.txt "ação" -Encoding UTF8. No PowerShell 7 você não precisa se preocupar.

Formas diferentes de gravar

FormaO que fazQuando usar
Set-Content a.txt "x"Substitui tudo.Gravar um texto ou valor.
Add-Content a.txt "x"Acrescenta no fim.Registros, listas que crescem.
"x" > a.txtSubstitui tudo (é o Out-File).Atalho rápido no terminal.

Quando dá errado

A pasta não existe 
PS C:\Users\ana\guia-ps-teste> Set-Content naoexiste\x.txt "oi"
Set-Content: Could not find a part of the path 'C:\Users\ana\guia-ps-teste\naoexiste\x.txt'.
Could not find a part of the path
"Não foi possível encontrar uma parte do caminho." Esta mensagem vem em inglês mesmo num Windows em português, porque é do próprio .NET, a base do PowerShell.
a part of the path
O arquivo pode não existir, ele seria criado. O que falta é a pasta naoexiste. O Set-Content cria arquivos, mas não cria pastas.

Como resolver: crie a pasta antes com New-Item -ItemType Directory naoexiste (aula Criando Arquivos e Pastas) ou confira se o nome da pasta está certo.

"Perdi o que estava no arquivo"

Não aparece erro: você usou Set-Content ou > num arquivo que já tinha conteúdo, e ele foi substituído. Não há como desfazer.

Como evitar: para acrescentar, use Add-Content ou >>. Na dúvida, confira antes com Test-Path se o arquivo já existe.

Resumo

  • Set-Content grava e substitui tudo. Se o arquivo não existe, ele cria.
  • Add-Content acrescenta no fim sem apagar.
  • > substitui e >> acrescenta. Os dois são atalhos do Out-File.
  • O PowerShell 7 grava em UTF-8. No 5.1, use -Encoding UTF8 para os acentos não quebrarem.
  • "Could not find a part of the path" quer dizer que a pasta não existe.
