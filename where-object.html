Where-Object: Filtrando

O Where-Object (apelidos where e ?) é a peneira do pipeline: cada objeto que chega é testado, e só passa quem cumpre a condição. É o comando de filtro mais usado do PowerShell.

Você vai aprender
  • A filtrar com um bloco de condição: Where-Object { $_.Campo -gt 10 }.
  • A juntar condições com -and e -or.
  • A filtrar texto com -like e -match.
  • A forma curta: Where-Object Campo -gt 10.
  • O método .Where(), para listas que já estão numa variável.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a peneira

Na peneira, o que é pequeno passa e o que é grande fica. No Where-Object, você escreve a regra da peneira, e o PowerShell aplica a regra a cada objeto. Quem dá True passa; quem dá False fica para trás.

Os exemplos usam esta lista de pedidos:

PS> $pedidos = @(
>>   [pscustomobject]@{ Id = 1; Cliente = "Ana"; Total = 120; Pago = $true }
>>   [pscustomobject]@{ Id = 2; Cliente = "Beto"; Total = 45; Pago = $false }
>>   [pscustomobject]@{ Id = 3; Cliente = "Carla"; Total = 300; Pago = $true }
>>   [pscustomobject]@{ Id = 4; Cliente = "Davi"; Total = 80; Pago = $false }
>> )

1. Uma condição

PS> $pedidos | Where-Object { $_.Total -gt 100 }

Id Cliente Total Pago
-- ------- ----- ----
 1 Ana       120 True
 3 Carla     300 True
Where-Object
A peneira.
{ $_.Total -gt 100 }
A regra: o campo Total do pedido da vez é maior que 100? Os pedidos 1 e 3 passam.

2. Várias condições: -and e -or

PS> $pedidos | Where-Object { $_.Pago -and $_.Total -gt 200 }

Id Cliente Total Pago
-- ------- ----- ----
 3 Carla     300 True
PS> $pedidos | Where-Object { -not $_.Pago -or $_.Total -lt 50 } | Select-Object Id, Cliente

Id Cliente
-- -------
 2 Beto
 4 Davi
$_.Pago -and $_.Total -gt 200
As duas coisas precisam ser verdade: pago e acima de 200. Só o pedido 3.
-not $_.Pago -or ...
Basta uma: não pago ou abaixo de 50. Veja a aula -and, -or e -not.

Experimente: filtre os pedidos que não foram pagos e mostre só o nome do cliente.

$pedidos = @(
    [pscustomobject]@{ Cliente = "Ana"; Pago = $true }
    [pscustomobject]@{ Cliente = "Beto"; Pago = $false }
    [pscustomobject]@{ Cliente = "Davi"; Pago = $false }
)
$pedidos | ForEach-Object { $_.Cliente }

$pedidos = @(
    [pscustomobject]@{ Cliente = "Ana"; Pago = $true }
    [pscustomobject]@{ Cliente = "Beto"; Pago = $false }
    [pscustomobject]@{ Cliente = "Davi"; Pago = $false }
)
$pedidos | Where-Object { -not $_.Pago } | ForEach-Object { $_.Cliente }

3. Filtrando texto

Com -like (curinga) e -match (expressão regular), a peneira olha para o texto (aula Comparando Textos):

PS> $frutas = "maçã", "melancia", "banana", "manga", "uva"
PS> $frutas | Where-Object { $_ -like "m*" }
maçã
melancia
manga
PS> $frutas | Where-Object { $_ -match "an" }
melancia
banana
manga

4. A forma curta

Para uma condição simples, dá para escrever sem as chaves e sem o $_: o nome do campo, o operador e o valor:

PS> $pedidos | Where-Object Total -lt 100 | Select-Object Id, Total

Id Total
-- -----
 2    45
 4    80

A forma curta não aceita -and/-or. Quando precisar de mais de uma condição, volte para as chaves.

5. O método .Where()

Se a lista já está numa variável, existe também o método .Where(). Ele faz a mesma peneira e é mais rápido em listas grandes:

PS> (1..10).Where({ $_ % 3 -eq 0 })
3
6
9

Quando dá errado

Usar = em vez de -eq 
PS> $pedidos | Where-Object { $_.Cliente = "Ana" }
PS> $pedidos | Select-Object Id, Cliente

Id Cliente
-- -------
 1 Ana
 2 Ana
 3 Ana
 4 Ana

Esse erro é traiçoeiro porque não aparece mensagem nenhuma. O = não compara: ele atribui. A "condição" trocou o cliente de todos os pedidos para Ana, e como uma atribuição não devolve nada, nenhum pedido passou pela peneira. Para comparar, use -eq: { $_.Cliente -eq "Ana" }.

Nenhum item passou 
PS> $pedidos | Where-Object { $_.Total -gt 1000 }

Se ninguém cumpre a regra, a saída fica vazia, sem erro. Não é defeito: a peneira simplesmente não deixou nada passar.

Referência rápida

Você digitaO que faz
Where-Object { $_.A -gt 10 }Só os que têm A maior que 10.
{ cond1 -and cond2 }As duas precisam ser verdade.
{ cond1 -or cond2 }Basta uma.
{ $_ -like "m*" }Texto que começa com m.

Exercícios

1. O comparador

Complete para deixar passar só os números maiores que 5:

1..10 | Where-Object { $_ 5 }

3. Para comparar igualdade dentro do Where-Object, o certo é:

Missão final: mostre o nome do cliente que pagou e gastou mais de 200. A resposta é Carla.

$pedidos = @(
    [pscustomobject]@{ Cliente = "Ana"; Total = 120; Pago = $true }
    [pscustomobject]@{ Cliente = "Carla"; Total = 300; Pago = $true }
    [pscustomobject]@{ Cliente = "Davi"; Total = 250; Pago = $false }
)

$pedidos = @(
    [pscustomobject]@{ Cliente = "Ana"; Total = 120; Pago = $true }
    [pscustomobject]@{ Cliente = "Carla"; Total = 300; Pago = $true }
    [pscustomobject]@{ Cliente = "Davi"; Total = 250; Pago = $false }
)
$pedidos | Where-Object { $_.Pago -and $_.Total -gt 200 } | ForEach-Object { $_.Cliente }

Resumo

  • Where-Object { condição } deixa passar só quem dá True.
  • $_ é o objeto da vez; $_.Campo é um campo dele.
  • Junte regras com -and e -or; inverta com -not.
  • Forma curta para uma condição: Where-Object Campo -gt 10.
  • Para comparar, -eq, nunca =.
