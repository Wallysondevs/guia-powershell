PowerShell -contains e -in

A Ana tem a lista de convidadas da festa e a lista de produtos da lojinha. A pergunta mais comum sobre uma lista é: esse item está nela? Para isso existem o -contains e o -in.

Você vai aprender
  • A perguntar se uma lista tem um item com -contains.
  • A mesma pergunta ao contrário com -in.
  • As versões negativas -notcontains e -notin.
  • Que esses operadores não procuram pedaços dentro de um texto.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: a lista de convidados

Na porta da festa, o segurança tem a lista. Dá para fazer a pergunta de dois jeitos: "a lista contém a Beto?" (-contains) ou "o Beto está na lista?" (-in). A resposta é a mesma; só muda a ordem da frase.

1. -contains: a lista é quem contém

PS C:\Users\ana> "Ana", "Beto", "Caio" -contains "Beto"
True
PS C:\Users\ana> "Ana", "Beto", "Caio" -contains "beto"
True
PS C:\Users\ana> "Ana", "Beto", "Caio" -ccontains "beto"
False
PS C:\Users\ana> "Ana", "Beto", "Caio" -notcontains "Dora"
True
"Ana", "Beto", "Caio"
A lista, à esquerda.
-contains
"Contém". Não diferencia maiúsculas; -ccontains diferencia.
"Beto"
O item procurado, à direita.

Experimente: a Dora foi convidada, mas não está na lista. Acrescente "Dora" à lista e rode.

$convidados = "Ana", "Beto", "Caio"
if ($convidados -contains "Dora") { "Pode entrar" } else { "Não está na lista" }

$convidados = "Ana", "Beto", "Caio", "Dora"
if ($convidados -contains "Dora") { "Pode entrar" } else { "Não está na lista" }

2. -in: o valor está na lista

PS C:\Users\ana> "Beto" -in "Ana", "Beto", "Caio"
True
PS C:\Users\ana> "Dora" -notin "Ana", "Beto", "Caio"
True
PS C:\Users\ana> 2 -in 1, 2, 3
True

Igual ao -contains, com o item à esquerda e a lista à direita. Muitas vezes fica mais natural de ler: if ($dia -in "sab", "dom").

Qual usar

FormaQuando
$lista -contains $itemQuando a frase começa pela lista.
$item -in $listaQuando a frase começa pelo item (mais natural num if).
-notcontains, -notinPara perguntar "não está".

3. Lista vazia

PS C:\Users\ana> @() -contains "Ana"
False
PS C:\Users\ana> $null -in @()
False

Lista vazia não contém nada, então a resposta é False, sem erro.

Quando dá errado

Procurou uma letra dentro de um texto 
PS C:\Users\ana> "a" -in "abc"
False
PS C:\Users\ana> "abc" -contains "a"
False

Não dá erro, mas a resposta surpreende: False. Para o -in e o -contains, "abc" é uma lista de um item só (o texto inteiro), e esse item não é "a". Eles comparam itens inteiros, não pedaços.

Como resolver: para procurar um pedaço dentro de um texto, use -like "*a*" ou -match "a" (aula Comparando Textos).

Inverteu a ordem

"Beto" -contains "Ana", "Beto" pergunta se o texto "Beto" contém a lista, e dá False. No -contains, a lista vem antes; no -in, depois.

Exercícios

1. Contém

Complete para perguntar se a lista tem "pão":

$compras "pão"

2. Está na lista

Complete para perguntar se $dia é sábado ou domingo:

$dia "sab", "dom"

3. O que "a" -in "abc" mostra?

4. O que "Ana", "Beto" -contains "ana" mostra?

Missão final: com -in, mostre Fim de semana quando $dia for "sab" ou "dom".

$dia = "dom"

$dia = "dom"
if ($dia -in "sab", "dom") { "Fim de semana" }

Resumo

  • lista -contains item e item -in lista respondem a mesma pergunta.
  • -notcontains e -notin perguntam o contrário.
  • Não diferenciam maiúsculas; -ccontains diferencia.
  • Comparam itens inteiros: para pedaços de texto, use -like ou -match.
