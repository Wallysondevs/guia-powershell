PowerShell Textos: Aspas Simples × Duplas

Nomes, recados, linhas de relatório: quase todo script trabalha com texto. No PowerShell, texto vai entre aspas, e existem dois tipos de aspas que se comportam de um jeito diferente. Saber qual usar evita muita confusão.

Você vai aprender
  • A escrever textos com aspas simples ' ' e duplas " ".
  • A diferença: só as duplas trocam $variavel pelo valor e entendem o acento grave `.
  • A colocar aspas dentro do texto.
  • Os caracteres especiais `n (nova linha) e `t (tabulação).

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: carimbo × formulário

Aspas simples são um carimbo: o que está escrito sai exatamente igual, sempre. Aspas duplas são um formulário com lacunas: onde houver $nome, o PowerShell preenche com o valor antes de mostrar.

1. Os dois jeitos

Texto (em inglês, string, "corda" de letras) vai entre aspas. Sem variável dentro, os dois jeitos dão o mesmo resultado:

PS C:\Users\ana> 'Olá, Ana'
Olá, Ana
PS C:\Users\ana> "Olá, Ana"
Olá, Ana

2. O que muda: o cifrão e o acento grave

PS C:\Users\ana> $nome = "Ana"
PS C:\Users\ana> 'Olá, $nome'
Olá, $nome
PS C:\Users\ana> "Olá, $nome"
Olá, Ana
PS C:\Users\ana> 'uma quebra:`nainda na mesma linha'
uma quebra:`nainda na mesma linha
PS C:\Users\ana> "uma quebra:`nagora em duas"
uma quebra:
agora em duas
'Olá, $nome'
Aspas simples: o $nome sai como está escrito.
"Olá, $nome"
Aspas duplas: o $nome vira Ana.
`n
O acento grave (`, a "crase" do teclado) seguido de n é uma nova linha. Só funciona entre aspas duplas.
Boa prática: use aspas simples quando o texto não tem variável. Assim você tem certeza de que nada vai ser trocado sem querer.

Experimente: o texto mostra $nome em vez do nome. Troque as aspas simples por duplas e rode.

$nome = 'Ana'
'Olá, $nome'

$nome = 'Ana'
"Olá, $nome"

3. Aspas dentro do texto

PS C:\Users\ana> 'ela disse "oi"'
ela disse "oi"
PS C:\Users\ana> "ela disse 'oi'"
ela disse 'oi'
PS C:\Users\ana> "ela disse `"oi`""
ela disse "oi"
PS C:\Users\ana> 'it''s ok'
it's ok
JeitoQuando usar
'ela disse "oi"'Aspas duplas dentro de simples: sem problema.
"ela disse 'oi'"Simples dentro de duplas: sem problema.
"`"oi`""Dupla dentro de dupla: ponha ` antes.
'it''s'Simples dentro de simples: escreva duas vezes.

4. Caracteres especiais

PS C:\Users\ana> "coluna1`tcoluna2"
coluna1	coluna2

`t é a tabulação (o "pulo" da tecla Tab), útil para alinhar colunas. Os mais usados: `n (nova linha), `t (tabulação), `" (aspas duplas), `$ (um cifrão de verdade entre aspas duplas).

Quando dá errado

Esqueceu de fechar as aspas

Este erro foi colhido com Invoke-Expression, que roda um texto como comando. Digitado direto no console, o PowerShell não mostra erro: ele fica esperando o resto, com o prompt >>, até você fechar o texto (ou apertar Ctrl+C para desistir). Num script o PowerShell também acusa o erro, mas essa saída não foi colhida.

PS C:\Users\ana> Invoke-Expression '"texto sem fechar'
Invoke-Expression: The string is missing the terminator: ".

"Falta o terminador do texto: "." Toda aspa aberta precisa de uma igual fechando.

Como resolver: "texto fechado".

O texto mostrou $nome em vez do nome

Não é erro do PowerShell: você usou aspas simples. Troque por duplas.

Resumo

  • Aspas simples: o texto sai exatamente como está.
  • Aspas duplas: $variavel vira o valor e `n, `t funcionam.
  • Sem variável, prefira aspas simples.
  • Para aspas dentro: misture os tipos, use `" ou repita ''.
