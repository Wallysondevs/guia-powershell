Ajuda nas Suas Funções

O Get-Help (aula Get-Help) não serve só para os cmdlets oficiais. Se você escrever um bloco de comentários especial na sua função, ele mostra a ajuda dela também, com resumo, parâmetros e exemplos.

Você vai aprender
  • A escrever o bloco &lt;# ... #&gt; com .SYNOPSIS, .DESCRIPTION, .PARAMETER e .EXAMPLE.
  • A ler a ajuda com Get-Help, -Examples e -Parameter.
  • Onde colocar o bloco de ajuda.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional. Os quadros marcados Saída no Windows (PowerShell 7.7) foram colhidos num Windows 10 em português, com o nome do computador e o da usuária trocados por exemplos (NOTEBOOK e ana).

A ideia: o manual que vem na caixa

Todo aparelho vem com um manual: para que serve, como ligar, um exemplo de uso. Sem manual, só quem fez sabe usar. A ajuda em comentários é o manual da sua função, e fica junto com ela.

1. O bloco de ajuda

function Get-Desconto {
    <#
    .SYNOPSIS
    Calcula o preço com desconto.

    .DESCRIPTION
    Recebe um preço e um percentual e devolve o preço final.

    .PARAMETER Preco
    O preço original, em reais.

    .PARAMETER Percentual
    Quanto de desconto, de 0 a 100. O padrão é 10.

    .EXAMPLE
    Get-Desconto -Preco 200 -Percentual 15
    Devolve 170.
    #>
    param([double]$Preco, [double]$Percentual = 10)
    $Preco * (1 - $Percentual / 100)
}
<# ... #>
Um comentário de várias linhas. Logo no começo da função, ele vira a ajuda.
.SYNOPSIS
O resumo de uma linha.
.DESCRIPTION
A explicação mais longa.
.PARAMETER Preco
A explicação de um parâmetro. Um .PARAMETER para cada um.
.EXAMPLE
Um exemplo: a primeira linha é o comando, as outras explicam.

3. Só os exemplos

PS> Get-Help Get-Desconto -Examples

NOME
    Get-Desconto
    
SYNOPSIS
    Calcula o preço com desconto.
    
    
    -------------------------- EXAMPLE 1 --------------------------
    
    PS > Get-Desconto -Preco 200 -Percentual 15
    Devolve 170.

Com -Examples, o Get-Help mostra o nome, o resumo e cada .EXAMPLE, numerado. Num Windows em português, os títulos das seções saem traduzidos (NOME, por exemplo), como você viu na aula Get-Help.

Experimente: escreva o bloco de ajuda com .SYNOPSIS dizendo Converte graus Celsius em Fahrenheit. e mostre o resumo com (Get-Help ConvertTo-Fahrenheit).Synopsis.

function ConvertTo-Fahrenheit {
    param([double]$Celsius)
    $Celsius * 9 / 5 + 32
}
(Get-Help ConvertTo-Fahrenheit).Synopsis

function ConvertTo-Fahrenheit {
    <#
    .SYNOPSIS
    Converte graus Celsius em Fahrenheit.
    #>
    param([double]$Celsius)
    $Celsius * 9 / 5 + 32
}
(Get-Help ConvertTo-Fahrenheit).Synopsis

4. Onde pode ficar

O bloco pode ficar em três lugares: logo depois da chave de abertura da função (como acima), logo antes da palavra function, ou no fim do corpo. O mais comum é dentro, no começo. Num script .ps1, o bloco no topo do arquivo vira a ajuda do script.

Quando dá errado

Palavra-chave escrita errado: a ajuda some 
PS> function Get-Teste {
>>   <#
>>   .RESUMO
>>   Faz um teste.
>>   #>
>>   param($x)
>>   $x
>> }
PS> (Get-Help Get-Teste).Synopsis

Get-Teste [[-x] <Object>]

Com uma palavra-chave que não existe (.RESUMO), o bloco deixa de ser ajuda. O Get-Help mostra só o "esqueleto" com o nome e a sintaxe. As palavras-chave são em inglês: .SYNOPSIS, .DESCRIPTION, .PARAMETER, .EXAMPLE, .NOTES, .LINK.

Referência rápida

Você escrevePara quê
.SYNOPSISResumo de uma linha.
.DESCRIPTIONExplicação longa.
.PARAMETER NomeExplica um parâmetro.
.EXAMPLEUm exemplo de uso (pode repetir).
.NOTESObservações, autor, versão.
Get-Help F -ExamplesLê só os exemplos.
Get-Help F -Parameter PLê a ajuda de um parâmetro.

Missão final: escreva a ajuda da Get-Soma com .SYNOPSIS (Mostra a soma de dois números.) e um .EXAMPLE, e mostre o resumo.

function Get-Soma {
    param([int]$A, [int]$B)
    $A + $B
}
(Get-Help Get-Soma).Synopsis

function Get-Soma {
    <#
    .SYNOPSIS
    Mostra a soma de dois números.
    .EXAMPLE
    Get-Soma 2 3
    #>
    param([int]$A, [int]$B)
    $A + $B
}
(Get-Help Get-Soma).Synopsis

Resumo

  • Um bloco &lt;# ... #&gt; com .SYNOPSIS, .DESCRIPTION, .PARAMETER e .EXAMPLE vira a ajuda da função.
  • O Get-Help lê como nos cmdlets: -Examples, -Parameter, -Full.
  • As palavras-chave são em inglês; escritas errado, a ajuda some.
