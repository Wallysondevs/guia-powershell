PowerShell Operadores Lógicos

A Ana dá desconto só quando a compra é grande e a pessoa tem cadastro. Uma condição sozinha não resolve: ela precisa juntar duas perguntas. Os operadores lógicos ligam respostas verdadeiras e falsas para formar uma decisão maior.

Você vai aprender
  • Juntar condições com -and (e) e -or (ou).
  • Inverter uma resposta com -not.
  • Reconhecer o ou exclusivo, -xor.
  • Entender por que às vezes o lado direito nem roda.

As saídas reais desta aula foram colhidas no PowerShell 7.7 de um Windows em português. Os exemplos do editor são exercícios, não transcrições do laboratório.

A ideia: as regras de um desconto

Imagine dois carimbos num cartão. Uma promoção exige os dois: é o -and. Outra aceita pelo menos um: é o -or. Uma terceira exige exatamente um, nunca ambos: é o -xor. O -not troca um sim por não, e um não por sim.

1. E: as duas condições precisam ser verdadeiras

$true significa verdadeiro; $false, falso. São valores lógicos, sem aspas. Comece com respostas prontas, antes de montar perguntas maiores.

PS C:\Users\ana> $true -and $true
True
PS C:\Users\ana> $true -and $false
False
$true -and $true
Verdadeiro e verdadeiro: o resultado é True.
$true -and $false
Uma resposta falsa já basta para o conjunto ser False.
-and
And é “e”. Fica entre duas condições.

2. Ou: basta uma condição verdadeira

PS C:\Users\ana> $true -or $false
True
PS C:\Users\ana> $false -or $false
False
-or
Or é “ou”. Basta um dos lados ser verdadeiro. Se ambos forem verdadeiros, também dá verdadeiro.
$false -or $false
Nenhum dos lados atende à regra: False.

Experimente: O desconto exige compra grande e cadastro. Troque o operador para que, neste caso, apareça Desconto: False.

$compraGrande = $true
$temCadastro = $false
"Desconto: " + ($compraGrande -or $temCadastro)

$compraGrande = $true
$temCadastro = $false
"Desconto: " + ($compraGrande -and $temCadastro)

3. Inverter e escolher exatamente uma opção

PS C:\Users\ana> -not $false
True
PS C:\Users\ana> -not $true
False
PS C:\Users\ana> !$false
True
PS C:\Users\ana> $true -xor $true
False
PS C:\Users\ana> $true -xor $false
True
-not $false
Not é “não”: inverte falso para verdadeiro.
!$false
O ponto de exclamação também inverte. Prefira -not ao começar: ele explica melhor a intenção.
-xor
“Ou exclusivo”: verdadeiro só quando exatamente um dos lados é verdadeiro. Dois verdadeiros dão falso.

4. Juntando comparações de verdade

Agora cada lado é uma pergunta. Os parênteses deixam visível onde começa e termina cada comparação.

PS C:\Users\ana> (5 -gt 3) -and (2 -lt 10)
True
PS C:\Users\ana> (5 -gt 3) -and (2 -gt 10)
False
PS C:\Users\ana> $nome = "Ana"
PS C:\Users\ana> ($null -eq $nome) -or ($nome -eq "Ana")
True
(5 -gt 3)
5 é maior que 3: verdadeiro.
(2 -lt 10)
2 é menor que 10: verdadeiro. Os dois juntos com -and dão verdadeiro.
($null -eq $nome) -or ($nome -eq "Ana")
O nome está ausente ou é Ana? Aqui vale a segunda condição. -eq compara igualdade, não guarda um valor.

5. Atalho: o lado direito só roda se precisar

Isso se chama curto-circuito. Com -and, se o primeiro lado é falso, o conjunto já é falso. Com -or, se o primeiro lado é verdadeiro, o conjunto já é verdadeiro. Não é necessário avaliar o resto.

PS C:\Users\ana> $false -and (1 / 0)
False
PS C:\Users\ana> $true -or (1 / 0)
True

O 1 / 0 é uma divisão impossível, mas aqui não foi executado: por isso não houve erro. Não conte com o lado direito para fazer uma tarefa obrigatória, como atualizar um contador.

Formas diferentes de combinar condições

FormaQuando usar / o que faz
a -and bExigir todas as condições.
a -or bAceitar pelo menos uma condição.
-not (a)Inverter uma condição inteira.
!$valorForma curta da negação.
a -xor bAceitar exatamente uma das duas condições.

Quando dá errado

Usou -xor querendo aceitar as duas opções
PS C:\Users\ana> $true -xor $true
False
PS C:\Users\ana> $true -xor $false
True

Não há mensagem de erro: é um erro de lógica. O primeiro resultado é False porque os dois lados são verdadeiros. Use -or quando ambos também puderem valer; reserve -xor para uma escolha exclusiva.

Esperou que uma divisão fosse executada

No trecho do curto-circuito, nenhum erro foi coletado porque a divisão nem rodou. Se uma ação precisa acontecer sempre, execute-a numa linha separada, não no lado direito de -and ou -or.

Esta coleta não contém mensagens de erro para os operadores lógicos. Os casos acima mostram resultados reais inesperados, sem inventar diagnóstico do terminal.

Experimente: Escreva um aviso para quando não houver cadastro. Use -not na condição para mostrar Faça seu cadastro.

$temCadastro = $false
if ($temCadastro) {
    'Faça seu cadastro'
}

$temCadastro = $false
if (-not $temCadastro) {
    'Faça seu cadastro'
}

Resumo

  • -and exige os dois; -or aceita um ou ambos.
  • -not e ! invertem o valor lógico.
  • -xor só aceita exatamente um verdadeiro.
  • Use parênteses para deixar as comparações claras.
  • O curto-circuito pode impedir a avaliação do lado direito.
