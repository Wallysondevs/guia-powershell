Projeto: Analisador de Log

Todo sistema escreve um diário: o arquivo de log. Quando algo dá errado, alguém precisa ler milhares de linhas para achar o problema. Neste projeto você ensina o PowerShell a fazer isso: transformar cada linha num objeto e responder perguntas como "quantos erros houve?" e "qual erro mais se repete?".

Você vai aprender
  • A ler um log com Get-Content.
  • A transformar texto em objetos com -match e grupos nomeados.
  • A contar e agrupar com Group-Object e Measure-Object.
  • A agrupar por hora com datas.
  • A gerar um relatório em CSV.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

1. O arquivo de log

Vamos criar um log de exemplo na pasta atual. No seu caso, seria o arquivo do sistema que você quer analisar:

PS> Set-Content app.log @'
>> 2026-11-20 08:01:12 INFO  Sistema iniciado
>> 2026-11-20 08:05:40 WARN  Disco com 85% de uso
>> 2026-11-20 08:17:03 ERROR Falha ao conectar no banco
>> 2026-11-20 09:02:55 INFO  Usuário ana entrou
>> 2026-11-20 09:10:21 ERROR Falha ao conectar no banco
>> 2026-11-20 09:45:00 ERROR Tempo esgotado na API de pagamentos
>> 2026-11-20 10:12:30 INFO  Usuário beto entrou
>> 2026-11-20 10:30:08 WARN  Fila com 120 mensagens
>> 2026-11-20 10:31:44 ERROR Falha ao conectar no banco
>> linha estranha sem formato
>> '@
PS> (Get-Content app.log).Count
10

2. Cada linha vira um objeto

PS> $padrao = '^(?<data>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}) (?<nivel>\w+)\s+(?<msg>.+)$'
PS> $eventos = Get-Content app.log | ForEach-Object {
>>     if ($_ -match $padrao) {
>>         [pscustomobject]@{
>>             Quando   = [datetime]$Matches.data
>>             Nivel    = $Matches.nivel
>>             Mensagem = $Matches.msg
>>         }
>>     } else {
>>         Write-Verbose "Ignorada: $_"
>>     }
>> }
PS> $eventos.Count
9
PS> $eventos | Select-Object -First 3 | Format-Table -AutoSize

Quando              Nivel Mensagem
------              ----- --------
20/11/2026 08:01:12 INFO  Sistema iniciado
20/11/2026 08:05:40 WARN  Disco com 85% de uso
20/11/2026 08:17:03 ERROR Falha ao conectar no banco
(?<data>...)
Grupo nomeado: a data e a hora. Depois é só usar $Matches.data.
(?<nivel>\w+)
A palavra do nível (INFO, WARN, ERROR).
\s+
Um ou mais espaços (o INFO tem dois espaços depois, para alinhar).
else { Write-Verbose ... }
Linhas fora do formato são ignoradas, sem quebrar o resto.
[datetime]$Matches.data
O texto 2026-11-20 08:01:12 vira uma data de verdade, que dá para comparar e agrupar.

A linha estranha ficou de fora: 9 eventos de 10 linhas.

3. Respondendo perguntas

Quantos eventos de cada nível?

PS> $eventos | Group-Object Nivel | Sort-Object Count -Descending | Select-Object Name, Count

Name  Count
----  -----
ERROR     4
INFO      3
WARN      2

Qual erro mais se repete?

PS> $eventos | Where-Object Nivel -eq "ERROR" | Group-Object Mensagem | Sort-Object Count -Descending | Select-Object Count, Name

Count Name
----- ----
    3 Falha ao conectar no banco
    1 Tempo esgotado na API de pagamentos

Quantos erros por hora?

PS> $eventos | Where-Object Nivel -eq "ERROR" | Group-Object { $_.Quando.ToString("HH'h'") } | Select-Object Name, Count

Name Count
---- -----
08h      1
09h      2
10h      1

Primeiro e último erro:

PS> $erros = $eventos | Where-Object Nivel -eq "ERROR" | Sort-Object Quando
PS> "Primeiro: {0:HH:mm} | Último: {1:HH:mm}" -f $erros[0].Quando, $erros[-1].Quando
Primeiro: 08:17 | Último: 10:31

Experimente: os eventos já estão prontos. Agrupe por Nivel e mostre cada grupo como NIVEL quantidade (ex.: ERROR 2).

$eventos = @(
  [pscustomobject]@{ Nivel = "INFO";  Mensagem = "Sistema iniciado" }
  [pscustomobject]@{ Nivel = "ERROR"; Mensagem = "Falha no banco" }
  [pscustomobject]@{ Nivel = "ERROR"; Mensagem = "Falha no banco" }
)

$eventos = @(
  [pscustomobject]@{ Nivel = "INFO";  Mensagem = "Sistema iniciado" }
  [pscustomobject]@{ Nivel = "ERROR"; Mensagem = "Falha no banco" }
  [pscustomobject]@{ Nivel = "ERROR"; Mensagem = "Falha no banco" }
)
$eventos | Group-Object Nivel | ForEach-Object { "$($_.Name) $($_.Count)" }

4. O relatório em CSV

PS> $eventos | Where-Object Nivel -ne "INFO" |
>>     Select-Object @{ n = "Data"; e = { $_.Quando.ToString("dd/MM/yyyy HH:mm") } }, Nivel, Mensagem |
>>     Export-Csv relatorio-log.csv -Delimiter ';'
PS> Get-Content relatorio-log.csv
"Data";"Nivel";"Mensagem"
"20/11/2026 08:05";"WARN";"Disco com 85% de uso"
"20/11/2026 08:17";"ERROR";"Falha ao conectar no banco"
"20/11/2026 09:10";"ERROR";"Falha ao conectar no banco"
"20/11/2026 09:45";"ERROR";"Tempo esgotado na API de pagamentos"
"20/11/2026 10:30";"WARN";"Fila com 120 mensagens"
"20/11/2026 10:31";"ERROR";"Falha ao conectar no banco"

5. Transformando em função

PS> function Get-EventoLog { param([Parameter(Mandatory)][string]$Path, [string]$Nivel)
>>     $padrao = '^(?<data>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}) (?<nivel>\w+)\s+(?<msg>.+)$'
>>     Get-Content $Path | ForEach-Object {
>>         if ($_ -match $padrao -and (-not $Nivel -or $Matches.nivel -eq $Nivel)) {
>>             [pscustomobject]@{ Quando = [datetime]$Matches.data; Nivel = $Matches.nivel; Mensagem = $Matches.msg }
>>         }
>>     }
>> }
PS> (Get-EventoLog -Path app.log -Nivel WARN).Mensagem
Disco com 85% de uso
Fila com 120 mensagens

Desafios

Exercícios

1. Por que converter a data com [datetime]?

2. O que acontece com uma linha fora do formato?

Missão final: use -match com o grupo (?<msg>.+) para mostrar só a mensagem da linha de erro.

$linha = "2026-11-20 08:17:03 ERROR Falha no banco"

$linha = "2026-11-20 08:17:03 ERROR Falha no banco"
if ($linha -match '^\S+ \S+ (?<nivel>\w+)\s+(?<msg>.+)$') { $Matches.msg }

Resumo

  • Regex com grupos nomeados transforma cada linha em objeto.
  • Com objetos, Group-Object, Sort-Object e Where-Object respondem perguntas.
  • Datas como [datetime] permitem agrupar por hora e filtrar por período.
  • Export-Csv -Delimiter ';' gera o relatório para o Excel.
