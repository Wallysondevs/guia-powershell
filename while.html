PowerShell while e do

O foreach e o for repetem quando você já tem uma lista, ou um número certo de voltas. Às vezes a Ana não sabe quantas vezes vai repetir: ela vende enquanto houver estoque, ou dobra um número até ele passar de 10. Para isso existe o while (“enquanto”) e o par do … while / do … until (“faça … enquanto” / “faça … até”).

Você vai aprender
  • O while, que testa a condição antes de cada volta e pode não rodar nenhuma vez.
  • O do { ... } while e o do { ... } until, que rodam pelo menos uma vez.
  • A diferença: while continua enquanto a condição é verdadeira; until continua até ela se tornar verdadeira.
  • Por que a variável da condição precisa mudar, senão o laço não termina.
  • O risco do laço infinito, explicado sem rodar, e um freio de segurança com break.
  • O erro real de esquecer os parênteses depois do while.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta pessoal da usuária fictícia ana.

A ideia: vender enquanto houver estoque

Pense no balcão da lojinha. Enquanto houver caneta na prateleira, a Ana vende uma, confere o que restou, e só para quando o estoque chega a zero. Ela olha primeiro: se já estiver zerado, não vende nenhuma. Isso é o while.

Agora imagine ela provando um bolo: ela prova pelo menos um pedaço, e só então decide se precisa de mais açúcar. Isso é o do … while e o do … until: o bloco roda uma vez antes da pergunta.

1. O while: testa antes

A Ana tem 3 canetas. Enquanto o estoque for maior que zero, ela vende uma:

PS C:\Users\ana> $estoque = 3
PS C:\Users\ana> while ($estoque -gt 0) { "Vendi 1, restam $($estoque - 1)"; $estoque-- }
Vendi 1, restam 2
Vendi 1, restam 1
Vendi 1, restam 0
$estoque = 3
O estoque começa em 3.
while ($estoque -gt 0)
“Enquanto o estoque for maior que zero”. A condição vai entre parênteses e é testada antes de cada volta. O -gt é “maior que” (aula Comparações).
"Vendi 1, restam $($estoque - 1)"
A mensagem da volta. O $($estoque - 1) calcula o que vai restar depois desta venda.
$estoque--
Tira 1 do estoque (aula Atribuição). Sem essa linha, a condição continuaria verdadeira para sempre.

Foram três voltas: 3, depois 2, depois 1. Quando o estoque chegou a 0, a condição ficou falsa e o laço parou. O prompt voltou.

Experimente: o estoque está zerado, então o while não roda. Mude o valor inicial para um número maior que zero (por exemplo 3) e confira se aparece uma linha com restam 0.

$estoque = 0
while ($estoque -gt 0) { "Vendi 1, restam $($estoque - 1)"; $estoque-- }

$estoque = 3
while ($estoque -gt 0) { "Vendi 1, restam $($estoque - 1)"; $estoque-- }

2. Quando o while não roda nenhuma vez

Se a condição já é falsa na primeira olhada, o bloco é pulado. A Ana está com estoque 0:

PS C:\Users\ana> $estoque = 0
PS C:\Users\ana> while ($estoque -gt 0) { "nunca" }; "while não rodou nenhuma vez"
while não rodou nenhuma vez

A palavra nunca não apareceu. Só a mensagem depois do laço. O ponto e vírgula ; apenas junta dois comandos na mesma linha: o while e o texto seguinte.

3. do-while e do-until: pelo menos uma vez

O do (“faça”) inverte a ordem: primeiro o bloco, depois a pergunta. Mesmo com o estoque em 0, o do-while roda uma vez:

PS C:\Users\ana> do { "do-while rodou com $estoque" } while ($estoque -gt 0)
do-while rodou com 0
do { ... }
O bloco roda primeiro, sem perguntar nada.
while ($estoque -gt 0)
A pergunta vem no fim. Como o estoque ainda é 0 (ficou da seção anterior), a condição é falsa e não há segunda volta. Mesmo assim a primeira já tinha acontecido.

O until (“até”) também roda o bloco primeiro, mas continua até a condição ficar verdadeira — o contrário do while. A Ana começa com 1 e vai dobrando até o número passar de 10:

PS C:\Users\ana> $n = 1
PS C:\Users\ana> do { "n = $n"; $n *= 2 } until ($n -gt 10)
n = 1
n = 2
n = 4
n = 8
$n = 1
O número começa em 1.
"n = $n"; $n *= 2
Mostra o valor atual e depois o dobra. O *= 2 é “multiplique por 2 e guarde”.
until ($n -gt 10)
“Até $n ser maior que 10”. Depois de mostrar 8, $n vira 16, a condição fica verdadeira e o laço para. Por isso o 16 não aparece na tela: a mensagem roda antes da dobra, e o until é testado depois.

Missão: começando com $n = 1, use um do { ... } until que mostre n = 1, n = 2, n = 4 e n = 8, dobrando o valor até ele passar de 10.

$n = 1
# complete com do ... until

$n = 1
do { "n = $n"; $n *= 2 } until ($n -gt 10)

do { ... } until (condição)Precisa rodar pelo menos uma vez, e continuar até a condição ficar verdadeira.

Quando dá errado

O laço que não termina

Se a condição nunca fica falsa, o while não devolve o prompt. Um exemplo clássico é usar $true (“verdadeiro”, sempre) e não ter um break lá dentro:

while ($true) {
    "isso não para nunca"
}

Este bloco não foi rodado no laboratório, de propósito. $true é sempre verdadeiro (aula $true, $false e $null), o texto se repetiria sem fim, e a linha PS C:\Users\ana> não voltaria. No terminal, a interrupção usual é Ctrl+C (aula Tab, Histórico e Atalhos). No editor do guia, evite um while ($true) sem saída: a missão pode ficar presa.

O jeito seguro de estudar um “enquanto verdadeiro” é colocar um freio: um contador e um break (aula break e continue). Isso o laboratório rodou:

PS C:\Users\ana> $i = 0; while ($true) { $i++; if ($i -ge 1000) { "freio de segurança em $i"; break } }
freio de segurança em 1000
while ($true)
A condição nunca fica falsa por si só.
$i++
Soma 1 no contador a cada volta.
if ($i -ge 1000) { ...; break }
Quando o contador chega a 1000 (maior ou igual), mostra a mensagem e o break sai do laço. O prompt volta.

Como evitar: toda condição de while precisa de um caminho para ficar falsa — uma variável que muda, ou um break com limite. Nunca rode um while ($true) “só para ver” sem freio.

Faltaram os parênteses depois do while

A condição foi escrita sem ( ):

PS C:\Users\ana> while $estoque -gt 0 { $estoque-- }
ParserError:
Line |
   1 |  while $estoque -gt 0 { $estoque-- }
     |       ~
     | Missing opening '(' after keyword 'while'.

Este é um ParserError: erro de leitura do código. O PowerShell recusa a linha antes de rodar qualquer coisa, mostra a linha (Line | 1) e aponta o problema com um tracinho ~. Esses erros saem em inglês no PowerShell 7.7, mesmo num Windows em português.

ParserError
Erro de leitura: a linha nem chegou a executar.
Line | 1
A linha com o problema, repetida ao lado.
~
O tracinho aponta logo depois da palavra while, onde deveria abrir o parêntese.
Missing opening '(' after keyword 'while'
Quer dizer que faltou abrir parênteses logo depois da palavra while. A condição precisa ficar entre parênteses: while ($estoque -gt 0).

Como resolver: escreva while ($estoque -gt 0) { ... }, com parênteses em volta da condição.

Missão final: com um while, mostre volta 1, volta 2 e volta 3 (e só essas três). Lembre de ir aumentando o contador, senão o laço não termina.

$i = 1

$i = 1

    "volta $i"
    $i++
}

Resumo

  • while (condição) { ... } testa antes de cada volta. Se a condição já for falsa, o bloco não roda nenhuma vez.
  • do { ... } while (condição) e do { ... } until (condição) rodam o bloco pelo menos uma vez, e perguntam no fim.
  • while continua enquanto a condição é verdadeira; until continua até ela se tornar verdadeira.
  • A variável da condição precisa mudar (por exemplo $estoque--). Sem isso, o laço não termina.
  • Um while ($true) sem break não devolve o prompt. Não rode um desses “só para ver”.
  • Esquecer os parênteses depois do while gera um ParserError em inglês: Missing opening '(' after keyword 'while'.
