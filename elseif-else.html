PowerShell elseif e else

Na aula if, o PowerShell aprendeu a fazer uma coisa se uma condição for verdadeira. Mas e quando ela é falsa? E quando existem várias faixas, como as notas da turma da Ana (excelente, aprovada, recuperação, reprovada)? Nesta aula você vai completar o if com else ("senão") e elseif ("senão, se").

Você vai aprender
  • A usar else para o caminho "senão".
  • A encadear várias condições com elseif.
  • Por que a ordem das condições muda o resultado.
  • A pôr uma variável seguida de dois-pontos dentro do texto com ${nota}.
  • Os erros mais comuns: else if, elsif e o else sozinho.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: a placa na bifurcação

Imagine uma estrada com placas. O if é a primeira placa: "se a nota for 9 ou mais, vá por aqui". O elseif é a próxima placa, que só é lida por quem não entrou na primeira: "senão, se for 7 ou mais, vá por ali". O else é o caminho final, para quem não entrou em nenhuma: "senão, siga em frente". Cada pessoa entra em um caminho só, o primeiro cuja placa combina com ela.

1. Dois caminhos: if + else

PS C:\Users\ana> $nota = 5
PS C:\Users\ana> if ($nota -ge 7) { "Aprovada" } else { "Recuperação" }
Recuperação
if ($nota -ge 7)
"Se a nota for maior ou igual a 7". O -ge vem de greater or equal (aula Comparações).
{ "Aprovada" }
O bloco que roda quando a condição é verdadeira.
else
"Senão". Não tem condição: pega tudo o que não entrou no if.
{ "Recuperação" }
O bloco que roda quando a condição é falsa. Como 5 não é maior ou igual a 7, foi este.

Com if e else, sempre roda exatamente um dos dois blocos: nunca os dois, nunca nenhum.

Experimente: a Ana tem 20 anos. Complete o else para que o script mostre Pode entrar quando a idade for 18 ou mais, e Menor de idade quando não for. (Dica: troque a condição, ou ponha cada texto no bloco certo.)

$idade = 20
if ($idade -lt 18) {
    "Menor de idade"
}

$idade = 20
if ($idade -lt 18) {
    "Menor de idade"
} else {
    "Pode entrar"
}

2. Vários caminhos: elseif

Para as quatro faixas de nota da turma, encadeie condições com elseif. O PowerShell testa de cima para baixo e para na primeira que for verdadeira:

foreach ($nota in 9.5, 7, 5, 2) {
    if ($nota -ge 9) { "${nota}: Excelente" }
    elseif ($nota -ge 7) { "${nota}: Aprovada" }
    elseif ($nota -ge 5) { "${nota}: Recuperação" }
    else { "${nota}: Reprovada" }
}
foreach ($nota in 9.5, 7, 5, 2)
Repete o bloco para cada nota da lista (aula foreach). Aqui ele só serve para testar as quatro notas de uma vez.
if ($nota -ge 9)
Primeira placa: 9 ou mais.
elseif ($nota -ge 7)
"Senão, se": só é testado quando a anterior foi falsa. Por isso aqui já se sabe que a nota é menor que 9.
elseif ($nota -ge 5)
Mais uma placa. Pode haver quantos elseif você quiser.
else
O que sobrou: menos de 5.
"${nota}: Excelente"
A variável entre ${ }. As chaves são obrigatórias aqui por causa dos dois-pontos logo depois do nome (veja Quando dá errado).

Rode o script no editor abaixo para ver cada nota com a sua faixa.

Experimente: este é o script das notas, mas com "$nota: ..." sem as chaves. Rode e veja o erro. Depois troque cada $nota: por ${nota}: e rode de novo.

foreach ($nota in 9.5, 7, 5, 2) {
    if ($nota -ge 9) { "$nota: Excelente" }
    elseif ($nota -ge 7) { "$nota: Aprovada" }

    if ($nota -ge 9) { "${nota}: Excelente" }
    elseif ($nota -ge 7) { "${nota}: Aprovada" }
    elseif ($nota -ge 5) { "${nota}: Recuperação" }
    else { "${nota}: Reprovada" }
}
Nos scripts, prefira o formato de várias linhas, com a chave { na mesma linha do if e 4 espaços de recuo. Fica bem mais fácil de ler quando os blocos crescem: 
if ($nota -ge 7) {
    "Aprovada"
} elseif ($nota -ge 5) {
    "Recuperação"
} else {
    "Reprovada"
}

3. A ordem importa

Como o PowerShell para na primeira condição verdadeira, a ordem das placas muda o resultado. Veja a nota 9.5 com as condições invertidas:

PS C:\Users\ana> $nota = 9.5
PS C:\Users\ana> if ($nota -ge 5) { "Recuperação" } elseif ($nota -ge 9) { "Excelente" }
Recuperação

9.5 é maior ou igual a 5, então a primeira condição já foi verdadeira e o elseif nem foi testado. A Ana, com 9.5, ficou de recuperação! Não é erro do PowerShell: ele fez exatamente o que foi escrito.

Regra prática: com faixas do tipo "maior ou igual", comece pela maior (9, depois 7, depois 5). Com "menor que", comece pela menor.

Formas diferentes de decidir

FormaO que fazQuando usar
if (...) { }Faz algo só se for verdade.Uma ação opcional, sem alternativa.
if (...) { } else { }Escolhe um de dois caminhos.Sim ou não, aprovado ou não.
if / elseif / elseEscolhe um entre vários, testando em ordem.Faixas (notas, preços, idades) ou condições diferentes entre si.

Quando dá errado

Dois-pontos logo depois da variável: "$nota: Excelente"

Dentro de aspas duplas, o PowerShell lê $nota: como o começo de um nome especial, do tipo $env:PATH (onde o que vem antes dos dois-pontos é um "drive", como env). Como depois dos dois-pontos vem um espaço, o nome fica inválido e o script nem chega a rodar: o PowerShell recusa o código inteiro, apontando cada linha onde aparece "$nota:.

No laboratório, a mensagem dizia: Variable reference is not valid. ':' was not followed by a valid variable name character. Consider using ${} to delimit the name. Ou seja: "A referência à variável não é válida. O ':' não foi seguido de um caractere válido para nome de variável. Considere usar ${} para delimitar o nome." A moldura completa do erro não aparece aqui porque foi colhida de um jeito diferente do console, mas você pode vê-la de verdade no segundo "Experimente" acima.

Como resolver: ponha o nome entre chaves, "${nota}: Excelente". Outra saída é tirar a variável de dentro do texto: "$nota" + ": Excelente".

Escrever else if separado 
PS C:\Users\ana> Invoke-Expression 'if ($nota -ge 7) { "A" } else if ($nota -ge 5) { "B" }'
Invoke-Expression: Missing statement block after 'else' keyword.
Invoke-Expression '...'
Para colher o erro, o código errado foi rodado como texto pelo Invoke-Expression. Por isso a linha começa com Invoke-Expression:. Digitando o código direto, a moldura muda um pouco, mas a mensagem é a mesma.
Missing statement block after 'else' keyword
"Falta o bloco de comandos depois da palavra 'else'." Depois de else, o PowerShell espera uma chave {, e encontrou if.

Em linguagens como C e JavaScript se escreve else if. No PowerShell é tudo junto: elseif.

Escrever elsif (como no Ruby ou no Perl) 
PS C:\Users\ana> Invoke-Expression 'if ($nota -ge 7) { "A" } elsif ($nota -ge 5) { "B" }'
A
Invoke-Expression: O termo "elsif" não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.
Verifique a ortografia do nome ou, se um caminho foi incluído, verifique se o caminho está correto e tente novamente.
A
Este é mais traiçoeiro: o if rodou normalmente (a $nota ainda era 9.5) e mostrou "A".
O termo "elsif" não é reconhecido
O PowerShell não conhece elsif, então achou que era o nome de outro comando, escrito depois do if, e não encontrou nenhum comando com esse nome.
Verifique a ortografia do nome
É exatamente isso: a grafia certa é elseif.
else sozinho, sem if antes 
PS C:\Users\ana> Invoke-Expression 'else { "sozinho" }'
Invoke-Expression: O termo "else" não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.
Verifique a ortografia do nome ou, se um caminho foi incluído, verifique se o caminho está correto e tente novamente.

O else só existe grudado num if. Sozinho, o PowerShell acha que é o nome de um comando. Isso também acontece no terminal se você aperta Enter depois da } do if e digita o else na linha seguinte, porque o if já terminou. No terminal, escreva o else na mesma linha da }.

Referência rápida

Você digitaO que faz
if (cond) { A } else { B }A se verdade, B se não.
if (c1) { A } elseif (c2) { B } else { C }Testa em ordem e roda só o primeiro bloco cuja condição é verdadeira.
elseifTudo junto. Nem else if, nem elsif.
"${nota}: texto"Variável seguida de dois-pontos dentro do texto.

Resumo

  • else é o "senão": roda quando nada antes foi verdadeiro.
  • elseif testa outra condição, só se as anteriores falharam. Escreve-se tudo junto.
  • Roda sempre um bloco só: o primeiro cuja condição é verdadeira. Por isso a ordem importa.
  • Variável seguida de : dentro do texto precisa de chaves: "${nota}: ...".
  • else if dá "Missing statement block after 'else' keyword", e elsif vira "termo não reconhecido".
