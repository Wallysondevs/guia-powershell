PowerShell Comparando Textos (-like, -match)

Quais arquivos da pasta Downloads são PDFs? Esse e-mail tem arroba? A senha tem número? Para perguntas sobre o formato de um texto, o -eq não basta: entram o -like e o -match.

Você vai aprender
  • A comparar textos por padrão com -like e os curingas * e ?.
  • A procurar padrões com -match (expressões regulares) e ler o resultado em $Matches.
  • A trocar pedaços do texto com -replace.
  • O erro real de uma expressão regular mal escrita.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: procurar com coringa

No baralho, o coringa vale qualquer carta. No -like, o * vale "qualquer coisa" e o ? vale "uma letra qualquer". Com eles, a Ana pergunta "esse arquivo termina com .txt?" sem saber o nome inteiro.

1. -like e curingas

PS C:\Users\ana> "arquivo.txt" -like "*.txt"
True
PS C:\Users\ana> "arquivo.log" -like "*.txt"
False
PS C:\Users\ana> "PowerShell" -like "power*"
True
PS C:\Users\ana> "PowerShell" -clike "power*"
False
PS C:\Users\ana> "a" -notlike "b*"
True
ParteO que faz
*Qualquer coisa (até nada).
?Exatamente uma letra qualquer.
-clikeDiferencia maiúsculas.
-notlikeO contrário: True quando não combina.

Experimente: o arquivo é uma foto .jpg. Corrija o padrão do -like.

$arquivo = "praia.jpg"
if ($arquivo -like "*.png") { "É foto" }

$arquivo = "praia.jpg"
if ($arquivo -like "*.jpg") { "É foto" }

2. -match e expressões regulares

O -match usa expressões regulares (regex): uma mini-linguagem de padrões, mais poderosa que os curingas. Alguns símbolos: \d = um dígito, + = "um ou mais", ^ = começo do texto, $ = fim.

PS C:\Users\ana> "abc123" -match "\d+"
True
PS C:\Users\ana> $Matches

Name                           Value
----                           -----
0                              123

PS C:\Users\ana> "PowerShell" -match "^Power"
True
PS C:\Users\ana> "ana@exemplo.com" -match "@"
True

Depois de um -match que deu True, a variável automática $Matches guarda o pedaço encontrado (no item 0). Dá até para dar nome aos pedaços:

PS C:\Users\ana> "abc123" -match "^(?<letras>\D+)(?<nums>\d+)$"
True
PS C:\Users\ana> $Matches

Name                           Value
----                           -----
letras                         abc
nums                           123
0                              abc123

(?<letras>\D+) quer dizer "um grupo chamado letras, com um ou mais não-dígitos". Depois, $Matches.letras devolve abc.

3. -replace

PS C:\Users\ana> "olá mundo" -replace "mundo", "Ana"
olá Ana
PS C:\Users\ana> "a b a" -replace "a", "X"
X b X

Troca todas as ocorrências. O primeiro valor também é uma expressão regular.

Formas diferentes

OperadorQuando
-likePadrões simples, como nomes de arquivo (*.txt).
-matchPadrões mais complexos: números, e-mails, começo/fim.
-replaceTrocar pedaços de texto.

Quando dá errado

Expressão regular inválida 
PS C:\Users\ana> "abc" -match "["
OperationStopped: Invalid pattern '[' at offset 1. Unterminated [] set.

"Padrão inválido [ na posição 1. Conjunto [] não terminado." Na regex, [ abre um conjunto de letras e precisa de um ]. Para procurar o colchete de verdade, escreva \[.

Usou -like sem curinga

"arquivo.txt" -like ".txt" dá False: sem *, o -like compara o texto inteiro. Use "*.txt".

Referência rápida

Você digitaO que faz
-like "*.txt"Combina com curingas.
-notlikeNão combina.
*, ?Qualquer coisa; uma letra.
-match "\d+"Combina com expressão regular.
$MatchesO que o último -match achou.
-replace "a", "b"Troca todas as ocorrências.
-clike, -cmatchDiferenciam maiúsculas.

Exercícios

1. Termina com

$arquivo -like ""

2. Trocar

$endereco "rua", "Rua"

3. Começa com

Complete o símbolo de regex que quer dizer "começo do texto":

"PowerShell" -match "Power"

4. Onde fica o pedaço encontrado depois de um -match?

5. O que "PowerShell" -like "power*" mostra?

Missão final: com -match e \d, mostre Tem número se $senha tiver algum dígito.

$senha = "gato2026"

$senha = "gato2026"
if ($senha -match "\d") { "Tem número" }

Resumo

  • -like usa curingas: * e ?.
  • -match usa expressões regulares e preenche $Matches.
  • -replace troca todas as ocorrências.
  • Prefixo c (-clike, -cmatch) diferencia maiúsculas.
