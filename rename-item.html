Rename-Item: Renomeando

A Ana baixou as fotos do celular e elas vieram com a extensão em maiúsculas: foto1.JPG, foto2.JPG. Também tem uma nota.txt que merecia um nome melhor. Nesta aula você vai trocar o nome de um arquivo, conferir o resultado, e depois renomear vários de uma vez sem medo, ensaiando antes com o -WhatIf.

Você vai aprender
  • A trocar o nome de um arquivo ou pasta com Rename-Item.
  • O que são o -Path (quem) e o -NewName (o nome novo).
  • O -PassThru, que mostra o arquivo depois de renomeado.
  • A renomear vários arquivos de uma vez, pelo pipeline (|).
  • O -WhatIf, que ensaia sem mudar nada.
  • Os três erros mais comuns, com a mensagem real.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, dentro de uma pasta de treino chamada guia-ps-teste, na pasta pessoal da usuária fictícia ana. Por isso o prompt aparece como PS C:\Users\ana\guia-ps-teste>.

A ideia: a etiqueta da pasta suspensa

Pense numa gaveta de arquivo com pastas suspensas. Renomear é trocar a etiqueta de uma pasta: o conteúdo continua igual, no mesmo lugar. Só o nome muda.

É exatamente isso que o Rename-Item faz. Ele não abre o arquivo, não copia, não move de pasta. Para levar o arquivo a outra pasta existe o Move-Item (aula Copiando e Movendo).

1. Trocando um nome

A pasta de treino tem uma nota.txt. Para chamá-la de anotacao.txt:

PS C:\Users\ana\guia-ps-teste> Rename-Item nota.txt anotacao.txt
PS C:\Users\ana\guia-ps-teste> Get-ChildItem -Name
anotacao.txt
foto1.JPG
foto2.JPG
foto3.JPG
Rename-Item
"Renomear item". Rename é "renomear" e Item é qualquer coisa que mora numa pasta: arquivo ou outra pasta.
nota.txt
Quem vai ser renomeado. É o parâmetro -Path ("caminho"), que pode ir sem o nome quando vem primeiro.
anotacao.txt
O nome novo. É o parâmetro -NewName, que pode ir sem o nome quando vem em segundo.

O Rename-Item não escreveu nada: no PowerShell, silêncio quer dizer que deu certo. O Get-ChildItem -Name (aula Listando) confirma que a nota.txt virou anotacao.txt.

Com os nomes dos parâmetros escritos

Nos scripts, escreva os nomes dos parâmetros. Fica mais fácil de ler daqui a um mês:

Rename-Item -Path nota.txt -NewName anotacao.txt

Experimente: o script cria lista.txt. Acrescente uma linha que troque o nome dele para compras.txt e rode o código.

'arroz' | Set-Content lista.txt

'arroz' | Set-Content lista.txt
Rename-Item -Path lista.txt -NewName compras.txt

2. Vendo o resultado: -PassThru

Se você quer uma confirmação na hora, sem listar a pasta, use -PassThru ("passar adiante"). Ele mostra o arquivo já com o nome novo:

PS C:\Users\ana\guia-ps-teste> Rename-Item anotacao.txt -NewName lembrete.txt -PassThru

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              4 lembrete.txt

É a mesma ficha que o Get-ChildItem mostra: a pasta, a data da última mudança, o tamanho (4 bytes: as letras oi e a quebra de linha) e o nome novo. Repare que a data não mudou para "agora": renomear não altera o conteúdo.

3. Vários de uma vez

As três fotos têm a extensão .JPG em maiúsculas. Renomear uma por uma seria chato. O jeito é listar as fotos e mandar a lista, pelo pipeline (|), para o Rename-Item, dizendo como calcular cada nome novo.

Primeiro, ensaie com -WhatIf

Mexer em muitos arquivos de uma vez pede cuidado. O -WhatIf ("e se?") mostra o que aconteceria, sem fazer nada:

PS C:\Users\ana\guia-ps-teste> Get-ChildItem *.JPG | Rename-Item -NewName { $_.Name -replace '\.JPG$', '.jpg' } -WhatIf
What If: Executando a operação "Renomear Arquivo" no destino "Item: C:\Users\ana\guia-ps-teste\foto1.JPG Destino: C:\Users\ana\guia-ps-teste\foto1.jpg".
What If: Executando a operação "Renomear Arquivo" no destino "Item: C:\Users\ana\guia-ps-teste\foto2.JPG Destino: C:\Users\ana\guia-ps-teste\foto2.jpg".
What If: Executando a operação "Renomear Arquivo" no destino "Item: C:\Users\ana\guia-ps-teste\foto3.JPG Destino: C:\Users\ana\guia-ps-teste\foto3.jpg".
Get-ChildItem *.JPG
Lista só os arquivos terminados em .JPG. O * quer dizer "qualquer coisa antes".
|
O pipeline: passa cada arquivo da lista para o próximo comando, um de cada vez.
-NewName { … }
Em vez de um nome fixo, uma receita entre chaves, calculada para cada arquivo.
$_
"O arquivo da vez". $_.Name é o nome dele, como foto1.JPG.
-replace '\.JPG$', '.jpg'
Troca o .JPG do fim ($ = fim do nome) por .jpg. O \. é um ponto de verdade. Você vai ver o -replace com calma em Comparando Textos.
-WhatIf
Só ensaia. A linha What If: descreve cada troca: Item é o nome atual e Destino é o nome novo.

O ensaio mostrou exatamente o que a Ana queria. Agora é só rodar sem o -WhatIf:

PS C:\Users\ana\guia-ps-teste> Get-ChildItem *.JPG | Rename-Item -NewName { $_.Name -replace '\.JPG$', '.jpg' }
PS C:\Users\ana\guia-ps-teste> Get-ChildItem -Name
foto1.jpg
foto2.jpg
foto3.jpg
lembrete.txt
Crie o hábito: antes de renomear, mover ou apagar muitos arquivos, rode uma vez com -WhatIf. Se o ensaio estiver certo, apague o -WhatIf e rode de novo.

Formas diferentes de renomear

FormaQuando usar
Rename-Item -Path a.txt -NewName b.txtNos scripts: tudo escrito, fácil de ler.
Rename-Item a.txt b.txtNo terminal, no dia a dia: os dois parâmetros pela posição.
ren a.txt b.txtApelido herdado do cmd (aula Apelidos). Funciona no terminal, evite em scripts.
Get-ChildItem … | Rename-Item -NewName { … }Vários arquivos com a mesma regra. Ensaie com -WhatIf.
Move-Item a.txt pasta\b.txtQuando, além de renomear, o arquivo tem de mudar de pasta. O Rename-Item não faz isso.

Quando dá errado

O arquivo não existe (ou o nome está errado) 
PS C:\Users\ana\guia-ps-teste> Rename-Item naoexiste.txt x.txt
Rename-Item: Não é possível localizar o caminho 'C:\Users\ana\guia-ps-teste\naoexiste.txt' porque ele não existe.
Rename-Item:
Qual comando reclamou.
Não é possível localizar o caminho '…\naoexiste.txt'
Ele procurou o arquivo na pasta atual (repare no caminho completo) e não achou.

Como resolver: liste a pasta com Get-ChildItem e copie o nome exato, com a extensão. Use a tecla Tab para completar o nome (aula Tab, Histórico e Atalhos).

Já existe um arquivo com o nome novo 
PS C:\Users\ana\guia-ps-teste> Rename-Item lembrete.txt foto1.jpg
Rename-Item: Não é possível criar um arquivo já existente.

A pasta já tem uma foto1.jpg. O PowerShell se recusa a passar por cima dela, e isso é bom: nenhum arquivo foi perdido. Na mensagem, "criar" quer dizer "criar um item com esse nome".

Como resolver: escolha outro nome, ou primeiro renomeie (ou apague) o arquivo que já usa esse nome.

Pôs uma pasta no nome novo 
PS C:\Users\ana\guia-ps-teste> Rename-Item lembrete.txt .\pasta\x.txt
Rename-Item: Não é possível renomear o destino especificado porque ele representa um caminho ou nome de dispositivo.

O -NewName aceita só o nome, nunca um caminho. "Representa um caminho" é o PowerShell dizendo: "isso aí tem pasta no meio".

Como resolver: para mudar de pasta, use Move-Item, que pode mudar a pasta e o nome ao mesmo tempo.

Referência rápida

New-Item IMG1.jpg, IMG2.jpg | Out-Null

New-Item IMG1.jpg, IMG2.jpg | Out-Null
Get-ChildItem IMG*.jpg | Rename-Item -NewName { $_.Name -replace '^IMG', 'ferias' }

Resumo

  • Rename-Item nome-atual nome-novo troca só a etiqueta: o conteúdo e a pasta continuam os mesmos.
  • -Path é quem, -NewName é o nome novo. Nos scripts, escreva os dois.
  • Sem mensagem = deu certo. Para ver o resultado na hora, use -PassThru.
  • Vários arquivos: Get-ChildItem … | Rename-Item -NewName { … }, com $_ sendo o arquivo da vez.
  • Ensaie com -WhatIf antes de mexer em muitos arquivos.
  • O -NewName não aceita pasta; para mudar de lugar, use Move-Item. E o PowerShell nunca passa por cima de um arquivo que já existe.
