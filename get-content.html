Get-Content: Lendo Arquivos

A Ana guarda um arquivo de texto com uma linha por tarefa e uma planilha simples em .csv. Para olhar o que tem dentro, ela não precisa abrir o Bloco de Notas: o Get-Content mostra o conteúdo direto no terminal. Nesta aula você vai ler um arquivo inteiro, só o começo, só o fim, uma linha específica, e contar linhas.

Você vai aprender
  • A mostrar o conteúdo de um arquivo com Get-Content.
  • A ler só as primeiras linhas (-TotalCount) ou só as últimas (-Tail).
  • Que o PowerShell entrega o arquivo como uma lista de linhas.
  • A contar linhas com .Count e pegar uma linha com [0].
  • A ler o arquivo como um texto único com -Raw.
  • A procurar uma palavra dentro do arquivo.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, dentro de uma pasta de treino guia-ps-teste, com dois arquivos criados para isso: linhas.txt (doze linhas, de "Linha 1" a "Linha 12") e pessoas.csv.

A ideia: o caderno de linhas numeradas

Pense num caderno em que cada linha é numerada. Você pode ler o caderno todo, só a primeira página, só as últimas linhas, ou ir direto à linha 1. O Get-Content trata o arquivo assim: cada linha vira um item, e você escolhe quais quer ver.

"Pegar conteúdo". Get é "pegar", e Content é "conteúdo".

O arquivo a ler, na pasta atual. É o parâmetro -Path, que pode ir sem o nome.

2. Só o começo ou só o fim

Arquivo grande demais para a tela? Peça só um pedaço:

PS C:\Users\ana\guia-ps-teste> Get-Content linhas.txt -TotalCount 3
Linha 1
Linha 2
Linha 3
PS C:\Users\ana\guia-ps-teste> Get-Content linhas.txt -Tail 2
Linha 11
Linha 12
-TotalCount 3
"No total, 3": as 3 primeiras linhas. Também aceita o nome curto -Head.
-Tail 2
"Rabo": as 2 últimas linhas. Ótimo para olhar o final de um arquivo de registro (log), onde ficam as coisas mais recentes.

3. O arquivo é uma lista de linhas

Coloque o comando entre parênteses e o resultado vira uma lista que você pode medir e consultar:

PS C:\Users\ana\guia-ps-teste> (Get-Content linhas.txt).Count
12
PS C:\Users\ana\guia-ps-teste> (Get-Content linhas.txt)[0]
Linha 1
( … )
"Rode isto primeiro e me dê o resultado inteiro."
.Count
Quantos itens a lista tem: aqui, 12 linhas.
[0]
O primeiro item. A contagem começa do zero: [0] é a linha 1, [1] é a linha 2, e [-1] é a última.

Experimente: mostre quantas linhas tem o tarefas.txt. A resposta deve ser 3.

'Comprar pão', 'Pagar a luz', 'Ligar para a mãe' | Set-Content tarefas.txt


'Comprar pão', 'Pagar a luz', 'Ligar para a mãe' | Set-Content tarefas.txt
(Get-Content tarefas.txt).Count

4. Tudo de uma vez: -Raw

Às vezes você quer o arquivo como um texto só, e não como lista. É para isso que serve o -Raw ("cru"). Aqui ele conta os caracteres do arquivo inteiro:

PS C:\Users\ana\guia-ps-teste> Get-Content linhas.txt -Raw | Measure-Object -Character

Lines Words Characters Property
----- ----- ---------- --------
                   111

São 111 caracteres: as letras e números das doze linhas (87) mais as quebras de linha. No Windows, cada quebra de linha conta como 2 caracteres invisíveis, e 12 linhas dão 24. O -Raw mantém as quebras dentro do texto.

5. Procurando uma palavra

O cat é um apelido do Get-Content. Com o Select-String (aula Select-String) você filtra só as linhas que têm uma palavra:

PS C:\Users\ana\guia-ps-teste> cat pessoas.csv
nome,idade
Ana,30
Beto,25
PS C:\Users\ana\guia-ps-teste> Get-Content pessoas.csv | Select-String Ana

Ana,30
Para um .csv de verdade, o Import-Csv (aula CSV) é melhor: ele entende as colunas. O Get-Content só enxerga linhas de texto.

Formas diferentes de ler

FormaQuando usar
Get-Content -Path a.txtNos scripts: tudo escrito.
Get-Content a.txtNo terminal, para olhar rápido.
cat a.txt, type a.txt, gc a.txtApelidos (aula Apelidos). Bons no terminal; evite em scripts.
Get-Content a.txt -RawQuando você quer um texto único, não uma lista.
Import-Csv a.csvPlanilhas .csv: lê por coluna.

Quando dá errado

O arquivo não existe 
PS C:\Users\ana\guia-ps-teste> Get-Content naoexiste.txt
Get-Content: Não é possível localizar o caminho 'C:\Users\ana\guia-ps-teste\naoexiste.txt' porque ele não existe.
Get-Content:
O comando que reclamou.
'C:\Users\ana\guia-ps-teste\naoexiste.txt'
Onde ele procurou: na pasta atual + o nome que você digitou.

Como resolver: confira a pasta pelo prompt e o nome exato com Get-ChildItem. Erros comuns: esquecer a extensão (notas em vez de notas.txt) ou estar em outra pasta. Use a tecla Tab para completar o nome.

Contou 1 linha num arquivo de várias

Se você usou (Get-Content a.txt -Raw).Count, o resultado é 1: com -Raw o arquivo vira um texto único, e um texto é um item só.

Como resolver: para contar linhas, tire o -Raw.

Resumo

  • Get-Content arquivo mostra o conteúdo, uma linha por vez.
  • -TotalCount pega o começo e -Tail pega o fim.
  • O arquivo vira uma lista: .Count conta as linhas e [0] pega a primeira.
  • -Raw devolve tudo como um texto só, com as quebras de linha.
  • "Não é possível localizar o caminho" quer dizer nome ou pasta errada.
