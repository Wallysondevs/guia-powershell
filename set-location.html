Mudando de Pasta (Set-Location)

Você já sabe perguntar onde está. Agora vai andar: entrar numa subpasta, subir um nível, ir para a pasta pessoal, marcar um lugar para voltar e — no PowerShell 7 — desfazer o último passo com cd -. Também vai ver os dois erros mais comuns: pasta que não existe e nome com espaço sem aspas.

Você vai aprender
  • O Set-Location, que muda a pasta atual, e o apelido cd.
  • O .., que sobe um nível, e o ~, que é a pasta pessoal.
  • Por que um nome com espaço precisa de aspas.
  • A pilha de pastas: Push-Location e Pop-Location.
  • O cd -, que volta à pasta anterior — uma novidade do PowerShell 7.
  • Os erros reais de uma pasta inexistente e de um espaço sem aspas.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta de teste C:\Users\ana\guia-ps-teste. Nela já existiam duas subpastas: fotos e minhas notas (este último nome tem um espaço, de propósito). No seu computador, pratique numa pasta de teste, não na raiz do disco.

A ideia: os cômodos de uma casa

A pasta atual é o cômodo em que você está. Set-Location fotos é atravessar a porta e entrar no quarto das fotos. .. é voltar para o corredor. ~ é ir direto para a sua casa (a pasta pessoal). O prompt, na porta, troca a plaquinha toda vez que você anda.

Na casaNo PowerShell
Entrar no quarto das fotosSet-Location fotos
Voltar ao corredorSet-Location ..
Ir para casa, de qualquer cômodoSet-Location ~
Deixar um marcador na porta e dar uma olhada no quartoPush-Location e Pop-Location

1. Entrando numa subpasta

Estando em guia-ps-teste, entre em fotos e peça a pasta atual para confirmar:

PS C:\Users\ana\guia-ps-teste> Set-Location fotos; Get-Location

Path
----
C:\Users\ana\guia-ps-teste\fotos
Set-Location
Verbo Set ("definir") + substantivo Location: "mude o local".
fotos
O destino, em relação à pasta atual: a subpasta fotos.
Get-Location
Na mesma linha, depois do ;, confirma para onde você foi. O ; separa dois comandos: o PowerShell roda um e, em seguida, o outro.

O caminho virou C:\Users\ana\guia-ps-teste\fotos. O próximo prompt já nasce nessa pasta.

Experimente: crie uma pasta fotos e entre nela com Set-Location.

New-Item -ItemType Directory -Name fotos -Force | Out-Null

New-Item -ItemType Directory -Name fotos -Force | Out-Null
Set-Location fotos

2. Subindo um nível: ..

Dois pontos seguidos, .., querem dizer "a pasta de cima" (a pasta-mãe). De dentro de fotos, suba de volta para guia-ps-teste:

PS C:\Users\ana\guia-ps-teste\fotos> Set-Location ..; Get-Location

Path
----
C:\Users\ana\guia-ps-teste

O prompt volta para PS C:\Users\ana\guia-ps-teste>. Um ponto sozinho, ., é a pasta atual; os dois pontos, .., são a de cima. Você vai ver os dois de novo na aula de Caminhos.

3. Nome com espaço: use aspas

A outra subpasta se chama minhas notas, com um espaço. Sem aspas, o PowerShell acharia que minhas é um parâmetro e notas é outro. Por isso o nome vai entre aspas (simples, aqui, porque não há variável no meio):

PS C:\Users\ana\guia-ps-teste> cd 'minhas notas'; Get-Location

Path
----
C:\Users\ana\guia-ps-teste\minhas notas

O caminho termina em \minhas notas, com o espaço, e o prompt também: PS C:\Users\ana\guia-ps-teste\minhas notas>. O apelido cd faz a mesma coisa que o Set-Location; nos scripts, prefira o nome completo.

4. Indo para casa: ~

O til ~ é um atalho para a pasta pessoal do usuário, a mesma do $HOME:

PS C:\Users\ana\guia-ps-teste\minhas notas> cd ~; Get-Location

Path
----
C:\Users\ana

Você saiu da pasta de teste e foi para C:\Users\ana. No seu computador, no lugar de ana aparece o seu usuário. Para voltar à pasta de teste, use o caminho completo ou um Set-Location até ela. (Foi o que o laboratório fez, em silêncio, antes dos próximos exemplos.)

5. Um marcador na porta: Push-Location e Pop-Location

Às vezes você quer entrar numa pasta, fazer uma coisa, e voltar exatamente para onde estava. A pilha de pastas serve para isso: Push-Location guarda o lugar atual e já entra no destino; Pop-Location desempilha e volta.

Pense numa pilha de pratos: o último que você pôs em cima é o primeiro que tira. "Push" é pôr; "Pop" é tirar.

PS C:\Users\ana\guia-ps-teste> Push-Location fotos; Get-Location; Pop-Location; Get-Location

Path
----
C:\Users\ana\guia-ps-teste\fotos
C:\Users\ana\guia-ps-teste

Os dois caminhos saíram na mesma tabela: primeiro \fotos (depois do Push-Location), depois \guia-ps-teste (depois do Pop-Location). Você deu uma puladinha no quarto das fotos e voltou para o corredor, sem ter de digitar o caminho de volta.

6. Voltar à anterior: cd - 7.7

No PowerShell 7 existe um atalho no estilo do Linux: cd - volta para a pasta em que você estava antes do último cd (ou Set-Location).

PS C:\Users\ana\guia-ps-teste> cd fotos; cd -; Get-Location

Path
----
C:\Users\ana\guia-ps-teste

O laboratório entrou em fotos e logo em seguida rodou cd -; o Get-Location confirmou que a pasta atual voltou a ser C:\Users\ana\guia-ps-teste.

No Windows PowerShell 5.1 o cd - não existe. O 5.1 trata o hífen como o nome de uma pasta chamada -, dentro da pasta atual, e reclama que ela não existe: 
PS C:\Users\ana\guia-ps-teste> cd fotos; cd -
cd : Não é possível localizar o caminho 'C:\Users\ana\guia-ps-teste\fotos\-' porque ele não existe.
Para voltar no 5.1, use o Pop-Location (se você entrou com Push-Location) ou digite o caminho de destino.

Missão: crie a pasta fotos, entre nela com Push-Location e volte com Pop-Location.

New-Item -ItemType Directory -Name fotos -Force | Out-Null
Set-Location fotos

New-Item -ItemType Directory -Name fotos -Force | Out-Null
Push-Location fotos
Pop-Location

Formas diferentes de mudar de pasta

FormaQuando usar
Set-Location fotosNos scripts e neste guia: o nome completo.
cd fotosAtalho no terminal. É o mesmo comando.
Set-Location ..Subir um nível, para a pasta-mãe.
Set-Location ~Ir para a pasta pessoal, de qualquer lugar.
Push-Location / Pop-LocationQuando você quer ir, fazer algo e voltar ao ponto de partida.
cd -No PowerShell 7, para voltar à pasta anterior. Não use no 5.1.

Quando dá errado

A pasta não existe

Pedimos uma pasta que não estava em guia-ps-teste:

PS C:\Users\ana\guia-ps-teste> Set-Location naoexiste
Set-Location: Não é possível localizar o caminho 'C:\Users\ana\guia-ps-teste\naoexiste' porque ele não existe.
Set-Location:
Quem está reclamando.
Não é possível localizar o caminho '…\naoexiste' porque ele não existe.
O PowerShell juntou o destino com a pasta atual e não achou essa combinação no disco. O caminho completo na mensagem ajuda a ver onde ele procurou.

Como resolver: confira o nome (maiúsculas não importam, mas um acento ou um espaço a mais importam) e se você já está na pasta certa. O erro não cria nem apaga nada; o prompt continua onde estava.

Nome com espaço, sem aspas

E se a gente esquecer as aspas em minhas notas?

PS C:\Users\ana\guia-ps-teste> cd minhas notas
Set-Location: Não foi possível encontrar um parâmetro posicional que aceite o argumento 'notas'.
Set-Location:
De novo o comando de verdade (o cd é só apelido).
Não foi possível encontrar um parâmetro posicional que aceite o argumento 'notas'.
O PowerShell leu minhas como o destino e notas como um segundo argumento solto, que o comando não aceita.

Como resolver: ponha o nome entre aspas: Set-Location 'minhas notas'. Qualquer caminho com espaço, no Windows, precisa disso.

Resumo

  • Set-Location (apelido cd) muda a pasta atual; o prompt acompanha.
  • .. sobe um nível; ~ vai para a pasta pessoal.
  • Nome com espaço vai entre aspas: Set-Location 'minhas notas'.
  • Push-Location guarda o lugar e entra; Pop-Location volta.
  • cd - volta à pasta anterior no PowerShell 7. No 5.1 isso dá erro.
  • Pasta inexistente ou espaço sem aspas geram erro vermelho, mas não alteram o disco: confira o nome e tente de novo.
