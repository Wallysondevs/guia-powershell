Select-Object

Um objeto pode ter muitos campos, e uma lista pode ter muitos itens. O Select-Object (apelido select) é a tesoura: escolhe quais colunas ficam e quantos itens passam.

Você vai aprender
  • A escolher colunas com -Property.
  • A pegar os primeiros e os últimos com -First e -Last.
  • A tirar os repetidos com -Unique.
  • A tirar o valor "puro" de um campo com -ExpandProperty.
  • A criar uma coluna calculada com @{ Name = ...; Expression = { ... } }.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a tesoura da planilha

Imagine uma planilha com dez colunas, mas você só quer imprimir o nome e o telefone das cinco primeiras pessoas. Você esconde as outras colunas e corta as linhas que sobram. É isso que o Select-Object faz.

Nesta aula, a lista de exemplo é esta turma:

PS> $turma = @(
>>   [pscustomobject]@{ Nome = "Ana"; Cidade = "Recife"; Nota = 9 }
>>   [pscustomobject]@{ Nome = "Beto"; Cidade = "Natal"; Nota = 6 }
>>   [pscustomobject]@{ Nome = "Caio"; Cidade = "Recife"; Nota = 8 }
>>   [pscustomobject]@{ Nome = "Duda"; Cidade = "Maceió"; Nota = 10 }
>> )
PS> $turma

Nome Cidade Nota
---- ------ ----
Ana  Recife    9
Beto Natal     6
Caio Recife    8
Duda Maceió   10

1. Escolhendo colunas

PS> $turma | Select-Object Nome, Nota

Nome Nota
---- ----
Ana     9
Beto    6
Caio    8
Duda   10
Select-Object
A tesoura.
Nome, Nota
As colunas que ficam, separadas por vírgula. É o parâmetro -Property, que pode ficar implícito.

2. Os primeiros e os últimos

PS> $turma | Select-Object -First 2

Nome Cidade Nota
---- ------ ----
Ana  Recife    9
Beto Natal     6
PS> $turma | Select-Object -Last 1 -Property Nome

Nome
----
Duda
-First 2
Só os 2 primeiros itens que chegarem.
-Last 1
Só o último. Dá para juntar com -Property para escolher a coluna.

Junto com o Sort-Object (aula Sort-Object), isso vira um "top 3": ordene e pegue os primeiros.

Experimente: as notas já estão ordenadas da maior para a menor. Complete com Select-Object -First 2 para ficar só com os dois melhores alunos.

$turma = @(
    [pscustomobject]@{ Nome = "Duda"; Nota = 10 }
    [pscustomobject]@{ Nome = "Ana"; Nota = 9 }
    [pscustomobject]@{ Nome = "Caio"; Nota = 8 }
)
$turma

$turma = @(
    [pscustomobject]@{ Nome = "Duda"; Nota = 10 }
    [pscustomobject]@{ Nome = "Ana"; Nota = 9 }
    [pscustomobject]@{ Nome = "Caio"; Nota = 8 }
)
$turma | Select-Object -First 2

3. Tirando os repetidos: -Unique

PS> "Recife", "Natal", "Recife", "Maceió", "Natal" | Select-Object -Unique
Recife
Natal
Maceió

O -Unique deixa passar cada valor só na primeira vez que ele aparece, e mantém a ordem original.

4. Só o valor: -ExpandProperty

Compare as duas formas. A primeira devolve objetos com uma coluna (por isso vem com cabeçalho). A segunda devolve só os textos:

PS> $turma | Select-Object -Property Nome

Nome
----
Ana
Beto
Caio
Duda
PS> $turma | Select-Object -ExpandProperty Nome
Ana
Beto
Caio
Duda
-Property Nome
Devolve fichas com um campo Nome. Na tela, vira uma tabela de uma coluna.
-ExpandProperty Nome
Abre a ficha e devolve o valor de dentro: os textos Ana, Beto… Use quando você quer uma lista simples.

5. Coluna calculada

Dá para criar uma coluna nova, calculada a partir das outras. Você passa uma hashtable com o nome da coluna e um bloco que calcula o valor:

PS> $turma | Select-Object Nome, @{ Name = "Situação"; Expression = { if ($_.Nota -ge 7) { "aprovado" } else { "recuperação" } } }

Nome Situação
---- --------
Ana  aprovado
Beto recuperação
Caio aprovado
Duda aprovado
@{ ... }
Uma hashtable (aula Hashtables) que descreve a coluna.
Name = "Situação"
O título da coluna nova.
Expression = { ... }
O bloco que calcula o valor para cada item. Dentro dele, $_ é o item da vez.

Quando dá errado

Coluna com nome errado: a coluna vem vazia 
PS> $turma | Select-Object Nome, Idade

Nome Idade
---- -----
Ana  
Beto 
Caio 
Duda

Não existe Idade na turma, mas o PowerShell não dá erro: ele cria a coluna e deixa vazia. Se uma coluna aparecer em branco, confira o nome com o Get-Member.

-ExpandProperty com um campo que não existe 
$turma | Select-Object -ExpandProperty Idade

Com -ExpandProperty, aí sim é erro: ele precisa abrir um campo que existe. A mensagem diz que a propriedade Idade não foi encontrada, e aparece uma vez para cada item da lista (aqui, quatro vezes).

Referência rápida

Você digitaO que faz
Select-Object A, BFica só com as colunas A e B.
-First 3 / -Last 3Os 3 primeiros / os 3 últimos.
-Skip 2Pula os 2 primeiros.
-UniqueTira os repetidos.
-ExpandProperty ADevolve só os valores do campo A.
@{ Name = "X"; Expression = { ... } }Coluna calculada.

$cidades = "Recife", "Natal", "Recife", "Maceió", "Natal"
$cidades

Resumo

  • Select-Object escolhe colunas (Nome, Nota) e quantidade de itens (-First, -Last, -Skip).
  • -Unique tira os repetidos.
  • -ExpandProperty devolve só os valores de um campo.
  • Coluna calculada: @{ Name = "X"; Expression = { ... } }.
  • Nome de coluna errado não dá erro: a coluna vem vazia.
