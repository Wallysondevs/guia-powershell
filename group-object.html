Group-Object: Agrupando

Quantos alunos há em cada cidade? Quantos pedidos em cada status? O Group-Object (apelido group) junta os objetos que têm o mesmo valor num campo e conta cada grupo.

Você vai aprender
  • A agrupar por um campo: Group-Object Cidade.
  • A ler as colunas Count, Name e Group.
  • A ordenar os grupos pelo tamanho.
  • A pegar os itens de dentro de um grupo.
  • A contar palavras repetidas com -NoElement.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: separar as meias

Depois de lavar a roupa, você separa as meias por cor: um monte de pretas, um de brancas, um de coloridas. Depois conta cada monte. O Group-Object faz exatamente isso.

1. Agrupando por um campo

PS> $turma = @(
>>   [pscustomobject]@{ Nome = "Ana"; Cidade = "Recife" }
>>   [pscustomobject]@{ Nome = "Beto"; Cidade = "Natal" }
>>   [pscustomobject]@{ Nome = "Caio"; Cidade = "Recife" }
>>   [pscustomobject]@{ Nome = "Duda"; Cidade = "Maceió" }
>>   [pscustomobject]@{ Nome = "Eva"; Cidade = "Recife" }
>> )
PS> $turma | Group-Object Cidade

Count Name                      Group
----- ----                      -----
    1 Maceió                    {@{Nome=Duda; Cidade=Maceió}}
    1 Natal                     {@{Nome=Beto; Cidade=Natal}}
    3 Recife                    {@{Nome=Ana; Cidade=Recife}, @{Nome=Caio; Cida…
Count
Quantos objetos caíram naquele grupo.
Name
O valor que eles têm em comum (a cidade).
Group
Os próprios objetos do grupo. Na tela aparecem resumidos entre chaves.

2. Do maior grupo para o menor

PS> $turma | Group-Object Cidade | Sort-Object Count -Descending | Select-Object Count, Name

Count Name
----- ----
    3 Recife
    1 Natal
    1 Maceió

Experimente: agrupe a lista de cidades com Group-Object para ver quantas vezes cada uma aparece.

$cidades = "Recife", "Natal", "Recife", "Recife", "Natal"
$cidades

$cidades = "Recife", "Natal", "Recife", "Recife", "Natal"
$cidades | Group-Object

3. Os itens de um grupo

O campo Group guarda os objetos. Dá para abrir um grupo e ver quem está nele:

PS> $grupos = $turma | Group-Object Cidade
PS> $grupos[0].Name
Maceió
PS> $grupos[0].Group.Nome
Duda
$grupos[0]
O primeiro grupo (a contagem começa no 0).
.Group.Nome
O campo Nome de cada objeto daquele grupo.

4. Contando palavras: -NoElement

Quando só a contagem interessa, -NoElement deixa a tabela mais limpa (sem a coluna Group):

PS> $texto = "o gato e o rato e o cão"
PS> $texto.Split(" ") | Group-Object -NoElement | Sort-Object Count -Descending

Count Name
----- ----
    3 o
    2 e
    1 cão
    1 gato
    1 rato

5. Grupos como hashtable: -AsHashTable

Com -AsHashTable, cada valor vira uma chave, e você acessa o grupo pelo nome (aula Hashtables):

PS> $porCidade = $turma | Group-Object Cidade -AsHashTable
PS> $porCidade["Natal"].Nome
Beto

Quando dá errado

Campo que não existe: um grupo só, sem nome 
PS> $turma | Group-Object Estado

Count Name                      Group
----- ----                      -----
    5                           {@{Nome=Ana; Cidade=Recife}, @{Nome=Beto; Cida…

Sem o campo, todos os objetos têm o "mesmo valor" (nada) e caem num grupo só, com Name vazio. Confira o nome do campo.

Referência rápida

Você digitaO que faz
Group-Object CampoAgrupa pelo campo.
... | Sort-Object Count -DescendingMaiores grupos primeiro.
-NoElementSó a contagem, sem a coluna Group.
-AsHashTableDevolve uma hashtable: grupo pelo nome.
$g.GroupOs objetos de um grupo.

Missão final: agrupe os pedidos pelo campo Status. A saída deve mostrar que há 3 pedidos com status pago.

$pedidos = @(
    [pscustomobject]@{ Id = 1; Status = "pago" }
    [pscustomobject]@{ Id = 2; Status = "pendente" }
    [pscustomobject]@{ Id = 3; Status = "pago" }
    [pscustomobject]@{ Id = 4; Status = "pago" }
)

$pedidos = @(
    [pscustomobject]@{ Id = 1; Status = "pago" }
    [pscustomobject]@{ Id = 2; Status = "pendente" }
    [pscustomobject]@{ Id = 3; Status = "pago" }
    [pscustomobject]@{ Id = 4; Status = "pago" }
)
$pedidos | Group-Object Status

Resumo

  • Group-Object Campo junta os objetos com o mesmo valor no campo.
  • Count = quantos; Name = o valor; Group = os objetos.
  • Ordene com Sort-Object Count -Descending para ver os maiores.
  • -NoElement deixa só a contagem; -AsHashTable dá acesso pelo nome.
