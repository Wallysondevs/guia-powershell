Instalando Módulos (PowerShell Gallery)

A PowerShell Gallery é a loja oficial (e gratuita) de módulos do PowerShell, em powershellgallery.com. Lá estão milhares de módulos feitos pela Microsoft e pela comunidade. Nesta aula você aprende a procurar, instalar, atualizar e remover módulos com segurança.

Você vai aprender
  • A procurar módulos com Find-PSResource (e o antigo Find-Module).
  • A instalar só para você, sem administrador.
  • A ver, atualizar e remover o que instalou.
  • Os cuidados de segurança antes de instalar.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional. Diferente das outras aulas de administração do Windows, as saídas desta foram colhidas no Linux, consultando a PowerShell Gallery de verdade em 21/11/2026: a galeria e os comandos são os mesmos no Windows, e os números de versão mudam com o tempo.

A ideia: a loja de aplicativos

No celular você abre a loja, procura um aplicativo, lê a descrição e instala. A PowerShell Gallery funciona igual, só que pelo terminal.

1. Dois jeitos: PSResourceGet e PowerShellGet

O PowerShell 7 traz o módulo novo Microsoft.PowerShell.PSResourceGet (comandos *-PSResource), mais rápido. O antigo PowerShellGet (comandos *-Module) continua funcionando. Os dois usam a mesma galeria:

PS> Get-PSResourceRepository

Name                      Uri                                      Trusted Prio
                                                                           rity
----                      ---                                      ------- ----
MicrosoftArtifactRegistry https://mcr.microsoft.com/               True    40  
PSGallery                 https://www.powershellgallery.com/api/v2 False   50  
PS> Get-Command Find-PSResource, Find-Module | Select-Object Name, Source

Name            Source
----            ------
Find-PSResource Microsoft.PowerShell.PSResourceGet
Find-Module     PowerShellGet

2. Procurando um módulo

PS> Find-PSResource -Name PSScriptAnalyzer | Select-Object Name, Version, Description

Name             Version Description
----             ------- -----------
PSScriptAnalyzer 1.25.0  PSScriptAnalyzer provides script analysis and checks …
PS> Find-PSResource -Name *Excel* | Select-Object -First 5 Name, Version

Name                   Version
----                   -------
Search-ExcelFileWithUI 1.0.7
Search-ExcelContent    1.0.7
Read-ExcelFile         2.1
QueryExcel             1.0.0
PSWriteExcel           0.1.15
Find-PSResource -Name
Procura pelo nome (aceita *).
Description
Leia a descrição antes de instalar.

No site da galeria você também vê o autor, o número de downloads e o código-fonte.

3. Instalando só para você

Install-PSResource -Name PSScriptAnalyzer -Scope CurrentUser
# ou, com o PowerShellGet antigo:
Install-Module -Name PSScriptAnalyzer -Scope CurrentUser
-Scope CurrentUser
Instala na sua pasta Documentos\PowerShell\Modules. Não precisa de administrador.
"Repositório não confiável"
Na primeira vez, o PowerShell avisa que a PSGallery não está marcada como confiável e pergunta se quer continuar. Responda S (Sim) se você confia no módulo.

4. Vendo o que você instalou

PS> Get-InstalledPSResource | Select-Object Name, Version, Repository
Get-InstalledPSResource: No match was found for package '*'.

No computador desta coleta nada tinha sido instalado pela galeria, então o comando respondeu com esse erro: não há nenhum pacote para listar. Depois do primeiro Install-PSResource, aparece uma tabela com o nome, a versão e PSGallery na coluna Repository.

5. Atualizando e removendo

Update-PSResource -Name PSScriptAnalyzer
Uninstall-PSResource -Name PSScriptAnalyzer
Segurança Um módulo é código que roda com as suas permissões. Antes de instalar: confira o autor, o número de downloads, se o projeto tem código-fonte público e se é mantido. Desconfie de nomes parecidos com módulos famosos.

Experimente: escreva, numa string, o comando que procura o módulo PSScriptAnalyzer na galeria e mostra só Name e Version. O simulador do guia não acessa a galeria; depois, rode o comando de verdade no seu terminal.

# Escreva o comando numa string. Não chame o cmdlet.
$comando = ''
Write-Output $comando

# Escreva o comando numa string. Não chame o cmdlet.
$comando = 'Find-PSResource -Name PSScriptAnalyzer | Select-Object Name, Version'
Write-Output $comando

Quando dá errado

"Administrator rights are required to install modules"

Você esqueceu o -Scope CurrentUser no Install-Module do Windows PowerShell 5.1. No PowerShell 7 o padrão já é CurrentUser.

"Unable to resolve package source" / sem resposta

Sem internet, proxy da empresa ou bloqueio de rede. Teste Test-NetConnection www.powershellgallery.com -Port 443.

Instalei, mas o comando não existe

Abra uma janela nova ou rode Import-Module NomeDoModulo. Confira com Get-Module -ListAvailable NomeDoModulo.

Referência rápida

Você digitaO que faz
Find-PSResource -Name xProcura na galeria.
Install-PSResource -Name x -Scope CurrentUserInstala para você.
Get-InstalledPSResourceLista o que instalou.
Update-PSResource -Name xAtualiza.
Uninstall-PSResource -Name xRemove.
Find-Module / Install-ModuleEquivalentes do PowerShellGet antigo.

Resumo

  • A PowerShell Gallery é a loja oficial de módulos.
  • Find-PSResource procura; Install-PSResource -Scope CurrentUser instala para você.
  • Get-InstalledPSResource, Update-PSResource e Uninstall-PSResource cuidam do resto.
  • Confira o autor e a reputação antes de instalar.
