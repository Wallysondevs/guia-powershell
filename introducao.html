O que é o PowerShell

O PowerShell é um programa para conversar com o computador por escrito. Você digita um pedido, aperta Enter e ele responde. A diferença para o cmd antigo (e para muita gente que imagina uma “tela preta só de texto”) é esta: o PowerShell não devolve só uma frase. Ele devolve um objeto — uma ficha com várias informações, das quais você pode aproveitar só o pedaço que interessa.

Você vai aprender
  • O que é o PowerShell e para que ele serve no dia a dia.
  • A diferença entre um texto (o que o cmd costuma devolver) e um objeto (o que o PowerShell devolve).
  • A ver a data com Get-Date e a pedir só o ano com (Get-Date).Year.
  • Que as “partes” de um objeto têm nome (Day, Hour, Year…) e dá para listar algumas delas.
  • Como o mesmo pedido no cmd aparece só como texto.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta pessoal da usuária fictícia ana. No Windows PowerShell 5.1 os mesmos comandos funcionam; a ideia de objeto é a mesma.

A ideia: uma ficha de cadastro, não um recado

Imagine que você pergunta “que dia é hoje?” para duas pessoas. A primeira responde só com um recado escrito: 20/11/2026. Útil, mas é só um texto: para pegar o ano, você teria que ler a frase e recortar os quatro últimos dígitos na mão.

A segunda pessoa entrega uma ficha de cadastro com vários campos: dia da semana, dia, mês, ano, hora. Você olha o campo “ano” e lê 2026, sem recortar nada. O PowerShell trabalha no segundo jeito. A ficha é o objeto; cada campo é uma propriedade (property, em inglês).

No dia a diaNo PowerShell
O recado no papelUm texto, como o que o cmd costuma devolver
A ficha de cadastroO objeto que o PowerShell devolve
O campo “ano” da fichaA propriedade Year
“Me mostra só o ano”(Get-Date).Year

1. Pedindo a data: Get-Date

Digite exatamente isto e aperte Enter:

PS C:\Users\ana> Get-Date

sexta-feira, 20 de novembro de 2026 17:13:06

A resposta veio em português, com o dia da semana, a data e a hora. As linhas em branco antes e depois fazem parte do jeito de mostrar uma data inteira. Não é erro. Na próxima aula, Seu Primeiro Comando, a gente desmonta o prompt e este comando com calma. Por enquanto, o importante é o que veio atrás desse texto bonito: uma ficha, não só a frase.

2. Pedindo só um campo: (Get-Date).Year

Se a Ana só precisa do ano — para o nome de uma pasta, por exemplo — ela não recorta o texto. Ela pede o campo Year:

PS C:\Users\ana> (Get-Date).Year
2026
(Get-Date)
Os parênteses mandam o PowerShell primeiro obter a data. Sem eles, o ponto não saberia de quem é o Year.
.
O ponto quer dizer “desta ficha, pegue o campo…”.
Year
O nome da propriedade: “ano”. A resposta é só o número 2026, sem linhas em branco.

Experimente: o editor já tem o Get-Date. Acrescente os parênteses e o .Year para mostrar só o ano, e clique em Rodar.

Get-Date

(Get-Date).Year

3. Quais campos a ficha tem?

Você não precisa decorar os nomes. Dá para perguntar ao próprio objeto quais propriedades ele tem. O comando abaixo ainda é um adiantamento (a aula completa de Get-Member vem no Nível 2); aqui ele só serve para ver os nomes. Pedimos as 5 primeiras propriedades da data:

PS C:\Users\ana> Get-Date | Get-Member -MemberType Property | Select-Object -First 5

   TypeName: System.DateTime

Name      MemberType Definition
----      ---------- ----------
Date      Property   datetime Date {get;}
Day       Property   int Day {get;}
DayOfWeek Property   System.DayOfWeek DayOfWeek {get;}
DayOfYear Property   int DayOfYear {get;}
Hour      Property   int Hour {get;}
TypeName: System.DateTime
O “tipo” da ficha: é uma data e hora (DateTime). Por isso ela tem dia, hora, ano…
Name
O nome de cada campo. Day é o dia do mês, DayOfWeek é o dia da semana, Hour é a hora. Year também existe: ele não apareceu aqui só porque pedimos as 5 primeiras, em ordem alfabética, e Year vem mais abaixo.
|
A barra vertical é a esteira (pipeline): a data segue para o próximo comando. Você vai usá-la o tempo todo a partir do Nível 2.

Não se preocupe em entender cada pedaço desta linha agora. Guarde só a ideia: por trás da frase tem uma ficha, e os campos têm nome.

4. O mesmo pedido no cmd

O cmd é o prompt antigo do Windows. Ele também sabe dizer a data, mas a resposta é só um texto:

PS C:\Users\ana> cmd /c echo %DATE%
20/11/2026
cmd /c
Manda o PowerShell chamar o cmd antigo, rodar um comando e voltar.
echo %DATE%
No cmd, echo escreve na tela e %DATE% é a data do sistema, como um texto.

Veio 20/11/2026, numa linha só, sem “ano” para você pedir. Se a Ana quisesse só o 2026, teria que recortar o texto. No PowerShell, (Get-Date).Year já devolve o número.

Rodamos o cmd de dentro do PowerShell só para comparar. No dia a dia deste guia você fica no PowerShell: o prompt começa com PS. Como abrir essa janela está em Abrindo o PowerShell.
A Ana quer o ano para o nome de uma pasta

Ela precisa criar algo como fotos-2026. Se a data viesse só como o texto 20/11/2026, ela teria que copiar os quatro últimos dígitos na mão, e no ano que vem fazer de novo. Com o objeto, o campo já existe:

PS C:\Users\ana> (Get-Date).Year
2026

É este o motivo de o PowerShell trabalhar com objetos desde o primeiro comando: você pede o campo pelo nome, em vez de recortar frase. O resto do guia parte daqui.

Referência rápida

Você digitaO que faz
Get-DateMostra a data e a hora de agora (por trás, um objeto DateTime).
(Get-Date).YearMostra só o ano, pedindo a propriedade Year.
(Get-Date).DayMostra só o dia do mês (o nome apareceu na lista de propriedades).
cmd /c echo %DATE%Pede a data ao cmd antigo: a resposta é só um texto.

Resumo

  • O PowerShell é um programa para pedir coisas ao computador por escrito: você digita, aperta Enter e lê a resposta.
  • A resposta não é só um texto. É um objeto, uma ficha com campos (propriedades) que têm nome.
  • Get-Date mostra a data e a hora; por trás, a ficha é do tipo DateTime.
  • (Get-Date).Year pede só o campo do ano. Os parênteses fazem o Get-Date rodar primeiro.
  • O cmd antigo, com echo %DATE%, devolve só o texto da data: não tem um campo Year para você pedir.
