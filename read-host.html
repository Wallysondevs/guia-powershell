Read-Host: Perguntando ao Usuário

Até aqui, os scripts só falavam. Agora a Ana quer um script que pergunte: o nome de quem está usando, a idade, a quantidade de um produto da lojinha. O Read-Host mostra uma pergunta, espera a pessoa digitar e entrega a resposta para o script. Nesta aula você vai fazer perguntas, guardar as respostas e entender por que "30" + 1 pode dar 301.

Você vai aprender
  • A fazer uma pergunta com Read-Host e guardar a resposta numa variável.
  • Que a resposta chega sempre como texto, mesmo quando a pessoa digita um número.
  • A transformar a resposta em número com [int].
  • A esconder o que é digitado (-MaskInput e -AsSecureString).
  • A ler o erro real de quando a resposta não é um número.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português. O Read-Host precisa de uma pessoa digitando na janela, e isso o nosso laboratório não fez. Por isso, a parte da pergunta na tela está descrita em texto, não copiada do terminal. Para ver de verdade, use os "Experimente": neles o editor responde por você, como se alguém tivesse digitado.

A ideia: o balcão de atendimento

Pense no balcão de uma loja. A atendente pergunta "Qual é o seu nome?", espera você responder e anota na ficha. O Read-Host é essa atendente: faz a pergunta, espera o Enter e entrega o que foi dito. A ficha é a variável onde você guarda a resposta.

1. Fazendo uma pergunta

$nome = Read-Host 'Qual é o seu nome?'
"Olá, $nome!"
Read-Host
"Ler do anfitrião". Read é "ler", e o Host é a janela do terminal: ele lê o que a pessoa digita ali.
'Qual é o seu nome?'
A pergunta. É o parâmetro -Prompt ("aviso"), que pode ir sem o nome.
$nome = …
Guarda a resposta na variável $nome (aula Variáveis). Sem isso, a resposta só aparece e se perde.

O que acontece na tela (descrito, não colhido no laboratório): o PowerShell mostra a pergunta seguida de dois-pontos, Qual é o seu nome?:, e o cursor fica piscando. O script para e espera. Quando a pessoa digita Ana e aperta Enter, o texto Ana vai para $nome e a linha seguinte mostra Olá, Ana!. Repare: o Read-Host coloca os dois-pontos sozinho, então não escreva : no fim da pergunta.

Experimente: o editor vai responder Ana à pergunta. Troque "visitante" pela variável $nome para o script cumprimentar quem respondeu.

$nome = Read-Host 'Qual é o seu nome?'
"Olá, visitante!"

$nome = Read-Host 'Qual é o seu nome?'
"Olá, $nome!"

2. A resposta é sempre texto

Se a pessoa digita 30, o Read-Host entrega o texto "30", não o número 30. Isso muda as contas. Veja o que o PowerShell faz com o texto "30" e o número 1:

PS C:\Users\ana> "30" + 1
301
PS C:\Users\ana> 1 + "30"
31
"30" + 1 → 301
Quem está à esquerda manda. Como é um texto, o + gruda os dois: "30" com "1" vira "301".
1 + "30" → 31
Agora a esquerda é um número, então o + soma, e o PowerShell converte o "30" em número.

Com o Read-Host, a resposta está quase sempre à esquerda ($idade + 1). Para fazer conta, transforme a resposta em número com [int] ("inteiro"):

$idade = Read-Host 'Quantos anos você tem'
$proximo = [int]$idade + 1
"No ano que vem você terá $proximo anos."
[int]$idade
"Trate $idade como número inteiro." O texto "30" vira o número 30, e aí + 1 dá 31. Mais sobre isso na aula Conversão de Tipos.

3. Escondendo o que é digitado

Para uma senha, não é bom que o texto apareça na tela. O Read-Host tem dois parâmetros para isso. Esta é a lista real de parâmetros dele no PowerShell 7.7:

PS C:\Users\ana> (Get-Command Read-Host).Parameters.Keys -join ", "
Prompt, AsSecureString, MaskInput, Verbose, Debug, ErrorAction, WarningAction, InformationAction, ProgressAction, ErrorVariable, WarningVariable, InformationVariable, OutVariable, OutBuffer, PipelineVariable
Prompt
A pergunta, que você já usou.
MaskInput
"Mascarar a entrada": cada letra digitada aparece como *, mas a resposta continua sendo um texto comum. Bom para algo que não deve aparecer na tela, mas que o script vai usar como texto.
AsSecureString
"Como texto seguro": também mostra *, e a resposta vem trancada num SecureString, que não dá para imprimir direto. É o jeito certo para senhas (aula Credenciais).
Verbose, Debug, ErrorAction…
Os parâmetros comuns, que todo cmdlet tem (aula Parâmetros).
Windows PowerShell 5.1: o -MaskInput não existe lá: ele não aparece na documentação do Read-Host do 5.1, só na do PowerShell 7. No 5.1, use -AsSecureString.

O uso fica assim (código para ler; a tela com os asteriscos não foi colhida no laboratório):

$senha = Read-Host 'Senha' -AsSecureString

Formas diferentes de receber dados

FormaQuando usar
Read-Host 'Pergunta'Scripts que conversam com uma pessoa na frente do computador.
[int](Read-Host 'Quantos?')Quando a resposta precisa ser um número.
Read-Host 'Senha' -AsSecureStringSenhas e segredos.
Read-Host 'Código' -MaskInputAlgo que não deve aparecer na tela, mas que você usa como texto (só no 7).
Parâmetros do script (param())Quando o script deve rodar sozinho, sem ninguém para responder (aula Parâmetros de Script).
Um script com Read-Host para e espera. Se ele for rodar sozinho (uma tarefa agendada, por exemplo), ninguém vai responder. Nesses casos, prefira parâmetros.

Quando dá errado

A pessoa digitou uma palavra no lugar do número

Se a resposta for "trinta", o [int] não consegue converter. Este é o erro real, colhido com o texto direto, sem a pergunta:

PS C:\Users\ana> [int]"trinta"
InvalidArgument: Cannot convert value "trinta" to type "System.Int32". Error: "The input string 'trinta' was not in a correct format."
InvalidArgument:
"Argumento inválido": o valor não serve para o que você pediu.
Cannot convert value "trinta" to type "System.Int32"
"Não dá para converter 'trinta' em número inteiro." System.Int32 é o nome completo do [int].
was not in a correct format
"Não estava num formato correto": só algarismos viram número.

Como resolver: peça para digitar com algarismos (30). Mais à frente, na aula Try/Catch, você aprende a perguntar de novo quando a resposta vem errada.

A conta deu um número estranho

A pessoa digitou 30 e o script mostrou 301 em vez de 31. É o caso da seção 2: a resposta é texto e o + grudou.

Como resolver: converta antes da conta: [int]$idade + 1.

Resumo

  • $x = Read-Host 'Pergunta' mostra a pergunta, espera o Enter e guarda a resposta.
  • A resposta é sempre texto: use [int] antes de fazer conta.
  • Texto à esquerda do + gruda ("30" + 1 = 301); número à esquerda soma.
  • Para senhas, use -AsSecureString. O -MaskInput só esconde a digitação e existe só no 7.
  • "Cannot convert value … to type System.Int32" quer dizer que a resposta não era um número.
