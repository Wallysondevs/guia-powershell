O que é este guia

O PowerShell é um programa para pedir coisas ao computador por escrito. Você digita um pedido, aperta Enter e lê a resposta. A diferença para o cmd antigo (aquela “tela preta” que muita gente imagina) é esta: o PowerShell não devolve só uma frase. Ele devolve um objeto — uma ficha com várias informações, das quais você aproveita só o pedaço que interessa. Com ele dá para listar pastas, organizar arquivos, repetir tarefas chatas e administrar o Windows. A aula O que é PowerShell mostra essa ideia com calma.

O guia é para quem nunca programou e nunca usou um terminal. Ele começa do zero absoluto (o que é o prompt? como se roda um comando?) e vai até scripts, a esteira (pipeline), módulos e a administração do Windows — inclusive usuários e grupos locais. Cada aula ensina um assunto só. Os exemplos acompanham a vida da Ana: as fotos do celular, a pasta Downloads bagunçada, a planilha da lojinha.

O texto está em português do Brasil. Os nomes dos comandos ficam em inglês, como o próprio PowerShell os escreve (Get-ChildItem, não get-childitem), e a gente traduz o termo na primeira vez.

A versão de referência: PowerShell 7.7

O guia ensina o PowerShell 7.7. No laboratório, o pedido que mostra só a versão respondeu isto:

PS C:\Users\ana> $PSVersionTable.PSVersion

Major  Minor  Patch  PreReleaseLabel BuildLabel
-----  -----  -----  --------------- ----------
7      7      0
$PSVersionTable
Uma variável automática: uma ficha com dados desta sessão do PowerShell. O cifrão $ marca o nome de uma variável (aula Variáveis).
.PSVersion
Desta ficha, pega só o campo da versão — do mesmo jeito que (Get-Date).Year pega só o ano.
Major 7, Minor 7, Patch 0
É a versão 7.7.0, a de referência deste guia. As duas últimas colunas vieram em branco: não é uma prévia, é a versão final.

No seu computador, no lugar de ana no prompt vai aparecer o seu nome de usuário. O caminho C:\Users\ana é o da usuária fictícia das aulas.

Windows PowerShell 5.1

O Windows já traz o Windows PowerShell 5.1. Quase tudo do Nível 1 funciona igual nos dois. Quando a resposta muda (um parâmetro que só existe no 7, um acento gravado de outro jeito, um apelido diferente), a aula mostra os dois lados numa nota. A comparação completa está em Windows PowerShell 5.1 × PowerShell 7. As novidades do 7.7 aparecem com a etiqueta 7.7 e estão reunidas em Novidades do PowerShell 7.7.

Como as aulas funcionam

Nenhum comando aparece “seco”. Toda aula segue o mesmo caminho:

  1. A ideia primeiro. Antes do comando, você entende o problema que ele resolve, com uma comparação do dia a dia: um balcão de atendimento, uma ficha de cadastro, uma gaveta de arquivos.
  2. Anatomia. Cada parte de um comando novo é separada e explicada.
  3. A saída real. Depois de cada exemplo, o que o PowerShell respondeu de verdade, no terminal. Nenhuma saída foi inventada.
  4. Experimente. Nas aulas, as caixas Experimente deixam você mudar o comando e rodar. As que têm Missão conferem sozinhas se você acertou.
  5. Várias formas de fazer. Quase sempre há mais de um jeito, e uma tabela “qual usar” mostra quando escolher cada um.
  6. Quando dá errado. O comando com erro e a mensagem real do PowerShell, traduzida e explicada linha por linha em português.
  7. Exercícios e resumo. Perguntas com correção na hora e uma lista curta do que levar da aula.

Como estudar

Terminal se aprende usando, como quem aprende a cozinhar cozinhando. Para cada aula, siga estes quatro passos:

  1. Leia com calma. Leia a ideia, a anatomia e a saída. Não pule a parte “Quando dá errado”: quem entende a mensagem de erro conserta o problema em segundos.
  2. Mexa nos exemplos. Onde houver uma caixa Experimente, mude um número, troque um texto, erre de propósito e veja o que o PowerShell responde.
  3. Faça as missões e os exercícios. As caixas com Missão e as perguntas do fim da aula conferem se você acertou. Tente de verdade antes de abrir a solução.
  4. Repita no seu computador. Instale o PowerShell 7 (aula Instalar o PowerShell 7), abra a janela (Abrindo o PowerShell) e refaça os comandos no seu terminal. Algumas coisas (criar usuário, serviços, Registro) só existem lá, no Windows de verdade.
A regra de ouro

Ler não basta: digite cada comando. Copiar e colar ensina pouco; digitar faz você reparar em cada hífen, cada aspa e cada $. Comece aqui, pela aula O que é PowerShell. O primeiro comando de verdade está em Seu Primeiro Comando.
