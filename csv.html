CSV (Import-Csv e Export-Csv)

CSV é a planilha em forma de texto: uma linha por registro, colunas separadas por vírgula (ou ponto e vírgula). O PowerShell lê e grava CSV transformando cada linha num objeto, então você filtra, ordena e soma com os cmdlets que já conhece.

Você vai aprender
  • A salvar objetos num CSV com Export-Csv.
  • A ler um CSV com Import-Csv e usar as colunas como propriedades.
  • A lidar com o ponto e vírgula do Excel em português (-Delimiter ';').
  • Que tudo o que vem do CSV é texto, e como converter para número.
  • A converter na memória com ConvertTo-Csv e ConvertFrom-Csv.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a lista de chamada

A professora tem uma lista em papel: na primeira linha, os títulos (Nome, Turma, Nota); nas outras, um aluno por linha. Um CSV é exatamente isso. A primeira linha diz o nome das colunas, e o PowerShell usa esses nomes como propriedades.

1. Salvando objetos em CSV

PS> $alunos = @(
>>   [pscustomobject]@{ Nome = "Ana";  Turma = "A"; Nota = 9.5 }
>>   [pscustomobject]@{ Nome = "Beto"; Turma = "B"; Nota = 6 }
>>   [pscustomobject]@{ Nome = "Caio"; Turma = "A"; Nota = 7.5 }
>> )
PS> $alunos | Export-Csv alunos.csv
PS> Get-Content alunos.csv
"Nome","Turma","Nota"
"Ana","A","9,5"
"Beto","B","6"
"Caio","A","7,5"
Export-Csv alunos.csv
Grava os objetos no arquivo alunos.csv, na pasta atual.
"Nome","Turma","Nota"
A primeira linha: os nomes das propriedades viram o cabeçalho.
"Ana","A","9,5"
Uma linha por objeto. No PowerShell 7 todos os valores vão entre aspas. O número 9.5 foi gravado como 9,5, no formato do idioma do sistema (pt-BR).

2. Lendo de volta

PS> $lidos = Import-Csv alunos.csv
PS> $lidos

Nome Turma Nota
---- ----- ----
Ana  A     9,5
Beto B     6
Caio A     7,5
PS> $lidos[0].Nome
Ana

Cada linha virou um objeto com as propriedades Nome, Turma e Nota. Agora vale tudo que você aprendeu:

PS> $lidos | Where-Object Turma -eq "A" | Select-Object Nome, Nota

Nome Nota
---- ----
Ana  9,5
Caio 7,5

3. Tudo vem como texto

O CSV não guarda tipos: tudo volta como string. Para comparar ou somar números, é preciso converter. E aqui mora uma pegadinha: o [double] lê números no formato internacional, com ponto decimal. A vírgula é tratada como separador de milhar:

PS> $lidos[0].Nota.GetType().Name
String
PS> [double]"9,5"
95
PS> [double]("9,5" -replace ',', '.')
9,5

Por isso, com notas gravadas com vírgula, troque a vírgula por ponto antes de converter:

PS> $lidos | Sort-Object { [double]($_.Nota -replace ',', '.') } -Descending | Select-Object -First 1 -ExpandProperty Nome
Ana
PS> ($lidos | Measure-Object { [double]($_.Nota -replace ',', '.') } -Average).Average
7,66666666666667
$_.Nota -replace ',', '.'
Troca a vírgula por ponto no texto da nota (veja -replace).
[double](...)
Converte o texto já com ponto para número.
-ExpandProperty Nome
Mostra só o valor, sem a tabela.

Experimente: o código grava um CSV com notas inteiras. Leia com Import-Csv e mostre só o Nome de quem tem nota maior ou igual a 9 (lembre do [int]).

@(
  [pscustomobject]@{ Nome = "Ana";  Nota = 10 }
  [pscustomobject]@{ Nome = "Beto"; Nota = 6 }
) | Export-Csv notas.csv

@(
  [pscustomobject]@{ Nome = "Ana";  Nota = 10 }
  [pscustomobject]@{ Nome = "Beto"; Nota = 6 }
) | Export-Csv notas.csv
Import-Csv notas.csv | Where-Object { [int]$_.Nota -ge 9 } | ForEach-Object Nome

4. O Excel em português usa ponto e vírgula

No Brasil, o Excel salva CSV com ;, porque a vírgula é a casa decimal. Use -Delimiter ';' para ler e para gravar:

PS> Set-Content gastos.csv @'
>> Item;Valor
>> Aluguel;1200,00
>> Mercado;850,50
>> '@
PS> $gastos = Import-Csv gastos.csv -Delimiter ';'
PS> $gastos

Item    Valor
----    -----
Aluguel 1200,00
Mercado 850,50

O valor 850,50 tem vírgula decimal. Para somar, troque a vírgula por ponto antes de converter:

PS> ($gastos | ForEach-Object { [double]($_.Valor -replace ',', '.') } | Measure-Object -Sum).Sum
2050,5

E para o Excel abrir certinho um arquivo que você gerou, grave com ; também:

PS> $alunos | Export-Csv alunos-excel.csv -Delimiter ';'
PS> Get-Content alunos-excel.csv -TotalCount 2
"Nome";"Turma";"Nota"
"Ana";"A";"9,5"

5. Sem arquivo: ConvertTo-Csv e ConvertFrom-Csv

PS> $alunos | ConvertTo-Csv
"Nome","Turma","Nota"
"Ana","A","9,5"
"Beto","B","6"
"Caio","A","7,5"
PS> "cor,qtd`nazul,3`nverde,5" | ConvertFrom-Csv

cor   qtd
---   ---
azul  3
verde 5

Quando dá errado

Tudo numa coluna só

Se o Import-Csv mostra uma única coluna chamada Item;Valor, o arquivo usa ; e você não avisou. Acrescente -Delimiter ';'.

Ordenar números como texto

Ordenando a coluna Nota sem converter, 10 vem antes de 9 (a comparação é letra a letra: "1" vem antes de "9"). Converta no Sort-Object, como na seção 3.

Export-Csv depois de Format-Table

Get-Process | Format-Table | Export-Csv grava lixo de formatação, não os dados. Os cmdlets Format-* são sempre o último passo, só para a tela. Use Select-Object para escolher colunas antes do Export-Csv.

Referência rápida

Você digitaO que faz
$dados | Export-Csv arq.csvGrava objetos em CSV.

Exercícios

1. Ler o CSV do Excel

Complete para ler um CSV com ponto e vírgula:

Import-Csv planilha.csv ';'

2. De que tipo é o valor de uma coluna lida com Import-Csv?

3. O que vira o cabeçalho quando você usa Export-Csv?

Missão final: leia gastos.csv (que usa ;), some a coluna Valor e mostre Total: seguido da soma.

Set-Content gastos.csv "Item;Valor`nAluguel;1200`nMercado;850"

Set-Content gastos.csv "Item;Valor`nAluguel;1200`nMercado;850"
$soma = (Import-Csv gastos.csv -Delimiter ';' | ForEach-Object { [double]$_.Valor } | Measure-Object -Sum).Sum
"Total: $soma"

Resumo

  • Export-Csv grava objetos; Import-Csv lê de volta como objetos.
  • O cabeçalho vira o nome das propriedades.
  • Tudo volta como texto: converta com [int] ou [double], trocando a vírgula decimal por ponto antes.
  • CSV do Excel em português: -Delimiter ';'.
