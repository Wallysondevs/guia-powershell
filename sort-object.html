Sort-Object: Ordenando

O Sort-Object (apelido sort) coloca as coisas em ordem: números do menor para o maior, textos em ordem alfabética, objetos pelo campo que você escolher.

Você vai aprender
  • A ordenar números e textos.
  • A inverter a ordem com -Descending.
  • A ordenar objetos por um campo, ou por dois.
  • A tirar os repetidos com -Unique.
  • Por que "10" vem antes de "9" quando os números são texto.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a fila por ordem de altura

Na foto da turma, o fotógrafo pede: "do mais baixo para o mais alto". Ele não muda as pessoas, só a posição delas. O Sort-Object faz isso com a sua lista: os itens são os mesmos, só a ordem muda.

1. Números e textos

PS> 5, 3, 9, 1 | Sort-Object
1
3
5
9
PS> "uva", "Banana", "abacaxi", "maçã" | Sort-Object
abacaxi
Banana
maçã
uva

Os textos são ordenados em ordem alfabética, sem diferenciar maiúsculas de minúsculas (Banana ficou entre abacaxi e maçã).

2. Do maior para o menor: -Descending

PS> 5, 3, 9, 1 | Sort-Object -Descending
9
5
3
1

3. Objetos: ordenando por um campo

PS> $turma = @(
>>   [pscustomobject]@{ Nome = "Beto"; Cidade = "Natal"; Nota = 6 }
>>   [pscustomobject]@{ Nome = "Ana"; Cidade = "Recife"; Nota = 9 }
>>   [pscustomobject]@{ Nome = "Duda"; Cidade = "Natal"; Nota = 10 }
>>   [pscustomobject]@{ Nome = "Caio"; Cidade = "Recife"; Nota = 8 }
>> )
PS> $turma | Sort-Object Nota -Descending

Nome Cidade Nota
---- ------ ----
Duda Natal    10
Ana  Recife    9
Caio Recife    8
Beto Natal     6
Sort-Object Nota
Ordena os objetos pelo campo Nota (é o parâmetro -Property).
-Descending
Da maior nota para a menor.

Experimente: mostre só o aluno com a maior nota: ordene por Nota com -Descending e pegue o primeiro com Select-Object -First 1.

$turma = @(
    [pscustomobject]@{ Nome = "Beto"; Nota = 6 }
    [pscustomobject]@{ Nome = "Duda"; Nota = 10 }
    [pscustomobject]@{ Nome = "Caio"; Nota = 8 }
)
$turma

$turma = @(
    [pscustomobject]@{ Nome = "Beto"; Nota = 6 }
    [pscustomobject]@{ Nome = "Duda"; Nota = 10 }
    [pscustomobject]@{ Nome = "Caio"; Nota = 8 }
)
$turma | Sort-Object Nota -Descending | Select-Object -First 1

4. Dois campos: desempate

Ordene primeiro pela cidade e, dentro de cada cidade, pelo nome:

PS> $turma | Sort-Object Cidade, Nome

Nome Cidade Nota
---- ------ ----
Beto Natal     6
Duda Natal    10
Ana  Recife    9
Caio Recife    8

5. Sem repetidos

PS> 3, 1, 3, 2, 1 | Sort-Object -Unique
1
2
3

Diferente do Select-Object -Unique, aqui o resultado sai ordenado.

Quando dá errado

Número guardado como texto 
PS> "10", "9", "100" | Sort-Object
10
100
9
PS> 10, 9, 100 | Sort-Object
9
10
100

Entre aspas, "10" é texto, e texto é ordenado letra a letra: o 1 vem antes do 9. Se os números vieram de um arquivo como texto, converta antes: | Sort-Object { [int]$_ }.

Campo com nome errado 
PS> $turma | Sort-Object Idade | Select-Object Nome

Nome
----
Beto
Ana
Duda
Caio

Sem o campo, o Sort-Object não tem o que comparar e não dá erro: a lista sai na ordem em que estava.

Referência rápida

Você digitaO que faz
Sort-ObjectOrdem crescente.
Sort-Object -DescendingOrdem decrescente.
Sort-Object CampoOrdena objetos por um campo.
Sort-Object A, BPor A; empate, por B.
Sort-Object -UniqueOrdena e tira repetidos.
Sort-Object { [int]$_ }Ordena pelo valor calculado.

Exercícios

1. Ao contrário

Complete para ordenar do maior para o menor:

5, 2, 8 | Sort-Object

2. Em que ordem saem "10", "9", "100" | Sort-Object?

3. Para ordenar por cidade e, no empate, por nome, você escreve:

Missão final: ordene os produtos do mais barato para o mais caro e mostre a lista. O Leite (5) deve vir primeiro, depois o Arroz (25) e por último o Café (32).

$produtos = @(
    [pscustomobject]@{ Nome = "Café"; Preco = 32 }
    [pscustomobject]@{ Nome = "Leite"; Preco = 5 }
    [pscustomobject]@{ Nome = "Arroz"; Preco = 25 }
)
$produtos

$produtos = @(
    [pscustomobject]@{ Nome = "Café"; Preco = 32 }
    [pscustomobject]@{ Nome = "Leite"; Preco = 5 }
    [pscustomobject]@{ Nome = "Arroz"; Preco = 25 }
)
$produtos | Sort-Object Preco

Resumo

  • Sort-Object ordena; -Descending inverte.
  • Objetos se ordenam por um campo: Sort-Object Nota.
  • Vários campos fazem o desempate: Sort-Object Cidade, Nome.
  • -Unique ordena e tira repetidos.
  • Número guardado como texto é ordenado como texto: converta com [int].
