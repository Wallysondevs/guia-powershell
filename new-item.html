Criando com New-Item

Você já sabe olhar pastas e andar por elas. Agora vai criar as suas: um arquivo em branco, uma pasta nova, vários itens de uma vez e até uma frase já dentro do arquivo. O comando é o New-Item (verbo New, "novo", + substantivo Item, "item": "crie um item").

Você vai aprender
  • A criar um arquivo com New-Item e a ler a tabela que ele devolve (o "comprovante").
  • O parâmetro -ItemType, para escolher entre arquivo (File) e pasta (Directory).
  • O parâmetro -Value, que já coloca um texto no arquivo novo.
  • A criar pastas no meio do caminho (a\b\c) e vários arquivos de uma vez.
  • Que o mkdir é uma função que chama o New-Item por baixo.
  • O que acontece quando o arquivo já existe, o -Force e o ensaio -WhatIf.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta de teste da usuária fictícia ana. No Windows PowerShell 5.1 os comandos são os mesmos; quando a mensagem muda, a aula avisa.

Pratique numa pasta de teste. Todos os exemplos desta aula foram rodados dentro de C:\Users\ana\guia-ps-teste. No seu computador, crie uma pasta só para treinar e trabalhe nela. Um jeito seguro: New-Item -ItemType Directory -Path (Join-Path $HOME 'guia-ps-teste') e depois Set-Location (Join-Path $HOME 'guia-ps-teste'). Assim você não mexe nas suas fotos, documentos ou no Windows. No fim da prática, apague só essa pasta.

A ideia: um pedido na secretaria

Pense na secretaria de uma escola. Você chega e pede: "abra uma pasta nova chamada fotos" ou "faça uma folha em branco chamada nota.txt". A secretaria cria o que você pediu, coloca no armário e te devolve um comprovante: o nome, a data e o tamanho.

O New-Item funciona igual. Você diz o nome (e, se quiser, o tipo e o conteúdo). Ele cria o item e mostra uma tabelinha — o comprovante. Se você não pedir conteúdo, a folha sai em branco.

Na secretariaNo PowerShell
O pedido ("uma folha chamada nota.txt")O comando New-Item nota.txt
O tipo: folha ou pastaO parâmetro -ItemType File ou Directory
A primeira frase já escrita na folhaO parâmetro -Value "texto"
O comprovante com nome, data e tamanhoA tabela que o New-Item mostra

1. Uma folha em branco

Na pasta de teste, digite isto e aperte Enter:

PS C:\Users\ana\guia-ps-teste> New-Item nota.txt

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              0 nota.txt
New-Item
O comando: "crie um item". Sem -ItemType, o PowerShell entende que você quer um arquivo.
nota.txt
O nome do arquivo novo, na pasta onde você está. A extensão .txt é só parte do nome: indica que é um texto, mas o PowerShell não liga para isso na hora de criar.
Diretório:
Onde o item foi criado: C:\Users\ana\guia-ps-teste.
Mode
Os atributos. -a--- quer dizer que é um arquivo (a de archive). Uma pasta aparece com d na frente.
LastWriteTime
A data e a hora da última alteração. Num item recém-criado, é "agora".
Length
O tamanho em bytes. 0 é folha em branco: não tem nada dentro.
Name
O nome que você pediu: nota.txt.

Repare nas linhas em branco em volta do título Diretório:: é o jeito do PowerShell desenhar essa tabela. Não é erro.

2. Uma pasta nova: -ItemType Directory

Para criar uma pasta, você precisa dizer o tipo. O parâmetro -ItemType (tipo do item) aceita Directory ("diretório", o nome técnico de pasta) ou File (arquivo).

PS C:\Users\ana\guia-ps-teste> New-Item -ItemType Directory fotos

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d----          20/11/2026    17:13                fotos
-ItemType
O parâmetro que escolhe o tipo. Tem um espaço antes do hífen, como nos outros parâmetros.
Directory
O valor: "pasta". Sem aspas, porque é uma palavra só.
fotos
O nome da pasta nova.
d----
O d no Mode confirma: é uma pasta. A coluna Length fica vazia: pasta não tem tamanho de arquivo.

Experimente: crie uma pasta chamada fotos com New-Item e -ItemType Directory.

# crie a pasta fotos

New-Item -ItemType Directory fotos

3. Já com texto dentro: -Value

E se você quiser a folha já escrita? O parâmetro -Value ("valor") coloca o texto no arquivo na hora de criar. O -Path deixa explícito o nome do arquivo; sem ele também funciona, como no primeiro exemplo.

PS C:\Users\ana\guia-ps-teste> New-Item -Path relatorio.txt -Value "Primeira linha"

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13             14 relatorio.txt

PS C:\Users\ana\guia-ps-teste> Get-Content relatorio.txt
Primeira linha
-Path relatorio.txt
O caminho (aqui, só o nome) do arquivo que vai nascer.
-Value "Primeira linha"
O conteúdo inicial. As aspas não entram no arquivo: só o texto. O tamanho passou a ser 14 bytes — o comprimento de Primeira linha.
Get-Content relatorio.txt
"Obter o conteúdo": lê o arquivo e mostra o texto. Tem aula própria, Lendo Arquivos.

Missão: crie o arquivo relatorio.txt já com o texto Primeira linha, usando New-Item e -Value.

# crie relatorio.txt com texto dentro

New-Item -Path relatorio.txt -Value "Primeira linha"

4. Pastas no meio do caminho

Quer criar a\b\c de uma vez, mesmo que a e b ainda não existam? O New-Item abre o caminho inteiro e devolve o comprovante só do último pedaço — a pasta c, que ficou dentro de a\b.

PS C:\Users\ana\guia-ps-teste> New-Item -ItemType Directory a\b\c

    Diretório: C:\Users\ana\guia-ps-teste\a\b

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d----          20/11/2026    17:13                c

O título Diretório: agora é C:\Users\ana\guia-ps-teste\a\b: é lá que a pasta c nasceu. As pastas a e b também foram criadas, mas não ganharam uma tabela só para elas.

5. Vários arquivos de uma vez

Você pode passar uma lista de nomes, separados por vírgula. Com -ItemType File, fica claro que são arquivos (e não pastas).

PS C:\Users\ana\guia-ps-teste> New-Item -ItemType File um.txt, dois.txt

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              0 um.txt
-a---          20/11/2026    17:13              0 dois.txt

Os dois nasceram vazios (Length 0), na mesma pasta, no mesmo horário. A vírgula é que monta a lista.

6. O atalho mkdir

Quem vem do cmd ou do Linux já conhece o mkdir ("make directory", "fazer diretório"). No PowerShell ele também cria pasta — e o comprovante é o mesmo do New-Item:

PS C:\Users\ana\guia-ps-teste> mkdir docs

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d----          20/11/2026    17:13                docs

PS C:\Users\ana\guia-ps-teste> Get-Command mkdir | Select-Object Name, CommandType

Name  CommandType
----  -----------
mkdir    Function

O Get-Command mkdir mostra a ficha dele: o nome é mkdir, mas o CommandType é Function, não um cmdlet. É uma função pronta que, por baixo, chama o New-Item -ItemType Directory. Funciona, e é ótimo no terminal do dia a dia. Nos scripts deste guia, preferimos o New-Item por extenso: fica óbvio o que a linha faz.

Função não é a mesma coisa que apelido (alias). Apelido é só outro nome para o mesmo comando (aula Apelidos). Função é um pedacinho de código com nome. O efeito, aqui, é o mesmo: nasce uma pasta.

Formas de criar

FormaQuando usar

Quando dá errado

O arquivo já existe

Tentamos criar de novo o nota.txt, que já estava na pasta:

PS C:\Users\ana\guia-ps-teste> New-Item nota.txt
New-Item: The file 'C:\Users\ana\guia-ps-teste\nota.txt' already exists.

A mensagem veio em inglês, mesmo no Windows em português. Isso acontece em alguns cmdlets do PowerShell 7: copie igual e leia com calma. Linha por linha:

New-Item:
Qual comando reclamou.
The file '…\nota.txt' already exists.
"O arquivo já existe." Ele se recusou a sobrescrever o que já estava lá. Nada foi apagado.

Como resolver: escolha outro nome, ou — só se você tiver certeza — use o -Force da próxima seção. Conferir com Test-Path antes de criar também evita o erro.

No Windows PowerShell 5.1 a mesma situação sai em português (O arquivo '…' já existe.) e vem com a ficha técnica longa (No linha:, CategoryInfo, IOException), no mesmo estilo do erro da aula Seu Primeiro Comando.

Reescrever de propósito: -Force

O parâmetro -Force ("à força") manda criar mesmo assim. No laboratório, o nota.txt já existia e foi recriado:

PS C:\Users\ana\guia-ps-teste> New-Item nota.txt -Force

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              0 nota.txt
Cuidado com o -Force. O comprovante mostra Length 0: o arquivo voltou a ficar vazio. O conteúdo antigo se perde, sem pergunta e sem ir para a Lixeira. Só use quando a intenção for realmente começar de novo.

Ensaiar sem criar: -WhatIf

Quer ver o que o comando faria, sem mexer em nada? O parâmetro -WhatIf ("e se?") é um ensaio. Ele conta a operação e o destino, e para por aí.

PS C:\Users\ana\guia-ps-teste> New-Item teste.txt -WhatIf
What If: Executando a operação "Criar Arquivo" no destino "Destino: C:\Users\ana\guia-ps-teste\teste.txt".
-WhatIf
Não cria o arquivo. Só descreve o que aconteceria.
What If:
"E se…". No PowerShell 7 a frase começa assim, com I maiúsculo.
Executando a operação "Criar Arquivo"
O que ele faria: criar um arquivo.
Destino: C:\Users\ana\guia-ps-teste\teste.txt
Onde o arquivo nasceria. Depois do ensaio, teste.txt não está na pasta.
No Windows PowerShell 5.1 a mesma frase começa com What if (i minúsculo) e diz Realizando a operação em vez de Executando a operação. O efeito é o mesmo: nada é criado.

Resumo

  • New-Item cria um item: arquivo ou pasta. Sem -ItemType, nasce um arquivo.
  • -ItemType Directory cria pasta; -ItemType File deixa explícito que é arquivo.
  • -Value "texto" já coloca conteúdo no arquivo novo.
  • Dá para criar um caminho inteiro (a\b\c) e vários nomes de uma vez, separados por vírgula.
  • mkdir é uma função que cria pasta; nos scripts, prefira o New-Item.
  • Se o arquivo já existe, o PowerShell 7 recusa (mensagem em inglês: already exists). O -Force recria e esvazia o arquivo.
  • -WhatIf ensaia sem criar. Pratique sempre numa pasta de teste.
