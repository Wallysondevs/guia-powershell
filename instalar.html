Instalar o PowerShell 7

O Windows já traz o Windows PowerShell 5.1. O PowerShell 7, que este guia ensina, é um programa à parte: você instala uma vez e depois abre pelo atalho ou pelo comando pwsh. Nesta aula você vê dois jeitos oficiais no Windows — a Microsoft Store e o winget — e como conferir, depois, se deu certo. Não vamos rodar a instalação daqui: quem instala no seu computador é você.

Você vai aprender
  • Por que o 7 precisa ser instalado (o 5.1 já vem no Windows, o 7 não).
  • A instalar pela Microsoft Store, com o aplicativo da Microsoft.
  • A instalar pelo winget, o instalador de programas da linha de comando do Windows.
  • A conferir se o winget existe e se o pacote se chama mesmo Microsoft.PowerShell.
  • O erro real do 5.1 quando o pwsh ainda não está instalado, e o que fazer.

As saídas desta aula foram colhidas no PowerShell 7.7 (e o erro, no 5.1) de um Windows em português. Nenhum comando daqui instala, altera ou lista os programas da sua máquina: a instalação em si você faz na Store ou digitando o winget install na sua janela, quando quiser.

A ideia: um aplicativo a mais, como um navegador

O 5.1 é como o bloco de notas que já veio no Windows: está lá, estável, mas não recebe as novidades. O 7 é como instalar um navegador atual: você baixa o aplicativo oficial, e as duas coisas podem conviver. Instalar o 7 não apaga o 5.1.

Depois de instalado, o atalho “PowerShell 7” e o comando pwsh abrem o 7. O atalho “Windows PowerShell” e o comando powershell continuam abrindo o 5.1. A aula Windows PowerShell 5.1 × PowerShell 7 mostra como ter certeza de qual janela é qual.

1. Pela Microsoft Store (o jeito mais visual)

Se você prefere clicar em vez de digitar, use a loja de aplicativos do Windows.

  1. Abra a Microsoft Store no menu Iniciar.
  2. Na busca, digite PowerShell.
  3. Abra o aplicativo publicado pela Microsoft Corporation (o nome é “PowerShell”, não “Windows PowerShell” e não é um guia de outra empresa).
  4. Clique em Obter ou Instalar e espere terminar.
  5. Feche a janela antiga, se houver uma aberta, e abra o atalho PowerShell 7 no menu Iniciar (é uma janela nova que já enxerga a instalação).
A Store atualiza o PowerShell junto com os outros aplicativos, o que é cômodo. Se a Store não estiver disponível na sua edição do Windows, use o winget da seção seguinte, ou baixe o instalador oficial em aka.ms/powershell.

2. Pelo winget (o jeito pela linha de comando)

O winget é o instalador de programas do próprio Windows, no terminal. Primeiro vale conferir se ele responde. No laboratório:

PS C:\Users\ana> winget --version
v1.29.380

Se aparecer um número de versão (o seu pode ser outro), o winget está pronto. Em seguida, você pode consultar o pacote oficial, sem instalar nada: o identificador é Microsoft.PowerShell.

PS C:\Users\ana> winget search --id Microsoft.PowerShell --exact --accept-source-agreements
Nome       ID                   Versão  Origem
-----------------------------------------------
PowerShell Microsoft.PowerShell 7.7.0.0 winget
winget search
Procura um pacote no catálogo. Não instala nada.
--id Microsoft.PowerShell
O identificador oficial, para não confundir com outro programa de nome parecido.
--exact
Só o que tem exatamente esse identificador.
Versão 7.7.0.0
A versão que o catálogo oferecia no dia da coleta. A sua busca pode mostrar uma versão mais nova, e tudo bem: instale a que a Microsoft estiver oferecendo.

Quando você quiser instalar de verdade, na sua janela (não no editor deste guia), o pedido é este:

winget install --id Microsoft.PowerShell --accept-package-agreements --accept-source-agreements

O winget vai baixar o pacote, pedir confirmação se fizer falta e concluir a instalação. A saída varia com a versão do winget e com o que já existe na máquina: por isso esta aula não reproduz uma instalação. Depois que terminar, feche a janela e abra o PowerShell 7.

Rode o winget install só se você quiser instalar (ou atualizar) o PowerShell 7 neste computador, e só numa janela sua. O editor do guia não instala programa nenhum no seu Windows.

3. Conferindo se deu certo

Abra uma janela nova do PowerShell 7 e rode $PSVersionTable.PSVersion. A versão deve começar com 7 (neste guia, a referência é a 7.7). Se ainda aparecer 5.1…, você abriu o 5.1: feche e escolha o atalho “PowerShell 7”, ou digite pwsh no menu Iniciar.

O editor abaixo já é um PowerShell 7 (o do navegador). Use-o para praticar o pedido da versão, sem mexer no que está instalado no seu Windows.

Experimente: mostre a versão do PowerShell que está atendendo, com $PSVersionTable.PSVersion.

Write-Output "Qual é a versão?"

$PSVersionTable.PSVersion

Quando dá errado

O 5.1 ainda não encontra o pwsh

Se você pede o pwsh numa janela do Windows PowerShell 5.1 e o 7 ainda não está instalado, a resposta real é esta:

PS C:\Users\ana> (Get-Command pwsh).Source
Get-Command : O termo 'pwsh' não é reconhecido como nome de cmdlet, função, arquivo de script ou programa operável.
Verifique a grafia do nome ou, se um caminho tiver sido incluído, veja se o caminho está correto e tente novamente.
No linha:1 caractere:2
+ (Get-Command pwsh).Source
+  ~~~~~~~~~~~~~~~~
    + CategoryInfo          : ObjectNotFound: (pwsh:String) [Get-Command], CommandNotFoundException
    + FullyQualifiedErrorId : CommandNotFoundException,Microsoft.PowerShell.Commands.GetCommandCommand

É o mesmo tipo de “não é reconhecido” da aula 5.1 × 7: o 5.1 procurou o programa pwsh e não achou.

Como resolver: instale o 7 pela Store ou pelo winget install --id Microsoft.PowerShell, feche a janela e abra o atalho PowerShell 7. Não adianta só rodar de novo na mesma janela antiga do 5.1 sem instalar nada.

O winget também não é reconhecido

Em algumas instalações do Windows o winget ainda não está disponível, ou a janela antiga não o enxerga. Nesse caso, use a Microsoft Store (seção 1) ou o instalador oficial em aka.ms/powershell, e abra uma janela nova depois.

Resumo

  • O 5.1 já vem no Windows; o PowerShell 7 se instala à parte e não apaga o 5.1.
  • Dois jeitos oficiais no Windows: a Microsoft Store (app “PowerShell” da Microsoft) e o winget install --id Microsoft.PowerShell.
  • winget --version e winget search só consultam. A instalação você roda na sua janela, quando quiser; esta aula não reproduz essa saída.
  • Depois, abra uma janela nova do PowerShell 7 e confira com $PSVersionTable.PSVersion (deve começar com 7).
  • Se o 5.1 diz que pwsh não é reconhecido, o 7 ainda não está instalado (ou você não abriu a janela dele).
