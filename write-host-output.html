Write-Host e Write-Output: Mostrando Coisas na Tela

A Ana quer que o script dela avise "Olá, Ana!", mostre a lista de frutas da feira e, às vezes, destaque um aviso em amarelo. No PowerShell há dois jeitos de pôr texto na tela, o Write-Output e o Write-Host. Na tela os dois parecem iguais, mas por dentro fazem coisas bem diferentes. Nesta aula você vai ver qual usar em cada situação.

Você vai aprender
  • A mostrar texto com Write-Output, com Write-Host e só com as aspas.
  • Que o Write-Output manda o resultado pela esteira (pipeline), e o Write-Host só pinta a tela.
  • Por que o que sai do Write-Host não pode ser guardado numa variável.
  • A usar cores (-ForegroundColor), separadores (-Separator) e a juntar linhas (-NoNewline).
  • A ler os erros reais de quem mistura os dois.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: a esteira e o letreiro

Imagine uma fábrica. O Write-Output coloca a peça na esteira: ela pode seguir para a próxima máquina (outro comando), ser guardada numa caixa (uma variável) ou, se a esteira acabar, cair na tela. O Write-Host é um letreiro luminoso na parede: todo mundo vê, pode ter cor, mas nada vai para a esteira. Ninguém consegue pegar o letreiro e colocar numa caixa.

1. Os dois na tela

PS C:\Users\ana> Write-Output "Olá, Ana!"
Olá, Ana!
PS C:\Users\ana> Write-Host "Olá, Ana!"
Olá, Ana!
PS C:\Users\ana> "Olá, Ana!"
Olá, Ana!
Write-Output
"Escrever na saída". Write é "escrever", e Output é "saída": a esteira do PowerShell.
Write-Host
"Escrever no anfitrião". O Host ("anfitrião") é a janela do terminal. O texto vai direto para a tela.
"Olá, Ana!"
Um texto sozinho numa linha. O PowerShell entende como Write-Output "Olá, Ana!": é o jeito mais curto e o mais usado.

Na tela, as três linhas dão o mesmo resultado. A diferença aparece quando você tenta usar o resultado.

2. A diferença: quem segue pela esteira

O Measure-Object ("medir objeto") conta quantos itens chegaram pela esteira. Veja o que ele recebe de cada um:

PS C:\Users\ana> Write-Output "maçã","banana","uva" | Measure-Object

Count             : 3
Average           : 
Sum               : 
Maximum           : 
Minimum           : 
StandardDeviation : 
Property          : 

PS C:\Users\ana> Write-Host "maçã","banana","uva" | Measure-Object
maçã banana uva

Count             : 0
Average           : 
Sum               : 
Maximum           : 
Minimum           : 
StandardDeviation : 
Property          :
|
A barra vertical liga a esteira de um comando à entrada do próximo (aula Pipeline).
Count : 3
Com Write-Output, as 3 frutas chegaram ao Measure-Object.
maçã banana uva / Count : 0
Com Write-Host, as frutas foram pintadas na tela (numa linha só, separadas por espaço), e nenhuma chegou ao Measure-Object: ele contou 0.

O mesmo vale para variáveis. O [$texto] entre colchetes mostra o que ficou guardado:

PS C:\Users\ana> $texto = Write-Output "guardado"; "Na variável: [$texto]"
Na variável: [guardado]
PS C:\Users\ana> $texto = Write-Host "não guardado"; "Na variável: [$texto]"
não guardado
Na variável: []

Com Write-Host, o texto apareceu na hora e a variável ficou vazia: []. O ; separa dois comandos na mesma linha.

Experimente: a variável $saudacao está saindo vazia. Troque o comando da primeira linha para que o texto fique guardado e apareça Guardado: [Olá, Ana!].

$saudacao = Write-Host 'Olá, Ana!'
"Guardado: [$saudacao]"

$saudacao = Write-Output 'Olá, Ana!'
"Guardado: [$saudacao]"

3. Cores, separadores e linha contínua (só Write-Host)

Se o Write-Host não serve para a esteira, para que ele existe? Para enfeitar a tela: mensagens para a pessoa que está olhando.

PS C:\Users\ana> Write-Host "Atenção" -ForegroundColor Yellow
Atenção
PS C:\Users\ana> Write-Host "a","b","c" -Separator " | "
a | b | c
PS C:\Users\ana> Write-Host "sem quebra " -NoNewline; Write-Host "de linha"
sem quebra de linha
-ForegroundColor Yellow
"Cor da frente": a cor das letras. No terminal de verdade, "Atenção" sai em amarelo (aqui na página não dá para ver a cor). Também existe -BackgroundColor, a cor do fundo.
-Separator " | "
"Separador": o que vai entre os itens. Sem ele, o separador é um espaço.
-NoNewline
"Sem nova linha": não pula de linha no fim, e o próximo texto continua ao lado.

Experimente: faça as frutas aparecerem separadas por - (espaço, traço, espaço), assim: maçã - banana - uva.

Write-Host 'maçã', 'banana', 'uva'

Write-Host 'maçã', 'banana', 'uva' -Separator ' - '

Formas diferentes de mostrar texto

FormaQuando usar
"Olá" (texto sozinho)O jeito do dia a dia. É o mesmo que Write-Output.
Write-Output "Olá"Quando você quer deixar claro, no script, que aquilo é resultado. Vai pela esteira.
echo "Olá"Apelido do Write-Output (aula Apelidos). Bom no terminal; evite em scripts.
Write-Host "Olá" -ForegroundColor GreenMensagens só para quem está olhando: cores, menus, "Pronto!". Não vai pela esteira.
Write-Warning, Write-Error…Avisos e erros têm comandos próprios (aula Outros Write).
Regra prática: se alguém (outro comando, uma variável, um arquivo) pode precisar do resultado, use Write-Output ou o texto sozinho. Use Write-Host só para enfeitar a tela.

Quando dá errado

Cor no Write-Output 
PS C:\Users\ana> Write-Output "oi" -ForegroundColor Red
oi
-ForegroundColor
Red

Não apareceu erro, mas o resultado está errado: nada ficou vermelho e o PowerShell mostrou três linhas. O Write-Output não tem o parâmetro -ForegroundColor, então ele tratou -ForegroundColor e Red como mais dois textos para mostrar.

Como resolver: cor é coisa do Write-Host: Write-Host "oi" -ForegroundColor Red.

Uma cor que não existe 
PS C:\Users\ana> Write-Host "oi" -ForegroundColor Roxo
Write-Host: Não é possível associar o parâmetro 'ForegroundColor'. Cannot convert value "Roxo" to type "System.ConsoleColor". Error: "Unable to match the identifier name Roxo to a valid enumerator name. Specify one of the following enumerator names and try again:
Black, DarkBlue, DarkGreen, DarkCyan, DarkRed, DarkMagenta, DarkYellow, Gray, DarkGray, Blue, Green, Cyan, Red, Magenta, Yellow, White"
Não é possível associar o parâmetro 'ForegroundColor'
O valor que você deu não serve para esse parâmetro.
Cannot convert value "Roxo" to type "System.ConsoleColor"
"Não dá para converter 'Roxo' numa cor do console." As cores têm nomes fixos, em inglês.
Specify one of the following…
"Escolha um destes": a lista das 16 cores que valem. Roxo é Magenta ou DarkMagenta.

Como resolver: use um nome da lista, em inglês: Write-Host "oi" -ForegroundColor Magenta.

A variável ficou vazia

Você fez $resultado = Write-Host "..." e depois $resultado não tem nada. Como viu na seção 2, o Write-Host não entrega nada para a variável.

Como resolver: troque por Write-Output ou pelo texto sozinho.

Exercícios

1. Complete o comando

Mostre "Pronto!" com letras verdes:

Write-Host "Pronto!" Green

2. Para a esteira

Complete para que as frutas sigam pela esteira e o Measure-Object conte 2:

"maçã","uva" | Measure-Object

3. Lado a lado

Complete para que "Carregando..." e "ok" saiam na mesma linha:

Write-Host "Carregando... " ; Write-Host "ok"

4. O que $x = Write-Host "oi" guarda em $x?

5. Uma linha só com "Olá" equivale a qual comando?

6. Quando o Write-Host é a melhor escolha?

Missão final: o script deveria mostrar Itens: 3, mas mostra Itens: 0. Conserte a primeira linha para as frutas irem pela esteira, usando Write-Output.

$medida = Write-Host 'maçã', 'banana', 'uva' | Measure-Object
"Itens: " + $medida.Count

$medida = Write-Output 'maçã', 'banana', 'uva' | Measure-Object
"Itens: " + $medida.Count

Resumo

  • Write-Output (ou o texto sozinho) manda o resultado pela esteira: dá para guardar, contar e passar adiante.
  • Write-Host só pinta a tela: nada vai para a variável nem para o próximo comando.
  • Cores (-ForegroundColor), -Separator e -NoNewline são do Write-Host.
  • As cores têm 16 nomes fixos, em inglês; um nome errado dá "Não é possível associar o parâmetro".
