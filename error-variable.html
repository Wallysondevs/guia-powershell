$Error e -ErrorVariable

Todo erro fica anotado num caderno chamado $Error. E, quando você quer os erros de um comando separados, o parâmetro -ErrorVariable guarda só eles numa variável sua.

Você vai aprender
  • Como a lista $Error funciona (o mais novo primeiro).
  • A guardar os erros de um comando com -ErrorVariable.
  • A acumular erros de vários comandos com +.
  • A conferir se um comando deu certo com $?.
  • A combinar com -ErrorAction SilentlyContinue para um relatório limpo.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: o caderno de ocorrências

Na portaria do prédio existe um caderno onde toda ocorrência é anotada, a mais recente em cima. Esse é o $Error. O -ErrorVariable é como pedir ao porteiro: "anote as ocorrências do meu apartamento numa folha separada".

1. A lista $Error

PS> $Error.Clear()
PS> try { 1 / 0 } catch { }
PS> try { [int]"abc" } catch { }
PS> $Error.Count
2
PS> $Error[0].Exception.Message
Cannot convert value "abc" to type "System.Int32". Error: "The input string 'abc' was not in a correct format."
PS> $Error[1].Exception.Message
Attempted to divide by zero.
$Error[0]
O erro mais recente.
$Error[1]
O anterior. A lista cresce para baixo, guardando até 256 erros por padrão.

Repare: até erros tratados com try/catch entram em $Error.

2. -ErrorVariable

Com -ErrorVariable nome (sem o $!), os erros daquele comando vão para $nome. Vamos usar uma função avançada que gera erro em alguns itens:

PS> function Testar-Nota { [CmdletBinding()] param([int]$Nota)
>>   if ($Nota -gt 10) { Write-Error "Nota $Nota acima de 10." } else { "Nota $Nota ok" }
>> }
PS> Testar-Nota 12 -ErrorVariable problemas -ErrorAction SilentlyContinue
PS> $problemas.Count
1
PS> $problemas[0].Exception.Message
Nota 12 acima de 10.
-ErrorVariable problemas
Guarda os erros em $problemas. O nome vai sem o $.
-ErrorAction SilentlyContinue
Esconde o erro da tela; ele continua guardado em $problemas.

Experimente: chame Testar-Nota 15 guardando o erro em erros (com -ErrorVariable e -ErrorAction SilentlyContinue), e mostre $erros[0].Exception.Message.

function Testar-Nota { [CmdletBinding()] param([int]$Nota)
  if ($Nota -gt 10) { Write-Error "Nota $Nota acima de 10." } else { "Nota $Nota ok" }

3. Acumulando com +

Normalmente cada chamada substitui o conteúdo da variável. Com + antes do nome, os erros vão se somando:

PS> foreach ($n in 8, 11, 9, 14) {
>>   Testar-Nota $n -ErrorVariable +ruins -ErrorAction SilentlyContinue
>> }
Nota 8 ok
Nota 9 ok
PS> "Problemas encontrados: $($ruins.Count)"
Problemas encontrados: 2
PS> $ruins | ForEach-Object { $_.Exception.Message }
Nota 11 acima de 10.
Nota 14 acima de 10.

4. Deu certo? $?

A variável $? diz se o último comando terminou sem erro (True) ou com erro (False):

PS> Testar-Nota 7; $?
Nota 7 ok
True
PS> [int]"abc"; $?
InvalidArgument: Cannot convert value "abc" to type "System.Int32". Error: "The input string 'abc' was not in a correct format."
False

O $? olha só para o último comando. Confira logo depois do comando que interessa, antes de rodar qualquer outro (por isso, aqui, ele está na mesma linha, depois do ;).

Quando dá errado

Escrever o $ no -ErrorVariable

-ErrorVariable $problemas usa o valor de $problemas como nome (geralmente vazio). Escreva -ErrorVariable problemas, sem o $.

Usar -ErrorVariable numa função simples

Só cmdlets e funções avançadas (com [CmdletBinding()]) têm -ErrorVariable. Numa função simples, o parâmetro vai parar em $args e não guarda nada.

function Testar-Nota { [CmdletBinding()] param([int]$Nota)
  if ($Nota -gt 10) { Write-Error "Nota $Nota acima de 10." } else { "Nota $Nota ok" }
}
foreach ($n in 5, 12, 30) {
  Testar-Nota $n -ErrorVariable +ruins -ErrorAction SilentlyContinue
}
"Problemas: $($ruins.Count)"

Resumo

  • $Error guarda todos os erros, o mais recente em [0].
  • -ErrorVariable nome guarda só os erros daquele comando.
  • +nome acumula entre chamadas.
  • $? diz se o último comando deu certo.
