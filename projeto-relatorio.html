Projeto: Relatório de Arquivos em CSV

"Para onde foi o espaço do meu disco?" Neste projeto você escreve um relatório que varre uma pasta, soma os tamanhos por tipo de arquivo e por subpasta, encontra os maiores e os mais antigos e salva tudo em CSV para abrir no Excel.

Você vai aprender
  • A varrer pastas com Get-ChildItem -Recurse -File.
  • A somar tamanhos com Group-Object e Measure-Object.
  • A formatar bytes em KB/MB.
  • A exportar para CSV que abre direito no Excel.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

5. Exportando para CSV

PS> $dados = Get-ChildItem -Recurse -File | Select-Object @{ n = 'Pasta'; e = { $_.Directory.Name } }, Name, Extension, @{ n = 'KB'; e = { [math]::Round($_.Length / 1KB, 1) } }, LastWriteTime
PS> $dados | Export-Csv relatorio.csv -UseCulture -NoTypeInformation -Encoding utf8BOM
AVISO: O parâmetro 'NoTypeInformation' está obsoleto. This parameter is obsolete and has no effect. The default behavior is to not include type information. Use -IncludeTypeInformation to include type information.
PS> (Get-Content relatorio.csv)[0]
"Pasta";"Name";"Extension";"KB";"LastWriteTime"
PS> (Import-Csv relatorio.csv -UseCulture).Count
5
-UseCulture
Usa o separador do Windows em português (;), que é o que o Excel brasileiro espera.
-Encoding utf8BOM
Faz o Excel reconhecer os acentos.
-NoTypeInformation agora é obsoleto No PowerShell 7.7 esse parâmetro não faz mais nada: o Export-Csv já não grava a linha de tipo (#TYPE ...). Ele só gera o AVISO que aparece na saída, e pode ser tirado do comando. Se o mesmo script também precisar rodar no Windows PowerShell 5.1, mantenha o parâmetro e ignore o aviso: lá ele ainda evita a linha de tipo.

Abra com Invoke-Item relatorio.csv.

6. Como função

function Get-RelatorioPasta {
    param([string]$Caminho = '.', [string]$Saida = 'relatorio.csv')
    Get-ChildItem $Caminho -Recurse -File -ErrorAction SilentlyContinue |
        Select-Object @{ n = 'Pasta'; e = { $_.DirectoryName } }, Name, Extension,
            @{ n = 'MB'; e = { [math]::Round($_.Length / 1MB, 2) } }, LastWriteTime |
        Export-Csv $Saida -UseCulture -NoTypeInformation -Encoding utf8BOM
}
Get-RelatorioPasta -Caminho $HOME\Downloads -Saida $HOME\Desktop\downloads.csv

-ErrorAction SilentlyContinue evita que pastas sem permissão interrompam o relatório.

Resumo

  • Get-ChildItem -Recurse -File varre tudo.
  • Group-Object + Measure-Object -Sum somam por tipo e pasta.
  • Sort-Object Length acha os maiores; LastWriteTime, os antigos.
  • Export-Csv -UseCulture -Encoding utf8BOM abre certinho no Excel.
