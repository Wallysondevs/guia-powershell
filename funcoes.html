Funções (function)

Uma função é um pedaço de código com nome. Você escreve uma vez e chama quantas vezes quiser, como se fosse um comando novo do PowerShell. É o primeiro passo para deixar de repetir código.

Você vai aprender
  • A criar uma função com function Nome { ... }.
  • A dar nomes no estilo Verbo-Substantivo, como os cmdlets.
  • A passar valores para a função e chamar sem parênteses e sem vírgulas.
  • Que a função precisa ser definida antes de ser chamada.
  • A ver as funções que existem com Get-Command -CommandType Function.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional. Os quadros marcados Saída no Windows (PowerShell 7.7) foram colhidos num Windows 10 em português, com o nome do computador e o da usuária trocados por exemplos (NOTEBOOK e ana).

A ideia: a receita com nome

No caderno de receitas, você escreve "Bolo de cenoura" e os passos uma vez. Depois, basta dizer "faz o bolo de cenoura" e todo mundo sabe o que fazer. A função é a receita: o nome é o título, o bloco { } são os passos.

1. A primeira função

PS> function Dizer-Ola { "Olá! Hoje é dia $((Get-Date -Year 2026 -Month 3 -Day 15).Day)." }
PS> Dizer-Ola
Olá! Hoje é dia 15.
PS> Dizer-Ola
Olá! Hoje é dia 15.
function
A palavra que cria a função.
Dizer-Ola
O nome. Depois de criada, você chama pelo nome, como um cmdlet.
{ ... }
O corpo: o que a função faz cada vez que é chamada.

2. Recebendo valores

Coloque nomes de variáveis entre parênteses depois do nome da função. Na hora de chamar, passe os valores separados por espaço:

PS> function Somar($a, $b) { $a + $b }
PS> Somar 2 3
5
PS> Somar -a 10 -b 5
15
Somar($a, $b)
A função recebe dois valores, que dentro dela se chamam $a e $b.
Somar 2 3
Chamada por posição: 2 vai para $a, 3 vai para $b.
Somar -a 10 -b 5
Chamada pelo nome, como os parâmetros de um cmdlet.

O jeito mais completo de declarar parâmetros é o bloco param(), assunto da aula Parâmetros.

Experimente: crie a função Dobro que recebe $n e mostra O dobro de 21 é 42 quando chamada com Dobro 21.

Dobro 21

function Dobro($n) { "O dobro de $n é $($n * 2)" }
Dobro 21

3. Nomes no estilo do PowerShell

Os cmdlets seguem o padrão Verbo-Substantivo (aula Cmdlets). Use o mesmo nas suas funções, com um verbo da lista aprovada (Get, Set, New, Show…). A aula Estilo e Verbos Aprovados mostra a lista.

PS> function Get-Quadrado($n) { $n * $n }
PS> Get-Quadrado 7
49
PS> (Get-Command Get-Quadrado).CommandType
Function

4. Funções com várias linhas

O corpo pode ter quantas linhas quiser. O [string] e o [double] na frente dos parâmetros dizem o tipo de cada um (mais na aula Parâmetros):

PS> function Show-Recibo([string]$cliente, [double]$valor) {
>>   "Cliente: $cliente"
>>   "Valor:   R$ {0:N2}" -f $valor
>>   "Obrigado pela compra!"
>> }
PS> Show-Recibo "Ana" 49.9
Cliente: Ana
Valor:   R$ 49,90
Obrigado pela compra!

Quando dá errado

Chamar com parênteses e vírgula 
PS> Somar(2, 3)
2
3

Com parênteses e vírgula, (2, 3) vira uma lista que vai inteira para $a. O $b fica vazio, e o resultado é a lista. Chame funções do PowerShell como comandos: Somar 2 3.

Chamar antes de criar 
PS> Show-Aviso
Show-Aviso: O termo "Show-Aviso" não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.
Verifique a ortografia do nome ou, se um caminho foi incluído, verifique se o caminho está correto e tente novamente.
PS> function Show-Aviso { "Atenção!" }
PS> Show-Aviso
Atenção!

O PowerShell lê e roda de cima para baixo. Na primeira chamada, a função ainda não existia, e aparece o mesmo erro de "termo não reconhecido" da aula Seu Primeiro Comando. Na segunda, ela já existe e mostra Atenção!. Nos scripts, coloque as funções no começo.

Resumo

  • function Nome { ... } cria um comando novo.
  • Parâmetros simples: function Nome($a, $b).
  • Chame como cmdlet: Nome 1 2 ou Nome -a 1 -b 2, nunca Nome(1, 2).
  • A função precisa ser criada antes de ser chamada.
  • Use nomes Verbo-Substantivo com verbos aprovados.
