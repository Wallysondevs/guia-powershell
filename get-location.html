Onde Estou (Get-Location)

Toda janela do PowerShell está "parada" em alguma pasta. É essa pasta que aparece no meio do prompt, e é nela que os comandos procuram um arquivo quando você não diz o caminho inteiro. Nesta aula você vai perguntar ao PowerShell onde você está, de três jeitos diferentes, e vai ver o que mais existe por trás dessa resposta.

Você vai aprender
  • O Get-Location, que mostra a pasta atual.
  • O apelido pwd e a variável automática $PWD, que fazem a mesma pergunta.
  • O $PWD.Path, que devolve só o caminho, como texto.
  • A ficha completa da pasta, com Format-List *: disco, provedor e caminho.
  • A ler o caminho no próprio prompt PS C:\Users\ana\guia-ps-teste>.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, dentro de uma pasta de teste chamada guia-ps-teste, na pasta pessoal da usuária fictícia ana. Os exemplos abaixo já partem de dentro dessa pasta. No seu computador, no lugar de ana vai aparecer o seu nome de usuário.

A ideia: a plaquinha "você está aqui"

No mapa de um shopping, uma plaquinha vermelha diz "você está aqui". Ela não te leva a lugar nenhum: só informa o andar e a loja do lado. Se você quiser ir à praça de alimentação, aí sim precisa andar (isso é a próxima aula, o Set-Location).

O Get-Location é essa plaquinha. Ele mostra a pasta atual; não muda nada.

1. Perguntando a pasta: Get-Location

Digite e aperte Enter:

PS C:\Users\ana\guia-ps-teste> Get-Location

Path
----
C:\Users\ana\guia-ps-teste
Get-Location
Verbo Get ("obter") + substantivo Location ("local"): "onde eu estou?".
Path
O nome da coluna: "caminho". É o endereço completo da pasta atual.
C:\Users\ana\guia-ps-teste
O valor: disco C:, pasta dos usuários, pasta da Ana, e dentro dela a pasta de teste desta aula.

Repare que o prompt já dizia a mesma coisa, antes do >: PS C:\Users\ana\guia-ps-teste>. O comando só confirma, numa tabelinha.

Experimente: use o Get-Location para ver a pasta atual do editor. (O caminho no editor é o do Linux, não o do Windows; o comando é o mesmo.)



Get-Location









2. Dois atalhos: pwd e $PWD


O mesmo resultado aparece de outras duas formas. A primeira é o apelido pwd ("print working directory", "imprima a pasta de trabalho"), herdado do Linux:


PS C:\Users\ana\guia-ps-teste> pwd

Path
----
C:\Users\ana\guia-ps-teste


A segunda é a variável automática $PWD (de present working directory). Variáveis começam com $ e já vêm prontas; a aula delas é Variáveis Automáticas. Por enquanto, pense nela como um papelzinho em que o PowerShell já anotou a pasta atual:


PS C:\Users\ana\guia-ps-teste> $PWD

Path
----
C:\Users\ana\guia-ps-teste


As três respostas são a mesma tabelinha com a coluna Path. Use o nome completo Get-Location nos scripts; pwd é atalho de terminal.






3. Só o texto do caminho: $PWD.Path


Às vezes você não quer a tabela, quer só o endereço, como um texto que dá para juntar com um nome de arquivo. Peça a propriedade Path depois de um ponto:


PS C:\Users\ana\guia-ps-teste> $PWD.Path
C:\Users\ana\guia-ps-teste



  
$PWD
O objeto "pasta atual", com várias informações dentro.

  
.
O ponto pede uma propriedade daquele objeto: um campo da ficha.

  
Path
O campo do caminho. Sai só a linha C:\Users\ana\guia-ps-teste, sem cabeçalho e sem linha em branco.




Isso vai ser muito útil quando você montar caminhos (aula Caminhos). (Get-Location).Path devolve o mesmo texto.

4. A ficha completa: Format-List *


A tabelinha padrão esconde alguns campos. Para ver a ficha inteira, mande o resultado para o Format-List * ("formate como lista, todos os campos"):


PS C:\Users\ana\guia-ps-teste> Get-Location | Format-List *

Drive        : C
Provider     : Microsoft.PowerShell.Core\FileSystem
ProviderPath : C:\Users\ana\guia-ps-teste
Path         : C:\Users\ana\guia-ps-teste



  
Drive
A letra do disco, aqui C. Sem os dois pontos.

  
Provider
O provedor: o tipo de lugar em que você está. FileSystem é o disco de arquivos. O PowerShell também tem outros, como o Env: e o Registro; isso é a aula Drives e Provedores.

  
ProviderPath
O caminho do jeito que o provedor entende. Em pastas de arquivo, em geral é igual ao Path.

  
Path
O caminho que você já conhece, o mesmo do prompt.

Quando dá errado




Achar que o Get-Location muda de pasta

Este é o tropeço mais comum, e quase nunca vem com uma mensagem vermelha. O Get-Location só mostra o lugar; ele não aceita um destino para "ir até lá". Quem muda de pasta é o Set-Location (próxima aula).


Se você olhar o prompt e ele continuar PS C:\Users\ana\guia-ps-teste> depois de um Get-Location, está certo: você perguntou onde estava, e continuou no mesmo lugar.






O caminho no prompt não é o que você esperava

A pasta atual é por sessão: cada janela do PowerShell tem a sua. Se você abriu uma janela nova, em geral ela começa na sua pasta pessoal (C:\Users\ana), não na pasta em que a janela anterior estava. Não é um erro, e não muda nada no seu disco. Use Get-Location para confirmar, e o Set-Location para ir até a pasta de trabalho.
