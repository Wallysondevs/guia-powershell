Cmdlets Mais Usados

Uma cola para deixar aberta ao lado do terminal: os cmdlets que mais aparecem no dia a dia, agrupados pelo que você quer fazer, com o apelido mais comum e a aula onde ele é explicado.

Você vai aprender
  • Qual cmdlet usar para cada tarefa comum.
  • O apelido curto de cada um (para o terminal).
  • Onde aprender mais sobre cada cmdlet neste guia.

Ajuda e descoberta

CmdletApelidoPara quê
Get-HelphelpAjuda de um comando (-Examples para exemplos).
Get-CommandgcmProcura comandos (Get-Command *csv*).
Get-MembergmPropriedades e métodos de um objeto.
Get-AliasgalDe quem um apelido é atalho.

Resumo

  • Para descobrir: Get-Help, Get-Command, Get-Member.
  • Para o pipeline: Where-Object, Select-Object, Sort-Object, ForEach-Object.
  • Apelidos são para o terminal; em scripts, use o nome completo.
