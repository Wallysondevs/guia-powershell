PowerShell Variáveis Dentro do Texto

A Ana quer mandar o mesmo recado para cada aluna, só trocando o nome e a nota. Em vez de juntar pedaços, ela escreve o texto uma vez e deixa o PowerShell encaixar as variáveis no lugar certo.

Você vai aprender
  • A colocar variáveis no meio de um texto (interpolação).
  • A armadilha do ponto: "$nome.Length" não funciona como parece.
  • A subexpressão $( ) para contas e propriedades dentro do texto.
  • A usar ${nome} quando a variável está colada em outra palavra.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: a carta com lacunas

Pense numa carta modelo: "Prezada ____, seu pedido chegou". Você escreve uma vez e preenche a lacuna para cada cliente. Interpolar é isso: o PowerShell preenche as lacunas de um texto entre aspas duplas com os valores das variáveis.

1. Variável no meio do texto

PS C:\Users\ana> $nome = "Ana"
PS C:\Users\ana> $idade = 30
PS C:\Users\ana> "Olá, $nome"
Olá, Ana
PS C:\Users\ana> "$nome tem $idade anos"
Ana tem 30 anos

Só funciona com aspas duplas (aula Textos: Aspas Simples × Duplas).

2. A armadilha do ponto

PS C:\Users\ana> "O nome $nome.Length parece uma propriedade, mas não é"
O nome Ana.Length parece uma propriedade, mas não é
PS C:\Users\ana> "O tamanho de $nome é $($nome.Length)"
O tamanho de Ana é 3

Dentro do texto, o PowerShell troca só o $nome. O .Length ("comprimento") ficou como texto comum. Para usar uma propriedade, ponha tudo dentro de $( ).

3. A subexpressão $( )

O $( ) roda o que está dentro e põe o resultado no texto. Serve para contas, propriedades e métodos:

PS C:\Users\ana> "2 + 3 = $(2 + 3)"
2 + 3 = 5
PS C:\Users\ana> "em maiúsculas: $($nome.ToUpper())"
em maiúsculas: ANA

Experimente: o texto mostra a conta em vez do resultado. Coloque a conta dentro de $( ).

$a = 10
$b = 20
"Total: $a + $b"

$a = 10
$b = 20
"Total: $($a + $b)"

4. Variável colada em outra palavra

PS C:\Users\ana> "${nome}zinha"
Anazinha
PS C:\Users\ana> "$nomezinha"

Em "$nomezinha", o PowerShell procurou uma variável chamada $nomezinha, que não existe, e mostrou nada (uma linha vazia). As chaves em ${nome} dizem onde o nome termina.

5. Aspas simples não interpolam

PS C:\Users\ana> 'Olá, $nome — $($nome.Length) letras'
Olá, $nome — $($nome.Length) letras

Formas diferentes

FormaQuando
"Olá, $nome"Variável sozinha.
"$($nome.Length)"Propriedade, método ou conta.
"${nome}zinha"Variável colada em letras.
'$nome'Quando você quer o texto $nome literal.

Quando dá errado

Saiu "Ana.Length" em vez do número

Veja a seção 2: propriedade dentro do texto precisa de $( ). Como resolver: "$($nome.Length)".

A variável sumiu do texto

Em "$nomezinha", o nome da variável "engoliu" as letras seguintes. Não aparece erro, só um vazio. Como resolver: "${nome}zinha".

Dois-pontos depois da variável

Em "$nota: Excelente", o : faz o PowerShell ler $nota: como um nome especial, e dá erro de verdade (você vê a mensagem na aula elseif e else). Como resolver: "${nota}: Excelente".

Referência rápida

Você digitaO que faz
"Olá, $nome"Troca a variável pelo valor.
"$($x.Length)"Propriedade, método ou conta dentro do texto.
"${nome}zinha"Separa o nome da variável do texto colado.
'$nome'Aspas simples: não troca nada.

Missão final: mostre Ana tem 3 letras usando $nome e a propriedade .Length.

$nome = "Ana"
"$nome tem $nome.Length letras"

$nome = "Ana"
"$nome tem $($nome.Length) letras"

Resumo

  • Entre aspas duplas, $variavel vira o valor.
  • Propriedades, métodos e contas vão dentro de $( ).
  • ${nome} separa o nome do texto colado.
  • Aspas simples nunca interpolam.
