Projeto: Menu Interativo

Scripts com menu são ótimos para quem não gosta de decorar comandos: a pessoa escolhe um número e o script faz o resto. Neste projeto você monta um menu de "utilidades" com opções numeradas, um switch para decidir o que fazer e um laço que só termina quando a pessoa escolhe "Sair".

Você vai aprender
  • A desenhar um menu com Write-Host e cores.
  • A ler a escolha com Read-Host e validar.
  • A decidir a ação com switch.
  • A repetir até a pessoa sair, com do { } until ().
  • A separar cada ação numa função, para testar sem o menu.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

1. As ações

Primeiro as funções que fazem o trabalho. Elas não sabem nada sobre o menu, por isso dá para testar cada uma sozinha:

PS> function Get-Saudacao { param([int]$Hora)
>>     if ($Hora -lt 12) { "Bom dia!" } elseif ($Hora -lt 18) { "Boa tarde!" } else { "Boa noite!" }
>> }
PS> function Get-Tabuada { param([int]$Numero)
>>     1..10 | ForEach-Object { "{0,2} x {1,2} = {2,3}" -f $Numero, $_, ($Numero * $_) }
>> }
PS> function ConvertTo-Fahrenheit { param([double]$Celsius) "{0:N1} °C = {1:N1} °F" -f $Celsius, ($Celsius * 9 / 5 + 32) }
PS> Get-Saudacao -Hora 9
Bom dia!
PS> Get-Tabuada 7 | Select-Object -First 3
 7 x  1 =   7
 7 x  2 =  14
 7 x  3 =  21
PS> ConvertTo-Fahrenheit 36.5
36,5 °C = 97,7 °F

2. Desenhando o menu

PS> function Show-Menu {
>>     Write-Host ""
>>     Write-Host "===== UTILIDADES =====" -ForegroundColor Cyan
>>     Write-Host " 1) Saudação"
>>     Write-Host " 2) Tabuada"
>>     Write-Host " 3) Celsius para Fahrenheit"
>>     Write-Host " 0) Sair"
>>     Write-Host "======================" -ForegroundColor Cyan
>> }
PS> Show-Menu

===== UTILIDADES =====
 1) Saudação
 2) Tabuada
 3) Celsius para Fahrenheit
 0) Sair
======================

O Write-Host escreve direto na tela (com cor). Como o menu é só para os olhos, não para o pipeline, aqui o Write-Host é a escolha certa (veja Write-Host × Write-Output).

3. Decidindo com switch

PS> function Invoke-Opcao { param([string]$Opcao, [string]$Valor)
>>     switch ($Opcao) {
>>         "1" { Get-Saudacao -Hora ([int]$Valor) }
>>         "2" { Get-Tabuada -Numero ([int]$Valor) }
>>         "3" { ConvertTo-Fahrenheit -Celsius ([double]($Valor -replace ',', '.')) }
>>         "0" { "Até logo!" }
>>         default { "Opção inválida: '$Opcao'. Escolha 0, 1, 2 ou 3." }
>>     }
>> }
PS> Invoke-Opcao 1 "20"
Boa noite!
PS> Invoke-Opcao 3 "25,5"
25,5 °C = 77,9 °F
PS> Invoke-Opcao 9
Opção inválida: '9'. Escolha 0, 1, 2 ou 3.
switch ($Opcao)
Compara a opção com cada caso. Veja switch.
default
Pega tudo que não combinou: é a validação da entrada.
($Valor -replace ',', '.')
Aceita "25,5" do jeito brasileiro antes de converter.

4. O laço do menu

Agora o programa completo. Ele usa Read-Host, então rode no seu terminal:

do {
    Show-Menu
    $opcao = Read-Host "Escolha"
    switch ($opcao) {
        "1" { $valor = (Get-Date).Hour }
        "2" { $valor = Read-Host "Número" }
        "3" { $valor = Read-Host "Temperatura em °C" }
        default { $valor = $null }
    }
    Invoke-Opcao $opcao $valor
    if ($opcao -ne "0") { Read-Host "Enter para continuar" | Out-Null }
} until ($opcao -eq "0")
do { } until (...)
Roda pelo menos uma vez e repete até a condição ser verdadeira. Veja while e do.
Read-Host "Escolha"
Mostra Escolha: e espera a pessoa digitar + Enter. Sempre devolve texto.
Read-Host "Enter para continuar"
Uma pausa, para a pessoa ler o resultado antes de o menu aparecer de novo.

Para salvar como script, coloque as funções e o laço num arquivo menu.ps1 e rode com .\menu.ps1.

    switch ($Opcao) {

        "0" { "Até logo!" }
    }
}

    switch ($Opcao) {
        "1" { "Saudação" }
        "0" { "Até logo!" }
        default { "Opção inválida: '$Opcao'. Escolha 0 ou 1." }
    }
}

Quando dá errado

Comparar a opção com número

O Read-Host devolve texto. switch ($opcao) { 1 { ... } } costuma funcionar porque o PowerShell converte, mas " 1" (com espaço) não combina. Use $opcao = (Read-Host "Escolha").Trim().

Laço infinito

Se a condição do until nunca fica verdadeira (por exemplo, comparando com 0 mas a opção de sair é "s"), o menu não termina. Use Ctrl+C para interromper e confira a condição.

Resumo

  • Separe as ações em funções; o menu só chama.
  • Write-Host desenha o menu; Read-Host lê a escolha (sempre texto).
  • switch com default decide e valida.
  • do { } until ($opcao -eq "0") repete até a pessoa sair.
