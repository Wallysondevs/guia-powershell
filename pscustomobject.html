Seus Objetos ([pscustomobject])

Os comandos do PowerShell devolvem objetos com campos. Com [pscustomobject] você cria os seus, do mesmo jeito: uma ficha com os campos que quiser, pronta para o pipeline, o Sort-Object, o Export-Csv e tudo mais.

Você vai aprender
  • A criar um objeto com [pscustomobject]@{ ... }.
  • A montar uma lista de objetos, inclusive num laço.
  • A acrescentar campos depois com Add-Member.
  • A diferença entre hashtable e [pscustomobject].

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: o formulário preenchido

A hashtable é uma folha de rascunho com anotações "chave: valor". O [pscustomobject] é o formulário oficial: os campos têm ordem fixa e qualquer comando do PowerShell sabe ler. Você escreve igual, mas o resultado se comporta como os objetos dos cmdlets.

1. Criando

PS> $livro = [pscustomobject]@{ Titulo = "Dom Casmurro"; Autor = "Machado de Assis"; Ano = 1899 }
PS> $livro

Titulo       Autor             Ano
------       -----             ---
Dom Casmurro Machado de Assis 1899
PS> $livro.Autor
Machado de Assis
PS> $livro.GetType().Name
PSCustomObject
[pscustomobject]
Transforma a hashtable que vem logo depois num objeto. A ordem dos campos é a da escrita.
$livro.Autor
Lê um campo, como em qualquer objeto.

2. Uma lista de objetos

PS> $livros = @(
>>   [pscustomobject]@{ Titulo = "Dom Casmurro"; Ano = 1899 }
>>   [pscustomobject]@{ Titulo = "Iracema"; Ano = 1865 }
>>   [pscustomobject]@{ Titulo = "Vidas Secas"; Ano = 1938 }
>> )
PS> $livros | Sort-Object Ano

Titulo        Ano
------        ---
Iracema      1865
Dom Casmurro 1899
Vidas Secas  1938

3. Criando objetos num laço

O jeito mais comum: transformar dados em objetos dentro de um laço e guardar a saída:

PS> $linhas = "Ana;9", "Beto;6", "Caio;8"
PS> $alunos = foreach ($l in $linhas) {
>>   $partes = $l.Split(";")
>>   [pscustomobject]@{ Nome = $partes[0]; Nota = [int]$partes[1] }
>> }
PS> $alunos | Where-Object Nota -ge 7

Nome Nota
---- ----
Ana     9
Caio    8
$l.Split(";")
Corta a linha no ;: nome e nota.
[int]$partes[1]
Converte a nota em número, para comparar e somar direito.
$alunos = foreach ...
Cada objeto que o laço "solta" vai para a lista.

Experimente: crie um objeto com Nome = "Duda" e Idade = 25 e mostre na tela.

$pessoa = @{ Nome = "Duda" }

$pessoa = [pscustomobject]@{ Nome = "Duda"; Idade = 25 }
$pessoa

4. Acrescentando um campo: Add-Member

PS> $livro | Add-Member -NotePropertyName Paginas -NotePropertyValue 256
PS> $livro.Paginas
256
PS> $livro.Ano = 1900
PS> $livro

Titulo       Autor             Ano Paginas
------       -----             --- -------
Dom Casmurro Machado de Assis 1900     256

Mudar um campo que existe é só atribuir. Para criar um campo novo num objeto que já existe, use Add-Member.

Formas diferentes: hashtable × [pscustomobject]

PS> $h = @{ Nome = "Ana"; Nota = 9 }
PS> $o = [pscustomobject]@{ Nome = "Ana"; Nota = 9 }
PS> $h

Name                           Value
----                           -----
Nome                           Ana
Nota                           9
PS> $o

Nome Nota
---- ----
Ana     9

Na hashtable, a ordem das linhas pode mudar de uma sessão para outra; no [pscustomobject], nunca.

Hashtable[pscustomobject]
Na telaDuas colunas Name e ValueUma coluna por campo
OrdemSó com [ordered]Sempre a da escrita
Campo novo$h.x = 1Add-Member
Melhor paraConfigurações, contagens, buscas por chaveDados, tabelas, CSV, JSON

Quando dá errado

Criar campo novo com = 
PS> $livro.Editora = "Garnier"
SetValueInvocationException: Exception setting "Editora": "The property 'Editora' cannot be found on this object. Verify that the property exists and can be set."

No [pscustomobject], o = só muda campos que já existem. Para criar, use Add-Member.

Resumo

  • [pscustomobject]@{ ... } cria um objeto com os campos na ordem da escrita.
  • Ele funciona com todos os cmdlets: ordenar, filtrar, exportar.
  • Monte listas de objetos guardando a saída de um laço.
  • Mude campos com =; crie campos novos com Add-Member.
