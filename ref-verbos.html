Verbos Aprovados

Todo cmdlet e toda função bem feita começam com um verbo da lista oficial. Esta página mostra os mais usados, por grupo, e ajuda a escolher o verbo certo para as suas funções (veja também Estilo e Verbos Aprovados).

Você vai aprender
  • A consultar a lista completa com Get-Verb.
  • Os verbos mais comuns de cada grupo.
  • Os pares que confundem (New × Add, Set × Update...).

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A lista completa

PS> (Get-Verb).Count
100
PS> Get-Verb -Group Security | Select-Object Verb, AliasPrefix

Verb      AliasPrefix
----      -----------
Block     bl
Grant     gr
Protect   pt
Revoke    rk
Unblock   ul
Unprotect up

Get-Verb lista os verbos com o grupo e a descrição (em inglês). Para conferir um verbo: Get-Verb -Verb Calcular (sem resultado = não é aprovado).

Pares que confundem

Em dúvida entreRegra
New × AddNew cria algo independente; Add coloca algo dentro de outra coisa.
Set × UpdateSet grava o valor que você deu; Update busca o valor mais recente.
Remove × ClearRemove apaga o item; Clear esvazia o conteúdo e mantém o item.
Get × Find × SearchGet quando você sabe o que quer; Find/Search para procurar.
Start × InvokeStart inicia algo que continua rodando; Invoke executa e termina.

Resumo

  • Get-Verb é a lista oficial; verbos fora dela geram aviso em módulos.
  • Get, Set, New, Remove, Test cobrem a maioria das funções.
  • O verbo diz o que acontece; o substantivo (singular) diz com o quê.
