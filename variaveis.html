PowerShell Variáveis ($)

A Ana anota o nome de cada aluna, a nota da prova, o preço de cada produto da lojinha. Num script, essas informações ficam guardadas em variáveis: caixinhas com nome, que você enche uma vez e usa quantas vezes quiser.

Você vai aprender
  • A criar uma variável com $ e =.
  • A trocar o valor e usar a variável em textos e contas.
  • A ver e apagar variáveis com Get-Variable e Remove-Variable.
  • A reconhecer os erros reais de quem esquece o $.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: uma caixa com etiqueta

Imagine uma caixa de papelão com uma etiqueta escrita "nome". Dentro, você guarda um papel com "Ana". Quando precisar do nome, não precisa lembrar o que estava escrito: basta pedir "a caixa nome". A variável é essa caixa. A etiqueta é o nome da variável, e no PowerShell ela sempre começa com $ (cifrão).

1. Criar e ver

PS C:\Users\ana> $nome = "Ana"
PS C:\Users\ana> $nome
Ana
PS C:\Users\ana> $idade = 30
PS C:\Users\ana> $idade
30
$nome
O nome da variável. O $ avisa: "isto é uma caixa, não um comando".
=
"Guarde dentro". Aqui o = não compara: ele coloca o valor da direita na caixa da esquerda.
"Ana"
O valor guardado. Texto vai entre aspas; número (30) vai sem aspas.

Digitar só $nome mostra o que está guardado. Criar a variável não mostra nada: o PowerShell só guarda e volta ao prompt.

Nomes: use nomes em português e sem acento, que dizem o que guardam: $preco, $totalGeral, $nomeAluna. Acentos funcionam, mas não são o costume. Maiúsculas não importam: $Nome e $nome são a mesma caixa.

2. Trocar o valor

Guardar de novo na mesma caixa joga fora o valor antigo:

PS C:\Users\ana> $nome = "Beto"
PS C:\Users\ana> $nome
Beto

3. Usar no texto e em conta

PS C:\Users\ana> "$nome tem $idade anos"
Beto tem 30 anos
PS C:\Users\ana> $idade + 1
31

Dentro de aspas duplas, o PowerShell troca cada variável pelo valor dela (detalhes na aula Variáveis Dentro do Texto). E a variável entra em contas como se fosse o próprio número. Repare que $idade + 1 mostra 31, mas não muda a caixa: $idade continua 30.

Experimente: guarde "Ana" na variável $nome (troque o texto "mundo") e rode.

$nome = "mundo"
"Olá, $nome!"

$nome = "Ana"
"Olá, $nome!"

4. Nome entre chaves e Get-Variable

O nome pode ir entre chaves: ${cidade} é o mesmo que $cidade. Isso vai ser útil quando o nome estiver colado em outro texto. E o cmdlet Get-Variable ("obter variável") mostra várias de uma vez:

PS C:\Users\ana> ${cidade} = "Recife"
PS C:\Users\ana> ${cidade}
Recife
PS C:\Users\ana> Get-Variable nome, idade, cidade | Format-Table Name, Value -AutoSize

Name   Value
----   -----
nome   Beto
idade  30
cidade Recife

5. Apagar

Remove-Variable ("remover variável") joga a caixa fora. O nome vai sem o $:

PS C:\Users\ana> Remove-Variable idade
PS C:\Users\ana> Get-Variable idade
Get-Variable: Cannot find a variable with the name 'idade'.

"Não encontrei uma variável com o nome 'idade'." Ela foi apagada mesmo.

Quando dá errado

Esqueceu o cifrão 
PS C:\Users\ana> nome = "Ana"
nome: O termo "nome" não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.
Verifique a ortografia do nome ou, se um caminho foi incluído, verifique se o caminho está correto e tente novamente.
nome:
A palavra que causou o problema.
não é reconhecido como … cmdlet, função…
Sem o $, o PowerShell achou que nome era um comando e foi procurar um comando com esse nome. Não achou.

Como resolver: $nome = "Ana".

Usou uma variável que nunca existiu

Normalmente, uma variável que não existe vale $null (nada) e o PowerShell não reclama: um erro de digitação no nome passa em silêncio. Com o modo estrito ligado (Set-StrictMode), ele avisa:

PS C:\Users\ana> Set-StrictMode -Version 1; try { $nuncaDefinida } finally { Set-StrictMode -Off }
InvalidOperation: The variable '$nuncaDefinida' cannot be retrieved because it has not been set.

"A variável $nuncaDefinida não pode ser lida porque nunca recebeu valor." O try … finally só desliga o modo estrito de novo no fim.

Como resolver: confira o nome. Em scripts maiores, Set-StrictMode -Version Latest no começo ajuda a pegar esses enganos.

Referência rápida

Remove-Variable xApaga a variável (nome sem $).

Resumo

  • Variável é uma caixa com nome; o nome começa com $.
  • = guarda; guardar de novo troca o valor.
  • Dentro de aspas duplas, a variável vira o valor.
  • Get-Variable e Remove-Variable usam o nome sem $.
  • Sem o $, o PowerShell procura um comando e dá erro.
