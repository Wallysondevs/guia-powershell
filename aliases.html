Apelidos (ls, dir, cd)

Se você já usou o Prompt de Comando do Windows ou o terminal do Linux, vai tropeçar em nomes curtos como ls, dir e cd. No PowerShell eles funcionam, mas não são os comandos de verdade: são apelidos (em inglês, aliases). Nesta aula você vai ver o que está por trás de cada um, por que ls -la não funciona, e como criar um apelido só para esta janela.

Você vai aprender
  • O que é um apelido e como o Get-Alias mostra o comando verdadeiro.
  • Os apelidos mais comuns: ls, dir, cd, cat, rm, cp, mv, pwd, echo e cls.
  • A listar todos os apelidos de um comando com -Definition.
  • Por que, nos scripts, o guia usa o nome completo e deixa o apelido para o dia a dia no terminal.
  • Que as opções do Linux (como -la) não valem nos apelidos do PowerShell.
  • A criar um apelido só desta sessão com Set-Alias.
  • A diferença do curl e do wget entre o PowerShell 7 e o 5.1.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta pessoal da usuária fictícia ana. Quando o 5.1 se comporta diferente, a aula avisa.

A ideia: o apelido da escola

Na escola, "Zé" é José. Quem chama "Zé" está falando com a mesma pessoa; o nome na lista de chamada continua sendo José. Se a professora pede o nome completo num trabalho oficial, você escreve José, não Zé.

No PowerShell é igual. ls é o apelido; Get-ChildItem é o nome na lista. Os dois fazem a mesma coisa. Nos scripts deste guia, a gente usa o nome completo: fica claro para quem está começando e não depende de o apelido existir.

Na escolaNo PowerShell
"Zé"O apelido, como ls ou cd
José, no diário de classeO cmdlet de verdade, como Get-ChildItem
A lista de apelidos da turmaO Get-Alias
Trabalho oficial com nome completoO script, escrito com o nome do cmdlet

1. Os apelidos mais comuns

O Get-Alias ("obter apelido") mostra, para cada nome curto, qual comando ele aponta:

PS C:\Users\ana> Get-Alias ls, dir, cd, cat, rm, cp, mv, pwd, echo, cls

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           ls -> Get-ChildItem                                           
Alias           dir -> Get-ChildItem                                          
Alias           cd -> Set-Location                                            
Alias           cat -> Get-Content                                            
Alias           rm -> Remove-Item                                             
Alias           cp -> Copy-Item                                               
Alias           mv -> Move-Item                                               
Alias           pwd -> Get-Location                                           
Alias           echo -> Write-Output                                          
Alias           cls -> Clear-Host
Get-Alias
O catálogo dos apelidos. Aqui pedimos dez nomes de uma vez, separados por vírgula.
ls -> Get-ChildItem
A seta quer dizer "aponta para": quando você digita ls, roda o Get-ChildItem (listar pastas e arquivos).
dir
O mesmo Get-ChildItem, no nome que o cmd antigo usava.
cd
Apelido de Set-Location, que muda de pasta (aula Mudando de Pasta).
cat
Apelido de Get-Content: lê o conteúdo de um arquivo.
rm, cp, mv
Apagar (Remove-Item), copiar (Copy-Item) e mover (Move-Item).
pwd
"Print working directory": apelido de Get-Location, que mostra a pasta atual.
echo
Apelido de Write-Output, que escreve um texto.
cls
Apelido de Clear-Host: limpa a tela do terminal.

Quem vem do Linux reconhece ls, cat, rm, cp, mv e pwd. Quem vem do cmd reconhece dir, cd, echo e cls. O PowerShell aceita os dois sotaques, mas por baixo é sempre o mesmo cmdlet.

Experimente: troque pwd por ls e veja para qual comando o apelido aponta.

Get-Alias pwd

Get-Alias ls

2. Todos os apelidos de um comando

O parâmetro -Definition inverte a pergunta: em vez de "para que aponta este apelido?", você pergunta "quais apelidos este comando tem?":

PS C:\Users\ana> Get-Alias -Definition Get-ChildItem

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           dir -> Get-ChildItem                                          
Alias           gci -> Get-ChildItem                                          
Alias           ls -> Get-ChildItem

Get-ChildItem tem três: dir (do cmd), ls (do Linux) e gci (a sigla de Get-ChildItem). Os três fazem exatamente a mesma coisa.

3. Quantos apelidos existem? E como confirmar um

PS C:\Users\ana> (Get-Alias).Count
140

Neste computador, no PowerShell 7.7, são 140 apelidos. O número pode mudar conforme os módulos instalados.

O Get-Command, da aula anterior, também denuncia o apelido: o tipo vem como Alias e a seta mostra o destino.

PS C:\Users\ana> Get-Command ls

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           ls -> Get-ChildItem

4. Um apelido só desta janela: Set-Alias

Você pode inventar um apelido com Set-Alias ("definir apelido"). Ele vale só nesta sessão: quando a janela fecha, some. Não grava no Windows.

PS C:\Users\ana> Set-Alias -Name hoje -Value Get-Date
PS C:\Users\ana> hoje

sexta-feira, 20 de novembro de 2026 17:12:59
Set-Alias
O comando que cria (ou troca) um apelido.
-Name hoje
O nome curto que você vai digitar.
-Value Get-Date
O comando de verdade por trás do apelido.
hoje
Na linha seguinte, o apelido já funciona: a data aparece com a mesma linha em branco de antes e depois que o Get-Date costuma ter.
PS C:\Users\ana> Get-Alias hoje

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           hoje -> Get-Date

O Get-Alias hoje confirma: hoje -> Get-Date.

Em script, prefira Get-Date direto. Apelido é atalho de quem está digitando no terminal, não de quem vai ler o código daqui a seis meses.

Missão: troque Write-Output pelo apelido echo, sem mudar o texto.

Write-Output "Olá, Ana!"

echo "Olá, Ana!"

gciAtalho curto, também só no terminal.

Quando dá errado

As opções do Linux não vêm junto com o apelido

No Linux, ls -la lista tudo, inclusive os arquivos escondidos, num formato longo. No PowerShell, ls é só um apelido do Get-ChildItem, e o -la não existe:

PS C:\Users\ana> ls -la
Get-ChildItem: Não foi possível encontrar um parâmetro correspondente ao nome de parâmetro 'la'.

Linha por linha:

Get-ChildItem:
Quem reclamou foi o comando de verdade, não o ls. Isso confirma que o apelido só trocou o nome.
Não foi possível encontrar um parâmetro… 'la'
O PowerShell leu -la como um parâmetro chamado la, e o Get-ChildItem não tem esse parâmetro.

Como resolver: use os parâmetros do próprio Get-ChildItem. Para ver arquivos escondidos, é Get-ChildItem -Force (aula Listando), não ls -la.

curl e wget não são apelidos no PowerShell 7

No PowerShell 7, se você pede esses dois apelidos, a mensagem vem em inglês (é assim que esse erro saiu neste laboratório):

PS C:\Users\ana> Get-Alias curl, wget
Get-Alias: This command cannot find a matching alias because an alias with the name 'curl' does not exist.
Get-Alias: This command cannot find a matching alias because an alias with the name 'wget' does not exist.

O PowerShell 7 não cria mais esses apelidos de propósito: no 7, curl pode ser o programa de verdade, e um apelido só atrapalharia. A mensagem diz, duas vezes, que não existe apelido com esse nome.

No Windows PowerShell 5.1 a história é outra: curl e wget existem e os dois apontam para o Invoke-WebRequest, que não é o curl de verdade. Quem vinha do Linux se assustava. Neste computador o 5.1 tinha 158 apelidos, contra 140 no 7.7. 
PS C:\Users\ana> Get-Alias curl, wget -ErrorAction SilentlyContinue

CommandType     Name                                               Version    Source                                    
-----------     ----                                               -------    ------                                    
Alias           curl -> Invoke-WebRequest                                                                               
Alias           wget -> Invoke-WebRequest                                                                               
PS C:\Users\ana> (Get-Alias).Count
158

Resumo

  • Apelido (alias) é um nome curto que aponta para um cmdlet. ls e dir são o Get-ChildItem; cd é o Set-Location.
  • Get-Alias ls mostra o destino; Get-Alias -Definition Get-ChildItem lista todos os apelidos daquele comando.
  • Nos scripts, use o nome completo. Apelido é atalho do terminal.
  • ls -la não funciona: o apelido não traz as opções do Linux. Use os parâmetros do cmdlet.
  • Set-Alias cria um apelido só desta janela; quando ela fecha, some.
  • No PowerShell 7, curl e wget não são apelidos. No 5.1, os dois apontam para Invoke-WebRequest.
