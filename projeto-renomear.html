Projeto: Renomear Fotos em Lote

A câmera grava nomes como IMG_0001.JPG, IMG_0002.JPG... e você queria Viagem-2026-001.jpg. Renomear 300 fotos clicando é impossível; com o PowerShell são duas linhas. Neste projeto você renomeia em lote com segurança e ainda guarda um jeito de desfazer.

Você vai aprender
  • A renomear com Rename-Item e -NewName calculado.
  • A numerar com zeros à esquerda ({0:D3}).
  • A usar a data do arquivo no nome.
  • A testar com -WhatIf e guardar um log para desfazer.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

2. Numerando com zeros

PS> "{0:D3}" -f 7
007
PS> "Viagem-{0:D3}.jpg" -f 42
Viagem-042.jpg
{0:D3}
Número com pelo menos 3 dígitos, completando com zeros: 007. Assim a ordem alfabética fica certa.

4. Renomeando e guardando o log

PS> $i = 1
PS> $log = Get-ChildItem *.JPG | Sort-Object Name | ForEach-Object {
>>     $novo = "Viagem-{0:D3}.jpg" -f $i; $i++
>>     Rename-Item $_ -NewName $novo
>>     [pscustomobject]@{ Antigo = $_.Name; Novo = $novo }
>> }
PS> $log | Export-Csv renomeados.csv -NoTypeInformation
AVISO: O parâmetro 'NoTypeInformation' está obsoleto. This parameter is obsolete and has no effect. The default behavior is to not include type information. Use -IncludeTypeInformation to include type information.
PS> (Get-ChildItem *.jpg).Name
Viagem-001.jpg
Viagem-002.jpg
Viagem-003.jpg
Viagem-004.jpg
Viagem-005.jpg
-NoTypeInformation agora é obsoleto No PowerShell 7.7 esse parâmetro não faz mais nada: o Export-Csv já não grava a linha de tipo (#TYPE ...). Ele só gera o AVISO que aparece na saída, e pode ser tirado do comando. Se o mesmo script também precisar rodar no Windows PowerShell 5.1, mantenha o parâmetro e ignore o aviso: lá ele ainda evita a linha de tipo.

5. Desfazendo

PS> Import-Csv renomeados.csv | ForEach-Object { Rename-Item $_.Novo -NewName $_.Antigo }
PS> (Get-ChildItem *.JPG).Name
IMG_0001.JPG
IMG_0002.JPG
IMG_0003.JPG
IMG_0004.JPG
IMG_0005.JPG

6. Com a data no nome

A data de modificação do arquivo vira parte do nome (para fotos reais, a data da foto fica nos metadados EXIF, mas a de modificação costuma servir):

PS> Get-ChildItem *.JPG | ForEach-Object { $_.LastWriteTime = [datetime]'2026-07-15 10:30' }
PS> Get-ChildItem *.JPG | Sort-Object Name | ForEach-Object -Begin { $n = 1 } -Process {
>>     Rename-Item $_ -NewName ("{0:yyyy-MM-dd}_{1:D3}.jpg" -f $_.LastWriteTime, $n)
>>     $n++
>> }
PS> (Get-ChildItem *.jpg).Name
2026-07-15_001.jpg
2026-07-15_002.jpg
2026-07-15_003.jpg
2026-07-15_004.jpg
2026-07-15_005.jpg

7. Trocando espaços e maiúsculas

PS> Set-Content "Minha Foto Bonita.JPG" "x"
PS> Get-ChildItem "* *" | Rename-Item -NewName { ($_.Name -replace ' ', '-').ToLower() }
PS> Test-Path minha-foto-bonita.jpg
True
-NewName { ... }
Um bloco que calcula o nome novo para cada arquivo que chega pelo pipeline.

Experimente: monte o nome Viagem-007.jpg a partir do número 7 usando {0:D3}.

$n = 7
"Viagem-$n.jpg"

$n = 7
"Viagem-{0:D3}.jpg" -f $n

Desafios

  • Renomeie só as fotos de um mês (LastWriteTime.Month).
  • Leia a data real da foto (EXIF) com System.Drawing ou Shell.Application.
  • Faça uma função com -WhatIf (SupportsShouldProcess).

Resumo

  • Rename-Item -NewName renomeia; um bloco { } calcula o nome de cada arquivo.
  • {0:D3} numera com zeros à esquerda.
  • Simule com -WhatIf e guarde um CSV para desfazer.
