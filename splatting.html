Splatting (@parametros)

Quando um comando tem muitos parâmetros, a linha fica enorme. O splatting resolve: você guarda os parâmetros numa hashtable e entrega todos de uma vez, trocando o $ do nome da variável por @.

Você vai aprender
  • A guardar parâmetros numa hashtable.
  • A passar a hashtable com @nome (e não $nome).
  • A reaproveitar os mesmos parâmetros em vários comandos.
  • A juntar splatting com parâmetros escritos na linha.
  • O splatting com array, para parâmetros por posição.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional. Os quadros marcados Saída no Windows (PowerShell 7.7) foram colhidos num Windows 10 em português, com o nome do computador e o da usuária trocados por exemplos (NOTEBOOK e ana).

A ideia: o pedido salvo no aplicativo

No aplicativo de lanche, você salva o pedido de sempre: "X-salada, sem cebola, batata grande, refrigerante". Depois, é só tocar em "pedir de novo". O splatting é o pedido salvo: os parâmetros ficam guardados e você só diz "use estes".

1. A linha comprida

PS> Get-Date -Year 2026 -Month 12 -Day 25 -Hour 20 -Minute 0 -Second 0 -Format "dd/MM/yyyy HH:mm"
25/12/2026 20:00

2. A mesma coisa com splatting

PS> $natal = @{
>>   Year   = 2026
>>   Month  = 12
>>   Day    = 25
>>   Hour   = 20
>>   Minute = 0
>>   Second = 0
>>   Format = "dd/MM/yyyy HH:mm"
>> }
PS> Get-Date @natal
25/12/2026 20:00
$natal = @{ ... }
Uma hashtable comum. Cada chave é o nome de um parâmetro, sem o hífen.
Get-Date @natal
O @ no lugar do $ "espalha" a hashtable: cada chave vira -Chave valor.

Experimente: a hashtable $msg já tem o parâmetro Object do Write-Output. Passe com splatting (@msg) para mostrar Olá, Ana!.

$msg = @{ Object = "Olá, Ana!" }
Write-Output $msg

$msg = @{ Object = "Olá, Ana!" }
Write-Output @msg

3. Reaproveitando e combinando

Guarde o que se repete e acrescente o resto na própria linha:

PS> $formato = @{ Format = "dd/MM/yyyy" }
PS> Get-Date -Year 2026 -Month 1 -Day 1 @formato
01/01/2026
PS> Get-Date -Year 2026 -Month 6 -Day 15 @formato
15/06/2026

Também dá para mudar a hashtable antes de usar de novo, como qualquer hashtable: $formato.Format = "yyyy-MM-dd".

4. Com suas funções

O splatting funciona em qualquer comando, inclusive nas suas funções:

PS> function Saudar { param($Nome, $Saudacao = "Olá") "$Saudacao, $Nome!" }
PS> $p = @{ Nome = "Beto"; Saudacao = "Bom dia" }
PS> Saudar @p
Bom dia, Beto!

5. Splatting com array

Com um array, os valores entram por posição, na ordem:

PS> $args2 = "Caio", "Boa noite"
PS> Saudar @args2
Boa noite, Caio!

Quando dá errado

Usar $ em vez de @ 
PS> Get-Date $natal
Get-Date: Não é possível associar o parâmetro 'Date'. Cannot create object of type "System.DateTime". The property 'Format' was not found for the 'System.DateTime' object. There is no settable property available.

Com $, a hashtable inteira vira um valor, entregue ao primeiro parâmetro de posição. O Get-Date tenta transformar a hashtable numa data e falha. Troque por @natal.

Chave com nome de parâmetro que não existe 
PS> $errado = @{ Ano = 2026 }
PS> Get-Date @errado
Get-Date: Não foi possível encontrar um parâmetro correspondente ao nome de parâmetro 'Ano'.

As chaves precisam ter o nome exato de um parâmetro do comando (Year, e não Ano). Com Ano, o erro diz que não existe parâmetro com esse nome.

Referência rápida

Você digitaO que faz
$p = @{ Nome = "x"; Ativo = $true }Guarda os parâmetros.
Comando @pPassa todos de uma vez.
Comando -Outro 1 @pMistura com parâmetros na linha.
$a = "x", "y"; Comando @aPor posição.

Missão final: monte a hashtable $p com Nome = "Duda" e Saudacao = "Bom dia" e chame Saudar @p.

function Saudar { param($Nome, $Saudacao = "Olá") "$Saudacao, $Nome!" }
$p = @{}
Saudar

function Saudar { param($Nome, $Saudacao = "Olá") "$Saudacao, $Nome!" }
$p = @{ Nome = "Duda"; Saudacao = "Bom dia" }
Saudar @p

Resumo

  • Splatting = parâmetros guardados numa hashtable e passados com @.
  • As chaves são os nomes dos parâmetros, sem hífen.
  • Dá para misturar com parâmetros escritos na linha e reaproveitar.
  • Com array, os valores entram por posição.
