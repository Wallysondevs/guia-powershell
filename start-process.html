Abrindo Programas (Start-Process)

Às vezes o que você quer é simplesmente abrir algo: um programa, um arquivo PDF, um site, uma pasta no Explorador. O Start-Process faz isso e ainda deixa você esperar o programa terminar, saber se deu certo e abrir como administrador.

Você vai aprender
  • A abrir programas, arquivos e sites com Start-Process.
  • A passar argumentos com -ArgumentList.
  • A esperar terminar (-Wait) e ler o código de saída (-PassThru).
  • A abrir como administrador (-Verb RunAs).
  • A diferença entre Start-Process, & e Invoke-Item.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

A ideia: o duplo clique

Start-Process é o duplo clique do PowerShell. Abrir um .txt abre o Bloco de Notas, abrir um link abre o navegador, abrir uma pasta abre o Explorador.

1. Abrindo coisas

Start-Process notepad
Start-Process "https://learn.microsoft.com/powershell"
Start-Process .            # a pasta atual no Explorador
Invoke-Item relatorio.pdf  # abre com o programa padrão (como o duplo clique)

O apelido start também funciona: start notepad.

2. Programas de linha de comando: & ou Start-Process?

Para rodar um programa de terminal e ver a saída aqui mesmo, chame direto (ou com &). O Start-Process abre uma janela separada e não traz a saída:

PS> & pwsh -NoProfile -Command '"saída aqui mesmo: $(2 + 2)"'
saída aqui mesmo: 4
PS> $LASTEXITCODE
0
&
Operador de chamada: roda o programa no terminal atual.
$LASTEXITCODE
Código de saída do último programa: 0 costuma ser sucesso.

3. Argumentos, -Wait e -PassThru

PS> $p = Start-Process pwsh -ArgumentList '-NoProfile', '-Command', 'exit 3' -Wait -PassThru -WindowStyle Hidden
PS> $p.ExitCode
3
-ArgumentList
Os argumentos do programa, em lista.
-Wait
Espera o programa fechar antes de seguir.
-PassThru
Devolve o objeto do processo (com ExitCode, Id...).
-WindowStyle Hidden
Roda sem mostrar janela (Normal, Minimized, Maximized também existem).

4. Guardando a saída num arquivo (e a pegadinha das aspas)

A ideia é rodar um pwsh que escreve duas linhas e guardar o que ele escreveu em saida.txt. Veja o que acontece de verdade no Windows:

PS> Start-Process pwsh -ArgumentList '-NoProfile', '-Command', '"linha 1"; "linha 2"' -Wait -NoNewWindow -RedirectStandardOutput saida.txt

linha: O termo "linha" não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.
Verifique a ortografia do nome ou, se um caminho foi incluído, verifique se o caminho está correto e tente novamente.
PS> Get-Content saida.txt
-NoNewWindow
Usa a janela atual em vez de abrir outra.
-RedirectStandardOutput
Grava a saída do programa num arquivo.

Deu errado, e é um erro clássico. No Windows, o Start-Process junta a lista do -ArgumentList numa linha de texto só, e as aspas duplas de dentro se perdem no caminho. O pwsh filho recebe linha 1; linha 2 e tenta rodar um comando chamado linha. Os erros aparecem na tela porque vão pelo canal de erros, que não foi redirecionado, e o saida.txt fica vazio.

O jeito seguro é colocar os comandos num arquivo .ps1 e passar o arquivo com -File, sem aspas para se perder:

Set-Content linhas.ps1 '"linha 1"; "linha 2"'
Start-Process pwsh -ArgumentList '-NoProfile', '-File', 'linhas.ps1' -Wait -NoNewWindow -RedirectStandardOutput saida.txt
Get-Content saida.txt

Essa versão corrigida não foi rodada na coleta desta aula. Rode no seu Windows: o saida.txt deve ficar com as duas linhas, linha 1 e linha 2.

5. Como administrador

Start-Process pwsh -Verb RunAs

O Windows mostra a janela de confirmação do Controle de Conta de Usuário (UAC). Não dá para usar -Verb RunAs junto com -NoNewWindow ou redirecionamentos.

6. Pasta de trabalho

Start-Process pwsh -WorkingDirectory C:\Projetos

Experimente: escreva, numa string, o comando que roda pwsh com exit 3, espera terminar e mostra o ExitCode. O simulador do guia não imita esse comando; depois, rode-o de verdade no seu Windows.

# Escreva o comando numa string. Não chame o cmdlet.
$comando = ''
Write-Output $comando

# Escreva o comando numa string. Não chame o cmdlet.
$comando = '(Start-Process pwsh -ArgumentList ''-NoProfile'', ''-Command'', ''exit 3'' -Wait -PassThru -WindowStyle Hidden).ExitCode'
Write-Output $comando

Quando dá errado

"Este comando não pode ser executado porque o arquivo não foi encontrado"

O programa não está no PATH. Use o caminho completo entre aspas: Start-Process "C:\Program Files\App\app.exe".

Argumentos com espaço quebrando

Se um argumento tem espaço, coloque aspas dentro: -ArgumentList '"C:\Meus Arquivos\a.txt"'.

Não vejo a saída do programa

Start-Process não traz a saída para o seu terminal. Use & ou -NoNewWindow -RedirectStandardOutput.

Resumo

  • Start-Process é o duplo clique: abre programas, arquivos e sites.
  • -Wait espera, -PassThru devolve o processo e seu ExitCode.
  • -Verb RunAs pede para abrir como administrador.
  • Para ver a saída de um programa de terminal, use &.
