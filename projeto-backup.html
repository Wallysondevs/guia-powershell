Projeto: Backup com Zip

Backup que depende de lembrar não acontece. Neste projeto você escreve um script que compacta uma pasta num arquivo zip com a data no nome, mantém só os backups mais recentes e anota tudo num log, pronto para rodar sozinho todo dia.

Você vai aprender
  • A montar nomes de arquivo com data (Get-Date -Format).
  • A compactar com Compress-Archive.
  • A manter só os N backups mais novos.
  • A gravar um log.
  • A juntar tudo num script com parâmetros.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

1. Pastas de teste

PS> New-Item -ItemType Directory backup-teste\Documentos, backup-teste\Backups -Force | Out-Null
PS> Set-Location backup-teste
PS> 1..3 | ForEach-Object { Set-Content "Documentos\arquivo$_.txt" "conteúdo $_" }
PS> (Get-ChildItem Documentos).Name
arquivo1.txt
arquivo2.txt
arquivo3.txt

2. O nome com data

PS> $nome = "Documentos_{0}.zip" -f (Get-Date -Format 'yyyy-MM-dd_HHmmss')
PS> $nome -match '^Documentos_\d{4}-\d{2}-\d{2}_\d{6}\.zip$'
True
yyyy-MM-dd_HHmmss
Ano-mês-dia_horaminutosegundo. Nesse formato, a ordem alfabética é a ordem cronológica.

3. Compactando

PS> Compress-Archive -Path Documentos\* -DestinationPath (Join-Path Backups $nome)
PS> (Get-ChildItem Backups).Count
1

4. Guardando só os 3 mais novos

Vamos criar mais alguns backups (esperando um segundo entre eles para o nome mudar) e apagar os antigos:

PS> 1..3 | ForEach-Object { Start-Sleep -Seconds 1; Compress-Archive -Path Documentos\* -DestinationPath ("Backups\Documentos_{0}.zip" -f (Get-Date -Format 'yyyy-MM-dd_HHmmss')) }
PS> (Get-ChildItem Backups).Count
4
PS> Get-ChildItem Backups -Filter *.zip | Sort-Object Name -Descending | Select-Object -Skip 3 | Remove-Item
PS> (Get-ChildItem Backups).Count
3
Sort-Object Name -Descending
Os mais novos primeiro (graças ao formato da data).
Select-Object -Skip 3
Pula os 3 primeiros: sobram só os antigos.
Remove-Item
Apaga os antigos.

5. O script completo

PS> Set-Content Backup.ps1 @'
>> param(
>>     [Parameter(Mandatory)][string]$Origem,
>>     [Parameter(Mandatory)][string]$Destino,
>>     [int]$Manter = 7
>> )
>> $log = Join-Path $Destino "backup.log"
>> try {
>>     New-Item -ItemType Directory $Destino -Force | Out-Null
>>     $nome = "{0}_{1}.zip" -f (Split-Path -Leaf $Origem), (Get-Date -Format 'yyyy-MM-dd_HHmmss')
>>     Compress-Archive -Path (Join-Path $Origem '*') -DestinationPath (Join-Path $Destino $nome) -ErrorAction Stop
>>     Get-ChildItem $Destino -Filter *.zip | Sort-Object Name -Descending | Select-Object -Skip $Manter | Remove-Item
>>     Add-Content $log "$(Get-Date -Format s) OK $nome"
>>     "Backup criado: $nome"
>> }
>> catch {
>>     Add-Content $log "$(Get-Date -Format s) ERRO $($_.Exception.Message)"
>>     throw
>> }
>> '@
PS> Start-Sleep -Seconds 1
PS> $r = .\Backup.ps1 -Origem .\Documentos -Destino .\Backups -Manter 2
PS> $r -like 'Backup criado: Documentos_*.zip'
True
PS> (Get-ChildItem Backups -Filter *.zip).Count
2
PS> (Get-Content Backups\backup.log).Count
1

6. Agendando

Para rodar todo dia às 20h, veja Tarefas Agendadas:

$acao = New-ScheduledTaskAction -Execute pwsh.exe -Argument '-NoProfile -File "C:\Scripts\Backup.ps1" -Origem "C:\Users\ana\Documents" -Destino "D:\Backups"'
Register-ScheduledTask -TaskName "Backup Documentos" -Action $acao -Trigger (New-ScheduledTaskTrigger -Daily -At 20:00)
Backup no mesmo disco não é backup Se o disco estragar, vão junto o original e o backup. Grave em outro disco, pendrive ou numa pasta sincronizada com a nuvem.

Experimente: monte o nome Fotos_AAAA-MM-DD.zip com a data de hoje e confira com -match '^Fotos_\d{4}-\d{2}-\d{2}\.zip$'.

$nome = "Fotos.zip"

$nome = "Fotos_{0}.zip" -f (Get-Date -Format 'yyyy-MM-dd')
$nome -match '^Fotos_\d{4}-\d{2}-\d{2}\.zip$'

Desafios

  • Mostre o tamanho do zip criado em MB.
  • Pule o backup se nada mudou desde o último (compare LastWriteTime).
  • Mande o log de erro por e-mail ou notificação.

Exercícios

1. Por que usar o formato yyyy-MM-dd no nome?

2. O que Select-Object -Skip 3 faz depois de ordenar do mais novo ao mais velho?

Missão final: da lista a.zip, b.zip, c.zip (ordem do mais velho ao mais novo), mantenha os 2 mais novos e mostre o que seria apagado.

$zips = "a.zip", "b.zip", "c.zip"

$zips = "a.zip", "b.zip", "c.zip"
$zips | Sort-Object -Descending | Select-Object -Skip 2

Resumo

  • Data no nome (yyyy-MM-dd_HHmmss) organiza os backups.
  • Compress-Archive cria o zip; -Skip acha os antigos.
  • try/catch + log registram sucesso e falha.
  • Agende e guarde em outro disco.
