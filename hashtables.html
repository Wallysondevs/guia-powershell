Hashtables (@{})

Uma hashtable guarda pares de chave e valor: "nome → Ana", "cidade → Recife". Em vez de lembrar a posição, como no array, você busca pelo nome da chave.

Você vai aprender
  • A criar uma hashtable com @{ chave = valor }.
  • A ler um valor com $h.chave ou $h["chave"].
  • A mudar, acrescentar e remover chaves.
  • A testar se uma chave existe com .ContainsKey().
  • A manter a ordem com [ordered].

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a agenda de telefones

Na agenda, você não procura "o terceiro telefone", procura pelo nome: "Beto → 9999-0002". O nome é a chave; o telefone é o valor. Numa agenda, cada nome aparece uma vez só.

1. Criando e lendo

PS> $pessoa = @{ Nome = "Ana"; Cidade = "Recife"; Idade = 30 }
PS> $pessoa

Name                           Value
----                           -----
Idade                          30
Nome                           Ana
Cidade                         Recife
PS> $pessoa.Nome
Ana
PS> $pessoa["Cidade"]
Recife
@{ ... }
Cria a hashtable. Os pares ficam separados por ; (ou um por linha).
Nome = "Ana"
Chave Nome, valor "Ana".
$pessoa.Nome
Lê o valor da chave com ponto.
$pessoa["Cidade"]
Lê com colchetes. Útil quando a chave está numa variável ou tem espaço.

Repare que a ordem na tela não é a ordem em que você escreveu. A hashtable comum não guarda ordem, e no PowerShell 7 essa ordem pode até mudar de uma sessão para outra: se você rodar o mesmo exemplo, as linhas podem sair em outra sequência. Quando a ordem importa, use [ordered] (adiante).

2. Mudando, acrescentando e removendo

PS> $pessoa.Idade = 31
PS> $pessoa.Email = "ana@exemplo.com"
PS> $pessoa.Remove("Cidade")
PS> $pessoa.Count
3
PS> $pessoa.ContainsKey("Email")
True
$pessoa.Idade = 31
A chave já existe: o valor é trocado.
$pessoa.Email = ...
A chave não existe: é criada.
.Remove("Cidade")
Tira a chave e o valor.
.Count
Quantos pares. Sobraram 3: Nome, Idade e o novo Email.
.ContainsKey("Email")
A chave existe? Mais sobre isso na seção 3. Para a lista das chaves, use .Keys; para os valores, .Values.

Experimente: crie a hashtable $loja com as chaves Nome = "Mercadinho" e Cidade = "Recife" e mostre só a cidade.

$loja = @{}

$loja = @{ Nome = "Mercadinho"; Cidade = "Recife" }
$loja.Cidade

3. A chave existe?

PS> $estoque = @{ arroz = 12; cafe = 0 }
PS> $estoque.ContainsKey("cafe")
True
PS> $estoque.ContainsKey("leite")
False
PS> $estoque["leite"]

Uma chave que não existe devolve $null (nada), sem erro. O ContainsKey diferencia "não existe" de "existe e vale 0".

4. Chaves não diferenciam maiúsculas

PS> $estoque["ARROZ"]
12

5. Mantendo a ordem: [ordered]

PS> $ficha = [ordered]@{ Nome = "Ana"; Cidade = "Recife"; Idade = 30 }
PS> $ficha

Name                           Value
----                           -----
Nome                           Ana
Cidade                         Recife
Idade                          30

Com [ordered] na frente, a ordem de escrita é respeitada.

Quando dá errado

Chave repetida 
PS> $h = @{ a = 1; a = 2 }
ParserError: 
Line |
   1 |  $h = @{ a = 1; a = 2 }
     |                 ~
     | Duplicate keys 'a' are not allowed in hash literals.

Numa hashtable, cada chave aparece uma vez só (Duplicate keys).

.Add() com chave que já existe 
PS> $h = @{ a = 1 }
PS> $h.Add("a", 2)
MethodInvocationException: Exception calling "Add" with "2" argument(s): "Item has already been added. Key in dictionary: 'a'  Key being added: 'a'"

O .Add() não troca valores: ele só cria chaves novas. Para trocar, use $h.a = 2 ou $h["a"] = 2.

Referência rápida

Você digitaO que faz
$h = @{ a = 1; b = 2 }Cria.

Resumo

  • Hashtable = pares chave → valor: @{ Nome = "Ana" }.
  • Leia com $h.Nome ou $h["Nome"]; troque ou crie com =.
  • .Remove(), .ContainsKey(), .Keys, .Values, .Count.
  • Chave inexistente devolve $null; chaves não diferenciam maiúsculas.
  • [ordered]@{ } mantém a ordem de escrita.
