Format-Table

Quando um comando devolve objetos, o PowerShell decide sozinho como mostrar: em tabela ou em lista. O Format-Table (apelido ft) manda mostrar em tabela, com as colunas e a largura que você escolher.

Você vai aprender
  • A escolher as colunas da tabela.
  • A ajustar a largura das colunas com -AutoSize.
  • A separar a tabela em blocos com -GroupBy.
  • A criar uma coluna calculada com rótulo e alinhamento.
  • Por que o Format-Table vai sempre no fim do pipeline.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a vitrine

O Format-Table é a vitrine da loja: ele arruma os produtos para alguém olhar. Depois que estão na vitrine, não dá mais para mexer neles como antes. Por isso ele é a última coisa que você faz.

Os exemplos usam esta lista:

PS> $produtos = @(
>>   [pscustomobject]@{ Nome = "Arroz integral"; Categoria = "Grãos"; Preco = 25.9; Estoque = 12 }
>>   [pscustomobject]@{ Nome = "Café"; Categoria = "Bebidas"; Preco = 18.5; Estoque = 40 }
>>   [pscustomobject]@{ Nome = "Feijão"; Categoria = "Grãos"; Preco = 9.75; Estoque = 0 }
>> )

1. Escolhendo as colunas

PS> $produtos | Format-Table Nome, Preco

Nome            Preco
----            -----
Arroz integral 25,900
Café           18,500
Feijão          9,750

2. -AutoSize: largura do tamanho do conteúdo

Sem opções, o PowerShell pode deixar espaços largos. O -AutoSize calcula a largura de cada coluna pelo maior valor:

PS> $produtos | Format-Table Nome, Categoria, Estoque -AutoSize

Nome           Categoria Estoque
----           --------- -------
Arroz integral Grãos          12
Café           Bebidas        40
Feijão         Grãos           0

3. Separando em blocos: -GroupBy

PS> $produtos | Sort-Object Categoria | Format-Table Nome, Preco -GroupBy Categoria

   Categoria: Bebidas

Nome  Preco
----  -----
Café 18,500

   Categoria: Grãos

Nome            Preco
----            -----
Arroz integral 25,900
Feijão          9,750
Sort-Object Categoria
Ordene antes. O -GroupBy começa um bloco novo cada vez que o valor muda.
-GroupBy Categoria
Um título para cada categoria, com a sua tabelinha.

4. Coluna calculada

Igual ao Select-Object, dá para criar uma coluna com @{ Label = ...; Expression = { ... } }. No Format-Table também existe Align:

PS> $produtos | Format-Table Nome, @{ Label = "Preço"; Expression = { "R$ {0:N2}" -f $_.Preco }; Align = "Right" }

Nome              Preço
----              -----
Arroz integral R$ 25,90
Café           R$ 18,50
Feijão          R$ 9,75

Experimente: mostre os produtos numa tabela com só as colunas Nome e Estoque.

$produtos = @(
    [pscustomobject]@{ Nome = "Café"; Preco = 18.5; Estoque = 40 }
    [pscustomobject]@{ Nome = "Feijão"; Preco = 9.75; Estoque = 0 }
)
$produtos

$produtos = @(
    [pscustomobject]@{ Nome = "Café"; Preco = 18.5; Estoque = 40 }
    [pscustomobject]@{ Nome = "Feijão"; Preco = 9.75; Estoque = 0 }
)
$produtos | Format-Table Nome, Estoque

Quando dá errado: formatar no meio do pipeline

Depois do Format-Table, não há mais objetos 
PS> $produtos | Format-Table Nome, Preco | Sort-Object Preco

Nome            Preco
----            -----
Arroz integral 25,900
Café           18,500
Feijão          9,750

PS> $produtos | Format-Table | Select-Object -First 1

O Format-Table transforma os objetos em "instruções de desenho" para a tela. O que sai dele já não tem os campos Nome e Preco. No primeiro exemplo, o Sort-Object não tinha o que ordenar e a tabela saiu na ordem original (o mais caro primeiro). No segundo, o Select-Object -First 1 pegou só a primeira instrução de desenho, e a tela ficou em branco. A regra é: filtre, ordene e escolha antes; formate por último.

Guardar o resultado numa variável 
PS> $t = $produtos | Format-Table
PS> $t[0].GetType().Name
FormatStartData

O que foi guardado não são produtos, são pedaços de formatação. Guarde os objetos ($t = $produtos) e formate só na hora de mostrar.

Resumo

  • Format-Table (apelido ft) mostra objetos em tabela, com as colunas que você escolher.
  • -AutoSize ajusta a largura; -GroupBy separa em blocos (ordene antes).
  • Coluna calculada: @{ Label = "X"; Expression = { ... } }.
  • O Format-Table é para os olhos: use sempre no fim do pipeline.
