PowerShell for

O foreach anda pela lista item por item. Às vezes, porém, você quer controlar a contagem: contar de 2 em 2, fazer uma contagem regressiva, ou saber a posição de cada item (1º, 2º, 3º...). Para isso existe o for ("para"), o laço com contador.

Você vai aprender
  • As três partes do for: começo, condição e passo.
  • A contar de 2 em 2 e de trás para frente.
  • A percorrer uma lista pela posição, com $lista[$i] e .Count.
  • Quando usar for e quando usar foreach.
  • Os erros comuns: passar do fim da lista, usar vírgula no lugar de ; e o laço infinito.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: a volta na pista de corrida

A Ana vai correr na pista do parque. Antes de sair, ela combina três coisas: começo ("estou na volta 1"), quando parar ("enquanto eu estiver na volta 5 ou menos, continuo") e o passo ("a cada volta, somo 1 no contador"). O for é exatamente esse combinado, escrito numa linha só.

1. O básico: as três partes

PS C:\Users\ana> for ($i = 1; $i -le 5; $i++) { "Volta $i" }
Volta 1
Volta 2
Volta 3
Volta 4
Volta 5
for
"Para". Começa o laço com contador.
$i = 1
Começo: roda uma vez só, antes de tudo. Cria o contador $i valendo 1. (O nome $i, de "índice", é um costume antigo da programação.)
;
O ponto e vírgula separa as três partes.
$i -le 5
Condição: testada antes de cada volta. Enquanto $i for menor ou igual (-le, de less or equal) a 5, o bloco roda. Quando ficar falsa, o laço acaba.
$i++
Passo: roda depois de cada volta. O ++ soma 1 ao contador (aula Atribuição).
{ "Volta $i" }
O bloco que se repete.

Passo a passo: $i vale 1, 1 ≤ 5, mostra "Volta 1", $i vira 2... até $i virar 6. Aí 6 ≤ 5 é falso e o laço termina, sem mostrar "Volta 6".

Experimente: o script mostra a tabuada do 3 só até 5. Mude a condição do for para ir até 10.

for ($i = 1; $i -le 5; $i++) {
    "Tabuada: 3 x $i = $(3 * $i)"
}

for ($i = 1; $i -le 10; $i++) {
    "Tabuada: 3 x $i = $(3 * $i)"
}

2. De 2 em 2 e de trás para frente

Mudando o passo, você muda a contagem. Com $i += 2, o contador pula de 2 em 2:

PS C:\Users\ana> for ($i = 0; $i -le 10; $i += 2) { $i }
0
2
4
6
8
10

Para contar de trás para frente, comece alto, use -ge (maior ou igual) na condição e $i-- (tira 1) no passo:

PS C:\Users\ana> for ($i = 3; $i -ge 1; $i--) { "$i..." }; "Já!"
3...
2...
1...
Já!
$i += 2
Soma 2 ao contador a cada volta.
$i -ge 1
Continua enquanto o contador for 1 ou mais.
$i--
Tira 1 do contador a cada volta.
; "Já!"
Fora do laço: o ; aqui separa dois comandos na mesma linha. O "Já!" aparece uma vez só, depois que o laço acaba.

3. Percorrendo uma lista pela posição

As listas guardam os itens em posições numeradas a partir de zero: $alunos[0] é o primeiro, $alunos[1] o segundo. O .Count diz quantos itens há. Com o for, dá para numerar a lista da turma:

PS C:\Users\ana> $alunos = "Ana", "Beto", "Caio"
PS C:\Users\ana> for ($i = 0; $i -lt $alunos.Count; $i++) { "$($i + 1). $($alunos[$i])" }
1. Ana
2. Beto
3. Caio
$i = 0
Começa no zero, a primeira posição.
$i -lt $alunos.Count
Enquanto $i for menor que (-lt, de less than) 3. As posições são 0, 1 e 2: a posição 3 não existe.
$alunos[$i]
O item que está na posição $i.
"$($i + 1). ..."
O $( ) calcula uma conta dentro do texto. Somamos 1 para mostrar "1." em vez de "0." (gente conta a partir do 1).

Formas diferentes de repetir

FormaComo escreveQuando usar
foreachforeach ($a in $alunos) { $a }Passar por todos os itens, sem precisar da posição. É o mais simples e o mais usado.

Quando dá errado

Passar do fim da lista

A lista $alunos tem as posições 0, 1 e 2. E se você pedir a posição 3, por exemplo com -le no lugar de -lt na condição?

PS C:\Users\ana> $alunos[3]
PS C:\Users\ana> $null -eq $alunos[3]
True
PS C:\Users\ana> Set-StrictMode -Version Latest; $alunos[3]
OperationStopped: Index was outside the bounds of the array.
PS C:\Users\ana> Set-StrictMode -Off
$alunos[3]
Normalmente, o PowerShell não reclama: devolve $null (nada) e não mostra nada. O $null -eq $alunos[3] dando True confirma. Num laço, isso vira uma volta "fantasma", com um aluno vazio.
Set-StrictMode -Version Latest
Liga o "modo rigoroso", em que o PowerShell reclama de erros como esse em vez de seguir em silêncio.
OperationStopped
A operação foi interrompida.
Index was outside the bounds of the array
Mensagem do .NET (a base do PowerShell), por isso em inglês. Quer dizer que a posição pedida está fora dos limites da lista: ela não tem posição 3.
Set-StrictMode -Off
Desliga o modo rigoroso de novo.

Como evitar: com posições que começam no zero, use $i -lt $lista.Count (menor que), nunca -le.

Vírgula no lugar de ponto e vírgula

Este erro foi colhido rodando o código errado como texto, com o Invoke-Expression; por isso a mensagem começa com Invoke-Expression:.

PS C:\Users\ana> Invoke-Expression 'for ($i = 1, $i -le 3, $i++) { $i }'
Invoke-Expression: Could not compare "1" to "3 1". Error: "Cannot convert the "System.Object[]" value of type "System.Object[]" to type "System.Int32"."
for ($i = 1, $i -le 3, $i++)
Com vírgulas, o PowerShell não enxerga mais três partes. A vírgula, para ele, cria uma lista, então tudo virou uma expressão só, cheia de listas.
Could not compare "1" to "3 1"
Quer dizer que ele não conseguiu comparar o número 1 com 3 1, que é uma lista de dois valores (3 e 1), e não um número.
Cannot convert ... System.Object[] ... to type "System.Int32"
O motivo: uma lista (System.Object[]) não pode ser convertida num número inteiro (System.Int32).

Como resolver: as três partes do for se separam com ponto e vírgula: for ($i = 1; $i -le 3; $i++).

O laço infinito

Se o passo anda no sentido errado, a condição nunca fica falsa. Aqui o $i-- faz o contador descer, e ele sempre vai ser menor ou igual a 3. Para a demonstração não travar, pusemos uma parada de emergência com break (aula break e continue):

PS C:\Users\ana> for ($i = 1; $i -le 3; $i--) { $i; if ($i -lt -2) { "(parei o laço infinito na mão)"; break } }
1
0
-1
-2
-3
(parei o laço infinito na mão)

Não aparece mensagem de erro: o PowerShell só faz o que foi pedido, para sempre. Sem o break, os números continuariam descendo sem parar.

Como resolver: se o terminal "travou" num laço, aperte Ctrl+C para interromper. Depois confira se o passo (++ ou --) combina com a condição (-le sobe, -ge desce).

Resumo

  • for (começo; condição; passo) { ... }: as três partes se separam com ;.
  • O começo roda uma vez; a condição é testada antes de cada volta; o passo roda depois de cada volta.
  • Mude o passo para contar de 2 em 2 ($i += 2) ou para trás ($i--).
  • Listas começam na posição 0: percorra com $i -lt $lista.Count.
  • Para passar por todos os itens sem precisar da posição, o foreach é mais simples.
  • Laço que não para? Ctrl+C, e confira se o passo combina com a condição.
