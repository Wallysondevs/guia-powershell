Percorrendo uma Hashtable

Uma hashtable no pipeline se comporta como um objeto só, e não como uma lista de pares. Para passar por cada chave e valor, você usa .Keys ou .GetEnumerator().

Você vai aprender
  • A percorrer as chaves com foreach ($k in $h.Keys).
  • A percorrer os pares com .GetEnumerator(), usando .Key e .Value.
  • A ordenar os pares por chave ou por valor.
  • A filtrar os pares com Where-Object.
  • Por que $h | ForEach-Object roda uma vez só.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: ler a agenda inteira

Para ligar para todo mundo da agenda, você passa página por página: nome e telefone, nome e telefone. Percorrer a hashtable é isso: visitar cada par.

Os exemplos usam este estoque:

PS> $estoque = [ordered]@{ arroz = 12; feijao = 0; cafe = 40; acucar = 5 }

1. Pelas chaves

PS> foreach ($item in $estoque.Keys) { "$item -> $($estoque[$item])" }
arroz -> 12
feijao -> 0
cafe -> 40
acucar -> 5
$estoque.Keys
A lista das chaves.
$estoque[$item]
O valor daquela chave. Aqui os colchetes são necessários, porque a chave está numa variável.

2. Pelos pares: GetEnumerator()

PS> $estoque.GetEnumerator() | ForEach-Object { "{0}: {1}" -f $_.Key, $_.Value }
arroz: 12
feijao: 0
cafe: 40
acucar: 5
.GetEnumerator()
Solta os pares, um por um, no pipeline.
$_.Key / $_.Value
A chave e o valor do par da vez.

Experimente: mostre cada item no formato arroz = 12, usando .GetEnumerator(), $_.Key e $_.Value.

$estoque = [ordered]@{ arroz = 12; cafe = 40 }
$estoque

$estoque = [ordered]@{ arroz = 12; cafe = 40 }
$estoque.GetEnumerator() | ForEach-Object { "$($_.Key) = $($_.Value)" }

3. Ordenando e filtrando

PS> $estoque.GetEnumerator() | Sort-Object Value -Descending

Name                           Value
----                           -----
cafe                           40
arroz                          12
acucar                         5
feijao                         0
PS> $estoque.GetEnumerator() | Where-Object { $_.Value -eq 0 } | ForEach-Object Key
feijao

O primeiro mostra do maior estoque para o menor. O segundo acha os itens em falta.

4. Somando os valores

PS> ($estoque.Values | Measure-Object -Sum).Sum
57

Quando dá errado

Mandar a hashtable direto para o pipeline 
PS> $estoque | ForEach-Object { "volta" }
volta

O bloco rodou uma vez só: a hashtable inteira passou como um objeto. Use .GetEnumerator() ou .Keys.

Mudar a hashtable enquanto percorre 
PS> $h = @{ a = 1; b = 2 }
PS> foreach ($k in $h.Keys) { $h[$k] = 0 }
OperationStopped: Collection was modified; enumeration operation may not execute.

Mudar a hashtable dentro do laço que percorre as chaves dela quebra a enumeração. Percorra uma cópia das chaves: foreach ($k in @($h.Keys)) { ... }.

Resumo

  • No pipeline, a hashtable é um objeto só.
  • Percorra as chaves com .Keys ou os pares com .GetEnumerator().
  • Cada par tem .Key e .Value; dá para ordenar e filtrar.
  • Para mudar a hashtable num laço, percorra uma cópia das chaves.
