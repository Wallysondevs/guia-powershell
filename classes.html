Classes

Com [pscustomobject] você monta objetos na hora. Com class você cria um molde: um tipo novo, com propriedades que têm tipo certo e métodos que sabem fazer coisas. É o mesmo recurso das linguagens como C# e Java, dentro do PowerShell.

Você vai aprender
  • A criar uma classe com propriedades tipadas e valores padrão.
  • A criar objetos com ::new() e com uma hashtable.
  • A escrever construtores e métodos (com return e $this).
  • A mudar como o objeto aparece com ToString().
  • Herança: uma classe que estende outra.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a forma de bolo

A forma define o formato; cada bolo que sai dela é um objeto diferente (um de chocolate, outro de cenoura). A class é a forma: diz que todo Produto tem Nome e Preco. Cada [Produto]::new(...) é um bolo novo.

1. A primeira classe

PS> class Produto {
>>     [string]$Nome
>>     [decimal]$Preco
>>     [int]$Estoque = 0
>> }
PS> $cafe = [Produto]::new()
PS> $cafe.Nome = "Café 500g"
PS> $cafe.Preco = 18.90
PS> $cafe

Nome       Preco Estoque
----       ----- -------
Café 500g 18,900       0
class Produto { }
Cria o tipo [Produto].
[string]$Nome
Uma propriedade com tipo. Atribuir outro tipo faz o PowerShell converter (ou dar erro).
[int]$Estoque = 0
Propriedade com valor padrão.
[Produto]
new() :: Cria um objeto (uma instância) da classe.

Também dá para criar a partir de uma hashtable, se a classe tiver um construtor sem argumentos (o padrão):

PS> [Produto]@{ Nome = "Pão"; Preco = 0.80; Estoque = 120 }

Nome Preco Estoque
---- ----- -------
Pão  0,800     120

2. Construtor

O construtor é um método com o mesmo nome da classe. Ele roda no ::new():

PS> class Aluno {
>>     [string]$Nome
>>     [double[]]$Notas
>>     Aluno([string]$nome, [double[]]$notas) {
>>         $this.Nome = $nome
>>         $this.Notas = $notas
>>     }
>>     [double] Media() {
>>         return ($this.Notas | Measure-Object -Average).Average
>>     }
>>     [string] ToString() {
>>         return "$($this.Nome) (média $($this.Media()))"
>>     }
>> }
PS> $ana = [Aluno]::new("Ana", @(8, 9.5, 10))
PS> $ana.Media()
9,16666666666667
PS> "$ana"
Ana (média 9.16666666666667)
$this
O próprio objeto. Dentro da classe, propriedades são sempre $this.Nome.
[double] Media()
Um método que devolve um double. O tipo antes do nome é obrigatório (use [void] se não devolver nada).
return
Em métodos, só sai o que vem no return. Diferente das funções, linhas soltas não viram saída.
ToString()
Define como o objeto vira texto (por exemplo, dentro de aspas).

Repare na diferença: $ana.Media() mostra 9,16... com vírgula, porque a tela usa o formato do idioma; dentro de aspas ("$ana"), o número vira texto no formato internacional, com ponto. Para controlar, formate você mesmo: "{0:N1}" -f $this.Media().

Experimente: crie a aluna Carla com as notas 7, 8 e 9 e mostre "$carla".

class Aluno {
    [string]$Nome
    [double[]]$Notas
    Aluno([string]$nome, [double[]]$notas) { $this.Nome = $nome; $this.Notas = $notas }
    [double] Media() { return ($this.Notas | Measure-Object -Average).Average }
    [string] ToString() { return "$($this.Nome) (média $($this.Media()))" }
}

class Aluno {
    [string]$Nome
    [double[]]$Notas
    Aluno([string]$nome, [double[]]$notas) { $this.Nome = $nome; $this.Notas = $notas }
    [double] Media() { return ($this.Notas | Measure-Object -Average).Average }
    [string] ToString() { return "$($this.Nome) (média $($this.Media()))" }
}
$carla = [Aluno]::new("Carla", @(7, 8, 9))
"$carla"

3. Estático: da classe, não do objeto

PS> class Contador {
>>     static [int]$Total = 0
>>     static [void] Somar() { [Contador]::Total++ }
>> }
PS> [Contador]::Somar()
PS> [Contador]::Somar()
PS> [Contador]::Total
2

4. Herança

Uma classe pode estender outra com :. Ela herda tudo e pode trocar (sobrescrever) métodos:

PS> class Animal {
>>     [string]$Nome
>>     Animal([string]$nome) { $this.Nome = $nome }
>>     [string] Falar() { return "..." }
>> }
PS> class Cachorro : Animal {
>>     Cachorro([string]$nome) : base($nome) { }
>>     [string] Falar() { return "$($this.Nome): Au au!" }
>> }
PS> $rex = [Cachorro]::new("Rex")
PS> $rex.Falar()
Rex: Au au!
PS> $rex -is [Animal]
True
class Cachorro : Animal
Cachorro herda de Animal.
: base($nome)
Chama o construtor da classe mãe.
-is [Animal]
Todo Cachorro também é um Animal.

Quando dá errado

Esquecer o return no método

Num método com tipo ([string] Ola()), a saída só sai pelo return. Escrever "Olá" sozinho numa linha não devolve nada, e o PowerShell reclama que nem todos os caminhos de código retornam um valor.

Usar $Nome em vez de $this.Nome

Dentro de um método, $Nome é uma variável comum (normalmente vazia). A propriedade do objeto é $this.Nome.

Mudar a classe e não ver a mudança

Na mesma sessão, redefinir uma classe que já foi usada pode deixar objetos antigos com o formato antigo. Se algo ficar estranho, abra uma sessão nova do PowerShell.

Resumo

  • class cria um tipo novo, com propriedades tipadas e valores padrão.
  • ::new() chama o construtor; $this é o próprio objeto.
  • Métodos têm tipo de retorno e só devolvem pelo return.
  • static é da classe; : Mae faz herança.
