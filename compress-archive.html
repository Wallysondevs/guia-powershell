Arquivos Zip (Compress-Archive)

Para mandar vários arquivos por e-mail, guardar um backup ou economizar espaço, juntamos tudo num arquivo .zip. O PowerShell faz isso sem programa extra: Compress-Archive cria o zip e Expand-Archive abre.

Você vai aprender
  • A compactar arquivos e pastas com Compress-Archive.
  • A acrescentar arquivos a um zip existente (-Update).
  • A extrair com Expand-Archive.
  • A listar o que tem dentro de um zip.
  • Os cuidados com -Force e nomes repetidos.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

A ideia: a mala de viagem

Em vez de carregar dez sacolas, você coloca tudo numa mala só. O zip é a mala: um arquivo que carrega vários outros, de preferência ocupando menos espaço.

1. Preparando arquivos de exemplo

PS> New-Item -ItemType Directory -Path zip-teste\docs -Force | Out-Null
PS> Set-Location zip-teste
PS> 1..3 | ForEach-Object { Set-Content "docs\nota$_.txt" ("Linha de exemplo " * 200) }
PS> Get-ChildItem docs | Select-Object Name, Length

Name      Length
----      ------
nota1.txt   3402
nota2.txt   3402
nota3.txt   3402

2. Criando o zip

PS> Compress-Archive -Path docs -DestinationPath docs.zip
PS> Get-Item docs.zip | Select-Object Name, Length

Name     Length
----     ------
docs.zip    517
-Path docs
O que vai para dentro: aqui, a pasta inteira (o zip terá a pasta docs dentro).
-DestinationPath docs.zip
O nome do zip a criar.

Os textos repetidos encolhem muito: três arquivos de alguns KB viram um zip bem menor.

3. Só o conteúdo, sem a pasta

Com docs\*, entram os arquivos, sem a pasta docs em volta:

PS> Compress-Archive -Path docs\* -DestinationPath so-arquivos.zip

4. Acrescentando e substituindo

PS> Set-Content docs\nota4.txt "nova"
PS> Compress-Archive -Path docs\nota4.txt -DestinationPath so-arquivos.zip -Update
PS> Compress-Archive -Path docs -DestinationPath docs.zip
Compress-Archive: The archive file C:\Users\ana\AppData\Local\Temp\guia-ps\compress-archive\zip-teste\docs.zip already exists. Use the -Update parameter to update the existing archive file or use the -Force parameter to overwrite the existing archive file.
-Update
Acrescenta ou atualiza arquivos dentro de um zip que já existe.
(sem -Update nem -Force)
Se o zip já existe, dá erro em vez de sobrescrever.
-Force
Sobrescreve o zip inteiro.

5. Vendo o que tem dentro

Não existe um cmdlet para listar o zip, mas o .NET resolve:

PS> Add-Type -AssemblyName System.IO.Compression.FileSystem
PS> $zip = [IO.Compression.ZipFile]::OpenRead((Join-Path $PWD so-arquivos.zip))
PS> $zip.Entries | Select-Object FullName, Length

FullName  Length
--------  ------
nota1.txt   3402
nota2.txt   3402
nota3.txt   3402
nota4.txt      6
PS> $zip.Dispose()
OpenRead
Abre o zip só para leitura.
.Entries
A lista de arquivos dentro do zip.
.Dispose()
Fecha o arquivo (senão ele fica travado).

Experimente: escreva, numa string, o comando que compacta a pasta docs em docs.zip. O simulador do guia não imita esse comando; depois, rode-o de verdade no seu Windows.

# Escreva o comando numa string. Não chame o cmdlet.
$comando = ''
Write-Output $comando

# Escreva o comando numa string. Não chame o cmdlet.
$comando = 'Compress-Archive -Path docs -DestinationPath docs.zip'
Write-Output $comando

Quando dá errado

"The archive file ... already exists"

O zip já existe. Use -Update para acrescentar ou -Force para sobrescrever.

"is not a supported archive file format"

Expand-Archive só abre .zip. Para .7z ou .rar, use outro programa. Se o arquivo é zip mas tem outra extensão, renomeie para .zip.

Arquivo maior que 2 GB

Compress-Archive tem limite de 2 GB por arquivo. Para arquivos enormes, use [IO.Compression.ZipFile]::CreateFromDirectory() ou o tar que vem com o Windows.

Referência rápida

Você digitaO que faz
Compress-Archive -Path p -DestinationPath z.zipCria o zip.
... -Path p\*Só o conteúdo, sem a pasta.
... -UpdateAcrescenta a um zip existente.
... -CompressionLevel FastestMais rápido, menos compressão (Optimal é o padrão; NoCompression só junta).
Expand-Archive z.zip -DestinationPath pastaExtrai.
Expand-Archive ... -ForceExtrai sobrescrevendo.

Resumo

  • Compress-Archive cria zips; Expand-Archive extrai.
  • -Path pasta inclui a pasta; -Path pasta\* só o conteúdo.
  • -Update acrescenta, -Force sobrescreve.
  • Para listar um zip, use [IO.Compression.ZipFile]::OpenRead().
