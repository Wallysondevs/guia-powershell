Projeto: Organizador de Downloads

A pasta Downloads de quase todo mundo é uma gaveta bagunçada: fotos, PDFs, instaladores e zips misturados. Neste projeto você escreve um script que separa cada arquivo na subpasta certa pela extensão, testando antes com -WhatIf para não estragar nada.

Você vai aprender
  • A agrupar arquivos por extensão.
  • A criar pastas só quando precisa.
  • A mover arquivos com Move-Item, testando com -WhatIf.
  • A tratar nomes repetidos.
  • A transformar tudo numa função com SupportsShouldProcess.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

PS> $destinos = @{

>>     '.pdf' = 'Documentos'; '.docx' = 'Documentos'; '.xlsx' = 'Documentos'; '.txt' = 'Documentos'
>>     '.zip' = 'Compactados'; '.7z' = 'Compactados'

Imagens
@{ '.jpg' = 'Imagens' }
A "tabela de decisão": para cada extensão, a pasta.
$destinos['.PNG']
As chaves da hashtable não diferenciam maiúsculas: .PNG acha .png.

5. Nomes repetidos

Se Imagens\ferias.jpg já existe, o Move-Item dá erro. Uma função que acha um nome livre resolve:

PS> function Get-NomeLivre {
>>     param([string]$Pasta, [string]$Nome)
>>     $base = [IO.Path]::GetFileNameWithoutExtension($Nome); $ext = [IO.Path]::GetExtension($Nome)
>>     $alvo = Join-Path $Pasta $Nome; $n = 1
>>     while (Test-Path $alvo) { $alvo = Join-Path $Pasta "$base ($n)$ext"; $n++ }
>>     $alvo
>> }
PS> Set-Content ferias.jpg "outra"
PS> Split-Path -Leaf (Get-NomeLivre -Pasta Imagens -Nome ferias.jpg)
ferias (1).jpg

6. A função completa

PS> function Invoke-Organizar {
>>     [CmdletBinding(SupportsShouldProcess)]
>>     param([string]$Caminho = '.')
>>     foreach ($arq in Get-ChildItem $Caminho -File) {
>>         $pasta = $destinos[$arq.Extension]; if (-not $pasta) { $pasta = 'Outros' }
>>         $dir = Join-Path $Caminho $pasta
>>         if ($PSCmdlet.ShouldProcess($arq.Name, "Mover para $pasta")) {
>>             New-Item -ItemType Directory $dir -Force | Out-Null
>>             Move-Item $arq.FullName (Get-NomeLivre -Pasta $dir -Nome $arq.Name)
>>             [pscustomobject]@{ Arquivo = $arq.Name; Pasta = $pasta }
>>         }
>>     }
>> }
PS> Invoke-Organizar

Arquivo    Pasta
-------    -----
ferias.jpg Imagens

SupportsShouldProcess
Dá à função os parâmetros -WhatIf e -Confirm de graça.
$PSCmdlet.ShouldProcess
Pergunta "posso?"; com -WhatIf, responde não e mostra o plano.

Desafios

Resumo

  • Uma hashtable decide a pasta de cada extensão.
  • -WhatIf mostra o plano antes de mexer.
  • Trate nomes repetidos antes de mover.
  • SupportsShouldProcess dá -WhatIf à sua função.
