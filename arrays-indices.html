Índices e Fatias

Cada item de uma lista tem um número de posição, o índice. Com ele, você pega o primeiro, o último, um pedaço da lista ou troca um item específico.

Você vai aprender
  • Que a contagem começa no zero: $lista[0] é o primeiro.
  • A pegar o último com $lista[-1].
  • A pegar vários itens: $lista[0, 2].
  • A pegar uma fatia com intervalo: $lista[1..3].
  • A trocar um item: $lista[1] = "novo".

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: os armários numerados

No vestiário, os armários são numerados, e o primeiro tem o número 0 (é assim em quase toda linguagem de programação). Para abrir um armário, você diz o número dele entre colchetes.

1. Pelo número

PS> $dias = "seg", "ter", "qua", "qui", "sex"
PS> $dias[0]
seg
PS> $dias[1]
ter
PS> $dias[4]
sex
$dias[0]
O item da posição 0: o primeiro.
$dias[4]
O quinto item. Numa lista de 5, o último índice é 4 (Count - 1).

2. Contando de trás para frente

Números negativos contam a partir do fim: -1 é o último, -2 o penúltimo:

PS> $dias[-1]
sex
PS> $dias[-2]
qui

3. Vários de uma vez e fatias

PS> $dias[0, 2, 4]
seg
qua
sex
PS> $dias[1..3]
ter
qua
qui
PS> $dias[-2..-1]
qui
sex
[0, 2, 4]
Vários índices separados por vírgula: os itens 0, 2 e 4.
[1..3]
Um intervalo: do 1 ao 3, incluindo os dois.
[-2..-1]
Os dois últimos.

Experimente: mostre os dois últimos dias da lista (qui e sex) usando índices.

$dias = "seg", "ter", "qua", "qui", "sex"
$dias

$dias = "seg", "ter", "qua", "qui", "sex"
$dias[-2..-1]

4. Trocando um item

PS> $dias[0] = "SEGUNDA"
PS> $dias -join ", "
SEGUNDA, ter, qua, qui, sex

5. Índices em texto

Um texto também aceita índice: cada posição é uma letra.

PS> $nome = "PowerShell"
PS> $nome[0]
P
PS> $nome[-1]
l
PS> $nome[0..4] -join ""
Power

Quando dá errado

Índice além do fim: nada aparece 
PS> $dias[10]

Ler um índice que não existe devolve $null, sem erro.

Escrever além do fim: aí é erro 
PS> $dias[10] = "sab"
OperationStopped: Index was outside the bounds of the array.

O array tem tamanho fixo. Para acrescentar um item, use += ou uma List.

Referência rápida

Você digitaO que faz

$a[1..3]Do item 1 ao 3.

Resumo

  • O índice começa no 0: $a[0] é o primeiro.
  • Negativos contam do fim: $a[-1] é o último.
  • $a[0, 2] pega vários; $a[1..3] pega uma fatia.
  • $a[1] = "x" troca um item; ler além do fim dá $null, escrever além do fim dá erro.
