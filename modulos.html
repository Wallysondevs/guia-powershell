Módulos (Import-Module)

Os comandos do PowerShell vêm organizados em pacotes chamados módulos. Um módulo junta cmdlets de um mesmo assunto: arquivos, rede, segurança... Saber ver, carregar e explorar módulos é o que faz você descobrir comandos novos sozinho.

Você vai aprender
  • O que é um módulo.
  • A ver os módulos carregados e os disponíveis com Get-Module.
  • A carregar com Import-Module (e por que quase nunca precisa).
  • Onde os módulos ficam ($env:PSModulePath).
  • A listar os comandos de um módulo.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

A ideia: a caixa de ferramentas

Você não carrega todas as ferramentas da casa no bolso. Elas ficam em caixas: uma de elétrica, uma de pintura, uma de jardim. Quando precisa, pega a caixa certa. Os módulos são essas caixas.

-ListAvailable procura em todas as pastas de módulos, carregados ou não.

3. Carregamento automático

Você não precisa importar um módulo para usar seus comandos: basta chamar o comando e o PowerShell carrega o módulo sozinho.

PS> Get-Module Microsoft.PowerShell.Archive | Select-Object Name
PS> Get-Command Compress-Archive | Select-Object Name, Source

Name             Source
----             ------
Compress-Archive Microsoft.PowerShell.Archive
PS> Get-Module Microsoft.PowerShell.Archive | Select-Object Name

Name
----
Microsoft.PowerShell.Archive

4. Import-Module

Às vezes você quer carregar explicitamente: para garantir uma versão, recarregar um módulo seu que mudou, ou usar um módulo fora das pastas padrão:

Import-Module Microsoft.PowerShell.Archive
Import-Module .\MeuModulo.psm1 -Force      # recarrega depois de editar
Import-Module NomeDoModulo -RequiredVersion 2.1.0

Para criar seus próprios módulos, veja Criando seu Módulo.

6. Explorando um módulo

PS> Get-Command -Module Microsoft.PowerShell.Archive

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Function        Compress-Archive                                   1.2.7      Microsoft.PowerShell.Archive
Function        Expand-Archive                                     1.2.7      Microsoft.PowerShell.Archive
PS> (Get-Command -Module Microsoft.PowerShell.Utility).Count
119

Essa é a melhor forma de descobrir o que um módulo sabe fazer.

Experimente: escreva, numa string, o comando que lista os comandos do módulo Microsoft.PowerShell.Archive. O simulador do guia não imita esse comando; depois, rode-o de verdade no seu Windows.

# Escreva o comando numa string. Não chame o cmdlet.
$comando = ''
Write-Output $comando

# Escreva o comando numa string. Não chame o cmdlet.
$comando = 'Get-Command -Module Microsoft.PowerShell.Archive'
Write-Output $comando

Quando dá errado

"O módulo especificado ... não foi carregado porque nenhum arquivo de módulo válido foi encontrado"

O módulo não está instalado ou está fora das pastas do $env:PSModulePath. Instale com Install-Module (veja PowerShell Gallery) ou use o caminho completo.

Mudei meu módulo e nada mudou

O PowerShell não recarrega um módulo já carregado. Use Import-Module ... -Force ou abra uma janela nova.

Módulo só do Windows PowerShell 5.1

Alguns módulos antigos não funcionam no 7. O PowerShell 7 tenta carregá-los em modo de compatibilidade (-UseWindowsPowerShell), o que funciona na maioria dos casos.

Resumo

  • Módulos são pacotes de comandos sobre um assunto.
  • Get-Module mostra os carregados; -ListAvailable, os instalados.
  • O carregamento é automático; Import-Module serve para casos especiais.
  • Get-Command -Module mostra o que um módulo oferece.
