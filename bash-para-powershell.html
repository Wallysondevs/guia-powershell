Do Bash para o PowerShell

Quem vem do Linux já pensa em pipeline: cat | grep | sort | uniq -c. No PowerShell, a ideia é a mesma, mas o que corre pelo cano são objetos, não linhas de texto. Isso elimina o cut e o awk na maior parte das vezes: você pede a propriedade pelo nome.

Você vai aprender
  • Os equivalentes dos comandos mais usados do Bash.
  • Como grep, sort, uniq -c e wc -l viram cmdlets.
  • Variáveis, export, $? e substituição de comando.
  • if, for e funções lado a lado.
  • As pegadinhas: aspas, operadores de comparação e apelidos que não existem no Linux.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a esteira de peças inteiras

No Bash, o pipe é uma esteira de papel picado (texto), e cada comando precisa recortar o pedaço que quer. No PowerShell, a esteira leva peças inteiras (objetos com etiquetas), e cada comando pega a etiqueta que precisa.

2. O pipeline lado a lado

Contar quantas vezes cada palavra aparece:

# Bash
cat frutas.txt | sort | uniq -c | sort -rn

PS> $frutas = "uva", "maçã", "uva", "pera", "uva", "maçã"
PS> $frutas | Group-Object | Sort-Object Count -Descending | Select-Object Count, Name

Count Name
----- ----
    3 uva
    2 maçã
    1 pera

Cortar a segunda coluna de um CSV:

# Bash
cut -d, -f2 dados.csv

PS> "nome,cidade`nAna,Recife`nBeto,Natal" | ConvertFrom-Csv | ForEach-Object cidade
Recife
Natal

4. Comparações: operadores com hífen

No PowerShell, > e < são redirecionamento, como no Bash. Para comparar, use operadores com hífen, parecidos com o test do Bash:

PS> 5 -gt 3
True
PS> "abc" -eq "ABC"
True
PS> "abc" -ceq "ABC"
False
PS> "relatorio.log" -like "*.log"
True

5. if, for e funções

# Bash
for i in 1 2 3; do
  if [ $i -gt 1 ]; then echo "maior: $i"; fi
done
saudar() { echo "Olá, $1"; }
saudar Ana

PS> foreach ($i in 1, 2, 3) {
>>   if ($i -gt 1) { "maior: $i" }
>> }
maior: 2
maior: 3
PS> function Saudar { param($Nome) "Olá, $Nome" }
PS> Saudar Ana
Olá, Ana

Quando dá errado

Aspas simples × duplas

Igual ao Bash: aspas duplas expandem variáveis ("Olá, $nome"), simples não ('Olá, $nome'). Mas o caractere de escape é a crase (` n `` para nova linha), não a barra invertida.

ls, cat e rm no PowerShell do Linux

No Windows, ls, cat e rm são apelidos de cmdlets. No PowerShell instalado no Linux ou no macOS, esses apelidos não existem: ls chama o programa do sistema, que devolve texto. Em scripts que rodam nos dois, use os nomes completos (Get-ChildItem).

Tratar a saída como texto

Hábito do Bash: Get-Process | Select-String chrome. Funciona, mas joga fora os objetos. Prefira Get-Process -Name chrome ou Where-Object Name -like '*chrome*', e você continua com as propriedades (CPU, Id...).

Resumo

  • O pipeline do PowerShell leva objetos: troque cut/awk por propriedades.
  • grep → Select-String; uniq -c → Group-Object; wc -l → Measure-Object.
  • Comparação com -gt, -eq, -match; > é redirecionamento.
  • Escape com crase; em scripts para Linux, nomes completos em vez de apelidos.
