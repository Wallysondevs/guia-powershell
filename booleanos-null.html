PowerShell $true, $false e $null

Aprovada ou não? O produto está em estoque? A aluna informou o telefone? Muitas perguntas num script têm resposta sim ou não, e às vezes a resposta simplesmente não existe. Para isso servem $true, $false e $null.

Você vai aprender
  • Os valores $true (verdadeiro), $false (falso) e $null (nada).
  • Por que o $null vai à esquerda na comparação.
  • O que o if considera falso.
  • O operador ??, que dá um valor padrão, e por que ele não existe no Windows PowerShell 5.1.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: sim, não e "em branco"

Num formulário, a pergunta "Tem filhos?" pode ter sim, não ou ficar em branco. No PowerShell é igual: $true é sim, $false é não e $null é o campo em branco, a ausência de valor.

1. Os três valores

PS C:\Users\ana> $true
True
PS C:\Users\ana> $false
False
PS C:\Users\ana> $null
PS C:\Users\ana> $true.GetType().Name
Boolean

O $null não mostra nada: é o nada. $true e $false são do tipo Boolean (booleano, em homenagem ao matemático George Boole). São escritos com $, porque são variáveis especiais que o PowerShell já traz prontas.

2. Comparar com $null: ele vai à esquerda

PS C:\Users\ana> $a = $null
PS C:\Users\ana> $null -eq $a
True
PS C:\Users\ana> $null -ne "Ana"
True

Escreva sempre $null -eq $x, e não $x -eq $null. Quando $x é uma lista, o -eq com a lista à esquerda filtra a lista em vez de responder True ou False (veja Comparações). Com o $null à esquerda, a resposta é sempre um True ou False.

3. O que o if considera falso

PS C:\Users\ana> if ($true) { "verdadeiro" } else { "falso" }
verdadeiro
PS C:\Users\ana> if ($false) { "verdadeiro" } else { "falso" }
falso
PS C:\Users\ana> if ($null) { "verdadeiro" } else { "falso" }
falso
PS C:\Users\ana> if (0) { "verdadeiro" } else { "falso" }
falso
PS C:\Users\ana> if ("") { "verdadeiro" } else { "falso" }
falso
PS C:\Users\ana> if (@()) { "verdadeiro" } else { "falso" }
falso
PS C:\Users\ana> if ("Ana") { "verdadeiro" } else { "falso" }
verdadeiro
ValorNo if
$false, $null, 0, "", @()Contam como falso.
Qualquer outro número, texto não vazio, lista com itensContam como verdadeiro.

Experimente: troque "Ana" por $null e veja o if ir para o else.

$nome = "Ana"
if ($nome) { "Nome: $nome" } else { "Sem nome" }

$nome = $null
if ($nome) { "Nome: $nome" } else { "Sem nome" }

4. O operador ?? (valor padrão) 7

PS C:\Users\ana> $a = $null
PS C:\Users\ana> $a ?? "padrão"
padrão
PS C:\Users\ana> "já tem" ?? "padrão"
já tem

O ?? lê assim: "use o da esquerda; se ele for $null, use o da direita". Ótimo para dar um valor padrão quando algo veio vazio.

Windows PowerShell 5.1: o ?? não existe lá, e o mesmo comando dá erro de sintaxe: 
PS C:\Users\ana> $a = $null
PS C:\Users\ana> $a ?? "padrão"
No linha:1 caractere:4
+ $a ?? "padrão"
+    ~~
Token '??' inesperado na expressão ou instrução.
    + CategoryInfo          : ParserError: (:) [], ParentContainsErrorRecordException
    + FullyQualifiedErrorId : UnexpectedToken
"Token (pedaço) ?? inesperado." O 5.1 não conhece esse sinal. Lá, use um if: if ($null -eq $a) { "padrão" } else { $a }.

Quando dá errado

Usou ?? no Windows PowerShell 5.1

A mensagem Token '??' inesperado (acima) quer dizer que você está no 5.1. Abra o PowerShell 7 (pwsh) ou troque por um if.

Escreveu true sem o $

Sem o cifrão, true é só uma palavra, e o PowerShell procura um comando com esse nome. Escreva sempre $true e $false.

Resumo

  • $true, $false e $null (nada).
  • Compare com o $null à esquerda: $null -eq $x.
  • $false, $null, 0, "" e @() são falsos no if.
  • ?? dá um valor padrão; só existe no PowerShell 7.
