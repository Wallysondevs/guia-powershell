PowerShell break e continue

Nos laços das aulas foreach, for e while e do, o PowerShell percorre a lista até o fim, ou enquanto a condição vale. Às vezes a Ana quer parar no meio: achou a primeira nota baixa e não precisa olhar o resto. Outras vezes ela quer só pular um item e seguir. Isso é o trabalho do break (“pare”) e do continue (“siga para o próximo”).

Você vai aprender
  • O break, que encerra o laço na hora e segue o que vem depois dele.
  • O continue, que pula o resto da volta atual e vai para o próximo item.
  • O padrão “procure e pare”: achar o primeiro caso e sair.
  • O que o break faz quando há um laço dentro de outro, e como um rótulo (:fora) sai dos dois de uma vez.
  • A pegadinha: dentro do ForEach-Object, use return para pular um item; o break pode parar bem mais do que o laço.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta pessoal da usuária fictícia ana.

A ideia: a lista de compras e a lata amassada

A Ana entra no mercado com uma lista. Se ela só precisa de leite e o encontra no primeiro corredor, ela para de procurar e vai para o caixa: isso é o break. O que vinha depois na lista nem é olhado, e a vida segue depois da porta do mercado.

Se no meio da prateleira ela vê uma lata amassada, ela pula aquela e pega a próxima: isso é o continue. A compra não acabou; só aquele item foi ignorado.

Quando ela está numa loja que fica dentro de um shopping, sair só da loja é um break comum. Sair do shopping inteiro pede um nome na porta — um rótulo.

Achei o leite, vou emborabreak: encerra o laço
Lata amassada, pego a próximacontinue: pula esta volta, segue no próximo item
Sair só da loja (o laço de dentro)break sem rótulo

1. break: pare o laço

A Ana percorre os números de 1 a 10, mas quer parar ao chegar no 4. O break sai do foreach antes de imprimir o 4. O que vem depois do laço roda normalmente:

PS C:\Users\ana> foreach ($n in 1..10) { if ($n -eq 4) { break }; "n = $n" }
n = 1
n = 2
n = 3
PS C:\Users\ana> "depois do laço"
depois do laço
foreach ($n in 1..10)
Para cada número de 1 até 10 (aula foreach).
if ($n -eq 4) { break }
Quando $n é 4, o break encerra o laço na hora. A linha "n = $n" desta volta nem roda, por isso o 4 não aparece.
"n = $n"
Só roda quando o if não disparou: 1, 2 e 3.
"depois do laço"
Está fora do foreach, então roda em seguida. O break não derruba o resto do script; só sai do laço.

Experimente: o laço imprime de 1 a 10. Coloque um break para parar ao chegar no 4: mostre n = 1, n = 2, n = 3 e, ao parar, a palavra parei. O 4 e os seguintes não devem ser impressos como n = ….

foreach ($n in 1..10) {
    "n = $n"
}

foreach ($n in 1..10) {
    if ($n -eq 4) { "parei"; break }
    "n = $n"
}

2. continue: pule esta volta

Agora a Ana quer mostrar só os ímpares de 1 a 6. Quando o número é par, o continue pula o resto daquela volta e vai para o próximo:

PS C:\Users\ana> foreach ($n in 1..6) { if ($n % 2 -eq 0) { continue }; "ímpar: $n" }
ímpar: 1
ímpar: 3
ímpar: 5
$n % 2 -eq 0
O % é o resto da divisão. Se o resto da divisão por 2 é 0, o número é par.
continue
“Pule o resto desta volta.” A linha "ímpar: $n" não roda para os pares, mas o laço não acaba: segue para 3, 5…
A diferença prática: break encerra o laço; continue só pula o item atual e segue.

Missão: use continue para pular os pares e mostrar só ímpar: 1, ímpar: 3 e ímpar: 5.

foreach ($n in 1..6) {
    "ímpar: $n"
}

foreach ($n in 1..6) {
    if ($n % 2 -eq 0) { continue }
    "ímpar: $n"
}

3. Procurar e parar

As notas da turma são 6, 8, 3 e 9. A Ana quer achar a primeira nota menor que 5 e parar ali, sem olhar as seguintes:

PS C:\Users\ana> $notas = 6, 8, 3, 9
PS C:\Users\ana> foreach ($nota in $notas) { if ($nota -lt 5) { "Achei nota baixa: $nota"; break } }
Achei nota baixa: 3

O 6 e o 8 passaram; o 3 disparou a mensagem e o break. O 9, que vem depois, não foi visitado. Sem o break, o laço continuaria até o fim da lista — o que, nesta lista, daria o mesmo resultado (só há uma nota baixa), mas numa lista com várias notas baixas mostraria todas.

4. Laço dentro de laço e rótulo

Quando um foreach está dentro de outro, o break sai só do laço de dentro. O de fora continua. Aqui $i é a “linha” e $j é a “coluna”; ao chegar em $j -eq 2, o laço interno para, e a próxima linha começa:

PS C:\Users\ana> foreach ($i in 1..3) { foreach ($j in 1..3) { if ($j -eq 2) { break }; "$i-$j" } }
1-1
2-1
3-1

Saíram só os pares em que a coluna é 1. As voltas com coluna 2 e 3 do laço interno foram abortadas, mas as três linhas (1, 2 e 3) aconteceram.

Para sair dos dois de uma vez, a Ana cola um rótulo no laço de fora: um nome com dois-pontos na frente, :fora, e o break fora aponta para ele:

PS C:\Users\ana> :fora foreach ($i in 1..3) { foreach ($j in 1..3) { if ($j -eq 2) { break fora }; "$i-$j" } }
1-1

Desta vez, ao chegar em j = 2 na primeira linha, o break fora encerrou o laço de fora também. Só apareceu 1-1.

:fora
O rótulo, colado na frente do laço que você quer poder encerrar de dentro. O nome você escolhe; evite acento.
break fora
Encerra o laço que tem esse rótulo, não só o mais interno.

Quando dá errado

A pegadinha do ForEach-Object

O cmdlet ForEach-Object (aula foreach, e com mais detalhes em ForEach-Object) não é o laço foreach. Dentro dele, o jeito de pular um item é o return, não o break. Com return, o 3 é pulado e os seguintes aparecem:

PS C:\Users\ana> 1..5 | ForEach-Object { if ($_ -eq 3) { return }; "item $_" }
item 1
item 2
item 4
item 5

Já o break dentro do ForEach-Object não “sai só da esteira”. No laboratório, o comando abaixo ainda tinha uma mensagem dentro do bloco e outra depois dele; as duas sumiram:

PS C:\Users\ana> & { 1..5 | ForEach-Object { if ($_ -eq 3) { break }; "item $_" }; "esta linha some" }; "fora do bloco"
item 1
item 2
& { ... }
Um bloco que roda na hora. Dentro dele, o ForEach-Object e, em seguida, o texto esta linha some.
break
Ao chegar no 3, o break não pulou só o item: item 3, item 4, item 5, esta linha some e até o fora do bloco (depois do & { ... }) deixaram de aparecer. Só restaram item 1 e item 2.

Como evitar: no laço foreach ($item in $lista), use break e continue à vontade. No ForEach-Object da esteira, para pular um item use return. Não use break ali: ele pode interromper bem mais do que você esperava.

Referência rápida

Resumo

  • break encerra o laço na hora. O que vem depois do laço roda normalmente.
  • continue pula o resto da volta atual e segue no próximo item.
  • “Procure e pare”: ao achar o que importava, mostre e dê break.
  • Num laço dentro de outro, o break sai só do de dentro. Um rótulo (:fora e break fora) sai dos dois.
  • No ForEach-Object, use return para pular um item. O break ali pode interromper o bloco inteiro — no laboratório, até a linha depois do bloco deixou de aparecer.
