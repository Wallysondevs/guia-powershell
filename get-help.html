Get-Help: a Ajuda

Você não precisa decorar parâmetro nenhum. O PowerShell traz o próprio manual: o Get-Help. Nesta aula você vai pedir a ajuda do Get-Date, ver o que ela mostra de fábrica (é uma ajuda parcial), aprender a pedir exemplos, a ficha de um parâmetro e uma busca por nome — e entender por que, neste computador, os exemplos ainda não aparecem.

Você vai aprender
  • O Get-Help, o cmdlet que mostra a ajuda de outro comando.
  • A ler as seções NOME, SYNTAX, ALIASES e REMARKS.
  • O que é a ajuda parcial (quando os arquivos de ajuda não estão instalados) e o que fazer nesse caso.
  • Os parâmetros -Examples, -Parameter e a ideia do -Online.
  • A buscar com curinga: Get-Help *location* e os tópicos about_*.
  • O atalho Get-Date -? e a diferença entre help e Get-Help.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, sem rodar o Update-Help (ele instala arquivos no sistema; neste guia a gente não faz isso). O que você vai ver é a ajuda de fábrica, a mesma de um PowerShell 7 recém-instalado. Quando o Windows PowerShell 5.1 responde diferente, a aula avisa.

A ideia: o manual que vem na caixa

Pense no manual de uma cafeteira. Você não precisa memorizar cada botão: abre o livrinho, acha o capítulo e segue o exemplo. O Get-Help é esse manual. O detalhe é que, de fábrica, a caixa às vezes vem só com o sumário — a lista dos botões — e não com os exemplos completos. É exatamente o que acontece aqui.

No manual da cafeteiraNo PowerShell
Abrir o capítulo de um botãoGet-Help Get-Date
Pedir um exemplo de usoGet-Help Get-Date -Examples
Ler só a ficha de um botãoGet-Help Get-Date -Parameter Format
Abrir o manual no site do fabricanteGet-Help Get-Date -Online

1. Pedindo a ajuda: Get-Help Get-Date

O primeiro argumento do Get-Help é o nome do comando sobre o qual você quer a ajuda. Vamos perguntar sobre o Get-Date, que você já conhece:

PS C:\Users\ana> Get-Help Get-Date

NOME
    Get-Date
    
SYNTAX
    Get-Date [[-Date] <datetime>] [-Year <int>] [-Month <int>] [-Day <int>] [-Hour <int>] [-Minute <int>] [-Second 
    <int>] [-Millisecond <int>] [-DisplayHint {Date | Time | DateTime}] [-Format <string>] [-AsUTC] [<CommonParameters>]

    <int>] [-Second <int>] [-Millisecond <int>] [-DisplayHint {Date | Time | DateTime}] [-AsUTC] [<CommonParameters>]
    
    Get-Date -UnixTimeSeconds <long> [-Year <int>] [-Month <int>] [-Day <int>] [-Hour <int>] [-Minute <int>] [-Second 
    <int>] [-Millisecond <int>] [-DisplayHint {Date | Time | DateTime}] [-Format <string>] [-AsUTC] [<CommonParameters>]
    
    Get-Date -UnixTimeSeconds <long> -UFormat <string> [-Year <int>] [-Month <int>] [-Day <int>] [-Hour <int>] [-Minute 
    <int>] [-Second <int>] [-Millisecond <int>] [-DisplayHint {Date | Time | DateTime}] [-AsUTC] [<CommonParameters>]
    

ALIASES
    Nenhum
    

REMARKS
    Get-Help cannot find the Help files for this cmdlet on this computer. It is displaying only partial help.
        -- To download and install Help files for the module that includes this cmdlet, use Update-Help.
        -- To view the Help topic for this cmdlet online, type: "Get-Help Get-Date -Online" or
           go to https://go.microsoft.com/fwlink/?LinkID=2096615.
Get-Help
O cmdlet da ajuda: verbo Get + substantivo Help (“obter a ajuda”).
Get-Date
O comando sobre o qual você quer a ajuda. Não é um parâmetro com hífen: é o nome, logo em seguida.
NOME
O nome do cmdlet. Aqui, simplesmente Get-Date.
SYNTAX
A “receita” de uso: o nome do comando e os parâmetros que ele aceita. No PowerShell 7, este título veio em inglês (no 5.1, aparece SINTAXE). Os quatro blocos são conjuntos de parâmetros diferentes: você escolhe um conjunto por vez, não mistura tudo.
[-Format <string>]
Um parâmetro opcional (está entre colchetes) que pede um texto (o formato). Você já usou: -Format "dd/MM/yyyy".
[<CommonParameters>]
Os parâmetros comuns, que quase todo cmdlet tem (-ErrorAction, -Verbose…). A aula anterior mostrou vários na lista do Get-ChildItem.
ALIASES
Os apelidos deste cmdlet. Nenhum quer dizer que o Get-Date não tem apelido oficial.
REMARKS
Os comentários. Aqui está o aviso mais importante desta aula: a ajuda é parcial.

Leia o aviso com calma. O PowerShell está dizendo duas coisas: ele não achou os arquivos de ajuda deste cmdlet neste computador, e por isso está mostrando só o essencial (o nome e a sintaxe). E ele oferece dois caminhos: baixar os arquivos com Update-Help, ou ler a ajuda na internet com -Online (o endereço aparece logo abaixo).

Neste guia a gente não roda o Update-Help: ele baixa e instala arquivos no sistema. A ajuda que você vê é a de fábrica. Se um dia você quiser a ajuda completa no seu computador, o próprio recado acima explica como. A alternativa que não instala nada é o Get-Help Get-Date -Online, que abre a documentação oficial no navegador. Não colhemos a saída do -Online aqui, porque ela não é um texto no terminal: ela abre uma página.
No Windows PowerShell 5.1 as seções vêm em português (SINTAXE, COMENTÁRIOS), e a sintaxe de fábrica é bem mais curta: praticamente só Get-Date [[-Date] <datetime>] [<CommonParameters>], duas vezes. O PowerShell 7, mesmo na ajuda parcial, já lista -Year, -Month, -Format, -AsUTC, -UFormat e -UnixTimeSeconds.

Experimente: peça a ajuda do Get-Date e rode o comando. A ajuda no seu PowerShell pode ser mais completa do que a desta aula; o comando é o mesmo.

Get-Date

Get-Help Get-Date

2. Pedindo exemplos: -Examples

O parâmetro -Examples pede só os exemplos de uso. É o capítulo mais gostoso do manual — quando os arquivos de ajuda estão instalados. Neste computador, de fábrica, eis o que sai:

PS C:\Users\ana> Get-Help Get-Date -Examples

NOME
    Get-Date

ALIASES
    Nenhum
    

REMARKS
    Get-Help cannot find the Help files for this cmdlet on this computer. It is displaying only partial help.
        -- To download and install Help files for the module that includes this cmdlet, use Update-Help.
        -- To view the Help topic for this cmdlet online, type: "Get-Help Get-Date -Online" or
           go to https://go.microsoft.com/fwlink/?LinkID=2096615.

Não veio exemplo nenhum: só o nome, “nenhum apelido” e o mesmo recado de ajuda parcial. Não é que o Get-Date não tenha exemplos. É que os exemplos moram nos arquivos de ajuda, e eles não estão aqui. Sem esses arquivos, -Examples não tem de onde tirar o capítulo.

Os exemplos não aparecem

Se você rodar Get-Help Get-Date -Examples e a tela vier quase vazia, como a de cima, não é typo e não é o PowerShell “quebrado”. É o aviso dos REMARKS acontecendo na prática.

Como resolver, no seu computador, se você quiser a ajuda completa: ou roda o Update-Help (precisa de internet e, em alguns casos, de administrador; neste guia a gente não faz isso por você), ou usa Get-Help Get-Date -Online e lê os exemplos na documentação oficial, sem instalar nada. Enquanto isso, as aulas deste guia já trazem os exemplos colhidos no laboratório, com a saída real.

3. A ficha de um parâmetro: -Parameter

Para ler um parâmetro só, use -Parameter e o nome dele, sem o hífen no valor. Vamos olhar o -Format, que você já usou:

PS C:\Users\ana> Get-Help Get-Date -Parameter Format

-Format <string>
    
    Required?                    false
    Position?                    Named
    Accept pipeline input?       false
    Parameter set name           DateAndFormat, UnixTimeSecondsAndFormat
    Aliases                      Nenhum
    Dynamic?                     false
    Accept wildcard characters?  false
-Format <string>
O nome do parâmetro e o tipo do valor: um texto (string).
Required? false
“Obrigatório? não.” Você pode rodar o Get-Date sem o -Format; ele só muda o jeito de mostrar.
Position? Named
“Posição? nomeado.” Este parâmetro não é posicional: você precisa escrever o nome, -Format. Não adianta soltar o "dd/MM/yyyy" solto na linha e esperar que ele entenda.
Accept pipeline input? false
Ele não aceita valor chegando pela esteira (|). O valor vai no próprio comando.
Parameter set name
Os conjuntos de parâmetros em que o -Format aparece: DateAndFormat e UnixTimeSecondsAndFormat. Por isso ele estava em alguns blocos da SYNTAX, e não em todos.
Aliases / Dynamic? / Accept wildcard characters?
Não tem apelido, não é um parâmetro dinâmico, e não aceita curinga (*) no valor.

Mesmo com a ajuda parcial, a ficha do parâmetro veio completa. É um dos pedaços que o PowerShell 7 consegue montar sem os arquivos baixados.

No Windows PowerShell 5.1 os rótulos desta ficha vêm em português (Necessário?, Posição? Nomeado, Aceitar entrada do pipeline?, Dinâmico?) e não aparece a linha Accept wildcard characters?.

Missão: peça a ficha do parâmetro Format do Get-Date.

Get-Help Get-Date

Get-Help Get-Date -Parameter Format

4. Buscando pelo nome: o curinga *

Quando você não lembra o nome exato, o Get-Help aceita o * no meio do texto, no mesmo espírito do -Filter *.txt. A busca abaixo acha tópicos cujo nome contém location (“localização”, “pasta atual”):

PS C:\Users\ana> Get-Help *location*

Name                              Category  Module                    Synopsis
----                              --------  ------                    --------
Get-Location                      Cmdlet    Microsoft.PowerShell.Man… …
Pop-Location                      Cmdlet    Microsoft.PowerShell.Man… …
Push-Location                     Cmdlet    Microsoft.PowerShell.Man… …
Set-Location                      Cmdlet    Microsoft.PowerShell.Man… …
Get-WinHomeLocation               Cmdlet    International             Get-WinHomeLocation…
Set-WinHomeLocation               Cmdlet    International             Set-WinHomeLocation…

Apareceram os quatro cmdlets de pasta que você vai ver em Onde Estou (Get-Location) e Mudando de Pasta (Set-Location) — Get-Location, Set-Location, Push-Location e Pop-Location — e mais dois só do Windows, Get-WinHomeLocation e Set-WinHomeLocation, de uma configuração internacional. Não se preocupe com esses dois agora.

Repare também no Synopsis (o resumo de uma linha): em vários itens ele aparece como …. De novo a ajuda parcial: sem os arquivos, o PowerShell às vezes não tem o texto do resumo para mostrar.

5. Os tópicos about_*

Além da ajuda de cada cmdlet, o PowerShell tem textos sobre assuntos: variáveis, funções, operadores, e por aí vai. Esses tópicos começam com about_. A busca abaixo pede os que existem e pede só os 8 primeiros:

PS C:\Users\ana> Get-Help about_* | Select-Object -First 8

Name                              Category  Module                    Synopsis
----                              --------  ------                    --------
about_BeforeEach_AfterEach        HelpFile                            performed at the beginning and end of every It bl…
about_Mocking                     HelpFile                            Pester provides a set of Mocking functions making…
about_Pester                      HelpFile                            Pester is a BDD based test runner for PowerShell.
about_should                      HelpFile                            Provides assertion convenience methods for compar…
about_TestDrive                   HelpFile                            A PSDrive for file activity limited to the scope …

Pedimos 8, mas só vieram 5. E os cinco são do Pester, um módulo de testes que veio neste computador, não os textos clássicos do PowerShell (about_Variables, about_Functions…). Acontece o mesmo de antes: os tópicos oficiais about_ moram nos arquivos de ajuda. Sem o Update-Help, a busca acha sobretudo o que algum módulo já trouxe junto.

Quando a ajuda completa estiver instalada no seu computador, a mesma busca fica bem maior. Até lá, o -Online e as aulas deste guia cobrem o caminho.

A saída é a mesma da primeira seção: nome, sintaxe, apelidos e o recado da ajuda parcial. Use o que for mais fácil de lembrar. Nos scripts e neste guia, preferimos o Get-Help por extenso, que deixa claro o que a linha está fazendo.

7. help ou Get-Help?

Você vai encontrar gente digitando só help Get-Date, sem o Get-. Não é o mesmo comando. O help é uma função que por baixo chama o Get-Help (e, no terminal, costuma mostrar a ajuda página por página). Confira o tipo:

PS C:\Users\ana> Get-Command help | Select-Object Name, CommandType

Name CommandType
---- -----------
help    Function
Name: help
O nome que a pessoa digita.
CommandType: Function
É uma função, não um cmdlet. O cmdlet de verdade é o Get-Help.

Os dois servem para pedir ajuda. Neste guia usamos o Get-Help nos scripts, pelo nome completo, no mesmo espírito de preferir Write-Output a echo (aula Apelidos).

Resumo

  • Get-Help Get-Date mostra a ajuda do comando. De fábrica, no PowerShell 7, ela pode ser parcial: nome e sintaxe, sem os textos longos nem os exemplos.
  • O recado nos REMARKS explica: faltam os arquivos de ajuda. O Update-Help os instala (neste guia a gente não roda). O -Online abre a documentação na internet, sem instalar nada.
  • -Examples pede os exemplos; sem os arquivos, a saída vem quase vazia. -Parameter Format mostra a ficha de um parâmetro — e esta, mesmo parcial, já veio completa.
  • Get-Help *location* busca pelo nome com curinga. Get-Help about_* lista tópicos de assunto; sem a ajuda instalada, podem aparecer só os de algum módulo (aqui, o Pester).
  • Get-Date -? é atalho de Get-Help Get-Date. O help (sem o Get-) é uma função; o cmdlet é o Get-Help.
