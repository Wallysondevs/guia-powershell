Get-Member: o que Tem no Objeto

Você já sabe que tudo no PowerShell é objeto. Mas como saber quais campos e quais ações um objeto tem? O Get-Member (apelido gm) é a "radiografia": mostra o tipo e a lista de tudo o que existe dentro dele.

Você vai aprender
  • A mandar um objeto para o Get-Member pelo pipeline.
  • A ler as colunas Name, MemberType e Definition.
  • A filtrar só as propriedades ou só os métodos com -MemberType.
  • A procurar um membro pelo nome, com curinga.
  • Que o Get-Member mostra cada tipo uma vez só.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a etiqueta da embalagem

Antes de usar um aparelho novo, você olha a etiqueta: o modelo, o que ele tem e o que ele faz. O Get-Member lê a etiqueta de um objeto. A primeira linha (TypeName) é o modelo, e a tabela embaixo lista as peças.

1. A radiografia de um objeto seu

Crie um objeto com três campos e passe para o Get-Member:

PS> $pessoa = [pscustomobject]@{ Nome = "Ana"; Cidade = "Recife"; Idade = 30 }
PS> $pessoa | Get-Member

   TypeName: System.Management.Automation.PSCustomObject

Name        MemberType   Definition
----        ----------   ----------
Equals      Method       bool Equals(System.Object obj)
GetHashCode Method       int GetHashCode()
GetType     Method       type GetType()
ToString    Method       string ToString()
Cidade      NoteProperty string Cidade=Recife
Idade       NoteProperty int Idade=30
Nome        NoteProperty string Nome=Ana
TypeName
O tipo do objeto. Aqui é PSCustomObject, um objeto feito por você.
Name
O nome do membro: é o que vem depois do ponto ($pessoa.Nome).
MemberType
O que ele é. Method é uma ação; NoteProperty é um campo que você criou.
Definition
Os detalhes: para campos, o tipo e o valor; para métodos, o que recebem e devolvem.
Equals, GetHashCode, GetType, ToString
Métodos que todo objeto tem, até os seus.

-MemberType Property
Só as propriedades. Um texto tem uma só: Length.
-Name To*
Só os membros cujo nome começa com To. O * é o curinga ("qualquer coisa").

Cada linha de Definition pode ter várias formas do mesmo método, separadas por vírgula: são os jeitos diferentes de chamar o método (com ou sem valores entre os parênteses).

Experimente: o código lista tudo o que o texto "PowerShell" tem. Acrescente -MemberType Property para ver só as propriedades.

"PowerShell" | Get-Member

"PowerShell" | Get-Member -MemberType Property

3. Uma linha por tipo

Mandando uma lista com vários itens do mesmo tipo, o Get-Member mostra o tipo uma vez só. Com tipos diferentes, aparece um bloco para cada tipo:

PS> 1, 2, 3 | Get-Member -MemberType Method -Name CompareTo

   TypeName: System.Int32

Name      MemberType Definition
----      ---------- ----------
CompareTo Method     int CompareTo(System.Object value), int CompareTo(int val…

PS> 1, "dois" | Get-Member -Name Length

   TypeName: System.String

Name   MemberType Definition
----   ---------- ----------
Length Property   int Length {get;}

No segundo, só o texto "dois" tem Length, então só aparece o bloco do String. O número 1 não tem esse membro.

4. Para que serve na prática

Quando um comando devolve objetos e você não sabe os nomes dos campos, o Get-Member responde. Por exemplo, a data do Get-Date:

PS> Get-Date | Get-Member -MemberType Property -Name D*

   TypeName: System.DateTime

Name      MemberType Definition
----      ---------- ----------
Date      Property   datetime Date {get;}
Day       Property   int Day {get;}
DayOfWeek Property   System.DayOfWeek DayOfWeek {get;}
DayOfYear Property   int DayOfYear {get;}

Pronto: agora você sabe que dá para pedir (Get-Date).DayOfYear ou .DayOfWeek.

Quando dá errado

Nada para inspecionar 
PS> $vazio = $null

$vazio | Get-Member

Com $null não há objeto nenhum na esteira, então o Get-Member não tem o que inspecionar e responde com um erro pedindo que você informe um objeto. Confira se a variável tem mesmo um valor.

Referência rápida

Você digitaO que faz
$x | Get-MemberLista o tipo e todos os membros.
$x | gmO mesmo, com o apelido.
-MemberType PropertySó as propriedades.
-MemberType MethodSó os métodos.
-Name To*Só os membros com nome parecido.

Resumo

  • Get-Member (apelido gm) mostra o tipo e os membros de um objeto.
  • Name é o que vem depois do ponto; MemberType diz se é campo ou ação.
  • -MemberType Property ou Method filtra; -Name aceita curinga.
  • Cada tipo diferente aparece uma vez só.
  • Com $null não há o que inspecionar.
