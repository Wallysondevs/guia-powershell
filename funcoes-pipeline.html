Funções no Pipeline (begin, process, end)

Os cmdlets recebem objetos pelo |. As suas funções também podem: basta marcar o parâmetro com ValueFromPipeline e colocar o trabalho no bloco process, que roda uma vez para cada objeto que chega.

Você vai aprender
  • A receber objetos do pipeline com ValueFromPipeline.
  • Os blocos begin, process e end.
  • A receber um campo do objeto com ValueFromPipelineByPropertyName.
  • O erro comum: esquecer o process e só processar o último item.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional. Os quadros marcados Saída no Windows (PowerShell 7.7) foram colhidos num Windows 10 em português, com o nome do computador e o da usuária trocados por exemplos (NOTEBOOK e ana).

A ideia: a máquina da linha de montagem

Na aula Pipeline, cada comando era uma máquina da esteira. Agora você constrói a sua máquina. O begin é ligar a máquina, o process é o trabalho em cada peça, o end é desligar e entregar o relatório.

1. Recebendo do pipeline

PS> function Get-Dobro {
>>   param([Parameter(ValueFromPipeline)][int]$Numero)
>>   process { $Numero * 2 }
>> }
PS> 1..4 | Get-Dobro
2
4
6
8
PS> Get-Dobro 10
20
ValueFromPipeline
O objeto que chega pelo | cai neste parâmetro.
process { ... }
Roda uma vez para cada objeto que chega.
Get-Dobro 10
A função continua aceitando o valor do jeito normal, sem pipeline.

2. Antes, durante e depois

PS> function Measure-Total {
>>   param([Parameter(ValueFromPipeline)][double]$Valor)
>>   begin { $total = 0; $n = 0 }
>>   process { $total += $Valor; $n++ }
>>   end { "Itens: $n | Total: $total" }
>> }
PS> 12.5, 30, 7.5 | Measure-Total
Itens: 3 | Total: 50
begin
Uma vez, antes do primeiro objeto: prepara as variáveis.
process
Para cada objeto: soma e conta.
end
Uma vez, depois do último: mostra o resultado.

Experimente: a função só mostra o último nome. Coloque o trabalho dentro de um bloco process { } para tratar cada nome que chega.

function ConvertTo-Maiuscula {
    param([Parameter(ValueFromPipeline)][string]$Texto)
    $Texto.ToUpper()
}
"ana", "beto" | ConvertTo-Maiuscula

function ConvertTo-Maiuscula {
    param([Parameter(ValueFromPipeline)][string]$Texto)
    process { $Texto.ToUpper() }
}
"ana", "beto" | ConvertTo-Maiuscula

3. Pegando um campo pelo nome

Com ValueFromPipelineByPropertyName, o parâmetro recebe o campo de mesmo nome do objeto que chega:

PS> function Show-Aluno {
>>   param(
>>     [Parameter(ValueFromPipelineByPropertyName)][string]$Nome,
>>     [Parameter(ValueFromPipelineByPropertyName)][int]$Nota
>>   )
>>   process { "{0,-5} {1,3}" -f $Nome, $Nota }
>> }
PS> $turma = @(
>>   [pscustomobject]@{ Nome = "Ana"; Nota = 9 }
>>   [pscustomobject]@{ Nome = "Beto"; Nota = 6 }
>> )
PS> $turma | Show-Aluno
Ana     9
Beto    6

Quando dá errado

Sem process: só o último 
PS> function Get-Triplo {
>>   param([Parameter(ValueFromPipeline)][int]$N)
>>   $N * 3
>> }
PS> 1..3 | Get-Triplo
9

Sem blocos, o corpo da função é tratado como end: roda uma vez só, no fim, quando o parâmetro tem o último objeto. Resultado: só 9.

Tipo que não combina 
PS> "dez" | Get-Dobro
Get-Dobro: O objeto de entrada não pode ser associado a nenhum parâmetro para o comando porque o comando não usa entrada de pipeline ou a entrada e suas propriedades não correspondem a nenhum dos parâmetros que usam entrada de pipeline.

O objeto que chega precisa caber no tipo do parâmetro ([int]). Como "dez" não vira número, o PowerShell não acha nenhum parâmetro que aceite esse objeto, e o erro diz que "o objeto de entrada não pode ser associado a nenhum parâmetro".

Referência rápida

Você digitaO que faz

[Parameter(ValueFromPipelineByPropertyName)]Recebe o campo de mesmo nome.
begin { }Antes do primeiro.
process { }Para cada um.
end { }Depois do último.

Exercícios

2. Sem nenhum bloco, o que acontece com 1..3 | F se F usa ValueFromPipeline?

3. Quantas vezes roda o bloco begin?

Missão final: complete a função com begin, process e end para que 10, 20, 30 | Get-Total mostre Total: 60.

function Get-Total {
    param([Parameter(ValueFromPipeline)][int]$Valor)
    "Total: $Valor"
}
10, 20, 30 | Get-Total

function Get-Total {
    param([Parameter(ValueFromPipeline)][int]$Valor)
    begin { $soma = 0 }
    process { $soma += $Valor }
    end { "Total: $soma" }
}
10, 20, 30 | Get-Total

Resumo

  • ValueFromPipeline faz o parâmetro receber o objeto do |.
  • begin (antes), process (cada um), end (depois).
  • Sem process, só o último objeto é tratado.
  • ValueFromPipelineByPropertyName liga campos do objeto a parâmetros de mesmo nome.
