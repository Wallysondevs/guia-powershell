Operadores

Todos os operadores do PowerShell numa página só, com um exemplo de cada. Lembre: na comparação de textos, o PowerShell ignora maiúsculas por padrão; coloque um c na frente (-ceq, -clike) para diferenciar.

Você vai aprender
  • Os operadores agrupados por tipo.
  • O resultado de cada um, com exemplos reais.
  • As versões que diferenciam maiúsculas (-c...).

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

Comparação

PS> 5 -eq 5
True
PS> "abc" -ne "ABC"
False
PS> 10 -gt 9
True
PS> "Maria" -like "Ma*"
True
PS> "Pedido 123" -match '\d+'
True
PS> 1, 2, 3 -contains 2
True
PS> "uva" -in "maçã", "uva"
True
OperadorSignifica
-eq / -neigual / diferente
-gt / -gemaior / maior ou igual
-lt / -lemenor / menor ou igual
-like / -notlikecombina com curinga (*, ?)
-match / -notmatchcombina com regex (preenche $Matches)
-contains / -notcontainsa lista contém o valor
-in / -notino valor está na lista
-ceq, -clike, -cmatch...versões que diferenciam maiúsculas

Tipos

PS> 42 -is [int]
True
PS> "42" -as [int]
42
PS> "abc" -as [int]

-as tenta converter e devolve $null se não der, sem erro.

Nulos, ternário e encadeamento (PowerShell 7)

PS> $nome = $null
PS> $nome ?? "visitante"
visitante
PS> $idade = 20
PS> $idade -ge 18 ? "maior" : "menor"
maior
OperadorSignifica
a ?? ba, ou b se a for nulo
$x ??= valoratribui só se $x for nulo
cond ? sim : nãoternário
$obj?.Propriedadeacesso que não falha se $obj for nulo (escreva ${obj}?.Prop)
cmd1 && cmd2 / cmd1 || cmd2roda se deu certo / se falhou

Resumo

  • Comparação usa letras com hífen (-eq, -gt); > é redirecionamento.
  • Texto: -like (curinga), -match/-replace/-split (regex), -join, -f.
  • PowerShell 7: ??, ??=, ? :, &&, ||.
