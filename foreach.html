PowerShell foreach

A Ana tem uma lista de frutas, uma lista de gastos do mês e uma lista de notas da turma. Fazer a mesma coisa com cada item, um por um, à mão, cansa. Nesta aula você vai usar o foreach ("para cada") para o PowerShell repetir um bloco de comandos uma vez para cada item de uma lista.

Você vai aprender
  • A repetir um bloco para cada item de uma lista com foreach (... in ...).
  • A somar os valores de uma lista.
  • A repetir um número certo de vezes com um intervalo, como 1..5.
  • A guardar numa variável tudo o que o laço produziu.
  • A diferença entre foreach e ForEach-Object.
  • O que acontece com uma lista vazia e os erros de digitação mais comuns.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: a fila do caixa

Pense na fila de um caixa de supermercado. O caixa chama o primeiro cliente, atende, chama o próximo, atende, e assim até a fila acabar. Ele faz o mesmo atendimento para cada pessoa, só muda quem está na frente dele. O foreach é esse caixa: a lista é a fila, e a variável do laço é "o cliente da vez".

1. O básico: para cada item da lista

PS C:\Users\ana> $frutas = "maçã", "banana", "uva"
PS C:\Users\ana> foreach ($fruta in $frutas) { "Eu gosto de $fruta" }
Eu gosto de maçã
Eu gosto de banana
Eu gosto de uva
foreach
"Para cada". A palavra que começa a repetição (o laço).
($fruta in $frutas)
"Cada $fruta em $frutas". O $frutas é a lista inteira. O $fruta é a variável que, a cada volta, guarda um item: primeiro "maçã", depois "banana", depois "uva". O nome você escolhe. O costume é o singular da lista.
{ "Eu gosto de $fruta" }
O bloco que se repete. Ele rodou 3 vezes, uma por fruta.

2. Somando uma lista

Um uso clássico: somar os gastos do mês. Comece com o total em zero e, a cada volta, acrescente o gasto da vez:

PS C:\Users\ana> $gastos = 12.5, 30, 7.25
PS C:\Users\ana> $total = 0
PS C:\Users\ana> foreach ($g in $gastos) { $total += $g }
PS C:\Users\ana> "Total: $total"
Total: 49.75
$total = 0
O "cofrinho" começa vazio, antes do laço.
$total += $g
"Some $g ao que já está em $total" (aula Atribuição). Voltas: 0 + 12.5 = 12.5, depois + 30 = 42.5, depois + 7.25 = 49.75.
(nada na tela)
O laço não mostrou nada, porque $total += $g só guarda. O resultado aparece na linha seguinte.

3. Repetindo um número de vezes: 1..5

O 1..5 cria a lista 1, 2, 3, 4, 5. Com ele, o foreach repete o bloco 5 vezes:

PS C:\Users\ana> foreach ($n in 1..5) { "Linha $n" }
Linha 1
Linha 2
Linha 3
Linha 4
Linha 5
1..5
O operador de intervalo: todos os números inteiros de 1 até 5, incluindo os dois.

4. Guardando o resultado do laço

Tudo o que o bloco "solta" pode ir direto para uma variável. Ela vira uma lista com os resultados:

PS C:\Users\ana> $dobro = foreach ($n in 1..3) { $n * 2 }
PS C:\Users\ana> $dobro -join ", "
2, 4, 6
$dobro = foreach ...
Em vez de aparecer na tela, cada $n * 2 foi guardado em $dobro.
-join ", "
Junta os itens da lista num texto só, separados por vírgula e espaço.

Formas diferentes: foreach × ForEach-Object

Existe também o cmdlet ForEach-Object, que recebe os itens pelo pipeline (o |, aula Pipeline). Dentro dele, o item da vez se chama $_ (aula Variáveis Automáticas):

PS C:\Users\ana> 1..3 | ForEach-Object { $_ * 10 }
10
20
30
FormaComo escreveQuando usar
foreach (palavra-chave)foreach ($n in $lista) { $n }Nos scripts, quando a lista já está numa variável. A variável tem um nome claro.
ForEach-Object (cmdlet)$lista | ForEach-Object { $_ }No meio de um pipeline, recebendo itens de outro comando. Mais detalhes na aula ForEach-Object.
forfor ($i = 0; $i -lt 3; $i++) { }Quando você precisa do número da posição ou de passos diferentes de 1. Veja a aula for.

Lista vazia e $null

PS C:\Users\ana> foreach ($x in @()) { "nunca" }; "lista vazia: nada rodou"
lista vazia: nada rodou
PS C:\Users\ana> foreach ($x in $null) { "rodou com [$x]" }

Com uma lista vazia (@()), o bloco não roda nenhuma vez, e não é erro: a fila estava vazia, o caixa não atendeu ninguém. Com $null (o "nada"), também não roda: repare que depois do segundo comando não apareceu nenhuma linha. Isso é útil: se um comando não encontrou nada, o seu foreach simplesmente não faz nada.

Quando dá errado

Para colher estes erros, o código errado foi rodado como texto pelo Invoke-Expression, por isso as mensagens começam com Invoke-Expression:. Digitando direto, a moldura muda um pouco (aparece como ParserError), mas a mensagem é a mesma. Esses erros de leitura do código saem em inglês no PowerShell 7.7, mesmo num Windows em português.

Trocar o in por outra palavra 
PS C:\Users\ana> Invoke-Expression 'foreach ($fruta of $frutas) { $fruta }'
Invoke-Expression: Missing 'in' after variable in foreach loop. The correct form is: foreach ($a in $b) {...}
Missing 'in' after variable in foreach loop
Quer dizer que faltou a palavra in depois da variável do laço. Quem vem do JavaScript às vezes escreve of.
The correct form is: foreach ($a in $b) {...}
Aqui o próprio PowerShell mostra o modelo certo do foreach.
Esquecer os parênteses 
PS C:\Users\ana> Invoke-Expression 'foreach $fruta in $frutas { $fruta }'

Missing opening '(' after keyword 'foreach'
Quer dizer que faltou abrir parênteses logo depois da palavra foreach. A parte $fruta in $frutas precisa ficar entre parênteses.

Resumo

  • foreach ($item in $lista) { ... } roda o bloco uma vez para cada item.
  • A variável do laço guarda o item da vez. Escolha um nome claro, como o singular da lista.
  • 1..5 cria uma lista de números e serve para repetir um número certo de vezes.
  • Dá para guardar tudo o que o laço produziu: $r = foreach (...) { ... }.
  • Lista vazia ou $null: o bloco não roda, e não é erro.
  • Nos scripts, prefira foreach. No meio de um pipeline, use ForEach-Object com $_.
