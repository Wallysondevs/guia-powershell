JSON (ConvertTo-Json e ConvertFrom-Json)

JSON é o formato de dados da internet: APIs, arquivos de configuração e aplicativos falam JSON. No PowerShell, dois cmdlets fazem a ponte: ConvertTo-Json transforma objetos em texto JSON e ConvertFrom-Json transforma o texto de volta em objetos.

Você vai aprender
  • Como é um texto JSON (chaves, colchetes, aspas).
  • A transformar objetos e hashtables em JSON.
  • A ler JSON e navegar nas propriedades.
  • O parâmetro -Depth para dados com vários níveis.
  • A salvar e carregar uma configuração em arquivo .json.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a ficha de cadastro

Uma ficha de cadastro tem campos com nome e valor: "nome: Ana", "idade: 30", "telefones: (dois números)". O JSON escreve essa ficha de um jeito que qualquer programa, em qualquer linguagem, consegue ler.

{
  "nome": "Ana",
  "idade": 30,
  "telefones": ["11 9999-0000", "11 3333-0000"]
}
No JSONVira no PowerShell
{ "chave": valor }Um objeto (PSCustomObject) com a propriedade chave.
[ 1, 2, 3 ]Um array.
"texto"string.
30 / 9.5Número.
true / false / null$true / $false / $null.

1. De objeto para JSON

PS> $pessoa = [pscustomobject]@{ Nome = "Ana"; Idade = 30; Ativa = $true }
PS> $pessoa | ConvertTo-Json
{
  "Nome": "Ana",
  "Idade": 30,
  "Ativa": true
}
PS> $pessoa | ConvertTo-Json -Compress
{"Nome":"Ana","Idade":30,"Ativa":true}
ConvertTo-Json
Gera o texto JSON, com recuo para ler fácil.
-Compress
Tudo numa linha só, sem espaços (bom para enviar a uma API).

2. De JSON para objeto

PS> $texto = '{"cidade":"Recife","temperatura":31.5,"bairros":["Boa Viagem","Casa Forte"]}'
PS> $clima = $texto | ConvertFrom-Json
PS> $clima

cidade temperatura bairros
------ ----------- -------
Recife      31,500 {Boa Viagem, Casa Forte}
PS> $clima.cidade
Recife
PS> $clima.bairros[1]
Casa Forte

Agora é um objeto normal: dá para filtrar, ordenar e usar Get-Member. Na tabela, o PowerShell mostra os números com casas decimais vindos do JSON com três casas (31,500), mas o valor continua sendo 31,5.

Experimente: transforme o texto de $texto em objeto com ConvertFrom-Json e mostre só a propriedade cidade.

$texto = '{"cidade":"Recife","temperatura":31.5}'
$texto

$texto = '{"cidade":"Recife","temperatura":31.5}'
($texto | ConvertFrom-Json).cidade

3. Listas de objetos

Um array JSON vira vários objetos no pipeline:

PS> $json = '[{"produto":"Café","preco":18.9},{"produto":"Pão","preco":7.5},{"produto":"Leite","preco":5.2}]'
PS> $itens = $json | ConvertFrom-Json
PS> $itens | Sort-Object preco

produto  preco
-------  -----
Leite    5,200
Pão      7,500
Café    18,900
PS> ($itens | Measure-Object preco -Sum).Sum
31,6

4. Dados aninhados e o -Depth

Por padrão, o ConvertTo-Json só desce 2 níveis. Além disso, ele escreve o objeto como texto e avisa:

PS> $pedido = @{ cliente = @{ nome = "Ana"; endereco = @{ cidade = "Recife"; uf = "PE" } } }
PS> $pedido | ConvertTo-Json -Depth 5
{
  "cliente": {
    "nome": "Ana",
    "endereco": {
      "cidade": "Recife",
      "uf": "PE"
    }
  }
}

Sem o -Depth 5, o endereco sairia como o texto System.Collections.Hashtable. Sempre que tiver dados dentro de dados, use -Depth com folga.

5. Salvando uma configuração

PS> $config = [ordered]@{ tema = "escuro"; idioma = "pt-BR"; fonte = 14 }
PS> $config | ConvertTo-Json | Set-Content config.json
PS> Get-Content config.json
{
  "tema": "escuro",
  "idioma": "pt-BR",
  "fonte": 14
}
PS> $lida = Get-Content config.json -Raw | ConvertFrom-Json
PS> "Fonte: $($lida.fonte)"
Fonte: 14
[ordered]@{...}
A hashtable ordenada mantém as chaves na ordem em que você escreveu.
Get-Content -Raw
Lê o arquivo inteiro como um texto só (o ConvertFrom-Json precisa do JSON completo).

6. -AsHashtable

Prefere uma hashtable em vez de objeto? Use -AsHashtable:

PS> $h = '{"a":1,"b":2}' | ConvertFrom-Json -AsHashtable
PS> $h["b"]
2
PS> $h.GetType().Name
OrderedHashtable

Quando dá errado

Esquecer o -Raw

Get-Content config.json | ConvertFrom-Json lê linha por linha. No PowerShell 7 isso costuma funcionar, porque o cmdlet junta as linhas, mas o -Raw deixa claro que é um texto só e é mais rápido. Use sempre.

Aspas simples no JSON

JSON só aceita aspas duplas: {'nome':'Ana'} não é JSON válido para outros programas. Por isso, no PowerShell, guarde o JSON entre aspas simples por fora: '{"nome":"Ana"}'.

Resumo

  • ConvertTo-Json transforma objetos em JSON; ConvertFrom-Json faz o caminho de volta.
  • Objeto JSON vira PSCustomObject; array vira lista.
  • Use -Depth para dados aninhados e -Compress para uma linha só.
  • Arquivo JSON: Set-Content para gravar, Get-Content -Raw para ler.
