Tipos ([int], [datetime]…)

Todo valor no PowerShell tem um tipo. Os colchetes servem para três coisas: converter ([int]"42"), restringir uma variável ([int]$idade = 30) e usar métodos do tipo ([int]::MaxValue). Veja as aulas Tipos e Conversão.

Você vai aprender
  • Os apelidos de tipo mais usados e o nome completo no .NET.
  • Como converter e como testar o tipo.
  • Os limites e cuidados de cada tipo numérico.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

Descobrindo o tipo

PS> (42).GetType().Name
Int32
PS> (3.5).GetType().Name
Double
PS> ("oi").GetType().Name
String
PS> (Get-Date -Year 2026 -Month 1 -Day 1).GetType().FullName
System.DateTime
PS> @(1, 2).GetType().Name
Object[]
PS> @{}.GetType().Name
Hashtable

Convertendo

PS> [int]"42" + 1
43
PS> [int]3.5
4
PS> [int]4.5
4
PS> [double]"3.75"
3,75
PS> [bool]"qualquer texto"
True
PS> [bool]""
False
PS> [string]123 + 4
1234
PS> [version]"7.10.0" -gt [version]"7.9.1"
True
[int]3.5 / [int]4.5
Arredonda para o par mais próximo quando está no meio: 3,5 vira 4 e 4,5 também vira 4.
[double]"3.75"
Texto com ponto converte direto; com vírgula, troque antes (-replace ',', '.').
[bool]"qualquer texto"
Todo texto não vazio é verdadeiro.
[version]
Compara versões do jeito certo (10 > 9), diferente de comparar texto.

Testando e convertendo sem erro

PS> 42 -is [int]
True
PS> "42" -is [int]
False
PS> "abc" -as [int]
PS> $null -eq ("abc" -as [int])
True

double × decimal

PS> 0.1 + 0.2
0,3
PS> (0.1 + 0.2) -eq 0.3
False
PS> 0.1d + 0.2d -eq 0.3d
True

O double guarda números em binário e às vezes tem pequenos erros de arredondamento escondidos (a tela mostra 0,3, mas a comparação dá False). Para dinheiro, use decimal: o sufixo d (0.1d) cria o número já como decimal. Cuidado com [decimal]0.1: ali o 0.1 nasce como double (com o erro escondido) e só depois é convertido.

Resumo

  • .GetType().Name mostra o tipo; -is testa; -as converte sem erro.
  • [int] arredonda para o par quando está no meio.
  • Dinheiro em [decimal]; versões em [version].
