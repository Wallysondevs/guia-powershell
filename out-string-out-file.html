Out-File, Out-String e o Redirecionamento (>)

Tudo o que aparece na tela pode ir para um arquivo. O Out-File e o sinal &gt; salvam a saída exatamente como você vê. O Out-String transforma a saída num texto só, e o Out-Null joga fora o que você não quer ver.

Você vai aprender
  • A salvar a saída num arquivo com Out-File e com &gt;.
  • A acrescentar no fim do arquivo com -Append e &gt;&gt;.
  • A diferença entre Out-File e Set-Content.
  • A transformar a saída em texto com Out-String.
  • A esconder uma saída com Out-Null.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a impressora

O Out-File é como apertar "imprimir" na tela: o arquivo fica igual ao que você veria, com tabela, espaços e tudo. Ele não guarda o objeto, guarda o desenho.

1. Salvando a tela num arquivo

PS> $turma = @(
>>   [pscustomobject]@{ Nome = "Ana"; Nota = 9 }
>>   [pscustomobject]@{ Nome = "Beto"; Nota = 6 }
>> )
PS> $turma | Out-File notas.txt
PS> Get-Content notas.txt

Nome Nota
---- ----
Ana     9
Beto    6
Out-File notas.txt
Salva no arquivo notas.txt, na pasta atual. Se o arquivo existir, ele é substituído.
Get-Content notas.txt
Lê o arquivo de volta (aula Get-Content). Repare que a tabela foi salva como ela aparece na tela.

2. O atalho &gt; e o &gt;&gt;

O &gt; é o mesmo que | Out-File. O &gt;&gt; acrescenta no fim, igual ao Out-File -Append:

PS> "linha 1" > log.txt
PS> "linha 2" >> log.txt
PS> "linha 3" | Out-File log.txt -Append
PS> Get-Content log.txt
linha 1
linha 2
linha 3

Experimente: a primeira linha já está no arquivo. Use &gt;&gt; para acrescentar compra 2 sem apagar a primeira, e leia o arquivo no fim.

"compra 1" > compras.txt
"compra 2" > compras.txt
Get-Content compras.txt

"compra 1" > compras.txt
"compra 2" >> compras.txt
Get-Content compras.txt

3. Out-File × Set-Content

O Set-Content (aula Set-Content) grava o valor de cada objeto convertido em texto. O Out-File grava o desenho da tela. Com objetos, a diferença aparece:

PS> $turma | Set-Content dados.txt
PS> Get-Content dados.txt
@{Nome=Ana; Nota=9}
@{Nome=Beto; Nota=6}

O Set-Content gravou cada objeto no "jeito texto" deles (@{Nome=Ana; Nota=9}). Para dados que você vai ler depois com outro programa, prefira CSV ou JSON.

4. Out-String: a tela num texto só

O Out-String faz o mesmo desenho que iria para a tela, mas devolve um texto que você pode guardar numa variável:

PS> $texto = $turma | Out-String
PS> $texto.GetType().Name
String
PS> $texto.Contains("Beto")
True

Útil para mandar uma tabela por e-mail ou procurar algo no que seria mostrado.

5. Out-Null: jogar fora

Alguns comandos devolvem coisas que você não quer ver. Mande para o Out-Null, ou atribua a $null:

PS> $lista = [System.Collections.ArrayList]::new()
PS> $lista.Add("a")
0
PS> $lista.Add("b") | Out-Null
PS> $null = $lista.Add("c")
PS> $lista.Count
3

O .Add() da ArrayList devolve a posição do item (o 0 que apareceu). Com Out-Null ou $null =, a tela fica limpa.

Quando dá errado

Usar &gt; quando queria &gt;&gt; 
PS> "primeira" > diario.txt
PS> "segunda" > diario.txt
PS> Get-Content diario.txt
segunda

O &gt; substitui o arquivo inteiro. A linha "primeira" sumiu. Para acrescentar, use &gt;&gt;.

Tabela cortada no arquivo

O Out-File respeita a largura da tela: colunas compridas podem ser cortadas com …. Use -Width para dar mais espaço:

PS> [pscustomobject]@{ Texto = "x" * 100 } | Out-File largo.txt -Width 200
PS> (Get-Content largo.txt)[3].Length
100

Referência rápida

Você digitaO que faz
... | Out-File a.txtSalva a saída (substitui o arquivo).
... > a.txtO mesmo, mais curto.
... | Out-File a.txt -AppendAcrescenta no fim.
... >> a.txtO mesmo, mais curto.
... | Out-StringA saída vira um texto só.
... | Out-NullJoga a saída fora.

Resumo

  • Out-File e &gt; salvam a saída como ela aparece na tela (e substituem o arquivo).
  • -Append e &gt;&gt; acrescentam no fim.
  • Set-Content grava o valor; Out-File grava o desenho.
  • Out-String devolve a tela como texto; Out-Null e $null = jogam fora.
