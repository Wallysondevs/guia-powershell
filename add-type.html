C# Dentro do PowerShell (Add-Type)

Às vezes você encontra a solução pronta em C# (a linguagem do .NET) ou precisa de um trecho muito rápido. Com Add-Type, o PowerShell compila esse código na hora e o tipo novo fica disponível, como qualquer [Math] ou [DateTime].

Você vai aprender
  • A compilar uma classe C# com Add-Type -TypeDefinition.
  • A chamar métodos estáticos e criar objetos do tipo novo.
  • A usar -MemberDefinition para métodos soltos.
  • A carregar uma biblioteca do .NET com -AssemblyName.
  • Os limites: o tipo não pode ser mudado na mesma sessão.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: o tradutor na reunião

Numa reunião com um colega que só fala inglês, um tradutor traduz o que ele diz na hora. O Add-Type é o tradutor: você entrega o texto em C# e ele "traduz" (compila) para algo que o PowerShell usa.

1. Uma classe C#

PS> Add-Type -TypeDefinition @'
>> public static class Calculadora
>> {
>>     public static int Somar(int a, int b) { return a + b; }
>>     public static double Media(double[] valores)
>>     {
>>         double soma = 0;
>>         foreach (var v in valores) soma += v;
>>         return soma / valores.Length;
>>     }
>> }
>> '@
PS> [Calculadora]::Somar(20, 22)
42
PS> [Calculadora]::Media(@(7, 8, 10))
8,33333333333333
-TypeDefinition @'...'@
O código C# numa here-string de aspas simples (assim o $ não é interpretado).
public static class
Uma classe estática: você usa direto com ::, sem criar objeto.
[Calculadora]
Somar(20, 22) :: Chamada igual à de qualquer tipo do .NET.

2. Objetos de uma classe C#

PS> Add-Type -TypeDefinition @'
>> public class Contador
>> {
>>     public int Valor { get; private set; }
>>     public void Mais() { Valor++; }
>> }
>> '@
PS> $c = [Contador]::new()
PS> $c.Mais(); $c.Mais(); $c.Mais()
PS> $c.Valor
3

3. Métodos soltos: -MemberDefinition

Para um ou dois métodos, o -MemberDefinition cria a classe para você. Você escolhe o nome e um "sobrenome" (namespace):

PS> $tipo = Add-Type -Name Texto -Namespace Util -PassThru -MemberDefinition @'
>> public static string Inverter(string s)
>> {
>>     char[] c = s.ToCharArray();
>>     System.Array.Reverse(c);
>>     return new string(c);
>> }
>> '@
PS> [Util.Texto]::Inverter("PowerShell")
llehSrewoP
PS> $tipo.FullName
Util.Texto

4. Carregando uma biblioteca do .NET

Algumas partes do .NET não vêm carregadas. O -AssemblyName carrega:

PS> Add-Type -AssemblyName System.Web
PS> [System.Web.HttpUtility]::UrlEncode("café com pão")
caf%c3%a9+com+p%c3%a3o
PS> [System.Web.HttpUtility]::HtmlEncode("<b>negrito</b>")
&lt;b&gt;negrito&lt;/b&gt;

Quando dá errado

Mudei o C# e rodei de novo

Um tipo compilado não pode ser trocado na mesma sessão. Rodar Add-Type de novo com o código diferente dá erro dizendo que o tipo já existe. Feche e abra o PowerShell (ou mude o nome da classe enquanto testa).

Erro de compilação

Se o C# tiver erro (um ; esquecido, um tipo errado), o Add-Type mostra a linha e a mensagem do compilador. Lembre: C# diferencia maiúsculas (string ≠ String em alguns lugares, Length ≠ length) e toda instrução termina com ;.

Usar Add-Type quando o PowerShell já resolve

Antes de escrever C#, veja se uma classe do PowerShell ou um tipo pronto do .NET (veja Usando o .NET) já resolvem. C# compensa para trechos que precisam de muita velocidade ou quando o exemplo pronto já está em C#.

Resumo

  • Add-Type -TypeDefinition compila C# e cria tipos novos na sessão.
  • Use os tipos como qualquer tipo do .NET: [Tipo]::Metodo() e ::new().
  • -MemberDefinition cria métodos soltos; -AssemblyName carrega bibliotecas.
  • Tipo compilado não muda na mesma sessão: abra outra para testar mudanças.
