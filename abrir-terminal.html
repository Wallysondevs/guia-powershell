Abrindo o PowerShell

Antes de digitar o primeiro comando, você precisa da janela certa. Nesta aula você abre o PowerShell 7 pelo menu Iniciar, conhece o Terminal do Windows (o aplicativo de abas que pode hospedar o 7, o 5.1 e o cmd) e aprende a perguntar à própria sessão: quem está me atendendo, e em que pasta eu estou?

Você vai aprender
  • A abrir o PowerShell 7 pelo menu Iniciar (e a não confundir com o 5.1).
  • O que é o Terminal do Windows e quando ele entra na história.
  • A ler o prompt PS C:\Users\ana>: o PS e a pasta inicial.
  • A perguntar o nome do host com $Host.Name e a versão com $Host.Version.
  • A ver a pasta em que a sessão começou, com Get-Location.
  • A variável $env:WT_SESSION, que diz se a sessão é do Terminal do Windows.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta da usuária fictícia ana. A coleta rodou no host clássico ConsoleHost, não dentro do Terminal do Windows: as respostas abaixo mostram exatamente isso, e a aula explica o que mudaria se você abrisse pelo Terminal.

A ideia: a janela é a recepção

O PowerShell é o atendente; a janela é a recepção onde ele trabalha. Pode ser a janela simples que abre com o atalho “PowerShell 7”, ou o Terminal do Windows, um aplicativo com abas, em que cada aba pode ser o 7, o 5.1 ou o cmd.

Os comandos são os mesmos nos dois casos. O que muda é o “prédio”: cores, abas, atalhos. Por isso, no começo de uma sessão, vale perguntar quem está hospedando e em que pasta você está.

1. Abrindo pelo menu Iniciar

  1. Clique no menu Iniciar do Windows (ou aperte a tecla do Windows).
  2. Digite PowerShell 7 (escreva o “7”, para não abrir o 5.1 por engano).
  3. Abra o aplicativo PowerShell 7 (às vezes aparece como “pwsh”).
  4. Espere o prompt: uma linha que começa com PS e termina em >, com o cursor piscando.
Se aparecer “Windows PowerShell” sem o 7, é o 5.1. Feche e procure de novo por “PowerShell 7”. Se o 7 ainda não estiver instalado, volte à aula Instalar o PowerShell 7.

O prompt desta aula, no laboratório, era este (no seu computador, no lugar de ana vai o seu usuário):

PS C:\Users\ana>
PS
Está no PowerShell, não no cmd (o prompt do cmd não tem esse PS).
C:\Users\ana
A pasta onde a sessão começou: a pasta pessoal da Ana. É o “você está aqui” do terminal. A aula Onde Estou aprofunda isso.
>
O fim do prompt. O que você digitar aparece depois dele.

2. O Terminal do Windows

O Terminal do Windows é um aplicativo à parte (muitas instalações do Windows 10 e 11 já o trazem). Ele abre uma janela com abas: numa você pode ter o PowerShell 7, noutra o 5.1, noutra o cmd.

  1. No menu Iniciar, digite Terminal e abra o Terminal (às vezes “Windows Terminal”).
  2. Se a aba que abrir não for o PowerShell 7, clique na setinha ao lado do + e escolha PowerShell (ou “PowerShell 7”).
  3. Confira o prompt: deve começar com PS. Depois, se quiser ter certeza da versão, rode $PSVersionTable.PSVersion.

Como saber se esta sessão está dentro do Terminal? O Terminal preenche a variável de ambiente WT_SESSION. O pedido abaixo pergunta se ela existe:

PS C:\Users\ana> $env:WT_SESSION -ne $null
False

False quer dizer: nesta coleta, a variável estava vazia — a sessão não estava no Terminal do Windows. Se você abrir pelo aplicativo Terminal, o mesmo pedido costuma responder True.

Nesta mesma sessão, o comando Get-Command wt (o executável do Terminal) não devolveu nenhum nome: o wt não estava à mão dali. Isso não significa que o Terminal não exista no seu Windows. Se o Iniciar achar o aplicativo “Terminal”, você pode abri-lo por lá.

3. Quem está me hospedando? $Host

O objeto automático $Host descreve o anfitrião da sessão. O nome e a versão, no PowerShell 7.7 desta coleta:

PS C:\Users\ana> $Host.Name
ConsoleHost

PS C:\Users\ana> $Host.Version

Major  Minor  Build  Revision
-----  -----  -----  --------
7      7      0      -1
ConsoleHost
O host clássico do PowerShell: a janela simples de console. É o nome que apareceu nesta coleta. Outros anfitriões existem (o editor deste guia é um, o Terminal é outro ambiente), mas o nome ConsoleHost é o mais comum numa janela “PowerShell 7” do Iniciar.
7 7 0
A versão do host, aqui 7.7.0 — a mesma do PowerShell 7.7. O Revision -1 faz parte da ficha; não é erro.
No Windows PowerShell 5.1, o nome do host também foi ConsoleHost, mas a versão é a do 5.1: 
PS C:\Users\ana> $Host.Version

Major  Minor  Build  Revision
-----  -----  -----  --------
5      1      19041  6456
Se aparecer 5 e 1 nessa tabela, você está no 5.1, não no 7.

Experimente: pergunte o nome do host com $Host.Name. (O nome pode variar conforme onde você roda; o pedido é o que importa.)

Write-Output "Quem está me hospedando?"

$Host.Name

4. A pasta inicial: Get-Location

Quando a janela abre, você está em alguma pasta. No laboratório, era a pasta pessoal da Ana:

PS C:\Users\ana> Get-Location

Path
----
C:\Users\ana

O caminho C:\Users\ana é o mesmo que aparece no meio do prompt. No seu computador será C:\Users\ seguido do seu usuário. No simulador deste guia a pasta pessoal também é C:\Users\ana, e as missões começam numa pasta de teste, C:\Users\ana\guia-ps-teste: o comando é o mesmo, só o caminho muda.

Missão: mostre a pasta atual com Get-Location.

Write-Output "Onde estou?"

Get-Location
Você abriu a janela, mas o prompt não tem PS

Se a linha termina em > e não começa com PS, provavelmente é o cmd antigo, não o PowerShell. Feche, volte ao Iniciar e abra PowerShell 7 (ou, no Terminal, uma aba de PowerShell). O prompt certo parece com PS C:\Users\ana>.

Se o prompt tem PS mas $Host.Version começa com 5 e 1, você está no 5.1: feche e abra o atalho com o “7” no nome. Nada disso apaga arquivo nenhum; é só fechar a janela errada e abrir a certa.

Resumo

  • Abra o PowerShell 7 pelo Iniciar (escreva o “7”, para não cair no 5.1). O prompt começa com PS e mostra a pasta atual.
  • O Terminal do Windows é o aplicativo de abas; nele você escolhe uma aba de PowerShell 7. $env:WT_SESSION -ne $null fica True quando a sessão é dele. Nesta coleta deu False: era o console clássico.
  • $Host.Name nesta coleta foi ConsoleHost; $Host.Version mostrou 7.7.0 (no 5.1, 5.1.19041).
  • Get-Location mostra a pasta atual: no laboratório, C:\Users\ana, a mesma do prompt.
  • Se o prompt não tem PS, não é PowerShell. Se a versão do host começa com 5 e 1, não é o 7. Feche e abra o atalho certo.
