Processos (Get-Process e Stop-Process)

Cada programa aberto no computador é um processo: o navegador, o Bloco de Notas, até o próprio PowerShell. É o que você vê no Gerenciador de Tarefas. Pelo PowerShell você lista, investiga e encerra processos, e consegue responder perguntas como "quem está comendo minha memória?".

Você vai aprender
  • A listar processos com Get-Process.
  • A filtrar, ordenar e calcular memória em MB.
  • A achar o processo do próprio PowerShell ($PID).
  • A encerrar com Stop-Process, testando antes com -WhatIf.
  • A esperar um processo terminar com Wait-Process.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

A ideia: o Gerenciador de Tarefas em texto

Tudo o que você faz clicando no Gerenciador de Tarefas dá para fazer com comandos, só que com uma vantagem: dá para filtrar, ordenar, salvar em arquivo e automatizar.

2. O próprio PowerShell

A variável $PID guarda o Id do PowerShell que você está usando:

PS> Get-Process -Id $PID | Select-Object Id, ProcessName, StartTime

  Id ProcessName StartTime
  -- ----------- ---------
1476 pwsh        21/11/2026 11:33:35

4. Agrupando por nome

Navegadores abrem dezenas de processos. Quanto cada programa usa no total?

PS> Get-Process | Group-Object ProcessName | ForEach-Object { [pscustomobject]@{ Programa = $_.Name; Processos = $_.Count; MB = [math]::Round(($_.Group | Measure-Object WorkingSet64 -Sum).Sum / 1MB) } } | Sort-Object MB -Descending | Select-Object -First 5

6. Encerrando com segurança

Vamos abrir um processo de teste (um PowerShell escondido que só espera 60 segundos) e encerrá-lo. Primeiro, sempre teste com -WhatIf:

PS> $teste = Start-Process pwsh -ArgumentList '-NoProfile', '-Command', 'Start-Sleep 60' -WindowStyle Hidden -PassThru
PS> Stop-Process -Id $teste.Id -WhatIf
What If: Executando a operação "Stop-Process" no destino "pwsh (14668)".
PS> Stop-Process -Id $teste.Id
PS> $teste.WaitForExit(5000)
True
PS> $teste.HasExited
True
-PassThru
Faz o Start-Process devolver o processo criado, para você guardar o Id.
-WhatIf
Mostra o que faria, sem fazer.
Stop-Process -Id
Encerra exatamente aquele processo. Pelo nome (-Name) encerraria todos com o mesmo nome.
Cuidado com -Name Stop-Process -Name chrome fecha todas as janelas do Chrome, sem perguntar e sem salvar nada. Prefira -Id e sempre teste com -WhatIf primeiro.

7. Esperando um processo terminar

PS> $p = Start-Process pwsh -ArgumentList '-NoProfile', '-Command', 'Start-Sleep 2' -WindowStyle Hidden -PassThru
PS> Wait-Process -Id $p.Id
PS> "Terminou com código $($p.ExitCode)"
Terminou com código 0

Experimente: escreva, numa string, o comando que mostra o nome do processo do PowerShell atual usando $PID. O simulador do guia não imita esse comando; depois, rode-o de verdade no seu Windows.

# Escreva o comando numa string. Não chame o cmdlet.
$comando = ''
Write-Output $comando

# Escreva o comando numa string. Não chame o cmdlet.
$comando = '(Get-Process -Id $PID).ProcessName'
Write-Output $comando

Quando dá errado

"Não é possível localizar um processo com o nome"

Nenhum processo com esse nome está aberto. Lembre: o nome é sem .exe. Use -ErrorAction SilentlyContinue se a ausência for normal.

"Acesso negado" ao encerrar

Processos de outros usuários ou do sistema exigem PowerShell como administrador. E alguns processos do Windows não devem ser encerrados nunca.

StartTime vazio ou erro

Para processos do sistema, ler StartTime ou Path pode exigir administrador. Isso é normal.

Missão final: escreva, numa string, o comando que mostra os 3 processos que mais usam memória, com uma coluna MB. O simulador do guia não imita esse comando; depois, rode-o de verdade no seu Windows.

# Escreva o comando numa string. Não chame o cmdlet.
$comando = ''
Write-Output $comando

# Escreva o comando numa string. Não chame o cmdlet.
$comando = 'Get-Process | Sort-Object WorkingSet64 -Descending | Select-Object -First 3 ProcessName, @{ n = ''MB''; e = { [math]::Round($_.WorkingSet64 / 1MB) } }'
Write-Output $comando

Resumo

  • Get-Process lista os programas em execução.
  • Ordene por WorkingSet64 para achar os pesados.
  • Stop-Process -Id encerra; teste com -WhatIf.
  • $PID é o Id do seu PowerShell.
