Atalhos do Teclado

O PowerShell 7 vem com o módulo PSReadLine, que dá ao terminal recursos de editor: completar com Tab, buscar no histórico, sugestões enquanto você digita. Estes atalhos valem para o modo padrão no Windows.

Você vai aprender
  • Os atalhos para completar, navegar e editar a linha.
  • Como buscar comandos antigos no histórico.
  • Como usar as sugestões (IntelliSense) e trocar a forma de exibição.

Completar e sugerir

AtalhoFaz
TabCompleta o comando, parâmetro, caminho ou valor. Aperte de novo para a próxima opção.
Shift+TabVolta para a opção anterior.
Ctrl+EspaçoMostra todas as opções numa lista para escolher com as setas.
→ (seta direita)Aceita a sugestão cinza do histórico.
Ctrl+→Aceita só a próxima palavra da sugestão.
F2Troca a sugestão entre "em linha" (cinza) e "lista".

Histórico

AtalhoFaz
↑ / ↓Comando anterior / próximo.
Ctrl+RBusca no histórico enquanto você digita (aperte de novo para resultados mais antigos).
F8Busca no histórico o que começa com o que já está digitado.
Get-History / hLista o histórico da sessão; r 5 repete o comando número 5.

O PSReadLine também guarda o histórico entre sessões num arquivo; para ver onde: (Get-PSReadLineOption).HistorySavePath.

Movendo na linha

AtalhoFaz
Home / EndInício / fim da linha.
Ctrl+← / Ctrl+→Palavra anterior / próxima.
Shift+EnterNova linha sem executar (para escrever blocos).
EscApaga a linha inteira.

Editando

AtalhoFaz
Ctrl+BackspaceApaga a palavra anterior.
Ctrl+DeleteApaga a próxima palavra.
Ctrl+Z / Ctrl+YDesfaz / refaz.
Ctrl+ASeleciona a linha toda.
Shift+← / Shift+→Seleciona caractere por caractere.
Ctrl+C (com seleção) / Ctrl+VCopia / cola.
Ctrl+Shift+V / clique direitoCola (no Terminal do Windows).

Controle

AtalhoFaz
Ctrl+C (sem seleção)Interrompe o comando que está rodando.
Ctrl+LLimpa a tela (como Clear-Host).
Alt+F7Limpa o histórico da sessão.
Ctrl+Alt+?Mostra todos os atalhos configurados.

Para ver e mudar atalhos: Get-PSReadLineKeyHandler e Set-PSReadLineKeyHandler. Coloque suas mudanças no perfil.

Resumo

  • Tab e Ctrl+Espaço completam; → aceita a sugestão cinza; F2 troca a visão.
  • ↑/↓ e Ctrl+R navegam no histórico.
  • Ctrl+C interrompe; Esc limpa a linha; Shift+Enter quebra a linha.
