Listando (Get-ChildItem)

A pasta atual já é conhecida. Agora você vai abrir a gaveta e ver o que tem dentro: pastas, arquivos, os escondidos, só os .txt, ou tudo o que está nas subpastas. O comando é o Get-ChildItem ("obter os itens filhos"). Os apelidos ls, dir e gci apontam para ele; neste guia a gente usa o nome completo.

Você vai aprender
  • O Get-ChildItem, que lista o conteúdo da pasta atual.
  • A ler as colunas Mode, LastWriteTime, Length e Name.
  • Os parâmetros -Name, -Force, -File, -Directory, -Filter e -Recurse.
  • A filtrar mais de uma extensão com -Include (sempre com -Recurse).
  • A ordenar e a escolher colunas, com Sort-Object e Select-Object.
  • O erro real de uma pasta ou arquivo que não existe.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, dentro da pasta de teste C:\Users\ana\guia-ps-teste. Nela havia duas subpastas (docs e fotos), dois arquivos à vista (dados.csv e nota.txt), um arquivo escondido (.escondido) e, dentro das subpastas, docs\relatorio.txt e fotos\praia.jpg.

Os exemplos desta aula listam somente a pasta de teste. Não liste a pasta pessoal (o atalho ~) com -Force: no Windows isso pode mostrar arquivos internos da sua conta. Fique na pasta de teste.

A ideia: abrir a gaveta

Uma gaveta de arquivos tem pastas penduradas e folhas soltas. Você pode pedir "me mostra tudo o que está nesta gaveta", "só as pastas", "só as folhas", "também o que está no fundo, escondido" ou "revira as pastas de dentro". O Get-ChildItem é esse pedido. Ele não abre o conteúdo do arquivo (isso é o Get-Content, mais à frente): só lista o que existe.

Na gavetaNo PowerShell
Olhar o que está no primeiro nívelGet-ChildItem
Só os nomes, sem fichaGet-ChildItem -Name
Incluir o que estava escondidoGet-ChildItem -Force
Só folhas, ou só pastas-File ou -Directory
Revirar as pastas de dentroGet-ChildItem -Recurse

1. A lista padrão

De dentro de guia-ps-teste, sem parâmetro nenhum:

PS C:\Users\ana\guia-ps-teste> Get-ChildItem

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d----          20/11/2026    17:13                docs
d----          20/11/2026    17:13                fotos
-a---          20/11/2026    17:13              5 dados.csv
-a---          20/11/2026    17:13              4 nota.txt
Diretório: C:\Users\ana\guia-ps-teste
O cabeçalho diz qual pasta está sendo listada.
Mode
Um código de cinco letras com o tipo e os atributos do item. A gente lê ele com calma mais abaixo.
LastWriteTime
A data e a hora da última alteração. Aqui, 20/11/2026 às 17:13, no formato brasileiro.
Length
O tamanho, em bytes. Pastas deixam essa coluna em branco. dados.csv tem 5 bytes; nota.txt, 4.
Name
O nome do item. Pastas vêm primeiro, depois os arquivos, em ordem alfabética.

O arquivo escondido .escondido não apareceu. A lista padrão omite o que está marcado como oculto.

Experimente: o arquivo nota.txt já é criado. Acrescente um Get-ChildItem -Name para listar o que existe.

'oi' | Set-Content nota.txt

'oi' | Set-Content nota.txt
Get-ChildItem -Name

2. Só os nomes: -Name

PS C:\Users\ana\guia-ps-teste> Get-ChildItem -Name
docs
fotos
dados.csv
nota.txt

Sem tabela, sem data, sem tamanho: uma linha por nome. Útil quando você quer só a lista, por exemplo para contar ou para passar adiante numa esteira.

3. Mostrando o escondido: -Force

PS C:\Users\ana\guia-ps-teste> Get-ChildItem -Force

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d----          20/11/2026    17:13                docs
d----          20/11/2026    17:13                fotos
-a-h-          20/11/2026    17:13              0 .escondido
-a---          20/11/2026    17:13              5 dados.csv
-a---          20/11/2026    17:13              4 nota.txt

Agora aparece o .escondido, com tamanho 0 e o h no Mode (de hidden, "oculto"). O -Force aqui quer dizer "não omita os ocultos"; ele não apaga nem altera nada. Use-o na pasta de teste, não na pasta pessoal.

4. Só arquivos, ou só pastas

PS C:\Users\ana\guia-ps-teste> Get-ChildItem -File

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              5 dados.csv
-a---          20/11/2026    17:13              4 nota.txt

O -File deixou de fora as pastas docs e fotos.

PS C:\Users\ana\guia-ps-teste> Get-ChildItem -Directory

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d----          20/11/2026    17:13                docs
d----          20/11/2026    17:13                fotos

O -Directory fez o contrário: só as pastas. ("Directory" é o nome técnico de pasta.)

5. Filtrando pelo nome: -Filter

O asterisco de novo: *.txt é "qualquer nome que termine em .txt".

PS C:\Users\ana\guia-ps-teste> Get-ChildItem -Filter *.txt

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              4 nota.txt

Só o nota.txt da pasta atual. O docs\relatorio.txt não entrou, porque o -Filter sozinho não desce nas subpastas. Para isso falta o -Recurse.

Missão: há um .txt e um .csv. Liste só o .txt, com -Filter e -Name.

'a' | Set-Content nota.txt
'b' | Set-Content dados.csv
Get-ChildItem -Name

'a' | Set-Content nota.txt
'b' | Set-Content dados.csv
Get-ChildItem -Filter *.txt -Name

6. Descendo nas subpastas: -Recurse

PS C:\Users\ana\guia-ps-teste> Get-ChildItem -Recurse

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d----          20/11/2026    17:13                docs
d----          20/11/2026    17:13                fotos
-a---          20/11/2026    17:13              5 dados.csv
-a---          20/11/2026    17:13              4 nota.txt

    Diretório: C:\Users\ana\guia-ps-teste\docs

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              3 relatorio.txt

    Diretório: C:\Users\ana\guia-ps-teste\fotos

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              3 praia.jpg

A saída vem em blocos, um por pasta: primeiro o conteúdo de guia-ps-teste, depois o de docs (com relatorio.txt, 3 bytes) e o de fotos (com praia.jpg, 3 bytes). "Recurse" quer dizer "repete o mesmo pedido lá dentro".

Juntando o filtro com o "revira tudo", e pedindo só os nomes:

PS C:\Users\ana\guia-ps-teste> Get-ChildItem -Recurse -Filter *.txt -Name
nota.txt
docs\relatorio.txt

Agora sim: nota.txt e docs\relatorio.txt. A barra invertida no segundo nome mostra que ele está dentro de docs.

7. Mais de uma extensão: -Include

O -Include aceita vários padrões, separados por vírgula. Ele só funciona de verdade quando vai junto com o -Recurse (ou com um caminho que já termine em *):

PS C:\Users\ana\guia-ps-teste> Get-ChildItem -Include *.txt, *.csv -Recurse

    Diretório: C:\Users\ana\guia-ps-teste\docs

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              3 relatorio.txt

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              5 dados.csv
-a---          20/11/2026    17:13              4 nota.txt

Vieram o relatorio.txt (de dentro de docs), o dados.csv e o nota.txt. O praia.jpg ficou de fora, como combinado.

8. Ordenando e escolhendo colunas

A esteira | de novo, agora para arrumar a lista. O Sort-Object Length -Descending ordena pelo tamanho, do maior para o menor:

PS C:\Users\ana\guia-ps-teste> Get-ChildItem | Sort-Object Length -Descending

    Diretório: C:\Users\ana\guia-ps-teste

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          20/11/2026    17:13              5 dados.csv
-a---          20/11/2026    17:13              4 nota.txt
d----          20/11/2026    17:13                docs
d----          20/11/2026    17:13                fotos

Os arquivos vêm primeiro (dados.csv com 5 bytes, nota.txt com 4); as pastas, sem tamanho, ficam no fim. O Select-Object pega só as colunas que você quer:

PS C:\Users\ana\guia-ps-teste> Get-ChildItem | Select-Object Name, Length, LastWriteTime

Name      Length LastWriteTime
----      ------ -------------
docs             20/11/2026 17:13:00
fotos            20/11/2026 17:13:00
dados.csv 5      20/11/2026 17:13:00
nota.txt  4      20/11/2026 17:13:00

Aqui a hora aparece com os segundos (17:13:00). Pastas não têm Length, então essa coluna fica vazia na linha delas. Os dois cmdlets — ordenar e escolher colunas — voltam com calma no Nível 2.

9. Lendo a coluna Mode

Cada letra (ou hífen) da coluna Mode é um atributo. Pedimos só Mode e Name, incluindo o escondido:

PS C:\Users\ana\guia-ps-teste> Get-ChildItem -Force | Format-Table Mode, Name

Mode  Name
----  ----
d---- docs
d---- fotos
-a-h- .escondido
-a--- dados.csv
-a--- nota.txt
SímboloQuer dizer
d no começoÉ uma pasta (directory). Sem o d (um hífen no lugar), é arquivo.
aArchive: o arquivo foi alterado desde o último backup. É comum em arquivos comuns do Windows; você não precisa se preocupar com ele agora.
hHidden: o item está oculto. Só aparece com -Force.
-Aquele atributo está desligado.

Então d---- é pasta, -a--- é um arquivo comum e -a-h- é um arquivo oculto. Existem outras letras (r de somente leitura, s de sistema); quando aparecerem, a lógica é a mesma.

Formas diferentes de listar

FormaQuando usar
Get-ChildItemA lista padrão da pasta atual, com data e tamanho.
Get-ChildItem -NameQuando você só quer os nomes.
Get-ChildItem -ForceQuando também quer os ocultos (na pasta de teste).
-File ou -DirectoryPara ficar só com arquivos ou só com pastas.
-Filter *.txtPara um padrão de nome na pasta atual.
-RecursePara incluir o que está nas subpastas.
ls / dir / gciApelidos, só no terminal. Nos scripts, o nome completo.

Quando dá errado

O caminho não existe

Pedimos para listar uma pasta que não estava em guia-ps-teste:

PS C:\Users\ana\guia-ps-teste> Get-ChildItem naoexiste
Get-ChildItem: Não é possível localizar o caminho 'C:\Users\ana\guia-ps-teste\naoexiste' porque ele não existe.
Get-ChildItem:
Quem está reclamando.
Não é possível localizar o caminho '…\naoexiste' porque ele não existe.
O PowerShell juntou o nome naoexiste com a pasta atual e não achou esse caminho no disco.

Como resolver: confira o nome e se você já está na pasta certa (use o Get-Location). O erro não apaga nada. Se a dúvida for "será que existe?", o comando certo mais à frente é o Test-Path.

Resumo

  • Get-ChildItem lista o que há na pasta atual: pastas primeiro, depois arquivos, sem os ocultos.
  • A coluna Mode diz o tipo (d = pasta, h = oculto); Length é o tamanho em bytes.
  • -Name, -Force, -File, -Directory, -Filter e -Recurse apertam ou alargam a lista.
  • -Include aceita vários padrões, mas vai junto com o -Recurse.
  • Se o caminho não existe, a mensagem é "não é possível localizar o caminho". Nada é apagado.
  • Pratique na pasta de teste. Não liste a pasta pessoal com -Force.
