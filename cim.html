Informações do Computador (Get-CimInstance)

Qual versão do Windows está instalada? Quanto espaço sobra no disco? Quanto de memória tem? Há quanto tempo o computador está ligado? O Get-CimInstance consulta o "banco de dados" interno do Windows (o CIM/WMI) e responde tudo isso em forma de objetos.

Você vai aprender
  • A consultar classes com Get-CimInstance.
  • Sistema operacional, processador, memória e BIOS.
  • Espaço livre em disco em GB.
  • Tempo ligado (uptime).
  • A filtrar com -Filter.

só Windows As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

A ideia: a ficha técnica

Todo computador tem uma ficha técnica, como a de um carro. O Windows mantém essa ficha atualizada em classes (uma para o sistema, uma para o disco, uma para o processador...). Você pergunta pela classe e recebe os dados.

1. O sistema operacional

PS> Get-CimInstance Win32_OperatingSystem | Select-Object Caption, Version, OSArchitecture

Caption                                   Version    OSArchitecture
-------                                   -------    --------------
Microsoft Windows 10 Pro for Workstations 10.0.19045 64 bits
Get-CimInstance
Consulta uma classe do CIM.
Win32_OperatingSystem
A classe com dados do Windows instalado.

2. Processador e memória

PS> Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, NumberOfLogicalProcessors
(saída não mostrada: o modelo do processador ajuda a identificar o computador)
PS> $cs = Get-CimInstance Win32_ComputerSystem
PS> "Memória: {0:N1} GB" -f ($cs.TotalPhysicalMemory / 1GB)
Memória: 16,0 GB

3. Discos e espaço livre

PS> Get-CimInstance Win32_LogicalDisk -Filter "DriveType = 3" | Select-Object DeviceID, @{ n = 'TamanhoGB'; e = { [math]::Round($_.Size / 1GB, 1) } }, @{ n = 'LivreGB'; e = { [math]::Round($_.FreeSpace / 1GB, 1) } }, @{ n = 'Livre%'; e = { [math]::Round($_.FreeSpace / $_.Size * 100) } }

DeviceID TamanhoGB LivreGB Livre%
-------- --------- ------- ------
C:          465,00  120,00  26,00
-Filter "DriveType = 3"
Só discos locais (3). Pendrives são 2, unidades de rede 4.
FreeSpace / Size
Em bytes; dividimos por 1GB para ficar legível.

O filtro usa a linguagem do WMI (WQL): =, <>, >, AND, LIKE 'C%'. Filtrar no -Filter é mais rápido que trazer tudo e usar Where-Object.

4. Há quanto tempo está ligado

PS> $os = Get-CimInstance Win32_OperatingSystem
PS> $ligado = (Get-Date) - $os.LastBootUpTime
PS> "Ligado há {0} dias e {1} horas" -f $ligado.Days, $ligado.Hours
Ligado há 0 dias e 0 horas

No PowerShell 7 também existe o atalho Get-Uptime.

5. BIOS e fabricante

PS> Get-CimInstance Win32_BIOS | Select-Object Manufacturer, SMBIOSBIOSVersion
(saída não mostrada: a versão da BIOS ajuda a identificar o computador)
PS> Get-CimInstance Win32_ComputerSystem | Select-Object Manufacturer, Model
(saída não mostrada: fabricante e modelo ajudam a identificar o computador)

Experimente: escreva, numa string, o comando que mostra o espaço livre do disco C: em GB, no formato Livre: 123,4 GB. O simulador do guia não imita esse comando; depois, rode-o de verdade no seu Windows.

# Escreva o comando numa string. Não chame o cmdlet.
$comando = ''
Write-Output $comando

# Escreva o comando numa string. Não chame o cmdlet.
$comando = '"Livre: {0:N1} GB" -f ((Get-CimInstance Win32_LogicalDisk -Filter "DeviceID = ''C:''").FreeSpace / 1GB)'
Write-Output $comando

Quando dá errado

"Classe inválida"

O nome da classe está errado. Procure com Get-CimClass -ClassName *parte*.

"Consulta inválida" no -Filter

O filtro usa WQL, não PowerShell: é = (não -eq) e texto vai entre aspas simples: -Filter "Name = 'pwsh.exe'".

Get-WmiObject não existe

Get-WmiObject é do Windows PowerShell 5.1 e foi removido no 7. Use Get-CimInstance, que faz o mesmo.

Referência rápida

ClasseO que tem
Win32_OperatingSystemWindows, versão, último boot, memória livre.
Win32_ComputerSystemFabricante, modelo, memória total.
Win32_ProcessorProcessador e núcleos.
Win32_LogicalDiskDiscos e espaço.
Win32_BIOSBIOS.
Win32_NetworkAdapterConfigurationPlacas de rede.
Win32_ProductEvite: é lento e pode disparar reparos de programas.

Resumo

  • Get-CimInstance Classe consulta a ficha técnica do Windows.
  • Win32_OperatingSystem, Win32_LogicalDisk e Win32_Processor são as mais usadas.
  • Filtre no -Filter (linguagem WQL) para ser rápido.
  • Get-WmiObject não existe no PowerShell 7.
