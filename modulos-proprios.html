Criando seu Módulo (.psm1)

Quando você junta várias funções úteis, chega a hora de empacotar tudo num módulo: um arquivo .psm1 que você carrega com Import-Module. Com ele, você escolhe o que fica visível, compartilha com colegas e carrega tudo com uma linha.

Você vai aprender
  • A criar um arquivo .psm1 com funções.
  • A carregar com Import-Module e listar os comandos do módulo.
  • A esconder funções auxiliares com Export-ModuleMember.
  • A recarregar depois de mudar o código (-Force).
  • O que é o manifesto .psd1 e onde guardar o módulo para carregar sozinho.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a caixa de ferramentas

Dot-sourcing é deixar as ferramentas soltas na bancada. Um módulo é a caixa: tem etiqueta (nome), tem divisórias (o que é público e o que é interno) e você leva para onde quiser.

1. O primeiro módulo

Um módulo é só um arquivo com a extensão .psm1:

PS> Set-Content Conversor.psm1 @'
>> function ConvertTo-Fahrenheit { param([double]$Celsius) $Celsius * 9 / 5 + 32 }
>> function ConvertTo-Celsius { param([double]$Fahrenheit) [math]::Round(($Fahrenheit - 32) * 5 / 9, 1) }
>> function Get-Fator { 1.8 }
>> Export-ModuleMember -Function ConvertTo-Fahrenheit, ConvertTo-Celsius
>> '@
.psm1
A extensão de módulo de script.
Export-ModuleMember
Diz quais funções ficam públicas. Get-Fator é interna: os comandos do módulo usam, mas quem importa não vê.

2. Importando e usando

PS> Import-Module .\Conversor.psm1
PS> ConvertTo-Fahrenheit 30
86
PS> ConvertTo-Celsius 100
37,8
PS> (Get-Command -Module Conversor).Name
ConvertTo-Celsius
ConvertTo-Fahrenheit
PS> Get-Command Get-Fator -ErrorAction SilentlyContinue | Measure-Object | ForEach-Object Count
0

O nome do módulo é o nome do arquivo (Conversor). Get-Fator não foi exportada, por isso não aparece.

3. Mudou o código? Recarregue

O Import-Module não carrega de novo um módulo que já está na memória. Depois de editar o arquivo, use -Force:

PS> Add-Content Conversor.psm1 'function Get-Versao { "1.1" }; Export-ModuleMember -Function Get-Versao'
PS> Import-Module .\Conversor.psm1 -Force
PS> Get-Versao
1.1

E para tirar o módulo da sessão:

PS> Remove-Module Conversor
PS> Get-Module Conversor | Measure-Object | ForEach-Object Count
0

4. O manifesto (.psd1)

Para compartilhar, o módulo ganha um manifesto: um arquivo .psd1 com versão, autor, descrição e o que é exportado. O New-ModuleManifest cria o arquivo para você:

New-ModuleManifest .\Conversor.psd1 -RootModule Conversor.psm1 -ModuleVersion 1.1.0 -Author "Ana" -Description "Converte temperaturas" -FunctionsToExport ConvertTo-Fahrenheit, ConvertTo-Celsius, Get-Versao

Depois disso, você importa pelo .psd1, e o PowerShell lê a versão e as funções dali.

5. Carregar sozinho, pelo nome

O PowerShell procura módulos nas pastas da variável $env:PSModulePath. Se você criar a pasta Conversor (com o mesmo nome do módulo) dentro de uma delas e colocar lá o Conversor.psm1 e o Conversor.psd1, basta digitar ConvertTo-Celsius em qualquer sessão: o módulo carrega sozinho. No Windows, a pasta do seu usuário é Documentos\PowerShell\Modules.

$env:PSModulePath -split ';'

Experimente: o módulo já foi gravado. Importe .\Conversor.psm1 e converta 30 °C com ConvertTo-Fahrenheit 30.

Set-Content Conversor.psm1 'function ConvertTo-Fahrenheit { param([double]$Celsius) $Celsius * 9 / 5 + 32 }'
ConvertTo-Fahrenheit 30

Set-Content Conversor.psm1 'function ConvertTo-Fahrenheit { param([double]$Celsius) $Celsius * 9 / 5 + 32 }'
Import-Module .\Conversor.psm1
ConvertTo-Fahrenheit 30

Quando dá errado

Mudei o arquivo e nada mudou

Sem -Force, o Import-Module usa a versão que já está na memória. Use Import-Module .\Arquivo.psm1 -Force ou abra uma sessão nova.

Pasta com nome diferente do módulo

Para carregar sozinho pelo $env:PSModulePath, a pasta precisa ter o mesmo nome do arquivo: Modules\Conversor\Conversor.psm1. Com outro nome, o PowerShell não encontra.

Verbo fora da lista

Se uma função exportada usar um verbo que não está no Get-Verb (por exemplo Calcular-Total), o Import-Module mostra um aviso. Use verbos aprovados (veja Estilo e Verbos Aprovados).

Resumo

  • Um módulo é um arquivo .psm1 com funções; carregue com Import-Module.
  • Export-ModuleMember escolhe o que é público.
  • -Force recarrega depois de mudanças.
  • Manifesto .psd1 + pasta no $env:PSModulePath = módulo que carrega sozinho.
