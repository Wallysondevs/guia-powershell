PowerShell Conversão de Tipos ([int], [string])

A Ana leu as quantidades do estoque de um arquivo, mas a soma deu "105" em vez de 15. O motivo: tudo que vem de arquivo e do teclado chega como texto. Nesta aula, você aprende a transformar um tipo em outro.

Você vai aprender
  • A converter um valor de um tipo para outro com [int], [string], [double], [datetime].
  • A pegadinha da vírgula em [double]"3,14".
  • O operador -as, que não dá erro, e o -is, que pergunta o tipo.
  • A pegadinha do [bool]"false", e os erros reais de conversão.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: trocar de embalagem

O número 42 pode vir escrito num papel (texto "42") ou estar na calculadora (número 42). Para fazer conta, você precisa passar do papel para a calculadora. Converter é trocar o valor de embalagem: de texto para número, de texto para data, de número para texto. Isso acontece muito com dados lidos de arquivos e do teclado, que sempre chegam como texto.

1. Conversão com colchetes

Escreva o tipo entre colchetes antes do valor:

PS C:\Users\ana> [int]"42"
42
PS C:\Users\ana> [string]42
42
PS C:\Users\ana> [datetime]"2026-11-20"

sexta-feira, 20 de novembro de 2026 00:00:00

Na tela, 42 e "42" parecem iguais, mas o primeiro é número (soma) e o segundo é texto (junta). A data aceitou o formato ano-mês-dia e foi mostrada em português.

2. A pegadinha da vírgula

PS C:\Users\ana> [double]"3,14"
314
PS C:\Users\ana> [double]"3.14"
3,14
PS C:\Users\ana> [int]3.9
4

Atenção: [double]"3,14" deu 314. A conversão com colchetes sempre usa o padrão americano, em que o decimal é o ponto e a vírgula é só separador de milhar. Com "3.14" deu certo. E [int]3.9 arredondou para 4 (não cortou as casas).

Cuidado com planilhas brasileiras: um preço escrito "3,14" num arquivo vira 314. Troque a vírgula por ponto antes: [double]("3,14" -replace ",", ".").

Experimente: os dois valores chegaram como texto, então o + juntou em vez de somar. Converta com [int].

$a = "10"
$b = "5"
"Total: $($a + $b)"

$a = "10"
$b = "5"
"Total: $([int]$a + [int]$b)"

3. O operador -as: tenta, sem erro

PS C:\Users\ana> "42" -as [int]
42
PS C:\Users\ana> "abc" -as [int]
PS C:\Users\ana> $null -eq ("abc" -as [int])
True

Quando a conversão não é possível, o -as ("como") devolve $null em vez de dar erro. Ótimo para conferir se um texto é um número.

4. O operador -is: pergunta o tipo

PS C:\Users\ana> 42 -is [int]
True
PS C:\Users\ana> "42" -is [int]
False
PS C:\Users\ana> "42" -is [string]
True
PS C:\Users\ana> (1, 2) -is [array]
True

5. A pegadinha do [bool]

PS C:\Users\ana> [bool]0
False
PS C:\Users\ana> [bool]1
True
PS C:\Users\ana> [bool]""
False
PS C:\Users\ana> [bool]"false"
True
PS C:\Users\ana> [bool]$null
False

O texto "false" virou True! Para o [bool], qualquer texto que não está vazio é verdadeiro, não importa o que está escrito. Veja $true, $false e $null.

Qual usar

FormaQuando
[int]$xVocê tem certeza de que dá para converter (erro se não der).
$x -as [int]Pode não dar; você quer $null em vez de erro.
$x -is [int]Só quer saber o tipo, sem converter.

Quando dá errado

Texto que não é número 
PS C:\Users\ana> [int]"abc"
InvalidArgument: Cannot convert value "abc" to type "System.Int32". Error: "The input string 'abc' was not in a correct format."

"Não consigo converter o valor abc para o tipo Int32. A entrada não está num formato correto." Como resolver: confira o valor, ou use -as [int] e teste se veio $null.

Texto que não é data 
PS C:\Users\ana> [datetime]"não é data"
InvalidArgument: Cannot convert value "não é data" to type "System.DateTime". Error: "The string 'não é data' was not recognized as a valid DateTime. There is an unknown word starting at index '0'."

"O texto não foi reconhecido como uma data válida. Há uma palavra desconhecida começando na posição 0." Como resolver: use o formato "2026-11-20" (ano-mês-dia), que funciona sempre.

Exercícios

Complete para converter o texto em inteiro:

2. Sem erro

Complete para tentar converter sem dar erro:

"abc" [int]

3. Quanto dá [double]"3,14"?

4. O que [bool]"false" mostra?

Missão final: use -as [int] para mostrar Inválido quando $entrada não for número.

$entrada = "doze"
$numero = [int]$entrada
$numero

$entrada = "doze"
$numero = $entrada -as [int]
if ($null -eq $numero) { "Inválido" } else { $numero }

Resumo

  • [tipo]valor converte; dá erro se não der.
  • -as [tipo] converte ou devolve $null.
  • -is [tipo] responde True ou False.
  • Conversão usa o ponto como decimal: [double]"3,14" vira 314.
  • Qualquer texto não vazio vira True no [bool].
