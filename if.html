PowerShell if: Tomando Decisões

A Ana corrige as provas da turma: nota 7 ou mais, aprovada. Na lojinha, se o estoque de um produto cai abaixo de 5, é hora de comprar mais. Até aqui, os scripts faziam tudo, sempre, de cima para baixo. Com o if ("se"), o script passa a decidir: faz uma coisa só quando uma condição é verdadeira.

Você vai aprender
  • A escrever um if com a condição entre ( ) e o bloco entre { }.
  • Que a condição sempre vira True (verdadeiro) ou False (falso).
  • Quais valores o PowerShell considera falsos: 0, texto vazio, $null e lista vazia.
  • A colocar várias linhas dentro do bloco.
  • A reconhecer os erros reais mais comuns, inclusive o = no lugar de -eq.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: o porteiro com a lista

Pense num porteiro de festa. Ele olha para quem chega e faz uma pergunta só: "o nome está na lista?". Se a resposta é sim, a pessoa entra. Se é não, nada acontece, e a fila segue. O if é esse porteiro: a pergunta é a condição, e o que fica dentro das chaves só acontece quando a resposta é sim.

1. O if simples

PS C:\Users\ana> $nota = 8
PS C:\Users\ana> if ($nota -ge 7) { "Aprovada" }
Aprovada
if
"Se". É uma palavra da linguagem, não um cmdlet: não tem verbo-substantivo.
($nota -ge 7)
A condição, sempre entre parênteses. -ge quer dizer "maior ou igual" (greater or equal). Os outros operadores estão na aula Operadores de Comparação.
{ "Aprovada" }
O bloco, entre chaves: o que roda quando a condição é verdadeira.

Agora com nota 5:

PS C:\Users\ana> $nota = 5
PS C:\Users\ana> if ($nota -ge 7) { "Aprovada" }

Nada apareceu. A condição foi falsa, então o bloco foi pulado, e o PowerShell voltou ao prompt sem mostrar nada. Não é erro: é exatamente o que o if deve fazer. Para mostrar outra coisa quando é falso, existe o else (aula elseif e else).

Experimente: o aviso deveria aparecer quando o estoque é menor que 5, mas o operador está errado. Troque -gt ("maior que") por -lt ("menor que") e rode.

$estoque = 2
if ($estoque -gt 5) {
    'Estoque baixo'
}

$estoque = 2
if ($estoque -lt 5) {
    'Estoque baixo'
}

2. A condição vira verdadeiro ou falso

A condição é uma pergunta, e a resposta é sempre True ou False. Você pode ver a resposta digitando só a condição:

PS C:\Users\ana> $nota -ge 7
False
PS C:\Users\ana> 8 -ge 7
True

Com $nota valendo 5, "5 é maior ou igual a 7?" dá False. "8 é maior ou igual a 7?" dá True. O if só olha essa resposta. Mais sobre True, False e $null na aula Booleanos e $null.

3. Valores que contam como falso

A condição nem precisa ser uma comparação. Qualquer valor serve, e o PowerShell decide se ele "conta como" verdadeiro ou falso. Aqui o else mostra o que aconteceu quando a condição foi falsa:

PS C:\Users\ana> if (0) { "sim" } else { "0 é falso" }
0 é falso
PS C:\Users\ana> if ("") { "sim" } else { "texto vazio é falso" }
texto vazio é falso
PS C:\Users\ana> if ($null) { "sim" } else { "$null é falso" }
 é falso
PS C:\Users\ana> if ("0") { "texto '0' é verdadeiro" }
texto '0' é verdadeiro
PS C:\Users\ana> if (@()) { "sim" } else { "lista vazia é falsa" }
lista vazia é falsa
0
O número zero é falso. Qualquer outro número é verdadeiro.
""
Um texto vazio é falso.
$null
"Nada" é falso. Repare na resposta: saiu só é falso. Isso acontece porque, entre aspas duplas, o $null virou o valor dele, que é nada. Veja em "Quando dá errado".
"0"
Pegadinha: o texto "0" não é vazio, então é verdadeiro.
@()
Uma lista vazia é falsa (aula Arrays).

4. Várias linhas no bloco

O bloco pode ter quantas linhas você quiser. No terminal, enquanto a chave { está aberta, o prompt muda para >>: o PowerShell está esperando o resto.

PS C:\Users\ana> $estoque = 3
PS C:\Users\ana> if ($estoque -lt 5) {
>>     Write-Output "Estoque baixo: $estoque unidades"
>>     Write-Output "Hora de comprar mais"
>> }
Estoque baixo: 3 unidades
Hora de comprar mais
{ na mesma linha do if
O costume do guia: a chave que abre fica no fim da linha do if.
4 espaços
As linhas de dentro ficam recuadas. O PowerShell não exige, mas o recuo mostra, de olho, o que está dentro do if.
}
Fecha o bloco. Só depois dela o PowerShell roda tudo.

Formas diferentes de decidir

FormaQuando usar
if (cond) { … } numa linhaNo terminal, para algo curto.
if (cond) { + linhas + }Nos scripts: mais fácil de ler e de crescer.
if … else …Quando há duas saídas: "aprovada" ou "reprovada" (aula elseif e else).
if … elseif … elseVárias faixas: excelente, boa, regular (mesma aula).
switchMuitas comparações com o mesmo valor (aula switch).

Quando dá errado

Usou = no lugar de -eq 
PS C:\Users\ana> if ($nota = 10) { "sempre entra: isso é atribuição" }; "nota agora vale $nota"
sempre entra: isso é atribuição
nota agora vale 10

Não aparece erro, e é por isso que esse engano é perigoso. No PowerShell, = guarda um valor (atribuição), não compara. O if guardou 10 em $nota, e o 10, como qualquer número diferente de zero, conta como verdadeiro. Resultado: o bloco sempre roda, e a nota antiga foi perdida.

Como resolver: para comparar, use -eq ("igual", equal): if ($nota -eq 10).

Esqueceu as chaves 
PS C:\Users\ana> if ($nota -ge 7) "Aprovada"
ParserError:
Line |
   1 |  if ($nota -ge 7) "Aprovada"
     |                 ~
     | Missing statement block after if ( condition ).
ParserError
Erro de leitura do código: o PowerShell recusou a linha antes de rodar qualquer coisa. Esses erros saem em inglês no PowerShell 7.7, mesmo num Windows em português.
Line | 1
A linha com o problema, repetida ao lado.
~
O tracinho aponta logo depois do ), onde o PowerShell esperava a chave {.
Missing statement block after if ( condition )
Quer dizer que falta o bloco de comandos depois da condição do if. O "Aprovada" precisa estar entre { }, mesmo sendo uma linha só.

Como resolver: if ($nota -ge 7) { "Aprovada" }.

Esqueceu os parênteses 
PS C:\Users\ana> if $nota -ge 7 { "Aprovada" }
ParserError:
Line |
   1 |  if $nota -ge 7 { "Aprovada" }
     |    ~
     | Missing '(' after 'if' in if statement.

O tracinho aponta logo depois do if: a mensagem quer dizer que faltou abrir parênteses ali. Em outras linguagens a condição pode ir solta; no PowerShell, os parênteses são obrigatórios.

Como resolver: if ($nota -ge 7) { "Aprovada" }.

O texto saiu sem a palavra $null

Na seção 3, "$null é falso" mostrou só é falso. Entre aspas duplas, tudo que começa com $ é trocado pelo valor (aula Interpolação), e o valor de $null é nada.

Como resolver: quando o texto não tem variável, use aspas simples: '$null é falso' mostra o texto como está.

Referência rápida

Você digitaO que faz
if ($x -ge 7) { … }Roda o bloco se $x for maior ou igual a 7.
-eq, -neIgual, diferente.
-gt, -geMaior, maior ou igual.
-lt, -leMenor, menor ou igual.
0, "", $null, @()Contam como falso.
"0", qualquer número diferente de 0Contam como verdadeiro.
=Guarda valor. Não use para comparar.

Exercícios

1. Complete o comando

Mostre "Passou" se $nota for maior ou igual a 7:

($nota -ge 7) { "Passou" }

2. O operador

Complete para mostrar "Promoção!" quando $preco for menor que 10:

if ($preco 10) { "Promoção!" }

3. Igual de verdade

Complete para comparar (e não guardar) a nota com 10:

if ($nota 10) { "Nota máxima" }

4. Com $nota = 5, o que if ($nota -ge 7) { "Aprovada" } mostra?

5. Qual destes valores conta como verdadeiro?

6. Por que if ($nota = 10) sempre entra no bloco?

Missão final: escreva um if que mostre Leve água quando $temperatura for maior ou igual a 30.

$temperatura = 32


$temperatura = 32
if ($temperatura -ge 30) {
    'Leve água'
}

Resumo

  • if (condição) { bloco }: o bloco só roda quando a condição é verdadeira.
  • Os parênteses e as chaves são obrigatórios.
  • A condição vira True ou False. 0, "", $null e @() contam como falso; o texto "0" conta como verdadeiro.
  • Condição falsa sem else: nada aparece, e não é erro.
  • Para comparar, use -eq, nunca =.
