Projeto: Lista de Tarefas (JSON)

Neste projeto você constrói um pequeno gerenciador de tarefas de terminal. As tarefas ficam num arquivo tarefas.json, e quatro funções fazem o trabalho: adicionar, listar, concluir e remover. Ele junta o que você viu em funções, objetos e JSON.

Você vai aprender
  • A guardar uma lista de objetos num arquivo JSON e ler de volta.
  • A organizar o projeto em funções pequenas com verbos aprovados.
  • A gerar um número (Id) para cada tarefa.
  • A filtrar e formatar a lista.
  • A tratar o caso do arquivo que ainda não existe.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

O plano

FunçãoO que faz
Get-TarefaLê o arquivo e devolve as tarefas (com filtro opcional de pendentes).
Add-TarefaCria uma tarefa com Id, título, prioridade e data.
Complete-TarefaMarca uma tarefa como feita.
Remove-TarefaApaga uma tarefa pelo Id.

Todas usam duas funções internas: uma que lê o JSON e outra que grava.

1. Ler e gravar

PS> $Arquivo = "tarefas.json"
PS> function Read-Tarefas {
>>     if (-not (Test-Path $Arquivo)) { return @() }
>>     $dados = Get-Content $Arquivo -Raw | ConvertFrom-Json
>>     return @($dados)
>> }
PS> function Save-Tarefas { param([object[]]$Lista)
>>     ConvertTo-Json -InputObject @($Lista) -Depth 3 | Set-Content $Arquivo
>> }
if (-not (Test-Path $Arquivo))
Na primeira vez, o arquivo não existe: devolvemos uma lista vazia.
@(Read-Tarefas)
Quem chama também usa @(...). Ao sair de uma função, um array é "desenrolado" no pipeline: uma lista com uma tarefa só chegaria como um objeto solto, e o $lista + $nova daria erro. O @() em volta da chamada garante que é sempre uma lista.
ConvertTo-Json -InputObject @($Lista)
Grava sempre como lista JSON ([...]), mesmo com zero ou um item.

2. Adicionar

PS> function Add-Tarefa {
>>     param(
>>         [Parameter(Mandatory)][string]$Titulo,
>>         [ValidateSet("Alta", "Media", "Baixa")][string]$Prioridade = "Media"
>>     )
>>     $lista = @(Read-Tarefas)
>>     $proximo = if ($lista.Count) { ($lista | Measure-Object Id -Maximum).Maximum + 1 } else { 1 }
>>     $nova = [pscustomobject]@{
>>         Id         = [int]$proximo
>>         Titulo     = $Titulo
>>         Prioridade = $Prioridade
>>         Feita      = $false
>>         Criada     = "2026-11-21"
>>     }
>>     Save-Tarefas ($lista + $nova)
>>     "Tarefa $($nova.Id) adicionada: $Titulo"
>> }
PS> Add-Tarefa "Pagar a conta de luz" -Prioridade Alta
Tarefa 1 adicionada: Pagar a conta de luz
PS> Add-Tarefa "Comprar café"
Tarefa 2 adicionada: Comprar café
PS> Add-Tarefa "Estudar PowerShell" -Prioridade Alta
Tarefa 3 adicionada: Estudar PowerShell

Para o exemplo ficar igual no seu computador, a data está fixa. No seu projeto, use Criada = Get-Date -Format "yyyy-MM-dd".

3. Listar

PS> function Get-Tarefa { param([switch]$Pendentes)
>>     $lista = @(Read-Tarefas)
>>     if ($Pendentes) { $lista = $lista | Where-Object { -not $_.Feita } }
>>     $lista | Sort-Object @{ Expression = { @{ Alta = 1; Media = 2; Baixa = 3 }[$_.Prioridade] } }, Id
>> }
PS> Get-Tarefa | Format-Table Id, Titulo, Prioridade, Feita

Id Titulo               Prioridade Feita
-- ------               ---------- -----
 1 Pagar a conta de luz Alta       False
 3 Estudar PowerShell   Alta       False
 2 Comprar café         Media      False
@{ Expression = { ... } }
Ordena por uma conta: Alta vira 1, Media 2, Baixa 3. Depois desempata pelo Id.

4. Concluir e remover

PS> function Complete-Tarefa { param([Parameter(Mandatory)][int]$Id)
>>     $lista = @(Read-Tarefas)
>>     $alvo = $lista | Where-Object Id -eq $Id
>>     if (-not $alvo) { Write-Warning "Não existe tarefa $Id."; return }
>>     $alvo.Feita = $true
>>     Save-Tarefas $lista
>>     "Concluída: $($alvo.Titulo)"
>> }
PS> function Remove-Tarefa { param([Parameter(Mandatory)][int]$Id)
>>     $lista = @(Read-Tarefas)
>>     $resto = @($lista | Where-Object Id -ne $Id)
>>     if ($resto.Count -eq $lista.Count) { Write-Warning "Não existe tarefa $Id."; return }
>>     Save-Tarefas $resto
>>     "Removida a tarefa $Id."
>> }
PS> Complete-Tarefa 1
Concluída: Pagar a conta de luz
PS> Remove-Tarefa 2
Removida a tarefa 2.
PS> Get-Tarefa | Format-Table Id, Titulo, Prioridade, Feita

Id Titulo               Prioridade Feita
-- ------               ---------- -----
 1 Pagar a conta de luz Alta        True
 3 Estudar PowerShell   Alta       False
PS> Get-Tarefa -Pendentes | ForEach-Object Titulo
Estudar PowerShell

6. Juntando tudo num módulo

Coloque as seis funções num arquivo Tarefas.psm1, troque $Arquivo por Join-Path $HOME "tarefas.json" (assim a lista é a mesma de qualquer pasta) e importe no seu perfil. Veja Criando seu Módulo.

Experimente: as funções básicas já estão prontas. Adicione a tarefa Regar as plantas.

$Arquivo = "tarefas.json"
function Read-Tarefas { if (-not (Test-Path $Arquivo)) { return @() }; @(Get-Content $Arquivo -Raw | ConvertFrom-Json) }
function Save-Tarefas { param([object[]]$Lista) ConvertTo-Json -InputObject @($Lista) -Depth 3 | Set-Content $Arquivo }
function Add-Tarefa { param([string]$Titulo)
    $lista = @(Read-Tarefas)
    $nova = [pscustomobject]@{ Id = $lista.Count + 1; Titulo = $Titulo; Feita = $false }
    Save-Tarefas ($lista + $nova)
    "Tarefa $($nova.Id) adicionada: $Titulo"
}

Resumo

  • O estado do programa fica num arquivo JSON: ler, mudar e gravar.
  • Funções pequenas, cada uma com um verbo aprovado.
  • @() e -InputObject @(...) evitam surpresas com zero ou um item.
  • O projeto vira módulo e entra no perfil para usar em qualquer pasta.
