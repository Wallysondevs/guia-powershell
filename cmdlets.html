Cmdlets: Verbo-Substantivo

Na aula anterior você digitou Get-Date e o PowerShell entendeu. Não foi sorte: quase todo comando do PowerShell segue a mesma regra de nome, Verbo-Substantivo. Nesta aula você vai aprender a ler esse nome, conhecer os verbos que mais aparecem e descobrir a “família” de um substantivo. No fim, a gente erra de propósito, traduzindo o comando para o português, para ver a mensagem real.

Você vai aprender
  • O que é um cmdlet (lê-se “comand-let”) e a regra Verbo-Substantivo.
  • O Get-Verb, que lista os verbos oficiais, e quantos existem no PowerShell 7.
  • Os quatro verbos que você mais vai usar: Get, Set, New e Remove.
  • O Get-Command, para achar os cmdlets de um verbo ou de um substantivo.
  • A ficha de um cmdlet: nome, tipo, módulo e versão.
  • O erro real de quem inventa um nome em português, como Pegar-Data.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta pessoal da usuária fictícia ana. Quando o Windows PowerShell 5.1 responde diferente, a aula avisa.

A ideia: uma caixa de ferramentas com etiqueta

Pense numa caixa de ferramentas em que cada ferramenta tem uma etiqueta de duas partes: o que ela faz e em quê ela faz. Não existe uma ferramenta genérica chamada “data” ou “arquivo”. Existe “obter a data”, “criar um item”, “apagar um item”.

No PowerShell é igual. O nome do comando — o cmdlet, um “comandinho” pronto — é sempre Verbo-Substantivo, colados por um hífen, sem espaço: Get-Date, New-Item, Remove-Item.

Na caixa de ferramentasNo PowerShell
O que a ferramenta fazO verbo: Get, New, Set, Remove…
Em quê ela fazO substantivo: Date, Item, Process…
A etiqueta completaO cmdlet: Get-Date, New-Item
O gaveteiro das etiquetasO Get-Verb e o Get-Command

Você já usou um: Get-Date. Vale reler as duas metades.

Get
O verbo: “obter”, “pegar”, “mostrar”. Cmdlets com Get em geral só leem: não apagam nem mudam nada. São os mais seguros para praticar.
-
O hífen junta as duas partes. Sem ele, ou com um espaço no meio (Get Date, GetDate), o PowerShell não reconhece o nome.
Date
O substantivo: “data”. Juntos: “obter a data”.
Cmdlet se fala “comand-let”. É o nome que a Microsoft deu aos comandos nativos do PowerShell. Existem outros tipos de comando (funções, apelidos, programas de fora); a aula Get-Command: Achando Comandos aprofunda isso. Por enquanto, pense: cmdlet = comando nativo com nome Verbo-Substantivo.

1. Quais verbos existem? Get-Verb

O próprio PowerShell lista os verbos oficiais. O comando abaixo pede os verbos e, na mesma linha, pede para mostrar só os 10 primeiros. A barra vertical | é o pipeline (“esteira”): a saída de um comando entra no seguinte. Você vai estudá-lo com calma mais adiante; por enquanto leia assim: “pegue os verbos e mostre só os 10 primeiros”.

PS C:\Users\ana> Get-Verb | Select-Object -First 10

Verb   AliasPrefix Group  Description
----   ----------- -----  -----------
Add    a           Common Adds a resource to a container, or attaches an item to another item
Clear  cl          Common Removes all the resources from a container but does not delete the container
Close  cs          Common Changes the state of a resource to make it inaccessible, unavailable, or unusable
Copy   cp          Common Copies a resource to another name or to another container
Enter  et          Common Specifies an action that allows the user to move into a resource
Exit   ex          Common Sets the current environment or context to the most recently used context
Find   fd          Common Looks for an object in a container that is unknown, implied, optional, or specified
Format f           Common Arranges objects in a specified form or layout
Get    g           Common Specifies an action that retrieves a resource
Hide   h           Common Makes a resource undetectable
Get-Verb
O cmdlet que lista os verbos oficiais. Ele também segue a regra: verbo Get + substantivo Verb.
| Select-Object -First 10
Depois da esteira, “quero só os 10 primeiros”. Sem isso, a lista inteira desceria a tela.
Verb
O verbo em si: Add, Get, Hide…
AliasPrefix
Uma abreviação oficial curta do verbo (o g de Get, o a de Add). Ela aparece em alguns apelidos; a aula Apelidos explica isso.
Group
A família do verbo. Estes 10 primeiros são do grupo Common (“comuns”).
Description
A descrição oficial, em inglês, mesmo no Windows em português. É o texto da Microsoft; não é erro de tradução da sua máquina.

Quantos verbos oficiais são, no total? Peça a contagem:

PS C:\Users\ana> (Get-Verb).Count
100

Os parênteses pedem: “primeiro rode o Get-Verb, depois conte o resultado”. No PowerShell 7.7 desta máquina, o número é 100.

No Windows PowerShell 5.1 a lista é um pouco menor: (Get-Verb).Count deu 98. E a tabela padrão do Get-Verb mostra só as colunas Verb e Group — sem AliasPrefix e sem a descrição.

Experimente: troque o comando para mostrar só o verbo Get, com Get-Verb -Verb Get, e clique em Rodar.

Get-Verb | Select-Object -First 10

Get-Verb -Verb Get

2. Os quatro verbos que você mais vai usar

De cem verbos, quatro resolvem a maior parte do dia a dia. Dá para pedi-los de uma vez só:

PS C:\Users\ana> Get-Verb -Verb Get, Set, New, Remove | Format-Table Verb, Group, Description

Verb   Group  Description
----   -----  -----------
Get    Common Specifies an action that retrieves a resource
New    Common Creates a resource
Remove Common Deletes a resource from a container
Set    Common Replaces data on an existing resource or creates a resource that contains some data
VerboEm portuguêsO que faz, na prática
GetObter, pegar, listarMostra algo que já existe, sem mudar. Comece sempre por aqui.
NewCriarCria algo novo: um arquivo, uma pasta, uma variável.
SetDefinir, alterarMuda algo que já existe (ou cria com algum valor).
RemoveRemover, apagarTira algo de um lugar. Use com calma.

Uma dica de ouro: enquanto estiver aprendendo, fique nos Get-*. Eles só leem. Os Remove-* e muitos Set-* mudam o computador — neste guia, quando a gente precisar deles, a demonstração acontece numa pasta de teste e é desfeita no fim.

No Windows PowerShell 5.1 o mesmo comando roda, mas a coluna Description vem vazia: o Get-Verb do 5.1 não traz esse texto.

3. Quantos cmdlets começam com Get?

Se o verbo é a ação, dá para perguntar ao PowerShell: “quantos comandos seus usam o verbo Get?”. Quem responde é o Get-Command (aula completa logo adiante). O Measure-Object conta o que chegou pela esteira.

PS C:\Users\ana> Get-Command -Verb Get | Measure-Object

Count             : 432
Average           : 
Sum               : 
Maximum           : 
Minimum           : 
StandardDeviation : 
Property          :

O que importa nesta aula é o Count: 432 cmdlets (e outros comandos) com o verbo Get, neste computador, no PowerShell 7.7. Os outros campos (média, soma, máximo…) vêm vazios porque a gente não pediu para medir uma propriedade — só quis a quantidade.

Esse número não é fixo: ele depende da versão do PowerShell e do que está instalado. No Windows PowerShell 5.1, na mesma máquina, a conta deu 437. Não tente decorar o número; o que vale é o jeito de perguntar.

4. A família de um substantivo: Item

Agora o outro lado da etiqueta. Se o substantivo é o “em quê”, que ferramentas existem para mexer com um Item (um arquivo, uma pasta, uma entrada)? Peça os comandos cujo substantivo é Item:

PS C:\Users\ana> Get-Command -Noun Item | Format-Table Name, CommandType

Name        CommandType
----        -----------
Clear-Item       Cmdlet
Copy-Item        Cmdlet
Get-Item         Cmdlet
Invoke-Item      Cmdlet
Move-Item        Cmdlet
New-Item         Cmdlet
Remove-Item      Cmdlet
Rename-Item      Cmdlet
Set-Item         Cmdlet

Olha que organização: é uma família inteira. Get-Item obtém, New-Item cria, Copy-Item copia, Move-Item move, Rename-Item renomeia, Remove-Item apaga, Set-Item altera, Clear-Item esvazia, Invoke-Item “abre” o item (como um clique duplo). Você não precisa decorar a lista: quando esquecer, pergunta de novo com Get-Command -Noun Item.

A coluna CommandType diz o tipo: aqui todos são Cmdlet. Isso vai importar na aula Get-Command: Achando Comandos.

Missão: liste os comandos cujo substantivo é Item.

Get-Command -Verb Get

Get-Command -Noun Item

5. A ficha de um cmdlet

Também dá para inspecionar um comando pelo nome completo. Abaixo, a gente não lista os processos do computador: só pergunta ao Get-Command o que ele sabe sobre o cmdlet Get-Process. O Format-List mostra cada campo numa linha.

PS C:\Users\ana> Get-Command Get-Process | Format-List Name, CommandType, Source, Version

Name        : Get-Process
CommandType : Cmdlet
Source      : Microsoft.PowerShell.Management
Version     : 7.0.0.0
Name
O nome do cmdlet: Get-Process.
CommandType
Cmdlet: é um comando nativo do PowerShell, não um apelido nem um programa de fora.
Source
O módulo de onde ele vem, aqui Microsoft.PowerShell.Management. Módulo = uma caixa de cmdlets sobre o mesmo assunto.
Version
A versão desse módulo: 7.0.0.0. Não confunda com a versão do PowerShell (nesta máquina, 7.7): o módulo pode ter um número próprio.
No Windows PowerShell 5.1 a ficha é a mesma, mas a versão do módulo aparece como 3.1.0.0.

Formas diferentes de descobrir um nome

Quando você não lembra o cmdlet certo, estas três perguntas costumam bastar:

Get-Verb
Get-Command -Verb Get
Get-Command -Noun Item
Você perguntaQuando usar
Get-VerbPara rever a lista de verbos oficiais (o que o comando faz).
Get-Command -Verb GetPara listar os comandos de um verbo. Troque Get por New, Set…
Get-Command -Noun ItemPara ver a família de um substantivo (o “em quê”).

Na dúvida entre um verbo e um substantivo, comece pelo substantivo: a família Item cabe numa olhada; a lista do verbo Get tem centenas de nomes.

Quando dá errado

Traduzir o nome para o português

Uma armadilha clássica de quem está começando: pensar “obter a data” e digitar o nome em português.

PS C:\Users\ana> Pegar-Data
Pegar-Data: O termo "Pegar-Data" não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.
Verifique a ortografia do nome ou, se um caminho foi incluído, verifique se o caminho está correto e tente novamente.

A mensagem aparece em vermelho, mas é o mesmo tipo de erro da aula Seu Primeiro Comando. Linha por linha:

Pegar-Data:
O nome que você digitou. Ele até parece um cmdlet (tem verbo, hífen e substantivo), mas não é um nome oficial.
O termo "Pegar-Data" não é reconhecido…
O PowerShell procurou um comando, uma função, um script ou um programa com esse nome e não achou.
Verifique a ortografia do nome…
A dica: confira se o nome existe. Aqui o problema não é um typo pequeno: o nome oficial é em inglês, Get-Date.

Como resolver: use o verbo oficial em inglês. Se não lembrar, pergunte com Get-Command -Noun Date ou com o Get-Help da próxima aula. O erro não estragou nada.

No Windows PowerShell 5.1 a mensagem é a mesma ideia, só que mais comprida: ela traz o “No linha:1 caractere:1”, os tils sublinhando o nome e a ficha técnica em inglês (CommandNotFoundException), como você já viu no erro do Get-Dat.
Esquecer o hífen ou inventar o substantivo

GetDate, Get Date ou um substantivo que não existe também caem no “não é reconhecido”. O nome precisa ser o oficial, com o hífen, as duas partes coladas. Na dúvida, não invente: pergunte ao Get-Command.
