Escopo das Variáveis

Uma variável criada dentro de uma função existe só lá dentro. E a função consegue ler as variáveis de fora, mas, ao mudar uma delas, cria uma cópia local. Entender esse "quem enxerga o quê" evita muitos bugs.

Você vai aprender
  • Que a função lê as variáveis de fora.
  • Que mudar uma variável dentro da função não muda a de fora.
  • Que as variáveis da função somem quando ela termina.
  • A usar $script: e $global: quando realmente precisar.
  • Por que devolver o valor é melhor que mexer em variável de fora.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a casa e os quartos

A casa (o escopo de fora) tem uma sala que todos os quartos (as funções) conseguem ver pela porta. Mas, se alguém pendura um quadro novo dentro do quarto, ele fica no quarto. Quando a pessoa sai do quarto e fecha a porta, o que estava lá dentro fica lá.

1. A função enxerga o que está fora

PS> $cidade = "Recife"
PS> function Show-Cidade { "Moro em $cidade" }
PS> Show-Cidade
Moro em Recife

2. Mudar dentro não muda fora

PS> $contador = 10
PS> function Add-Um { $contador = $contador + 1; "dentro: $contador" }
PS> Add-Um
dentro: 11
PS> "fora: $contador"
fora: 10
$contador = $contador + 1
Lê o 10 de fora e cria uma variável nova, local, com 11.
fora: 10
A variável de fora não mudou.

3. O que nasce na função, morre na função

PS> function New-Segredo { $segredo = "abc"; "criei o segredo" }
PS> New-Segredo
criei o segredo
PS> "segredo fora: [$segredo]"
segredo fora: []

Experimente: a função soma, mas o $total de fora não muda. Em vez de mexer na variável de fora, faça a função devolver a soma e guarde: $total = Add-Valor $total 5.

$total = 10
function Add-Valor($atual, $mais) { $total = $atual + $mais }
Add-Valor $total 5
"Total: $total"

$total = 10
function Add-Valor($atual, $mais) { return $atual + $mais }
$total = Add-Valor $total 5
"Total: $total"

4. $script: e $global:

Com um prefixo, você diz em qual escopo a variável mora. $script: é o escopo do arquivo .ps1 (no console, é o mesmo que o global). $global: é a sessão inteira:

PS> $pontos = 0
PS> function Add-Ponto { $script:pontos++ }
PS> Add-Ponto
PS> Add-Ponto
PS> "pontos: $pontos"
pontos: 2

Funciona, mas use pouco: uma função que mexe em variáveis de fora é difícil de entender e de testar. Prefira receber por parâmetro e devolver o resultado.

5. Os escopos ficam em camadas

Uma função chamada por outra enxerga as variáveis da que chamou:

PS> function Externa { $nivel = "da externa"; Interna }
PS> function Interna { "Interna vê: $nivel" }
PS> Externa
Interna vê: da externa

Quando dá errado

O "contador que não conta" 
PS> $visitas = 0
PS> function Registrar { $visitas++ }
PS> Registrar; Registrar; Registrar
PS> "visitas: $visitas"
visitas: 0

Cada $visitas++ dentro da função mexeu numa cópia local. Fora, continua 0. Corrija com $script:visitas++ ou, melhor, devolvendo o valor.

Resumo

  • A função lê as variáveis de fora, mas mudar cria uma cópia local.
  • O que nasce na função some quando ela termina.
  • $script: e $global: escolhem o escopo, mas use pouco.
  • O melhor caminho: receba por parâmetro e devolva o resultado.
