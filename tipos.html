PowerShell Tipos de Dados

Um nome, uma idade, um preço com centavos, uma data de entrega. Para a Ana, são só informações. Para o PowerShell, cada uma é de um tipo diferente, e o tipo decide o que dá para fazer com ela.

Você vai aprender
  • O que é o tipo de um valor: texto, número inteiro, número decimal, verdadeiro/falso, data, lista.
  • A descobrir o tipo com .GetType().
  • Por que o tipo importa nas contas e comparações.
  • O erro real de quem escreve o nome do método errado.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: cada coisa no seu pote

Na cozinha, açúcar vai num pote, feijão em outro, ovos na caixinha. Você não guarda ovo no pote de açúcar, porque cada coisa se usa de um jeito. No PowerShell, todo valor tem um tipo: o texto "Ana" é um tipo, o número 30 é outro. O tipo diz o que dá para fazer com o valor: número soma, texto vira maiúsculo, data tem dia e mês.

1. O tipo de cada valor

Todo valor sabe o próprio tipo. Pergunte com .GetType().Name ("obter tipo", e o nome dele):

PS C:\Users\ana> "Ana".GetType().Name
String
PS C:\Users\ana> (30).GetType().Name
Int32
PS C:\Users\ana> (3.14).GetType().Name
Double
PS C:\Users\ana> $true.GetType().Name
Boolean
PS C:\Users\ana> (Get-Date).GetType().Name
DateTime
PS C:\Users\ana> (1, 2, 3).GetType().Name
Object[]
PS C:\Users\ana> @{ nome = "Ana"; idade = 30 }.GetType().Name
Hashtable
TipoO que guarda
StringTexto ("corda" de letras): "Ana".
Int32Número inteiro: 30.
DoubleNúmero com casas decimais: 3.14.
BooleanVerdadeiro ou falso: $true, $false.
DateTimeData e hora.
Object[]Lista (os [] querem dizer "vários").
HashtableFicha com campos: @{ nome = "Ana" }.

Repare: no código, o decimal usa ponto (3.14), mesmo com o Windows em português. A vírgula separa itens de lista.

2. A variável aceita qualquer tipo

A caixa (variável) não tem tipo fixo: o tipo é do valor que está dentro. Por isso você pode ter numa mesma lista um texto, um número, um decimal, um booleano, um $null e outra lista:

PS C:\Users\ana> $valores = "Ana", 30, 3.14, $true, $null, (1, 2)
PS C:\Users\ana> $valores | ForEach-Object { if ($null -eq $_) { "null" } else { $_.GetType().Name } }
String
Int32
Double
Boolean
null
Object[]

O $null ("nada") não tem tipo, por isso o comando trata ele à parte. Ele tem uma aula só dele: $true, $false e $null. Para forçar um tipo, veja Conversão de Tipos.

Experimente: troque o 30 por 30.5 e veja o tipo mudar de Int32 para Double.

$numero = 30
$numero.GetType().Name

$numero = 30.5
$numero.GetType().Name

3. Por que o tipo importa

O mesmo sinal faz coisas diferentes conforme o tipo. Com números, + soma; com texto, + junta. Você vai ver isso nas aulas Números e Textos. O nome completo do tipo aparece com .FullName:

PS C:\Users\ana> $nome = "Ana"
PS C:\Users\ana> $nome.GetType().FullName
System.String

System.String é o nome "de registro" do tipo texto no .NET, a plataforma em que o PowerShell foi construído.

Quando dá errado

Escreveu o nome do método errado 
PS C:\Users\ana> (30).GetTyp()
InvalidOperation: Method invocation failed because [System.Int32] does not contain a method named 'GetTyp'.
Method invocation failed
"A chamada do método falhou." Método é uma ação que o valor sabe fazer, como GetType().
[System.Int32] does not contain a method named 'GetTyp'
"O tipo Int32 não tem um método chamado GetTyp." Faltou o e. Repare que o erro já conta o tipo do valor.

Como resolver: (30).GetType(). Os parênteses em volta do 30 também são necessários: sem eles, o ponto seria lido como casa decimal.

Exercícios

1. Descubra o tipo

Complete para ver o tipo de $preco:

Que tipo (7).GetType().Name mostra?

3. Qual é o tipo de "30" (com aspas)?

4. Qual destes é um número decimal escrito do jeito certo no código?

Missão final: guarde $true em $ativo e mostre o nome do tipo.

$ativo = "sim"
$ativo.GetType().Name

$ativo = $true
$ativo.GetType().Name

Resumo

  • Todo valor tem um tipo: String, Int32, Double, Boolean, DateTime, Object[], Hashtable.
  • .GetType().Name mostra o tipo.
  • A variável aceita qualquer tipo; o tipo é do valor.
  • No código, decimal usa ponto: 3.14.
