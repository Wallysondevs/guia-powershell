Arrays (Listas)

Um array é uma lista: uma variável só que guarda vários valores em fila. Você já usou listas no foreach; nesta aula você aprende a criar, contar e juntar listas do jeito certo.

Você vai aprender
  • A criar uma lista com vírgulas: $frutas = "maçã", "uva".
  • A criar com @(), inclusive a lista vazia e a lista de um item só.
  • A contar os itens com .Count.
  • A juntar duas listas com +.
  • Que o resultado de um comando com vários itens vira um array sozinho.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a fila de cadeiras

Pense numa fileira de cadeiras numeradas num auditório. Cada cadeira guarda uma pessoa, e a fileira inteira tem um nome ("fileira B"). O array é a fileira; cada valor é uma pessoa sentada numa cadeira.

1. Criando com vírgulas

PS> $frutas = "maçã", "banana", "uva"
PS> $frutas
maçã
banana
uva
PS> $frutas.Count
3
PS> $frutas.GetType().Name
Object[]
"maçã", "banana", "uva"
As vírgulas criam a lista. Cada valor vira um item.
.Count
Quantos itens a lista tem.
Object[]
O tipo de um array comum: [] quer dizer "lista de", e Object quer dizer que cabe qualquer coisa.

2. Criando com @()

O @( ) também cria um array. Ele é o jeito certo de criar uma lista vazia ou de um item só:

PS> $vazia = @()
PS> $vazia.Count
0
PS> $um = @("só eu")
PS> $um.Count
1
PS> $numeros = @(
>>   10
>>   20
>>   30
>> )
PS> $numeros.Count
3
@()
Lista vazia, com zero itens.
@("só eu")
Lista de um item. Sem o @(), seria só um texto, não uma lista.
@( um por linha )
Dentro do @(), cada linha vira um item. Fica bom para listas compridas.

3. Intervalos de números

PS> $dias = 1..7
PS> $dias -join " "
1 2 3 4 5 6 7
PS> $contagem = 5..1
PS> $contagem -join " "

4. Misturando tipos e juntando listas

Um array comum aceita valores de tipos diferentes. E o + junta duas listas numa nova:

PS> $mistura = "Ana", 30, $true
PS> $mistura | ForEach-Object { $_.GetType().Name }
String
Int32
Boolean
PS> $a = 1, 2
PS> $b = 3, 4
PS> $a + $b
1
2
3
4

5. Comandos devolvem arrays

Quando um comando solta vários itens e você guarda numa variável, ela vira um array sozinha:

PS> $pares = 1..10 | Where-Object { $_ % 2 -eq 0 }
PS> $pares.Count
5
PS> $pares.GetType().Name
Object[]

Cuidado: se o comando soltar um item só, a variável recebe o item, não uma lista. Para garantir uma lista, coloque tudo dentro de @( ):

PS> $um = 1..10 | Where-Object { $_ -eq 7 }
PS> $um.GetType().Name
Int32
PS> $lista = @(1..10 | Where-Object { $_ -eq 7 })
PS> $lista.GetType().Name
Object[]

Quando dá errado

Esquecer a vírgula 
PS> $frutas = "maçã" "banana"
ParserError: 
Line |
   1 |  $frutas = "maçã" "banana"
     |                   ~~~~~~~~
     | Unexpected token '"banana"' in expression or statement.

Sem vírgula, o PowerShell não sabe o que fazer com o segundo texto e para na leitura: Unexpected token. Separe os itens com vírgula.

Tipo fixo não aceita outro tipo 
PS> [int[]]$idades = 30, 25
PS> $idades += "trinta"
MetadataError: Cannot convert value "trinta" to type "System.Int32". Error: "The input string 'trinta' was not in a correct format."

Com [int[]] na frente, a lista só aceita números inteiros. O texto "trinta" não dá para converter.

Resumo

  • Array é uma lista: $a = 1, 2, 3.
  • @() cria a lista vazia; @("x") a lista de um item; @( comando ) garante lista.
  • .Count conta os itens; + junta listas.
  • Um array comum aceita tipos misturados; [int[]] aceita só inteiros.
