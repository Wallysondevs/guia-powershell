Expressões Regulares (-match, -replace)

Uma expressão regular (regex) é um molde de texto: "três dígitos, um traço, quatro dígitos". Com ela você encontra CEPs, e-mails e datas no meio de um texto, troca pedaços e divide frases, tudo com uma linha só.

Você vai aprender
  • Os símbolos mais usados: \d, \w, +, *, ?, {n}, ^, $.
  • A testar e capturar com -match e $Matches.
  • A trocar texto com -replace e grupos ($1).
  • A dividir com -split usando um padrão.
  • A procurar em várias linhas com Select-String.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: o molde de biscoito

O molde de estrela corta só estrelas, não importa a massa. Uma regex é um molde para texto: você descreve a forma ("5 dígitos, traço, 3 dígitos") e o PowerShell encontra tudo que tem essa forma.

2. -match: combina?

PS> "CEP 01310-100" -match '\d{5}-\d{3}'
True
PS> "sem número" -match '\d'
False
PS> "Ana" -match 'ana'
True
PS> "Ana" -cmatch 'ana'
False
-match
True se o padrão aparece em algum lugar do texto. Não diferencia maiúsculas.
-cmatch
Versão que diferencia maiúsculas de minúsculas.
'\d{5}-\d{3}'
Use aspas simples: assim o $ e a crase não são interpretados pelo PowerShell.

3. $Matches: o que foi encontrado

Depois de um -match que deu True, a variável $Matches guarda o pedaço encontrado e os grupos:

PS> if ("Pedido 4821 entregue em 15/03/2026" -match '(\d{2})/(\d{2})/(\d{4})') {
>>   "Data: $($Matches[0])"
>>   "Dia: $($Matches[1]), mês: $($Matches[2]), ano: $($Matches[3])"
>> }
Data: 15/03/2026
Dia: 15, mês: 03, ano: 2026

Com grupos nomeados fica mais fácil de ler:

PS> if ("ana.souza@exemplo.com.br" -match '^(?<usuario>[\w.]+)@(?<dominio>.+)$') {
>>   $Matches.usuario
>>   $Matches.dominio
>> }
ana.souza
exemplo.com.br

Experimente: use -match com um grupo para capturar os 5 primeiros dígitos do CEP e mostre $Matches[1].

$texto = "Rua X, 100, CEP 01310-100"

$texto = "Rua X, 100, CEP 01310-100"
if ($texto -match '(\d{5})-\d{3}') { $Matches[1] }

4. -replace: trocando pelo padrão

PS> "Telefone: (11) 98765-4321" -replace '\D', ''
11987654321
PS> "2026-12-25" -replace '(\d{4})-(\d{2})-(\d{2})', '$3/$2/$1'
25/12/2026
PS> "muitos     espaços   aqui" -replace '\s+', ' '
muitos espaços aqui
'\D'
\D maiúsculo é o contrário de \d: tudo que não é dígito. Trocar por '' apaga.
'$3/$2/$1'
Na troca, $1, $2, $3 são os grupos encontrados. Use aspas simples, senão o PowerShell acha que $1 é uma variável.

5. -split por padrão

PS> "maçã, banana;uva  pera" -split '[,;\s]+'
maçã
banana
uva
pera

6. Procurando em várias linhas: Select-String

PS> $log = "10:01 INFO início", "10:02 ERRO disco cheio", "10:05 INFO fim", "10:07 ERRO sem rede"
PS> $log | Select-String 'ERRO'

10:02 ERRO disco cheio
10:07 ERRO sem rede
PS> ($log | Select-String 'ERRO (.+)').Matches | ForEach-Object { $_.Groups[1].Value }
disco cheio
sem rede

Com arquivos, o Select-String também recebe -Path e mostra o nome do arquivo e o número da linha de cada resultado.

Quando dá errado

O ponto que combina com tudo

"arquivo.txt" -match 'arquivo.txt' é True, mas "arquivoXtxt" também! O . quer dizer "qualquer caractere". Para um ponto de verdade, escreva \.. Se o texto vem de uma variável, proteja com [regex]::Escape($texto).

$Matches com valor antigo

O $Matches só é atualizado quando o -match dá True. Se der False, ele continua com o resultado anterior. Por isso, use $Matches sempre dentro de um if (... -match ...).

Aspas duplas no -replace

-replace '(\d+)', "[$1]" com aspas duplas troca por []: o PowerShell substituiu $1 (uma variável vazia) antes da regex. Use aspas simples: '[$1]'.

Resumo

  • Regex é um molde: \d dígito, \w letra, + um ou mais, {n} repetição.
  • -match testa e preenche $Matches; use grupos ( ) para capturar.
  • -replace troca pelo padrão; $1, $2 são os grupos (aspas simples!).
  • -split divide por padrão; Select-String filtra linhas.
