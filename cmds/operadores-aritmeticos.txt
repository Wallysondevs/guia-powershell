# operadores-aritmeticos — comandos para colher no Windows (só leitura/demonstração)
# Formato: "## rótulo" = nome do bloco na aula; "# shell: pwsh|powershell" vale até o próximo "# shell:".
# Linhas com "#ERRO" são erros de propósito (precisamos da mensagem real). Anonimizar antes de usar.
# shell: pwsh
## os operadores
5 + 2
5 - 2
5 * 2
5 / 2
5 % 2
## parênteses mudam o resultado
2 + 3 * 4
(2 + 3) * 4
## lista na conta
1, 2, 3 | ForEach-Object { $_ * 10 }
(1, 2, 3).Count
## com [math]
[math]::Abs(-8)
[math]::Ceiling(3.1)
[math]::Floor(3.9)
[math]::Max(3, 9)
## erro
5 / 0   #ERRO
"Ana" / 2   #ERRO
