# get-help — comandos para colher no Windows (só leitura/demonstração)
# ATENÇÃO 20/11: no Windows só existe o 5.1 (sem pwsh). Blocos que comparam com o 7 ficam ilustrativos ou vêm de outra fonte.
# Formato: "## rótulo" = nome do bloco na aula; "# shell: pwsh|powershell" vale até o próximo "# shell:".
# Linhas com "#ERRO" são erros de propósito (precisamos da mensagem real). Anonimizar antes de usar.
# shell: powershell
## ajuda (sem Update-Help: não mudar o sistema)
Get-Help Get-Date
Get-Help Get-Date -Examples
Get-Help Get-Date -Parameter Format
Get-Help *location*
Get-Help about_* | Select-Object -First 8
Get-Date -?
## help vs Get-Help
Get-Command help | Select-Object Name, CommandType
