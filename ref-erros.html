Mensagens de Erro Comuns

Consulte esta página quando aparecer um erro em vermelho. As mensagens abaixo são do PowerShell 7 num Windows em português: algumas aparecem traduzidas e outras em inglês, porque vêm de partes do .NET que não são traduzidas. Onde está ..., a mensagem mostra o nome, o valor ou o caminho do seu caso. Se a sua aparecer no outro idioma, o sentido é o mesmo. Para aprender a ler qualquer erro, veja Lendo uma Mensagem de Erro.

Você vai aprender
  • O que cada mensagem comum quer dizer.
  • A causa mais provável de cada uma.
  • Como resolver.

Comandos e parâmetros

MensagemCausa provávelSolução
O termo "..." não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.Nome digitado errado, módulo não carregado, ou script da pasta atual sem .\.Confira a grafia com Get-Command *parte*; para scripts, use .\script.ps1.
Não foi possível encontrar um parâmetro correspondente ao nome de parâmetro '...'.O parâmetro não existe nesse comando (às vezes é de outro cmdlet).Get-Help comando -Parameter * lista os parâmetros.
O parâmetro não pode ser processado porque o nome do parâmetro '...' é ambíguo. As possíveis correspondências incluem: ...Abreviou demais o parâmetro (-P pode ser -Path ou -ProgressAction).Escreva mais letras ou o nome completo.
Não foi possível encontrar um parâmetro posicional que aceite o argumento '...'.Sobrou um valor solto, muitas vezes um texto com espaço sem aspas.Coloque aspas: cd "Meus Documentos".
Não é possível associar o parâmetro '...'. Cannot convert value "..." to type "..."O valor não serve para o tipo do parâmetro (texto onde precisava de número, cor que não existe).Confira o tipo em Get-Help comando -Parameter Nome.

Arquivos e caminhos

MensagemCausa provávelSolução
Não é possível localizar o caminho '...' porque ele não existe.Arquivo ou pasta não existe, ou você está em outra pasta.Get-Location para ver onde está; Test-Path antes de usar.
Could not find a part of the path '...'.Uma das pastas do caminho não existe (ao gravar um arquivo).Crie a pasta antes: New-Item -ItemType Directory.
The file '...' already exists.New-Item de um arquivo que já existe.Use -Force para substituir, ou outro nome.
Não é possível criar um arquivo já existente.Rename-Item/Move-Item para um nome que já existe.Escolha outro nome ou apague o antigo antes.
Cannot find drive. A drive with the name '...' does not exist.Letra de unidade que não existe (Z:).Get-PSDrive lista as unidades.

Valores, tipos e objetos

MensagemCausa provávelSolução
Cannot convert value "..." to type "System.Int32". Error: "The input string '...' was not in a correct format."Converter texto que não é número ([int]"abc").Confira o valor; use -as [int] para testar sem erro.
Cannot convert value "..." to type "System.DateTime".Texto que não é uma data reconhecida.Use o formato aaaa-mm-dd.
Method invocation failed because [...] does not contain a method named '...'.Método digitado errado ou que não existe naquele tipo (ou o valor é uma lista, não um item).$valor | Get-Member -MemberType Method.
You cannot call a method on a null-valued expression.A variável está vazia ($null) e você chamou um método nela.Confira de onde vem o valor; teste com if ($x).
Attempted to divide by zero.Divisão por zero.Teste o divisor antes de dividir.
Index was outside the bounds of the array.Posição que não existe (com o modo estrito ligado; sem ele, vem $null).Confira .Count; o último é [-1].
The variable '$...' cannot be retrieved because it has not been set.Variável nunca criada (com o modo estrito).Crie a variável antes ou corrija o nome.
Error formatting a string: Format specifier was invalid.Formato inválido no -f (por exemplo {0:Q}).Veja os formatos em Formatos do -f.

Sintaxe

MensagemCausa provávelSolução
Missing closing '}' in statement block or type definition.Abriu { e não fechou.Conte as chaves; o editor VS Code destaca o par.
Missing '(' after 'if' in if statement.if $x -gt 1 sem parênteses.if ($x -gt 1) { }.
Missing statement block after if ( condition ).Faltou o { } depois da condição.if (...) { comandos }.
Unexpected token '...' in expression or statement.Operador digitado errado (-eg), vírgula ou aspas sobrando.Olhe a posição marcada com ~~~.
The string is missing the terminator: ".Aspas abertas e não fechadas.Feche as aspas; cuidado com aspas "curvas" copiadas da internet.
Variable reference is not valid. ':' was not followed by a valid variable name character."$nome: texto" — o : grudado na variável."${nome}: texto" ou "$($nome): texto".

Scripts e permissões

MensagemCausa provávelSolução
... cannot be loaded because running scripts is disabled on this system. (ou a mesma frase em português)A política de execução não deixa rodar scripts.Set-ExecutionPolicy -Scope CurrentUser RemoteSigned (veja Política de Execução).
Access to the path '...' is denied. / Acesso negadoSem permissão: pasta do sistema, arquivo aberto em outro programa ou precisa de administrador.Feche o programa que usa o arquivo; abra o PowerShell como administrador só se for mesmo necessário.
O PowerShell está no modo NonInteractive. A funcionalidade de Leitura e Prompt não está disponível.O comando quis perguntar algo (confirmação ou Read-Host) numa sessão sem teclado (agendada, automática).Passe tudo por parâmetro e use -Confirm:$false ou -Force quando for seguro.

Resumo

  • Leia a categoria e a frase inteira: a mensagem quase sempre diz o que corrigir.
  • "Não é reconhecido" = nome errado; "não foi possível encontrar um parâmetro" = parâmetro errado.
  • "Cannot convert value" = tipo errado; "null-valued expression" = variável vazia.
  • Erros de sintaxe mostram a posição com ~~~: olhe ali.
