Enum

Um enum é uma lista fixa de opções com nome: tamanhos P, M e G; status Pendente, Pago e Cancelado. Com ele, o PowerShell recusa valores que não estão na lista e ainda completa os nomes com a tecla Tab.

Você vai aprender
  • A criar um enum com valores e números.
  • A converter texto e número em um valor do enum.
  • A usar o enum como tipo de parâmetro.
  • A listar todas as opções.
  • A combinar opções com [Flags()].

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: o cardápio de tamanhos

Na lanchonete, o copo é P, M ou G. Ninguém pede "copo médio-grandinho". O enum é esse cardápio fechado: só vale o que está na lista.

1. Criando um enum

PS> enum Tamanho {
>>     P = 1
>>     M = 2
>>     G = 3
>> }
PS> [Tamanho]::M
M
PS> [int][Tamanho]::G
3
enum Tamanho { }
Cria o tipo [Tamanho].
P = 1
Cada nome tem um número por trás. Sem o = 1, a contagem começa em 0.
[int][Tamanho]
G :: Converte o valor para o número dele.

2. Convertendo

PS> [Tamanho]"G"
G
PS> [Tamanho]2
M
PS> [Tamanho]"m"
M

Texto e número viram o valor do enum, sem diferenciar maiúsculas. Um nome fora da lista dá erro, e é isso que você quer: o erro aparece logo, antes de o dado errado se espalhar.

3. No parâmetro de uma função

PS> function Pedir-Cafe { param([Tamanho]$Copo = "M")
>>     $preco = @{ P = 5; M = 7; G = 9 }[$Copo.ToString()]
>>     "Café ${Copo}: R$ $preco"
>> }
PS> Pedir-Cafe -Copo G
Café G: R$ 9
PS> Pedir-Cafe
Café M: R$ 7

No terminal, depois de -Copo , a tecla Tab mostra P, M e G.

Experimente: chame Pedir-Cafe pedindo o copo grande (G).

enum Tamanho { P = 1; M = 2; G = 3 }
function Pedir-Cafe { param([Tamanho]$Copo = "M")
    $preco = @{ P = 5; M = 7; G = 9 }[$Copo.ToString()]
    "Café ${Copo}: R$ $preco"
}
Pedir-Cafe

4. Listando as opções

PS> [enum]::GetNames([Tamanho])
P
M
G
PS> [enum]::GetValues([Tamanho]) | ForEach-Object { "{0} = {1}" -f $_, [int]$_ }
P = 1
M = 2
G = 3

5. Várias opções ao mesmo tempo: [Flags()]

Com [Flags()], um valor pode juntar várias opções. Use números que são potências de 2 (1, 2, 4, 8...):

PS> [Flags()] enum Dias {
>>     Seg = 1
>>     Ter = 2
>>     Qua = 4
>>     Qui = 8
>>     Sex = 16
>> }
PS> $aulas = [Dias]"Seg, Qua, Sex"
PS> $aulas
Seg, Qua, Sex
PS> $aulas.HasFlag([Dias]::Qua)
True
PS> $aulas.HasFlag([Dias]::Ter)
False
PS> [int]$aulas
21

Quando dá errado

Valor fora da lista

[Tamanho]"GG" dá erro de conversão, e a mensagem lista os nomes válidos. Leia o fim da mensagem: está lá o que você pode usar.

O dois-pontos depois da variável

Em "Café $Copo: ...", o PowerShell entende $Copo: como o começo de um nome com unidade (como $env:) e a função nem é criada: dá um erro de sintaxe dizendo que o : não foi seguido de um nome válido. Use "Café ${Copo}: ..." ou "Café $($Copo): ..." (veja interpolação).
