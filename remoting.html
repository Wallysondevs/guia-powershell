PowerShell Remoto (Enter-PSSession e SSH)

Com o PowerShell Remoting você roda comandos em outros computadores como se estivesse sentado na frente deles: um servidor no escritório, o computador da sala, dezenas de máquinas de uma vez. O PowerShell 7 fala por dois "canais": o WinRM (tradicional do Windows) e o SSH (que funciona também com Linux e macOS).

Você vai aprender
  • A diferença entre WinRM e SSH.
  • A rodar um comando remoto com Invoke-Command.
  • A abrir uma sessão interativa com Enter-PSSession.
  • A reaproveitar uma conexão com New-PSSession.
  • A testar tudo no próprio computador (localhost).

A ideia: o controle remoto

Em vez de ir até a outra sala para ligar a TV, você usa o controle remoto. O remoting é o controle remoto do PowerShell: os comandos rodam lá, e o resultado volta para você como objetos.

1. Os dois canais

CanalComo chamarQuando usar
WinRM-ComputerName PC01Redes Windows de empresa (domínio). Precisa de Enable-PSRemoting no destino.
SSH-HostName usuario@pc01Entre sistemas diferentes, ou quando já existe um servidor OpenSSH.

2. Preparando o destino (WinRM)

No computador que vai receber os comandos, como administrador:

Enable-PSRemoting

Isso liga o serviço WinRM e libera o firewall na rede de domínio ou privada. Em redes "públicas" o Windows não libera por segurança.

3. Conferindo o que já está ligado

Estes comandos só leem e funcionam sem administrador:

PS> Get-Service WinRM | Select-Object Name, Status, StartType

Name   Status StartType
----   ------ ---------
WinRM Stopped    Manual
PS> Get-PSSessionConfiguration -ErrorAction SilentlyContinue | Select-Object Name
PS> $?
True

4. Invoke-Command: um comando, muitos computadores

Invoke-Command -ComputerName PC01, PC02 -ScriptBlock { Get-CimInstance Win32_OperatingSystem | Select-Object Caption }
-ComputerName
Um ou vários computadores. Os comandos rodam em paralelo.
-ScriptBlock
O que rodar lá.
PSComputerName
Coluna acrescentada ao resultado: de qual computador veio cada linha.

Para levar variáveis daqui para lá, use $using: (como nos jobs):

$pasta = "C:\Logs"
Invoke-Command -ComputerName PC01 { Get-ChildItem $using:pasta }

5. Enter-PSSession: sessão interativa

Enter-PSSession -ComputerName PC01
[PC01]: PS C:\Users\ana\Documents> hostname
PC01
[PC01]: PS C:\Users\ana\Documents> Exit-PSSession

O prompt ganha [PC01]: na frente para lembrar que você está no outro computador.

6. Pelo SSH

Com o OpenSSH instalado no destino e o PowerShell 7 configurado como subsistema SSH:

Enter-PSSession -HostName ana@servidor
Invoke-Command -HostName ana@servidor -ScriptBlock { $PSVersionTable.PSVersion }

7. Sessões reaproveitáveis

Cada Invoke-Command -ComputerName abre e fecha uma conexão. Para vários comandos, abra uma sessão e reaproveite:

$s = New-PSSession -ComputerName PC01
Invoke-Command -Session $s { $contador = 1 }
Invoke-Command -Session $s { $contador + 1 }     # 2: a sessão lembra as variáveis
Remove-PSSession $s

Experimente: escreva, numa string, o comando que mostra se o serviço WinRM está rodando (a propriedade Status). O simulador do guia não imita esse comando; depois, rode-o de verdade no seu Windows.

# Escreva o comando numa string. Não chame o cmdlet.
$comando = ''
Write-Output $comando

# Escreva o comando numa string. Não chame o cmdlet.
$comando = '(Get-Service WinRM).Status'
Write-Output $comando

Quando dá errado

"Falha na conexão com o servidor remoto ... WinRM não pode concluir a operação"

O destino não tem o remoting ligado (Enable-PSRemoting), o firewall bloqueia ou o nome está errado. Teste a porta com Test-NetConnection PC01 -Port 5985.

"Acesso negado"

Por padrão, só administradores do computador destino podem conectar.

Fora de um domínio

Entre computadores sem domínio, o WinRM exige configurar TrustedHosts ou usar HTTPS. Nesses casos, o SSH costuma ser mais simples.

Resumo

  • O remoting roda comandos em outros computadores e traz objetos.
  • Invoke-Command para comandos; Enter-PSSession para trabalhar interativamente.
  • WinRM com -ComputerName; SSH com -HostName.
  • New-PSSession reaproveita a conexão; $using: leva variáveis.
