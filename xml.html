XML

XML é um formato de dados mais antigo que o JSON, ainda muito usado em arquivos de configuração, notas fiscais eletrônicas e relatórios de sistemas. O PowerShell transforma um XML num objeto que você percorre com o ponto, como pastas dentro de pastas.

Você vai aprender
  • Como é um documento XML (elementos e atributos).
  • A converter texto em XML com [xml].
  • A navegar com o ponto e ler atributos.
  • A filtrar com XPath usando Select-Xml.
  • A alterar um valor e gerar o XML de novo.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: as caixas dentro de caixas

Uma mudança bem organizada tem caixas etiquetadas: a caixa "Cozinha" tem a caixa "Talheres", que tem os garfos. O XML é assim: cada <etiqueta> abre uma caixa e </etiqueta> fecha. Dentro, vão outras caixas ou um valor.

<loja nome="Padaria Central">
  <produto codigo="1">
    <nome>Pão francês</nome>
    <preco>0.80</preco>
  </produto>
</loja>
ParteExemploO que é
Elemento<nome>Pão francês</nome>Uma caixa com um valor.
Atributocodigo="1"Uma etiqueta dentro da tag de abertura.
Raiz<loja>A caixa que guarda todas as outras. Só existe uma.

1. De texto para XML

PS> $texto = @'
>> <loja nome="Padaria Central">
>>   <produto codigo="1"><nome>Pão francês</nome><preco>0.80</preco></produto>
>>   <produto codigo="2"><nome>Café 500g</nome><preco>18.90</preco></produto>
>>   <produto codigo="3"><nome>Leite</nome><preco>5.20</preco></produto>
>> </loja>
>> '@
PS> $xml = [xml]$texto
PS> $xml.loja.nome
Padaria Central
PS> $xml.loja.produto

codigo nome        preco
------ ----        -----
1      Pão francês 0.80
2      Café 500g   18.90
3      Leite       5.20
[xml]$texto
Converte o texto num documento XML (System.Xml.XmlDocument).
$xml.loja
Entra na caixa loja.
.nome
Em loja, nome é um atributo (nome="Padaria Central"). O ponto lê atributos e elementos do mesmo jeito.
.produto
Como há vários produto, vem uma lista.

2. Navegando e filtrando

PS> $xml.loja.produto[1].nome
Café 500g
PS> $xml.loja.produto | Where-Object { [double]$_.preco -gt 5 } | ForEach-Object nome
Café 500g
Leite
PS> $xml.loja.produto.nome
Pão francês
Café 500g
Leite

Como no CSV, os valores vêm como texto. O XML usa ponto decimal (18.90), então o [double] converte direto.

3. XPath com Select-Xml

XPath é a "regex do XML": um caminho que encontra elementos. O Select-Xml aceita XPath:

PS> Select-Xml -Xml $xml -XPath "//produto[@codigo='2']/nome" | ForEach-Object { $_.Node.InnerText }
Café 500g
PS> $xml.SelectNodes("//preco").Count
3
XPathEncontra
//produtoTodos os produto, em qualquer nível.
/loja/produtoOs produto logo abaixo da raiz loja.
//produto[@codigo='2']O produto com atributo codigo igual a 2.
//produto/nomeOs nome dentro de produto.

4. Alterando e salvando

PS> $xml.loja.produto[0].preco = "0.90"
PS> $novo = $xml.CreateElement("produto")
PS> $novo.SetAttribute("codigo", "4")
PS> $novo.InnerXml = "<nome>Manteiga</nome><preco>12.50</preco>"
PS> $null = $xml.loja.AppendChild($novo)
PS> $xml.loja.produto.Count
4
PS> $xml.OuterXml.Length -gt 0
True

Para gravar num arquivo, use o método Save com um caminho completo, por exemplo $xml.Save("$HOME\loja.xml"). Para ler um arquivo: $xml = [xml](Get-Content loja.xml -Raw).

Quando dá errado

XML mal formado

Se faltar fechar uma tag (<nome>Leite sem </nome>), a conversão [xml] falha com uma mensagem dizendo a linha e a posição do problema. Confira se cada tag aberta foi fechada e se só existe uma raiz.

Maiúsculas no nome

No XML, <Nome> e <nome> são caixas diferentes. $xml.loja.Produto não encontra nada se a tag é produto. Escreva os nomes exatamente como estão no arquivo.

Resumo

  • [xml] transforma texto num documento que você percorre com o ponto.
  • Atributos e elementos são lidos do mesmo jeito: $no.nome.
  • Select-Xml e SelectNodes buscam com XPath (//elemento).
  • Os valores vêm como texto: converta antes de fazer contas.
