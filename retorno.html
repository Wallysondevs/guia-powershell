O que uma Função Devolve

Em muitas linguagens, a função devolve só o que vem depois do return. No PowerShell é diferente: tudo o que a função solta e ninguém guarda vira resultado. Isso surpreende quem vem de outras linguagens.

Você vai aprender
  • Que toda saída "solta" dentro da função vira retorno.
  • Que o return encerra a função (e pode devolver um valor).
  • A evitar lixo no resultado com $null = e Out-Null.
  • Que várias saídas viram uma lista.
  • A diferença entre Write-Host e saída de verdade.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: o que cai na esteira

Imagine a função como uma máquina em cima de uma esteira. Qualquer coisa que cair da máquina vai para a esteira, mesmo que você não quisesse. O return é o botão de desligar a máquina.

1. Sem return, também devolve

PS> function Get-Dobro($n) { $n * 2 }
PS> $r = Get-Dobro 5
PS> $r
10

O $n * 2 não foi guardado em lugar nenhum dentro da função, então ele "caiu na esteira" e virou o resultado.

2. Várias saídas viram lista

PS> function Get-Info { "linha 1"; "linha 2"; 42 }
PS> $x = Get-Info
PS> $x.Count
3
PS> $x[2]
42

3. O return encerra

PS> function Test-Idade($idade) {
>>   if ($idade -lt 0) { return "idade inválida" }
>>   if ($idade -ge 18) { return "maior de idade" }
>>   "menor de idade"
>> }
PS> Test-Idade 20
maior de idade
PS> Test-Idade 10
menor de idade
PS> Test-Idade -3
idade inválida
return "..."
Devolve o valor e sai da função na hora. As linhas de baixo não rodam.
"menor de idade"
Só chega aqui quem não saiu antes.

4. O lixo que vaza

Alguns métodos devolvem valores que você não pediu. Dentro de uma função, eles vão parar no resultado:

PS> function New-Lista {
>>   $l = [System.Collections.ArrayList]::new()
>>   $l.Add("a")
>>   $l.Add("b")
>>   return $l
>> }
PS> $r = New-Lista
PS> $r
0
1
a
b

Os 0 e 1 são as posições que o .Add() devolveu, e vieram misturados com a lista. Corrija jogando fora com $null = ou | Out-Null:

PS> function New-Lista2 {
>>   $l = [System.Collections.ArrayList]::new()
>>   $null = $l.Add("a")
>>   $l.Add("b") | Out-Null
>>   return $l
>> }
PS> New-Lista2
a
b

Experimente: a função devolve um "lixo" além do número. Jogue fora o resultado do .Add() com $null = para a saída ficar só Resultado: 10.

function Get-Soma {
    $log = [System.Collections.ArrayList]::new()
    $log.Add("somando")
    return 4 + 6
}
"Resultado: $(Get-Soma)"

function Get-Soma {
    $log = [System.Collections.ArrayList]::new()
    $null = $log.Add("somando")
    return 4 + 6
}
"Resultado: $(Get-Soma)"

5. Write-Host não é retorno

PS> function Get-Total { Write-Host "calculando..."; 100 }
PS> $t = Get-Total
calculando...
PS> "t vale $t"
t vale 100

O Write-Host vai direto para a tela, sem passar pela esteira. Por isso $t ficou só com 100. Use o Write-Host para mensagens e a saída normal para o resultado (aula Write-Host × Write-Output).

Quando dá errado

Achar que o return é a única saída 
PS> function Get-Nome { "debug: entrei"; return "Ana" }
PS> "Nome: $(Get-Nome)"
Nome: debug: entrei Ana

A linha de debug virou parte do resultado. Troque por Write-Verbose ou Write-Host, ou tire.

Missão final: use return para a função Get-Situacao devolver aprovado quando a nota for 7 ou mais, e reprovado nos outros casos. Teste com Get-Situacao 8.

function Get-Situacao($nota) {
    "reprovado"
}
Get-Situacao 8

function Get-Situacao($nota) {
    if ($nota -ge 7) { return "aprovado" }
    return "reprovado"
}
Get-Situacao 8

Resumo

  • Toda saída não guardada dentro da função vira resultado.
  • Várias saídas viram uma lista.
  • return devolve e sai; o que vem depois não roda.
  • Jogue fora o que não quer com $null = ou | Out-Null.
  • Write-Host vai para a tela e não entra no resultado.
