Apelidos (Aliases)

Apelidos são atalhos para cmdlets: dir é o Get-ChildItem, % é o ForEach-Object. Use à vontade no terminal; em scripts, prefira o nome completo. Veja a aula Apelidos para os detalhes.

Você vai aprender
  • Os apelidos mais comuns e o cmdlet de cada um.
  • Os apelidos que vêm do cmd e do Linux.
  • A descobrir e criar apelidos.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional. Os quadros marcados Saída no Windows (PowerShell 7.7) foram colhidos num Windows 10 em português, com o nome do computador e o da usuária trocados por exemplos (NOTEBOOK e ana).

Descobrindo

PS> (Get-Alias %).Definition
ForEach-Object
PS> (Get-Alias foreach).Definition
ForEach-Object

Para ver todos os apelidos de um cmdlet, use -Definition:

PS> Get-Alias -Definition Get-ChildItem

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           dir -> Get-ChildItem                                          
Alias           gci -> Get-ChildItem                                          
Alias           ls -> Get-ChildItem

No Windows aparecem dir, gci e ls. No PowerShell instalado no Linux ou no macOS, ls (e outros, como cat e rm) não são apelidos: eles chamam os programas do próprio sistema. Cuidado também com Get-Alias ?: o ? é curinga e lista todos os apelidos de uma letra.

Criando os seus

Set-Alias np notepad.exe
Set-Alias -Name gerar -Value New-Relatorio

O apelido some quando você fecha o PowerShell. Para ter sempre, coloque o Set-Alias no seu perfil. Apelidos não aceitam parâmetros fixos; para isso, crie uma função.

Resumo

  • Apelidos são atalhos: ótimos no terminal, ruins em scripts.
  • Get-Alias nome mostra o cmdlet; Get-Alias -Definition Cmdlet mostra os apelidos.
  • No Linux, ls, cat, rm e outros chamam os programas do sistema.
