Measure-Object: Contando e Somando

Quantos itens tem a lista? Quanto dá a soma? Qual a média? O Measure-Object (apelido measure) é a calculadora do pipeline: recebe os objetos e devolve as contas.

Você vai aprender
  • A contar itens com Measure-Object.
  • A somar, tirar a média, o mínimo e o máximo com -Sum, -Average, -Minimum e -Maximum.
  • A medir um campo dos objetos com -Property.
  • A pegar só o número do resultado com .Sum ou .Average.
  • A contar linhas, palavras e caracteres de um texto.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a calculadora do caixa

No fim do dia, o caixa quer saber: quantas vendas, quanto entrou, qual foi a maior e qual a média. Ele não quer a lista de vendas, quer o resumo. O Measure-Object devolve esse resumo.

1. Contando

PS> "maçã", "banana", "uva" | Measure-Object

Count             : 3
Average           : 
Sum               : 
Maximum           : 
Minimum           : 
StandardDeviation : 
Property          :

Sem opções, ele só conta (Count). Os outros campos ficam vazios.

2. Todas as contas de uma vez

PS> $vendas = 120, 45, 300, 80
PS> $vendas | Measure-Object -Sum -Average -Minimum -Maximum

Count             : 4
Average           : 136,25
Sum               : 545
Maximum           : 300
Minimum           : 45
StandardDeviation : 
Property          :
Count
Quantos valores.
Average
A média (soma dividida pela quantidade).
Sum
A soma.
Maximum / Minimum
O maior e o menor.
Property
O campo medido. Vazio quando a lista é de números soltos.

Repare que o resultado é um objeto com campos, e não um texto. Para ficar só com um número, use o ponto:

PS> ($vendas | Measure-Object -Sum).Sum
545
PS> ($vendas | Measure-Object -Average).Average
136,25

Experimente: mostre Soma: 545 usando Measure-Object -Sum e o campo .Sum do resultado.

$vendas = 120, 45, 300, 80
$total = 0
"Soma: $total"

$vendas = 120, 45, 300, 80
$total = ($vendas | Measure-Object -Sum).Sum
"Soma: $total"

3. Medindo um campo dos objetos

PS> $produtos = @(
>>   [pscustomobject]@{ Nome = "Arroz"; Preco = 25.9 }
>>   [pscustomobject]@{ Nome = "Café"; Preco = 18.5 }
>>   [pscustomobject]@{ Nome = "Azeite"; Preco = 42 }
>> )
PS> $produtos | Measure-Object -Property Preco -Sum -Maximum

Count             : 3
Average           : 
Sum               : 86,4
Maximum           : 42
Minimum           : 
StandardDeviation : 
Property          : Preco

Com -Property, a conta é feita só com aquele campo. Num PowerShell em português, os números com casas decimais aparecem com vírgula na tela (86,4).

4. Contando linhas, palavras e letras

Com texto, o Measure-Object conta como o wc do Linux:

PS> $poema = @"
>> Batatinha quando nasce
>> esparrama pelo chão
>> "@
PS> $poema | Measure-Object -Line -Word -Character

Lines Words Characters Property
----- ----- ---------- --------
    2     6         42

Quando dá errado

Somar texto que não é número 
"10", "vinte" | Measure-Object -Sum

O -Sum precisa de números. O "10" é convertido, mas "vinte" não: aparece um erro dizendo que esse valor não é numérico, e a soma fica vazia.

Referência rápida

Você digitaO que faz
Measure-ObjectConta os itens.
-Sum -Average -Minimum -MaximumSoma, média, menor, maior.
-Property PrecoFaz as contas com um campo.
(... | Measure-Object -Sum).SumSó o número da soma.
-Line -Word -CharacterConta linhas, palavras e letras.

Exercícios

1. A média

Complete para tirar a média:

7, 8, 9 | Measure-Object

2. O que devolve (1, 2, 3 | Measure-Object -Sum).Sum?

3. Para medir o campo Preco de uma lista de produtos, você usa:

Missão final: mostre a maior venda no formato Maior: 300, usando Measure-Object -Maximum e o campo .Maximum.

$vendas = 120, 45, 300, 80

$vendas = 120, 45, 300, 80
$maior = ($vendas | Measure-Object -Maximum).Maximum
"Maior: $maior"

Resumo

  • Measure-Object conta; com -Sum, -Average, -Minimum e -Maximum faz as contas.
  • -Property Campo mede um campo dos objetos.
  • O resultado é um objeto: use .Sum, .Average… para ter só o número.
  • Com texto: -Line, -Word, -Character.
