PowerShell Textos de Várias Linhas (Here-Strings)

A Ana precisa mandar o mesmo e-mail de boas-vindas para cada aluna nova, com várias linhas. Em vez de montar o texto pedaço por pedaço, ela cola o bloco inteiro numa here-string.

Você vai aprender
  • A escrever textos de várias linhas com @" "@ e @' '@.
  • A diferença entre a versão com aspas duplas (troca variáveis) e simples (texto puro).
  • A guardar um texto longo numa variável.
  • A regra do fechamento no começo da linha, e o erro real quando ela é quebrada.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português.

A ideia: colar um bloco inteiro

Às vezes você quer um texto grande, com várias linhas: um e-mail, um aviso, um trecho de configuração. Em vez de juntar linha por linha com `n, a here-string ("texto aqui") deixa você colar o bloco inteiro entre uma marca de abertura e uma de fechamento.

1. Com aspas duplas: troca as variáveis

No console, depois da primeira linha, o prompt vira >>: o PowerShell está esperando o resto.

PS C:\Users\ana> $nome = "Ana"
PS C:\Users\ana> $curso = "PowerShell"
PS C:\Users\ana> @"
>> Olá, $nome!
>> Bem-vinda ao curso de $curso.
>> "@
Olá, Ana!
Bem-vinda ao curso de PowerShell.
@"
Abre a here-string. Nada pode vir depois na mesma linha.
as linhas do meio
O texto, do jeito que você quer. Aspas dentro não precisam de cuidado nenhum.
"@
Fecha. Precisa ficar no começo da linha, sem espaço antes.

2. Com aspas simples: texto puro

PS C:\Users\ana> @'
>> Olá, $nome!
>> O preço é $10.
>> '@
Olá, $nome!
O preço é $10.

Igual às aspas simples comuns: nada é trocado. Bom para textos com $ que não é variável.

3. Guardar numa variável

PS C:\Users\ana> $carta = @"
>> Prezada $nome,
>> Seu cadastro foi aceito.
>> "@
PS C:\Users\ana> $carta
Prezada Ana,
Seu cadastro foi aceito.

Num script (.ps1) fica assim, sem os >>:

$nome = "Ana"
$carta = @"
Prezada $nome,
Seu cadastro foi aceito.
"@
$carta

Experimente: a carta mostra $nome em vez do nome. Troque @' e '@ por @" e "@.

$nome = 'Ana'
@'
Bem-vinda, $nome!
Sua matrícula está ativa.
'@

$nome = 'Ana'
@"
Bem-vinda, $nome!
Sua matrícula está ativa.
"@

Formas diferentes de fazer várias linhas

FormaQuando usar
@" … "@Bloco grande com variáveis: cartas, e-mails.
@' … '@Bloco grande sem troca: textos com $ literal.
"linha 1`nlinha 2"Duas ou três linhas curtas; fica difícil de ler se crescer.
Várias linhas com Write-OutputUma por comando; bom quando cada linha é calculada à parte.

Quando dá errado

Espaço antes do fechamento

Este erro foi colhido com Invoke-Expression, que roda um texto como comando (o `n dentro dele faz as quebras de linha). Num script o PowerShell também acusa o erro, mas essa saída não foi colhida.

PS C:\Users\ana> Invoke-Expression "@`" `nOlá`n `"@"
Invoke-Expression: White space is not allowed before the string terminator.

"Não é permitido espaço antes do terminador do texto." O "@ estava com um espaço na frente. Isso acontece muito quando o código está indentado dentro de um if.

Como resolver: encoste o "@ (ou '@) na margem esquerda, mesmo que o resto do código esteja indentado.

O console fica preso em >>

Se o fechamento estiver errado, o console interativo não mostra erro: continua esperando com >>. Digite "@ no começo de uma linha, ou aperte Ctrl+C para desistir.

Resumo

  • @" … "@: várias linhas, com variáveis.
  • @' … '@: várias linhas, texto puro.
  • A abertura termina a linha; o fechamento começa a linha.
  • Espaço antes do fechamento dá erro.
