Projeto: Monitor de Serviços

Em empresas, alguns serviços não podem parar: o spooler de impressão, o banco de dados, o antivírus. Neste projeto você constrói um monitor que confere uma lista de serviços, mostra um painel com cores, guarda o histórico e avisa quando algum está parado.

Você vai aprender
  • A conferir serviços com Get-Service.
  • A montar um painel com objetos e cores.
  • A gravar um histórico em CSV.
  • A avisar quando algo muda.
  • A repetir a verificação em intervalos.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

Só leitura Este monitor apenas lê o estado dos serviços. Reiniciar serviços (Restart-Service) exige administrador e fica como desafio, com cuidado.

O serviço inexistente não aparece, em vez de dar erro.

2. Um resultado por serviço, inclusive os que não existem

PS> function Get-EstadoServico {
>>     param([string[]]$Nome)
>>     foreach ($n in $Nome) {
>>         $s = Get-Service -Name $n -ErrorAction SilentlyContinue
>>         [pscustomobject]@{
>>             Hora    = Get-Date -Format 'HH:mm:ss'
>>             Servico = $n
>>             Estado  = if ($s) { [string]$s.Status } else { 'NaoEncontrado' }
>>         }
>>     }
>> }
PS> Get-EstadoServico -Nome $servicos | Select-Object Servico, Estado

Servico             Estado
-------             ------
Spooler             Running
EventLog            Running
Dnscache            Running
ServicoQueNaoExiste NaoEncontrado

3. O painel colorido

PS> function Show-Painel {
>>     param($Estados)
>>     foreach ($e in $Estados) {
>>         $cor = switch ($e.Estado) { 'Running' { 'Green' } 'Stopped' { 'Red' } default { 'Yellow' } }
>>         Write-Host ("{0,-22} {1}" -f $e.Servico, $e.Estado) -ForegroundColor $cor
>>     }
>> }
PS> Show-Painel (Get-EstadoServico -Nome $servicos)
Spooler                Running
EventLog               Running
Dnscache               Running
ServicoQueNaoExiste    NaoEncontrado
{0,-22}
Ocupa 22 colunas, alinhado à esquerda: as colunas ficam retas.
Write-Host -ForegroundColor
Escreve colorido na tela (só para pessoas lerem; não vai para o pipeline).

4. O histórico

----                -----
Dnscache                2
EventLog                2
ServicoQueNaoExiste     2
Spooler                 2
-NoTypeInformation agora é obsoleto No PowerShell 7.7 esse parâmetro não faz mais nada: o Export-Csv já não grava a linha de tipo (#TYPE ...). Ele só gera o AVISO que aparece na saída, e pode ser tirado do comando. Se o mesmo script também precisar rodar no Windows PowerShell 5.1, mantenha o parâmetro e ignore o aviso: lá ele ainda evita a linha de tipo.

5. Avisando quando algo não está rodando

PS> $problemas = Get-EstadoServico -Nome $servicos | Where-Object Estado -ne 'Running'
PS> if ($problemas) { "ATENÇÃO: " + ($problemas.Servico -join ', ') }
ATENÇÃO: ServicoQueNaoExiste

Uma notificação do Windows também é possível com o módulo BurntToast da galeria (New-BurntToastNotification -Text "Serviço parado").

6. Repetindo de tempos em tempos

while ($true) {
    Clear-Host
    $estados = Get-EstadoServico -Nome $servicos
    Show-Painel $estados
    $estados | Export-Csv historico.csv -Append -NoTypeInformation
    Start-Sleep -Seconds 60
}

Aperte Ctrl+C para parar. Para rodar sem janela aberta, agende o script (sem o while) a cada 5 minutos em Tarefas Agendadas.

Experimente: escreva, numa string, o comando que mostra NaoEncontrado quando o serviço ServicoQueNaoExiste não existir, sem erro na tela. O simulador do guia não imita esse comando; depois, rode-o de verdade no seu Windows.

# Escreva o comando numa string. Não chame o cmdlet.
$comando = ''
Write-Output $comando

# Escreva o comando numa string. Não chame o cmdlet.
$comando = 'if (Get-Service ServicoQueNaoExiste -ErrorAction SilentlyContinue) { "Existe" } else { "NaoEncontrado" }'
Write-Output $comando

Desafios

  • Mostre há quanto tempo cada serviço está parado, lendo o histórico.
  • Como administrador, tente Restart-Service uma vez antes de avisar.
  • Monitore serviços de outro computador com Invoke-Command (PowerShell Remoto).

Resumo

  • Get-Service com -ErrorAction SilentlyContinue lê o estado sem erros.
  • Objetos com Hora, Servico e Estado alimentam o painel e o histórico.
  • Export-Csv -Append guarda o histórico.
  • Agende para monitorar sem janela aberta.
