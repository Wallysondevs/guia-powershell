Parâmetros (param)

O bloco param() é o jeito completo de dizer o que a sua função recebe: o nome, o tipo, o valor padrão e se é obrigatório. É ele que faz sua função se comportar como um cmdlet de verdade.

Você vai aprender
  • A declarar parâmetros com param( ... ).
  • A dar um tipo, como [int] ou [string].
  • A dar um valor padrão.
  • A criar uma chave liga/desliga com [switch].
  • A tornar um parâmetro obrigatório.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional. Os quadros marcados Saída no Windows (PowerShell 7.7) foram colhidos num Windows 10 em português, com o nome do computador e o da usuária trocados por exemplos (NOTEBOOK e ana).

A ideia: o formulário com campos

Um formulário bem feito diz: "Nome (obrigatório)", "Idade (número)", "Cidade (se não preencher, fica Recife)", "[ ] Quero receber novidades". O param() é esse formulário: cada parâmetro é um campo, com as regras dele.

1. O bloco param

PS> function Saudar {
>>   param(
>>     [string]$Nome,
>>     [string]$Saudacao = "Olá"
>>   )
>>   "$Saudacao, $Nome!"
>> }
PS> Saudar -Nome "Ana"
Olá, Ana!
PS> Saudar -Nome "Beto" -Saudacao "Bom dia"
Bom dia, Beto!
PS> Saudar "Caio" "Boa noite"
Boa noite, Caio!
param( ... )
A primeira coisa dentro da função. Cada parâmetro separado por vírgula.
[string]$Nome
Um parâmetro do tipo texto.
$Saudacao = "Olá"
Valor padrão: usado quando ninguém passa esse parâmetro.
Saudar "Caio" "Boa noite"
Por posição: o primeiro valor vai para o primeiro parâmetro, e assim por diante.

2. O tipo converte e confere

PS> function Dobrar { param([int]$Numero) $Numero * 2 }
PS> Dobrar 21
42
PS> Dobrar "21"
42
PS> Dobrar 2.6
6

Com [int], o texto "21" foi convertido em número, e 2.6 foi arredondado para 3 antes da conta (3 × 2 = 6).

3. Liga/desliga: [switch]

Um [switch] não recebe valor: só a presença dele já liga a opção:

PS> function Show-Preco {
>>   param([double]$Valor, [switch]$ComDesconto)
>>   if ($ComDesconto) { $Valor = $Valor * 0.9 }
>>   "R$ {0:N2}" -f $Valor
>> }
PS> Show-Preco 100
R$ 100,00
PS> Show-Preco 100 -ComDesconto
R$ 90,00

Experimente: acrescente o [switch]$Metade e, se ele estiver ligado, divida o valor por 2. A chamada Show-Valor 90 -Metade deve mostrar R$ 45,00.

function Show-Valor {
    param([double]$Valor)
    "R$ {0:N2}" -f $Valor
}
Show-Valor 90 -Metade

function Show-Valor {
    param([double]$Valor, [switch]$Metade)
    if ($Metade) { $Valor = $Valor / 2 }
    "R$ {0:N2}" -f $Valor
}
Show-Valor 90 -Metade

4. Obrigatório

Com [Parameter(Mandatory)], o parâmetro não pode faltar. No console, se você esquecer, o PowerShell pergunta o valor. Num script rodando sem ninguém para responder (-NonInteractive), ele dá erro:

PS> function Get-Cpf { param([Parameter(Mandatory)][string]$Numero) "CPF: $Numero" }
PS> Get-Cpf -Numero "000.000.000-00"
CPF: 000.000.000-00

A aula Funções Avançadas mostra o [Parameter()] com mais calma.

Quando dá errado

Valor que não converte para o tipo 
PS> Dobrar "vinte"
Dobrar: Não é possível processar a transformação do argumento no parâmetro 'Numero'. Cannot convert value "vinte" to type "System.Int32". Error: "The input string 'vinte' was not in a correct format."

O [int] não consegue converter "vinte", e a função nem chega a rodar. O erro diz qual parâmetro falhou (Numero) e o motivo: o texto não está num formato de número.

Nome de parâmetro errado: sem erro, mas errado 
PS> Saudar -Nmoe "Ana"
Olá, !

Numa função simples, um nome de parâmetro desconhecido não dá erro: o -Nmoe "Ana" vai parar na variável automática $args, e o $Nome fica vazio. Por isso saiu Olá, !. Com [CmdletBinding()] (aula Funções Avançadas), o PowerShell passa a recusar nomes errados. E com Tab, ele completa os nomes certos.

    "Bem-vinda, $Nome, de $Cidade!"
}

}

Resumo

  • param( ... ) declara os parâmetros, no começo da função.
  • Tipo ([int], [string]) converte e confere; valor padrão com =.
  • [switch] liga uma opção só por estar presente.
  • [Parameter(Mandatory)] torna obrigatório.
  • Por posição, os valores seguem a ordem do param.
