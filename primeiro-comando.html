Seu Primeiro Comando

A janela do PowerShell está aberta, o cursor está piscando e nada acontece. É normal: o PowerShell está esperando você. Nesta aula você vai digitar os primeiros comandos de verdade: perguntar a data ao computador, pedir que ele escreva uma frase, fazer uma conta e, de propósito, errar um nome para ver como é uma mensagem de erro (e perder o medo dela).

Você vai aprender
  • O que é o prompt PS C:\Users\ana> e o que cada pedaço dele quer dizer.
  • A rodar um comando: digitar e apertar Enter.
  • O Get-Date, que mostra a data e a hora, e o parâmetro -Format, que muda o jeito de mostrar.
  • O Write-Output, que escreve um texto na tela.
  • Que dá para fazer contas direto no terminal, como numa calculadora.
  • O $?, que diz se o último comando deu certo.
  • A ler, linha por linha, a mensagem de erro real de um comando digitado errado.

Todas as saídas desta aula foram colhidas no PowerShell 7.7 de um Windows em português, na pasta pessoal da usuária fictícia ana. No Windows PowerShell 5.1, que já vem no Windows, os comandos são os mesmos; quando a resposta muda, a aula avisa.

A ideia: um balcão de atendimento

Pense no balcão de uma repartição. O atendente fica parado, olhando para você, até você falar o que quer. Você faz o pedido, ele resolve, entrega a resposta e volta a olhar para você, pronto para o próximo pedido.

O PowerShell funciona igual. A linha que termina em > é o atendente esperando: o prompt. Você digita o pedido (o comando), aperta Enter, ele mostra a resposta (a saída) e o prompt aparece de novo.

No balcãoNo PowerShell
O atendente esperandoO prompt PS C:\Users\ana>
O seu pedidoO comando que você digita
"Pode falar"A tecla Enter, que entrega o pedido

PS C:\Users\ana>

No seu computador, no lugar de ana vai aparecer o seu nome de usuário do Windows. Isso é normal e não muda nada nos comandos.

1. Que dia é hoje? Get-Date

Digite exatamente isto e aperte Enter:

PS C:\Users\ana> Get-Date

sexta-feira, 20 de novembro de 2026 17:13:08
Get
O verbo: "pegar", "obter". Todo comando do PowerShell começa com um verbo dizendo o que ele faz.
-
O hífen junta o verbo ao substantivo, sem espaço.
Date
O substantivo: "data". Juntos: "obter a data". Essa regra Verbo-Substantivo tem uma aula só para ela: Cmdlets: Verbo-Substantivo.

O PowerShell respondeu com o dia da semana, a data e a hora, em português, porque o Windows está em português. Repare na linha em branco antes e depois: é o jeito do PowerShell mostrar uma data inteira. Não é erro.

O PowerShell não liga para maiúsculas e minúsculas nos nomes dos comandos: get-date e GET-DATE fazem a mesma coisa. Neste guia escrevemos Get-Date porque é o jeito oficial e o mais fácil de ler.

Experimente: rode o código e confira a data de hoje.

Get-Date

Get-Date

2. Do seu jeito: -Format

E se você só quiser a data, no formato que a gente escreve no Brasil? Muitos comandos aceitam parâmetros: palavras que começam com hífen e mudam o jeito do comando trabalhar.

PS C:\Users\ana> Get-Date -Format "dd/MM/yyyy"
20/11/2026
Get-Date
O mesmo comando de antes.
-Format
O parâmetro: "use este formato". Repare no espaço antes do hífen: é ele que separa o comando do parâmetro.
"dd/MM/yyyy"
O valor do parâmetro, entre aspas: dd = dia com 2 dígitos, MM = mês com 2 dígitos (M maiúsculo; o mm minúsculo é minuto!), yyyy = ano com 4 dígitos. As barras saem como estão.

Agora a resposta veio numa linha só, sem linhas em branco. Os parâmetros têm a aula própria deles: Parâmetros dos Comandos.

3. Escrevendo na tela: Write-Output

PS C:\Users\ana> Write-Output "Olá, mundo!"
Olá, mundo!
Write-Output
Verbo Write ("escrever") + substantivo Output ("saída"): "escreva na saída".
"Olá, mundo!"
O texto. As aspas marcam onde ele começa e termina e não aparecem na resposta. Espaços, vírgulas e acentos saem iguaizinhos.

Por que "Olá, mundo!"? É uma tradição: desde os anos 1970, o primeiro programa de quem aprende uma linguagem nova costuma mostrar essa frase.

Missão: troque "mundo" por "Ana" e rode o código.

Write-Output "Olá, mundo!"

Write-Output "Olá, Ana!"

4. O terminal também é calculadora

Você não precisa de comando nenhum para fazer uma conta: digite a conta e aperte Enter.

PS C:\Users\ana> 2 + 3
5

O PowerShell calculou e mostrou o resultado. Os outros sinais (-, * para vezes, / para dividir) e as pegadinhas das contas estão na aula Operadores Aritméticos.

Cuidado com as aspas: 2 + 3 é uma conta, mas "2 + 3" é um texto, e o PowerShell mostra o texto como está, sem calcular.

5. Deu certo? $?

Depois de qualquer comando, o PowerShell guarda num lugar especial chamado $? se o último comando deu certo. Para ver, digite $? e aperte Enter:

PS C:\Users\ana> $?
True

True é "verdadeiro" em inglês: o comando anterior funcionou. Quando o último comando falha, o $? fica False ("falso"). Isso vai ser muito útil nos scripts; por enquanto, basta saber que ele existe. As variáveis que começam com $ e já vêm prontas são assunto da aula Variáveis Automáticas.

Formas diferentes de mostrar um texto

Você vai ver estas três formas por aí. Todas mostram Olá, mundo!:

Write-Output "Olá, mundo!"
"Olá, mundo!"
echo "Olá, mundo!"
FormaQuando usar
Write-Output "texto"Nos scripts, quando você quer deixar claro que a linha mostra algo. É o jeito deste guia no começo.
"texto" sozinhoAtalho do dia a dia: um texto sozinho numa linha já vai para a saída. Muito usado por quem já tem prática.
echo "texto"Apelido do Write-Output, para quem vem do cmd ou do Linux (aula Apelidos). Funciona, mas evite em scripts.

Existe ainda o Write-Host, que parece igual mas não é: a diferença tem aula própria, Write-Host × Write-Output.

Quando dá errado

Nome do comando digitado errado

Faltou o e no fim de Get-Date:

PS C:\Users\ana> Get-Dat
Get-Dat: O termo "Get-Dat" não é reconhecido como um nome de um cmdlet, função, arquivo de script ou programa executável.
Verifique a ortografia do nome ou, se um caminho foi incluído, verifique se o caminho está correto e tente novamente.

A mensagem aparece em vermelho e assusta, mas é só o PowerShell dizendo "não conheço esse nome". Linha por linha:

Get-Dat:
O nome que você digitou, para você saber de qual comando ele está falando.
O termo "Get-Dat" não é reconhecido…
O que aconteceu: ele procurou um comando chamado Get-Dat e não achou nenhum com esse nome.
Verifique a ortografia do nome…
A dica: confira se você escreveu certo. É quase sempre isso.

Como resolver: confira a grafia (Get-Date) e rode de novo. Não precisa fechar a janela nem "limpar" nada: o erro não estragou coisa nenhuma.

No Windows PowerShell 5.1 a mesma mensagem é mais comprida: ela mostra também onde está o erro e uma "ficha técnica" em inglês. 
PS C:\Users\ana> Get-Dat
Get-Dat : O termo 'Get-Dat' não é reconhecido como nome de cmdlet, função, arquivo de script ou programa operável.
Verifique a grafia do nome ou, se um caminho tiver sido incluído, veja se o caminho está correto e tente novamente.
No linha:1 caractere:1
+ Get-Dat
+ ~~~~~~~
    + CategoryInfo          : ObjectNotFound: (Get-Dat:String) [], CommandNotFoundException
    + FullyQualifiedErrorId : CommandNotFoundException
No linha:1 caractere:1 diz onde está o problema, os tils ~~~~~~~ sublinham o pedaço errado, e CommandNotFoundException ("comando não encontrado") é útil para pesquisar na internet.
Esqueceu o hífen ou pôs um espaço no meio

Get Date ou GetDate também não são o nome do comando: o PowerShell vai dar o mesmo tipo de erro "não é reconhecido". O nome é sempre Verbo-Substantivo, colados pelo hífen.
