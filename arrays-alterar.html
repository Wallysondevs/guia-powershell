Adicionando e Removendo Itens (List)

O array do PowerShell tem tamanho fixo. O += "acrescenta" criando uma lista nova a cada vez. Para listas que crescem e diminuem, existe a List do .NET, com Add, Remove e companhia.

Você vai aprender
  • A acrescentar com += e o que acontece por trás.
  • A filtrar para "remover" de um array.
  • A criar uma List com [System.Collections.Generic.List[string]]::new().
  • A usar Add, Insert, Remove, RemoveAt e Contains.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: a caixa de ovos e a sacola

O array é uma caixa de ovos: tem um número fixo de lugares. Para pôr mais um ovo, você precisa de uma caixa maior e passar todos para ela. A List é uma sacola: você vai pondo e tirando à vontade.

1. O += no array

PS> $compras = "arroz", "feijão"
PS> $compras += "café"
PS> $compras -join ", "
arroz, feijão, café

O += parece acrescentar, mas cria um array novo com os itens antigos mais o novo. Com poucos itens, tudo bem. Com milhares, dentro de um laço, fica lento.

2. "Removendo" de um array: filtre

Arrays não têm "remover". O jeito é criar outro sem o item:

PS> $compras = $compras | Where-Object { $_ -ne "feijão" }
PS> $compras -join ", "
arroz, café

3. A List do .NET

PS> $lista = [System.Collections.Generic.List[string]]::new()
PS> $lista.Add("arroz")
PS> $lista.Add("feijão")
PS> $lista.Add("café")
PS> $lista.Count
3
PS> $lista
arroz
feijão
café
[System.Collections.Generic.List[string]]
O tipo: uma List de textos (string). Para números, List[int].
new() :: Cria uma List nova, vazia.
.Add("arroz")
Acrescenta no fim, sem criar outra lista.

4. Inserir, remover, procurar

PS> $lista.Insert(0, "açúcar")
PS> $lista.Remove("feijão")
True
PS> $lista.RemoveAt(0)
PS> $lista.Contains("café")
True
PS> $lista -join ", "
arroz, café
.Insert(0, "açúcar")
Põe na posição 0 (o começo).
.Remove("feijão")
Tira pelo valor. Devolve True se achou e tirou.
.RemoveAt(0)
Tira pela posição.
.Contains("café")
Tem esse item? True ou False.

Experimente: a List começa vazia. Acrescente pão e leite com .Add() e mostre a lista junta por vírgula.

$lista -join ", "

Quando dá errado

.Add() num array comum 
PS> $fixo = "a", "b"
PS> $fixo.Add("c")
MethodInvocationException: Exception calling "Add" with "1" argument(s): "Collection was of a fixed size."

O array comum tem tamanho fixo (Collection was of a fixed size). Use += ou uma List.

Tipo errado na List 
PS> $numeros = [System.Collections.Generic.List[int]]::new()
PS> $numeros.Add("dez")
MethodException: Cannot convert argument "item", with value: "dez", for "Add" to type "System.Int32": "Cannot convert value "dez" to type "System.Int32". Error: "The input string 'dez' was not in a correct format.""

A List[int] só aceita números inteiros.

Resumo

  • O array tem tamanho fixo: += cria um novo; para tirar, filtre.
  • A List[T] cresce e diminui: Add, Insert, Remove, RemoveAt, Contains.
  • .Add() num array comum dá erro de tamanho fixo.
  • Para montar listas num laço, guarde a saída do laço ou use uma List.
