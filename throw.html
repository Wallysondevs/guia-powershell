throw: Lançando Erros

Até aqui você tratou erros que o PowerShell gerou. Com throw, é você que gera o erro, com a sua mensagem, quando percebe que algo está errado e não faz sentido continuar.

Você vai aprender
  • A lançar um erro com throw "mensagem".
  • Que o throw sempre encerra (para tudo).
  • A validar dados no começo de uma função.
  • A relançar um erro dentro do catch.
  • A diferença entre throw e Write-Error.

As saídas desta aula foram colhidas no PowerShell 7.7 rodando no Linux, com o idioma em português (pt-BR), num console de 80 colunas. Os comandos funcionam do mesmo jeito no PowerShell 7 do Windows; a aula só mostra saídas que não dependem do sistema operacional.

A ideia: o juiz que apita

No futebol, quando a regra é quebrada, o juiz apita e o jogo para na hora. O throw é o apito: a execução para e o erro sobe até alguém tratar (um catch) ou até aparecer na tela.

1. O throw mais simples

PS> throw "O arquivo de configuração está vazio."
Exception: O arquivo de configuração está vazio.
throw
Lança um erro que encerra.
"O arquivo..."
A mensagem que vai aparecer. Escreva pensando em quem vai ler.
Exception:
A categoria de um erro lançado com texto simples.

2. Parando uma função com dado errado

PS> function Definir-Idade { param([int]$Idade)
>>   if ($Idade -lt 0) { throw "Idade não pode ser negativa: $Idade" }
>>   "Idade definida: $Idade"
>> }
PS> Definir-Idade 30
Idade definida: 30

Com um valor ruim, o throw para a função antes da última linha:

PS> try { Definir-Idade -5 } catch { "Aviso: $($_.Exception.Message)" }
Aviso: Idade não pode ser negativa: -5

Experimente: complete a função Definir-Preco para lançar Preço inválido: + o valor quando o preço for menor que zero. A chamada já está num try.

function Definir-Preco { param([int]$Preco)
  "Preço: $Preco"
}
try { Definir-Preco -3 } catch { "Aviso: $($_.Exception.Message)" }

function Definir-Preco { param([int]$Preco)
  if ($Preco -lt 0) { throw "Preço inválido: $Preco" }
  "Preço: $Preco"
}
try { Definir-Preco -3 } catch { "Aviso: $($_.Exception.Message)" }

3. throw para tudo, até o que vem depois

PS> function Etapas {
>>   "etapa 1"
>>   throw "falhou na etapa 2"
>>   "etapa 3"
>> }
PS> try { Etapas } catch { "Parou: $($_.Exception.Message)" }
etapa 1
Parou: falhou na etapa 2

A etapa 3 nunca roda. Isso é bom: não adianta continuar um processo com dado quebrado.

4. Relançando no catch

Às vezes você quer registrar o erro e deixar ele seguir para cima. Um throw sozinho, dentro do catch, relança o mesmo erro:

PS> function Importar {
>>   try { [int]"x" }
>>   catch { "(registrei o erro no log)"; throw }
>> }
PS> try { Importar } catch { "Quem chamou também soube: $($_.Exception.GetType().Name)" }
(registrei o erro no log)
Quem chamou também soube: RuntimeException

5. Lançando um tipo de exceção

Dá para lançar uma exceção de um tipo específico do .NET, e quem chamar pode usar um catch [Tipo]:

PS> try { throw [System.ArgumentException]::new("Nome não pode ficar vazio.") }
>> catch [System.ArgumentException] { "Argumento ruim: $($_.Exception.Message)" }
Argumento ruim: Nome não pode ficar vazio.

6. throw ou Write-Error?

UseQuando
throwO problema impede de continuar. Para a função (e o script) na hora.
Write-ErrorO problema é com um item; dá para seguir com os outros. É um erro que não encerra.

Quando dá errado

Mensagem sem informação

throw "Erro!" não ajuda ninguém. Diga o que estava errado e, se puder, o valor: throw "Idade não pode ser negativa: $Idade".

throw dentro de um laço achando que só pula aquele item

O throw para o laço inteiro. Se a ideia é pular só um item, use continue (veja break e continue) ou Write-Error.

Referência rápida

Você digitaO que faz
throw "mensagem"Lança um erro que encerra.
throw (sozinho, no catch)Relança o erro atual.
throw [System.ArgumentException]::new("msg")Lança um tipo específico.
Write-Error "mensagem"Erro que não encerra.

Missão final: na função Saudar, lance Nome vazio quando $Nome estiver vazio. Depois chame Saudar "" dentro de um try e, no catch, mostre Erro: + a mensagem.

function Saudar { param([string]$Nome)
  "Olá, $Nome!"
}
Saudar ""

function Saudar { param([string]$Nome)
  if (-not $Nome) { throw "Nome vazio" }
  "Olá, $Nome!"
}
try { Saudar "" } catch { "Erro: $($_.Exception.Message)" }

Resumo

  • throw "mensagem" gera um erro que encerra, com o seu texto.
  • Use para parar quando um dado essencial está errado.
  • throw sozinho no catch relança o erro.
  • Para erros por item, que deixam seguir, prefira Write-Error.
