Depurando (Set-PSBreakpoint)

O script roda, mas o resultado sai errado. Onde está o problema? Depurar é investigar o código enquanto ele roda: ver o valor das variáveis, seguir o caminho linha a linha e parar num ponto para olhar com calma.

Você vai aprender
  • A mostrar valores escondidos com Write-Debug e -Debug.
  • A rastrear cada linha com Set-PSDebug -Trace 1.
  • A criar pontos de parada com Set-PSBreakpoint.
  • Os comandos do depurador (s, v, c, q...).
  • A depurar com cliques no VS Code.

As saídas desta aula foram colhidas no PowerShell 7.7 de um Windows 10 em português (pt-BR), numa pasta de testes dentro do TEMP. O nome do computador e o da usuária foram trocados por exemplos (NOTEBOOK e ana), e listas que mostrariam os programas instalados foram reduzidas aos itens do próprio Windows.

A ideia: o detetive

O detetive não adivinha: ele segue pistas. Na depuração, as pistas são os valores das variáveis em cada momento. Em vez de olhar o script inteiro e chutar, você observa onde o valor começa a ficar errado.

1. O script com defeito

Este script deveria calcular a média das notas, mas está dando errado:

PS> New-Item -ItemType Directory depurar-teste -Force | Out-Null
PS> Set-Location depurar-teste
PS> Set-Content media.ps1 @'
>> [CmdletBinding()]
>> param([int[]]$Notas = @(8, 6, 10))
>> $soma = 0
>> foreach ($n in $Notas) {
>>     $soma = $n
>>     Write-Debug "n=$n soma=$soma"
>> }
>> $media = $soma / $Notas.Count
>> "Média: $media"
>> '@
PS> .\media.ps1
Média: 3.33333333333333

A média de 8, 6 e 10 é 8, não 3,33...

2. Write-Debug e -Debug

As mensagens de Write-Debug ficam escondidas até você pedir com -Debug (o script precisa de [CmdletBinding()]):

PS> .\media.ps1 -Debug
DEPURAR: n=8 soma=8
DEPURAR: n=6 soma=6
DEPURAR: n=10 soma=10
Média: 3.33333333333333

A pista aparece: a soma nunca acumula. A linha $soma = $n deveria ser $soma += $n.

4. Pontos de parada (breakpoints)

Um breakpoint faz o script pausar num ponto e abrir o depurador, onde você digita comandos:

PS> Set-PSBreakpoint -Script .\media.ps1 -Line 8 | Select-Object Id, Line

Id Line
-- ----
 1    8
PS> Get-PSBreakpoint | Select-Object Id, Script, Line

Id Script                                                                Line
-- ------                                                                ----
 1 C:\Users\ana\AppData\Local\Temp\guia-ps\depuracao\depurar-teste\media.ps1    8
PS> Get-PSBreakpoint | Remove-PSBreakpoint

Ao rodar .\media.ps1 com o breakpoint ativo, o prompt vira [DBG]: PS> e você pode investigar:

[DBG]: PS> $soma
10
[DBG]: PS> $Notas
8
6
10
[DBG]: PS> c
ComandoNo depurador
$variavelMostra o valor.
s (StepInto)Executa a próxima linha (entra em funções).
v (StepOver)Executa a próxima linha (sem entrar em funções).
o (StepOut)Sai da função atual.
c (Continue)Continua até o próximo breakpoint.
l (List)Mostra o código em volta.

q (Quit)Para o script.

Também dá para parar quando uma variável muda: Set-PSBreakpoint -Script .\media.ps1 -Variable soma -Mode Write.

5. Wait-Debugger e o VS Code

  • Wait-Debugger no meio do código pausa ali, como um breakpoint escrito no script.
  • No VS Code com a extensão PowerShell, clique à esquerda do número da linha para criar um breakpoint e aperte F5: as variáveis aparecem num painel.

Experimente: corrija o cálculo da soma para a média dar Média: 8.

$Notas = 8, 6, 10
$soma = 0
foreach ($n in $Notas) { $soma = $n }
"Média: $($soma / $Notas.Count)"

$Notas = 8, 6, 10
$soma = 0
foreach ($n in $Notas) { $soma += $n }
"Média: $($soma / $Notas.Count)"

Quando dá errado

-Debug não mostra nada

O script ou a função precisa de [CmdletBinding()] para aceitar -Debug. Sem ele, use $DebugPreference = 'Continue'.

O breakpoint não para

O -Script precisa apontar para o mesmo arquivo que você roda, e a linha precisa ter código executável (não pode ser vazia ou só comentário).

Esqueci o Set-PSDebug ligado

Tudo fica cheio de linhas DEPURAR:. Rode Set-PSDebug -Off.

Referência rápida

Você digitaO que faz
Write-Debug "x=$x"Pista que só aparece com -Debug.
Set-PSDebug -Trace 1 / -OffRastreia linha a linha.
Set-PSBreakpoint -Script s.ps1 -Line 8Para na linha 8.
Set-PSBreakpoint -Variable x -Mode WritePara quando $x muda.
Get-PSBreakpoint | Remove-PSBreakpointRemove todos.
Wait-DebuggerBreakpoint escrito no código.

Exercícios

1. Rastreando

Complete para ligar o rastreamento:

Set-PSDebug 1

2. No depurador, qual comando continua até o próximo breakpoint?

3. O que o script precisa para aceitar -Debug?

Missão final: com $DebugPreference = 'Continue', use Write-Debug para mostrar soma=24 depois de somar 8, 6 e 10.

$soma = 0
8, 6, 10 | ForEach-Object { $soma += $_ }

$DebugPreference = 'Continue'
$soma = 0
8, 6, 10 | ForEach-Object { $soma += $_ }
Write-Debug "soma=$soma"

Resumo

  • Write-Debug + -Debug mostram pistas sem poluir a saída normal.
  • Set-PSDebug -Trace 1 mostra cada linha executada.
  • Set-PSBreakpoint pausa o script para você investigar.
  • No VS Code, breakpoints são um clique.
